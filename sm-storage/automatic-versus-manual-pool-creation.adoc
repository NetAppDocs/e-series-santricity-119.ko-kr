= SANtricity System Manager에서 자동 풀 생성과 수동 풀 생성에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
풀을 자동으로 또는 수동으로 생성하여 물리적 스토리지를 그룹화하고 필요에 따라 동적으로 할당할 수 있습니다. 풀이 생성되면 물리적 드라이브를 추가할 수 있습니다.



== 자동 생성

시스템 관리자가 스토리지 어레이에서 할당되지 않은 용량을 감지하면 자동 풀 생성이 시작됩니다. 할당되지 않은 용량이 감지되면 시스템 관리자는 하나 이상의 풀을 생성하거나 기존 풀에 할당되지 않은 용량을 추가하거나 둘 다를 수행하도록 사용자에게 자동으로 안내합니다.

자동 풀 생성은 다음 조건 중 하나가 참일 때 발생합니다.

* 스토리지 어레이에 풀이 존재하지 않으며 새 풀을 생성하기에 충분한 유사한 드라이브가 있습니다.
* 하나 이상의 풀이 있는 스토리지 어레이에 새 드라이브가 추가됩니다.


풀에 있는 각 드라이브는 동일한 드라이브 유형(HDD 또는 SSD)이어야 하며 용량도 비슷해야 합니다. System Manager는 다음 작업을 완료하도록 안내합니다.

* 해당 유형의 드라이브가 충분히 있는 경우 단일 풀을 생성합니다.
* 할당되지 않은 용량이 서로 다른 드라이브 유형으로 구성된 경우 여러 풀을 생성하십시오.
* 스토리지 어레이에 풀이 이미 정의되어 있는 경우 기존 풀에 드라이브를 추가하고 동일한 드라이브 유형의 새 드라이브를 풀에 추가합니다.
* 기존 풀에 동일한 드라이브 유형의 드라이브를 추가하고, 새 드라이브의 드라이브 유형이 서로 다른 경우 다른 드라이브 유형을 사용하여 별도의 풀을 생성하십시오.




== 수동 생성

자동 생성 기능이 최적의 구성을 결정할 수 없는 경우 풀을 수동으로 생성할 수 있습니다. 이러한 상황은 다음과 같은 이유로 발생할 수 있습니다.

* 새 드라이브는 잠재적으로 둘 이상의 풀에 추가될 수 있습니다.
* 새로운 풀 후보 중 하나 이상은 쉘프 손실 방지 또는 드로어 손실 방지 기능을 사용할 수 있습니다.
* 현재 풀 후보 중 하나 이상이 쉘프 손실 보호 또는 드로어 손실 보호 상태를 유지할 수 없습니다.


스토리지 어레이에 여러 애플리케이션이 있고 동일한 드라이브 리소스를 두고 경쟁하는 것을 방지하려면 수동으로 풀을 생성하는 것이 좋습니다. 이 경우 하나 이상의 애플리케이션에 대해 더 작은 풀을 수동으로 생성하는 것을 고려해 볼 수 있습니다. 데이터를 분산해야 하는 여러 볼륨이 있는 대규모 풀에 워크로드를 할당하는 대신 하나 또는 두 개의 볼륨만 할당할 수 있습니다. 특정 애플리케이션의 워크로드 전용으로 별도의 풀을 수동으로 생성하면 스토리지 어레이 작업 속도가 향상되고 경합이 줄어듭니다.
