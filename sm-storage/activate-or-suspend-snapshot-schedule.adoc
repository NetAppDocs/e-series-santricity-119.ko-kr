= SANtricity System Manager에서 스냅샷 스케줄 활성화 및 일시 중지
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 공간을 절약해야 할 때 스냅샷 이미지의 예약된 수집을 일시적으로 일시 중단할 수 있습니다. 이 방법은 스냅샷 일정을 삭제하고 나중에 다시 생성하는 것보다 효율적입니다.

.이 작업 정보
스냅샷 스케줄 상태는 *Activate* 옵션을 사용하여 예약된 스냅샷 작업을 재개할 때까지 일시 중단된 상태로 유지됩니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. 아직 표시되지 않은 경우 * Schedules * 탭을 클릭합니다.
+
일정은 해당 페이지에 나와 있습니다.

. 일시 중지할 활성 스냅샷 일정을 선택한 다음 *Activate / Suspend*를 클릭합니다.
+
State 열 상태가 *Suspended*로 변경되고 스냅샷 스케줄이 모든 스냅샷 이미지 수집을 중지합니다.

. 스냅샷 이미지 수집을 재개하려면 재개할 일시 중단된 스냅샷 스케줄을 선택한 다음 *Activate / Suspend*를 클릭하십시오.
+
상태 열 상태가 *활성*으로 변경됩니다.
