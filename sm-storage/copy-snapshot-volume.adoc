= SANtricity System Manager에서 스냅샷 볼륨을 복사합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨에서 볼륨 복사본 프로세스를 수행할 수 있습니다.

.이 작업 정보
일반 볼륨 복사본 작업에서 수행되는 것처럼 스냅샷 볼륨을 타겟 볼륨으로 복사할 수 있습니다. 그러나 스냅샷 볼륨은 볼륨 복사본 프로세스 중에 온라인 상태를 유지할 수 없습니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *스냅샷 볼륨* 탭을 선택합니다.
+
스냅샷 볼륨 테이블이 나타나고 스토리지 어레이와 연결된 모든 스냅샷 볼륨이 표시됩니다.

. 복사할 스냅샷 볼륨을 선택한 다음 *볼륨 복사본*을 선택합니다.
+
타겟을 선택하라는 메시지가 표시되는 볼륨 복사본 대화 상자가 나타납니다.

. 복사 대상으로 사용할 타겟 볼륨을 선택한 다음 *완료*를 클릭합니다.
