= SANtricity System Manager에서 스냅샷 일관성 그룹 멤버 볼륨에 대한 스냅샷 이미지 롤백을 시작합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
롤백 작업을 수행하여 스냅샷 일관성 그룹 구성원 볼륨의 콘텐츠를 스냅샷 이미지에 저장된 콘텐츠와 일치하도록 변경할 수 있습니다.

롤백 작업은 스냅샷 일관성 그룹과 연결된 스냅샷 이미지의 콘텐츠를 변경하지 않습니다.

.시작하기 전에
* 롤백 작업을 시작하기에 충분한 예약된 용량을 사용할 수 있습니다.
* 선택한 스냅샷 이미지가 최적이며 선택한 볼륨이 최적입니다.
* 선택한 볼륨에는 현재 진행 중인 롤백 작업이 없습니다.


.이 작업 정보
롤백 시작 시퀀스를 사용하면 스토리지 용량을 추가하는 옵션을 제공하면서 스냅샷 일관성 그룹의 스냅샷 이미지에서 롤백을 시작할 수 있습니다. 스냅샷 일관성 그룹에 대해 한 번에 두 개 이상의 롤백 작업을 시작할 수 없습니다.

[NOTE]
====
호스트는 새롭게 롤백된 볼륨에 즉시 액세스할 수 있지만, 롤백이 시작된 후에는 기존 멤버 볼륨에 대한 호스트 읽기-쓰기 액세스가 더 이상 허용되지 않습니다. 복구 목적으로 롤백 전 기본 볼륨을 보존하기 위해 롤백 시작 직전에 멤버 볼륨의 스냅샷 이미지를 생성할 수 있습니다.

====
스냅샷 일관성 그룹의 스냅샷 이미지 롤백을 시작하는 프로세스는 여러 단계를 거치는 절차입니다.



== 1단계: 멤버 선택

롤백할 멤버 볼륨을 선택해야 합니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *스냅샷 이미지* 탭을 선택합니다.
. 스냅샷 일관성 그룹 스냅샷 이미지를 선택한 다음 menu:Rollback[Start]을 선택합니다.
+
롤백 시작 대화 상자가 나타납니다.

. 멤버 볼륨을 하나 또는 여러 개 선택하십시오.
. *다음*을 클릭하고 다음 중 하나를 수행하십시오.
+
** 선택한 멤버 볼륨 중 하나라도 스냅샷 이미지를 저장하는 예약 용량 객체와 둘 이상 연결되어 있는 경우 용량 검토 대화 상자가 나타납니다. <<2단계: 용량 검토>>로 이동하십시오.
** 선택한 멤버 볼륨 중 스냅샷 이미지를 저장하는 예약 용량 객체와 둘 이상 연결된 볼륨이 없는 경우, 우선순위 편집 대화 상자가 나타납니다. <<3단계: 우선순위 편집>>로 이동하십시오.






== 2단계: 용량 검토

스냅샷 그룹 및 예약된 용량 볼륨과 같이 둘 이상의 예약된 용량 객체와 연결된 구성원 볼륨을 선택한 경우 롤백된 볼륨에 대한 예약된 용량을 검토하고 늘릴 수 있습니다.

.단계
. 예약 용량이 매우 낮거나 0인 멤버 볼륨 옆에 있는 *편집* 열의 *용량 증가* 링크를 클릭합니다.
+
예약된 용량 증가 대화 상자가 나타납니다.

. 스피너 상자를 사용하여 용량 비율을 조정한 다음 *증가*를 클릭합니다.
+
선택한 스토리지 객체가 포함된 풀 또는 볼륨 그룹에 여유 용량이 없고 스토리지 어레이에 할당되지 않은 용량이 있는 경우 용량을 추가할 수 있습니다. 새 풀 또는 볼륨 그룹을 생성하고 해당 풀 또는 볼륨 그룹의 새 여유 용량을 사용하여 이 작업을 다시 시도할 수 있습니다.

. *다음*을 클릭하고 <<3단계: 우선순위 편집>>(으)로 이동합니다.
+
우선 순위 편집 대화 상자가 나타납니다.





== 3단계: 우선순위 편집

필요한 경우 롤백 작업의 우선순위를 편집할 수 있습니다.

.이 작업 정보
롤백 우선순위는 시스템 성능을 희생하면서 롤백 작업에 할당되는 시스템 리소스의 양을 결정합니다.

.단계
. 필요에 따라 슬라이더를 사용하여 롤백 우선순위를 조정하십시오.
. 이 작업을 수행할 것인지 확인한 다음 *마침*을 클릭합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 선택한 스냅샷 이미지에 저장된 콘텐츠를 사용하여 스냅샷 일관성 그룹 멤버 볼륨을 복원합니다.
* 롤백된 볼륨을 호스트에서 즉시 사용할 수 있게 됩니다. 롤백 작업이 완료될 때까지 기다릴 필요가 없습니다.


.완료한 후
롤백 작업의 진행 상황을 보려면 menu:Home[View Operations in Progress]를 선택하십시오.

롤백 작업이 성공하지 못하면 작업이 일시 중지됩니다. 일시 중지된 작업을 다시 시작할 수 있으며, 그래도 문제가 해결되지 않으면 Recovery Guru의 절차에 따라 문제를 해결하거나 기술 지원 부서에 문의하십시오.
