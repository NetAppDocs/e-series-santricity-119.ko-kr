= SANtricity System Manager에서 보류 중인 스냅샷 이미지를 취소합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 이미지가 완료되기 전에 보류 중인 스냅샷 이미지를 취소할 수 있습니다. 스냅샷은 비동기적으로 수행되며 스냅샷이 완료될 때까지 스냅샷 상태가 보류 중입니다. 스냅샷 이미지는 동기화 작업이 완료되는 즉시 완료됩니다.

.이 작업 정보
다음과 같은 동시 발생 조건으로 인해 스냅샷 이미지가 보류 중 상태입니다.

* 스냅샷 그룹의 기본 볼륨 또는 이 스냅샷 이미지를 포함하는 일관성 그룹의 하나 이상의 멤버 볼륨은 비동기 미러 그룹의 멤버입니다.
* 볼륨이 현재 비동기 미러링 동기화 작업 중입니다.


.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. *예약된 용량* 탭을 클릭합니다.
. 보류 중인 스냅샷 이미지를 취소할 스냅샷 그룹을 선택한 다음 menu:Uncommon Tasks[Cancel pending snapshot image]를 클릭합니다.
. 보류 중인 스냅샷 이미지를 취소하려면 *예*를 클릭합니다.
