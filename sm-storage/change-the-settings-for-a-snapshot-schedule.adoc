= SANtricity System Manager에서 스냅샷 일정 설정을 변경하세요.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 일정의 경우 자동 수집 시간 또는 수집 빈도를 변경할 수 있습니다.

.이 작업 정보
기존 스냅샷 일정에서 설정을 가져오거나 필요에 따라 설정을 수정할 수 있습니다.

스냅샷 일정은 스냅샷 그룹 또는 스냅샷 일관성 그룹과 연결되어 있으므로 일정 설정 변경으로 인해 예약된 용량이 영향을 받을 수 있습니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *일정* 탭을 클릭합니다.
. 변경하려는 스냅샷 일정을 선택한 다음 *편집*을 클릭합니다.
+
스냅샷 일정 편집 대화 상자가 나타납니다.

. 다음 중 하나를 수행합니다.
+
** *다른 스냅샷 객체에서 이전에 정의된 스냅샷 일정 사용* -- *스냅샷 일정 가져오기*를 클릭하고 가져올 스냅샷 일정이 있는 객체를 선택한 다음 *가져오기*를 클릭합니다.
** *일정 설정 편집* -- 아래 필드 세부 정보를 참조하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
일 / 월
 a| 
다음 옵션 중 하나를 선택하십시오.

*** *일별/주별* -- 동기화 스냅샷을 저장할 특정 날짜를 선택하세요. 매일 일정을 저장하려면 오른쪽 상단의 *모든 날짜 선택* 확인란을 선택할 수도 있습니다.
*** *월별/연간* -- 동기화 스냅샷을 저장할 특정 월을 선택하세요. *일* 필드에 동기화할 날짜를 입력하세요. 유효한 입력값은 *1*부터 *31*까지, 그리고 *마지막*입니다. 여러 날짜는 쉼표 또는 세미콜론으로 구분할 수 있습니다. 포함 날짜에는 하이픈을 사용하세요. 예: 1,3,4,10-15,마지막. 월별 스냅샷 일정을 원하시면 오른쪽 상단의 *모든 월 선택* 확인란을 선택하세요.




 a| 
시작 시간
 a| 
드롭다운 목록에서 일일 스냅샷의 새 시작 시간을 선택하십시오. 30분 단위로 선택할 수 있습니다. 시작 시간은 기본적으로 현재 시간보다 30분 앞선 시간으로 설정되어 있습니다.



 a| 
시간대
 a| 
드롭다운 목록에서 스토리지 어레이의 시간대를 선택하십시오.



 a| 
일일 스냅샷 수

스냅샷 간 시간
 a| 
하루에 생성할 스냅샷 이미지 수를 선택합니다.

복원 지점을 두 개 이상 선택하는 경우 복원 지점 간 시간도 선택하십시오. 여러 복원 지점의 경우 적절한 예약된 용량이 있는지 확인하십시오.



 a| 
시작 날짜

종료일

종료 날짜 없음
 a| 
동기화를 시작할 시작 날짜를 입력합니다. 종료 날짜를 입력하거나 *종료 날짜 없음*을 선택합니다.

|===
====


. *저장*을 클릭합니다.
