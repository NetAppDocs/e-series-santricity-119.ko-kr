= SANtricity System Manager에서 예약된 용량을 줄입니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
용량 감소 옵션을 사용하여 스냅샷 그룹, 스냅샷 볼륨 및 일관성 그룹 멤버 볼륨과 같은 스토리지 객체의 예약 용량을 줄일 수 있습니다. 예약 용량은 증가시킨 용량만큼만 줄일 수 있습니다.

.시작하기 전에
* 스토리지 객체에는 예약된 용량 볼륨이 두 개 이상 포함되어야 합니다.
* 스토리지 객체는 미러링된 쌍 볼륨이 아니어야 합니다.
* 스토리지 객체가 스냅샷 볼륨인 경우 비활성화된 스냅샷 볼륨이어야 합니다.
* 스토리지 객체가 스냅샷 그룹인 경우 연결된 스냅샷 이미지가 포함되어 있으면 안 됩니다.


.이 작업 정보
다음 지침을 검토하십시오.

* 예약된 용량 볼륨은 추가된 순서의 역순으로만 제거할 수 있습니다.
* 읽기 전용 스냅샷 볼륨은 예약 용량이 할당되어 있지 않으므로 예약 용량을 줄일 수 없습니다. 예약 용량은 읽기/쓰기 가능한 스냅샷 볼륨에만 필요합니다.


.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. *예약된 용량* 탭을 클릭합니다.
. 예약된 용량을 줄이려는 스토리지 객체를 선택한 다음 *용량 감소*를 클릭합니다.
+
예약된 용량 감소 대화 상자가 나타납니다.

. 예약된 용량을 줄일 용량을 선택한 다음 * 감소 * 를 클릭합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 스토리지 객체의 용량을 업데이트합니다.
* 스토리지 객체에 대해 새로 업데이트된 예약 용량을 표시합니다.
* 스냅샷 볼륨의 용량을 줄이면 System Manager는 스냅샷 볼륨을 자동으로 사용 안 함 상태로 전환합니다. 사용 안 함 상태는 스냅샷 볼륨이 현재 스냅샷 이미지와 연결되어 있지 않으므로 I/O를 위해 호스트에 할당할 수 없음을 의미합니다.
