= SANtricity System Manager에서 볼륨 설정을 변경합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨의 이름, 호스트 할당, 세그먼트 크기, 수정 우선 순위, 캐싱 등과 같은 설정을 변경할 수 있습니다.

.시작하기 전에
변경하려는 볼륨이 최적 상태입니다.


NOTE: 볼륨 설정 변경이 진행 중일 때 일부 작업을 사용할 수 없습니다

.단계
. 메뉴: Storage[Volumes]를 선택합니다.
. 변경하려는 볼륨을 선택한 다음 *View/Edit Settings*를 선택합니다.
+
볼륨 설정 대화 상자가 나타납니다. 이 대화 상자에는 선택한 볼륨의 구성 설정이 표시됩니다.

. * 기본 * 탭을 선택하여 볼륨 이름과 호스트 할당을 변경합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
이름
 a| 
볼륨 이름을 표시합니다. 현재 이름이 더 이상 의미 있거나 적절하지 않은 경우 볼륨 이름을 변경합니다.



 a| 
용량
 a| 
선택한 볼륨에 대해 보고된 용량과 할당된 용량을 표시합니다.

씩 볼륨의 경우 보고된 용량과 할당된 용량이 동일하지만 씬 볼륨의 경우에는 다릅니다. 씩 볼륨의 경우 물리적으로 할당된 공간은 호스트에 보고되는 공간과 같습니다. 씬 볼륨의 경우 보고된 용량은 호스트에 보고되는 용량이고 할당된 용량은 현재 데이터 쓰기를 위해 할당된 드라이브 공간의 양입니다.



 a| 
풀/볼륨 그룹
 a| 
풀 또는 볼륨 그룹의 이름과 RAID 레벨을 표시합니다. 풀 또는 볼륨 그룹이 보안 기능을 지원하는지, 보안이 활성화되어 있는지 여부를 나타냅니다.



 a| 
호스트
 a| 
볼륨 할당을 표시합니다. I/O 작업을 위해 액세스할 수 있도록 호스트 또는 호스트 클러스터에 볼륨을 할당합니다. 이 할당을 통해 호스트 또는 호스트 클러스터가 스토리지 어레이의 특정 볼륨 또는 여러 볼륨에 액세스할 수 있습니다.

** *할당 대상* -- 선택한 볼륨에 액세스할 수 있는 호스트 또는 호스트 클러스터를 식별합니다.
** *LUN* -- 논리 장치 번호(LUN)는 호스트가 볼륨에 액세스하는 데 사용하는 주소 공간에 할당된 번호입니다. 볼륨은 LUN 형태의 용량으로 호스트에 제공됩니다. 각 호스트는 고유한 LUN 주소 공간을 가지고 있습니다. 따라서 동일한 LUN을 여러 호스트에서 사용하여 서로 다른 볼륨에 액세스할 수 있습니다.
+

NOTE: NVMe 인터페이스의 경우 이 열에는 네임스페이스 ID가 표시됩니다. 네임스페이스는 블록 액세스용으로 포맷된 NVM 스토리지입니다. 이는 스토리지 어레이의 볼륨과 관련된 SCSI의 논리 유닛과 유사합니다. 네임스페이스 ID는 네임스페이스에 대한 NVMe 컨트롤러의 고유 식별자이며 1에서 255 사이의 값으로 설정할 수 있습니다. 이는 SCSI의 논리 유닛 번호(LUN)와 유사합니다.





 a| 
식별자
 a| 
선택한 볼륨의 식별자를 표시합니다.

** *WWID(World-wide identifier)* -- 볼륨의 고유한 16진수 식별자입니다.
** *확장 고유 식별자(EUI)* -- 볼륨에 대한 EUI-64 식별자입니다.
** *하위 시스템 식별자(SSID)* -- 볼륨의 스토리지 어레이 하위 시스템 식별자입니다.


|===
====
. 풀 또는 볼륨 그룹의 볼륨에 대한 추가 구성 설정을 변경하려면 *고급* 탭을 선택하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
애플리케이션 및 워크로드 정보
 a| 
볼륨 생성 시 애플리케이션별 워크로드 또는 기타 워크로드를 생성할 수 있습니다. 해당되는 경우, 선택한 볼륨에 대해 워크로드 이름, 애플리케이션 유형 및 볼륨 유형이 표시됩니다.

원하는 경우 워크로드 이름을 변경할 수 있습니다.



 a| 
서비스 품질 설정
 a| 
*데이터 보증 영구 비활성화* -- 이 설정은 볼륨에 데이터 보증(DA)이 활성화된 경우에만 나타납니다. DA는 데이터가 컨트롤러를 거쳐 드라이브로 전송되는 동안 발생할 수 있는 오류를 검사하고 수정합니다. 이 옵션을 사용하여 선택한 볼륨에서 DA를 영구적으로 비활성화할 수 있습니다. 비활성화된 경우 해당 볼륨에서 DA를 다시 활성화할 수 없습니다.

*읽기 전 중복 검사 활성화* -- 이 설정은 볼륨이 씩 볼륨인 경우에만 나타납니다. 읽기 전 중복 검사는 읽기 작업이 수행될 때마다 볼륨의 데이터 일관성 여부를 확인합니다. 이 기능이 활성화된 볼륨은 컨트롤러 펌웨어에서 데이터가 일관되지 않은 것으로 확인되면 읽기 오류를 반환합니다.



 a| 
컨트롤러 소유권
 a| 
볼륨의 소유 또는 기본 컨트롤러로 지정된 컨트롤러를 정의합니다.

컨트롤러 소유권은 매우 중요하며 신중하게 계획해야 합니다. 전체 I/O 측면에서 컨트롤러는 최대한 균형을 이루어야 합니다.



 a| 
세그먼트 크기 조정
 a| 
볼륨 그룹의 볼륨에만 나타나는 세그먼트 크기 설정을 표시합니다. 성능을 최적화하기 위해 세그먼트 크기를 변경할 수 있습니다.

*허용되는 세그먼트 크기 전환* -- System Manager는 허용되는 세그먼트 크기 전환을 결정합니다. 현재 세그먼트 크기에서 부적절한 전환에 해당하는 세그먼트 크기는 드롭다운 목록에서 사용할 수 없습니다. 허용되는 전환은 일반적으로 현재 세그먼트 크기의 두 배 또는 절반입니다. 예를 들어, 현재 볼륨 세그먼트 크기가 32KiB인 경우 새 볼륨 세그먼트 크기는 16KiB 또는 64KiB가 허용됩니다.

*SSD Cache 지원 볼륨* -- SSD Cache 지원 볼륨의 경우 4KiB 세그먼트 크기를 지정할 수 있습니다. 4KiB 세그먼트 크기는 작은 블록 I/O 작업(예: 16KiB 이하의 I/O 블록 크기)을 처리하는 SSD Cache 지원 볼륨에만 선택하십시오. 큰 블록 순차 작업을 처리하는 SSD Cache 지원 볼륨에 4KiB 세그먼트 크기를 선택하면 성능에 영향을 미칠 수 있습니다.

*세그먼트 크기 변경 소요 시간* -- 볼륨의 세그먼트 크기를 변경하는 데 걸리는 시간은 다음 변수에 따라 달라집니다.

** 호스트의 I/O 로드
** 볼륨의 수정 우선 순위
** 볼륨 그룹의 드라이브 수
** 드라이브 채널 수
** 스토리지 어레이 컨트롤러의 처리 능력 볼륨의 세그먼트 크기를 변경하면 I/O 성능에 영향을 미치지만 데이터는 계속 사용할 수 있습니다.




 a| 
수정 우선 순위
 a| 
볼륨 그룹의 볼륨에만 표시되는 수정 우선 순위 설정을 표시합니다.

수정 우선 순위는 시스템 성능과 관련하여 볼륨 수정 작업에 할당되는 처리 시간을 정의합니다. 볼륨 수정 우선 순위를 높일 수 있지만 시스템 성능에 영향을 줄 수 있습니다.

슬라이더 막대를 이동하여 우선 순위 레벨을 선택합니다.

*수정 우선순위 속도* -- 가장 낮은 우선순위 속도는 시스템 성능에 도움이 되지만 수정 작업에 시간이 더 오래 걸립니다. 가장 높은 우선순위 속도는 수정 작업에 도움이 되지만 시스템 성능이 저하될 수 있습니다.



 a| 
캐싱
 a| 
볼륨의 전반적인 I/O 성능에 영향을 줄 수 있도록 변경할 수 있는 캐싱 설정을 보여줍니다.



 a| 
SSD 캐시
 a| 
읽기 전용 성능을 향상시키는 방법으로 호환되는 볼륨에서 활성화할 수 있는 SSD Cache 설정을 표시합니다. 볼륨은 동일한 Drive Security 및 Data Assurance 기능을 공유하는 경우 호환됩니다.

*SSD Cache 기능은 하나 또는 여러 개의 SSD(Solid State Disk)를 사용하여 읽기 캐시를 구현합니다*. SSD의 빠른 읽기 시간 덕분에 애플리케이션 성능이 향상됩니다. 읽기 캐시가 스토리지 어레이에 있으므로 스토리지 어레이를 사용하는 모든 애플리케이션에서 캐싱이 공유됩니다. 캐시할 볼륨을 선택하기만 하면 캐싱이 자동으로 동적으로 수행됩니다.

|===
====
. *저장*을 클릭합니다.
+
System Manager는 사용자의 선택에 따라 볼륨 설정을 변경합니다.



.완료한 후
메뉴에서 Home[진행 중인 작업 보기]를 선택하여 선택한 볼륨에 대해 현재 실행 중인 변경 작업의 진행 상황을 볼 수 있습니다.
