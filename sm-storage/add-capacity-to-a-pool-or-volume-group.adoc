= SANtricity System Manager에서 풀 또는 볼륨 그룹에 용량 추가
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기존 풀 또는 볼륨 그룹의 여유 용량을 확장하려면 드라이브를 추가할 수 있습니다.

확장을 통해 풀 또는 볼륨 그룹에 추가 여유 용량이 포함됩니다. 이 여유 용량을 사용하여 추가 볼륨을 생성할 수 있습니다. 이 작업 중에도 볼륨의 데이터는 계속 액세스할 수 있습니다.

.시작하기 전에
* 드라이브가 최적 상태여야 합니다.
* 드라이브는 동일한 드라이브 유형(HDD 또는 SSD)이어야 합니다.
* 풀 또는 볼륨 그룹은 최적 상태여야 합니다.
* 볼륨 그룹에 허용되는 최대 볼륨 수는 256개입니다.
* 풀에 허용되는 최대 볼륨 수는 스토리지 시스템 모델에 따라 다릅니다.
+
** 2,048개 볼륨(EF600 및 E5700 시리즈)
** 1,024개 볼륨(EF300)
** 512개 볼륨(E4000 및 E2800 시리즈)


* 풀 또는 볼륨 그룹에 보안 기능을 지원하는 드라이브가 모두 포함되어 있는 경우, 보안 기능을 지원하는 드라이브만 추가하여 기존 보안 지원 드라이브의 암호화 기능을 계속 사용하십시오.
+
보안 기능을 갖춘 드라이브는 Full Disk Encryption(FDE) 드라이브 또는 Federal Information Processing Standard(FIPS) 드라이브일 수 있습니다.



.이 작업 정보
풀의 경우 한 번에 최대 60개의 드라이브를 추가할 수 있습니다. 볼륨 그룹의 경우 한 번에 최대 2개의 드라이브를 추가할 수 있습니다. 최대 드라이브 수보다 더 많은 드라이브를 추가해야 하는 경우 위의 절차를 반복하십시오. (풀에는 스토리지 시스템의 최대 제한보다 많은 드라이브를 포함할 수 없습니다.)

[NOTE]
====
드라이브를 추가하면 보존 용량을 늘려야 할 수 있습니다. 확장 작업 후에는 예약된 용량을 늘리는 것을 고려해야 합니다.

====
[NOTE]
====
데이터 보증(DA) 기능을 지원하지 않는 풀 또는 볼륨 그룹에 용량을 추가할 때 DA 기능을 지원하는 드라이브를 사용하지 마십시오. 해당 풀 또는 볼륨 그룹은 DA 지원 드라이브의 기능을 활용할 수 없습니다. 이러한 경우에는 DA 기능을 지원하지 않는 드라이브를 사용하는 것을 고려하십시오.

====
.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 드라이브를 추가할 풀 또는 볼륨 그룹을 선택한 다음 *용량 추가*를 클릭합니다.
+
용량 추가 대화 상자가 나타납니다. 풀 또는 볼륨 그룹과 호환되는 할당되지 않은 드라이브만 표시됩니다.

. *Select drives to add capacity...*에서 기존 풀 또는 볼륨 그룹에 추가할 하나 이상의 드라이브를 선택합니다.
+
컨트롤러 펌웨어는 할당되지 않은 드라이브를 최적의 옵션부터 맨 위에 정렬합니다. 풀 또는 볼륨 그룹에 추가되는 총 여유 용량은 목록 아래의 *선택된 총 용량*에 표시됩니다.

+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 필드 | 설명 


 a| 
쉘프
 a| 
드라이브의 쉘프 위치를 나타냅니다.



 a| 
베이
 a| 
드라이브의 베이 위치를 나타냅니다.



 a| 
용량(GiB)
 a| 
드라이브 용량을 나타냅니다.

** 가능하면 풀 또는 볼륨 그룹에 있는 현재 드라이브의 용량과 동일한 용량의 드라이브를 선택하십시오.
** 용량이 더 작은 할당되지 않은 드라이브를 추가해야 하는 경우, 현재 풀 또는 볼륨 그룹에 있는 각 드라이브의 사용 가능한 용량이 줄어든다는 점에 유의하십시오. 따라서 풀 또는 볼륨 그룹 전체의 드라이브 용량은 동일합니다.
** 용량이 더 큰 할당되지 않은 드라이브를 추가해야 하는 경우 추가하는 할당되지 않은 드라이브의 사용 가능한 용량이 풀 또는 볼륨 그룹의 드라이브 현재 용량과 일치하도록 줄어든다는 점에 유의하십시오.




 a| 
보안 가능
 a| 
드라이브가 보안 기능을 지원하는지 여부를 나타냅니다.

** 드라이브 보안 기능을 사용하여 풀 또는 볼륨 그룹을 보호하려면 모든 드라이브가 보안 기능을 지원해야 합니다.
** 보안 기능을 지원하는 드라이브와 지원하지 않는 드라이브가 혼합된 풀 또는 볼륨 그룹을 생성할 수 있지만 드라이브 보안 기능은 활성화할 수 없습니다.
** 보안 기능을 지원하는 드라이브로만 구성된 풀 또는 볼륨 그룹은 암호화 기능을 사용하지 않더라도 예비용 또는 확장용으로 보안 기능이 없는 드라이브를 허용할 수 없습니다.
** 보안 기능이 있는 것으로 보고되는 드라이브는 FDE(Full Disk Encryption) 드라이브 또는 FIPS(Federal Information Processing Standard) 드라이브일 수 있습니다.
** FIPS 드라이브는 140-2 또는 140-3 레벨일 수 있으며, 140-3 레벨이 더 높은 보안 레벨입니다. 140-2 레벨과 140-3 레벨의 드라이브를 혼합하여 선택하는 경우, 풀 또는 볼륨 그룹은 더 낮은 보안 레벨(140-2)로 작동합니다.




 a| 
DA 지원
 a| 
드라이브가 DA(Data Assurance) 지원 가능 여부를 나타냅니다.

** DA(Data Assurance) 지원 풀 또는 볼륨 그룹에 용량을 추가하기 위해 DA를 지원하지 않는 드라이브를 사용하는 것은 권장되지 않습니다. 풀 또는 볼륨 그룹에 더 이상 DA 기능이 없으며 풀 또는 볼륨 그룹 내에서 새로 생성된 볼륨에 DA를 활성화하는 옵션이 더 이상 없습니다.
** 데이터 보증(DA) 기능을 지원하는 드라이브를 사용하여 DA 기능을 지원하지 않는 풀 또는 볼륨 그룹에 용량을 추가하는 것은 권장되지 않습니다. DA 기능을 지원하는 드라이브의 기능을 해당 풀 또는 볼륨 그룹이 활용할 수 없기 때문입니다(드라이브 속성이 일치하지 않음). 이러한 경우에는 DA 기능을 지원하지 않는 드라이브를 사용하는 것을 고려하십시오.




 a| 
DULBE 지원
 a| 
드라이브에 할당 해제 또는 미기록 논리 블록 오류(DULBE) 옵션이 있는지 여부를 나타냅니다. DULBE는 NVMe 드라이브의 옵션으로, EF300 또는 EF600 스토리지 어레이에서 리소스 프로비저닝 볼륨을 지원할 수 있도록 합니다.

|===
====
. *추가*를 클릭합니다.
+
풀 또는 볼륨 그룹에 드라이브를 추가하는 경우 선택한 드라이브로 인해 풀 또는 볼륨 그룹이 다음 속성 중 하나 이상을 더 이상 갖지 못하게 되면 확인 대화 상자가 나타납니다.

+
** 쉘프 손실 방지 ^*^
** 드로어 손실 방지 ^*^
** 전체 디스크 암호화 기능
** 데이터 보증 기능
** DULBE 기능





NOTE: ^*^ 현재 셸프 손실 방지 또는 드로어 손실 방지 기능이 있는 풀에 드라이브를 추가할 때 확인 대화 상자가 표시되지 않습니다.

. 계속하려면 *예*를 클릭하고, 그렇지 않으면 *취소*를 클릭합니다.


.결과
할당되지 않은 드라이브를 풀 또는 볼륨 그룹에 추가하면 해당 풀 또는 볼륨 그룹의 각 볼륨에 있는 데이터가 추가된 드라이브를 포함하도록 재분배됩니다.
