= SANtricity System Manager의 스토리지 드라이브 FAQ
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 FAQ는 질문에 대한 빠른 답변을 찾고 있을 때 도움이 될 수 있습니다.



[[what-is-a-hot-spare-drive]]
== 핫 스페어 드라이브란 무엇입니까?

핫 스페어는 RAID 1, RAID 5 또는 RAID 6 볼륨 그룹에서 대기 드라이브 역할을 합니다. 데이터는 저장되어 있지 않지만 기능은 완벽하게 작동하는 드라이브입니다. 볼륨 그룹의 드라이브에 오류가 발생하면 컨트롤러는 오류가 발생한 드라이브의 데이터를 핫 스페어로 자동으로 재구성합니다.

스토리지 어레이에서 드라이브에 장애가 발생하면 물리적인 교체 없이 핫 스페어 드라이브가 자동으로 장애가 발생한 드라이브를 대체합니다. 드라이브에 장애가 발생했을 때 핫 스페어 드라이브를 사용할 수 있는 경우 컨트롤러는 이중화 데이터를 사용하여 장애가 발생한 드라이브의 데이터를 핫 스페어 드라이브로 재구성합니다.

핫 스페어 드라이브는 특정 볼륨 그룹에 전용으로 할당되지 않습니다. 대신, 스토리지 어레이에서 용량이 같거나 더 작은 용량을 가진 장애가 발생한 드라이브에 핫 스페어 드라이브를 사용할 수 있습니다. 핫 스페어 드라이브는 보호 대상 드라이브와 동일한 미디어 유형(HDD 또는 SSD)이어야 합니다.

[NOTE]
====
풀에서는 핫 스페어 드라이브가 지원되지 않습니다. 핫 스페어 드라이브 대신 풀을 구성하는 각 드라이브의 보존 용량을 사용합니다.

====


[[what-is-preservation-capacity]]
== 보존 용량이란 무엇입니까?

보존 용량은 잠재적인 드라이브 장애를 지원하기 위해 풀에 예약된 용량(드라이브 수)입니다.

풀이 생성될 때 시스템은 풀에 포함된 드라이브 수에 따라 기본 보존 용량을 자동으로 예약합니다.

풀은 재구성 중에 보존 용량을 사용하는 반면, 볼륨 그룹은 동일한 목적으로 핫 스페어 드라이브를 사용합니다. 보존 용량 방식은 재구성을 더 빠르게 수행할 수 있기 때문에 핫 스페어 드라이브보다 개선된 방식입니다. 보존 용량은 핫 스페어 드라이브의 경우처럼 하나의 드라이브가 아닌 풀의 여러 드라이브에 분산되므로 하나의 드라이브의 속도나 가용성에 제한을 받지 않습니다.



[[why-would-i-logically-replace-a-drive]]
== 드라이브를 논리적으로 교체하는 이유는 무엇입니까?

드라이브에 오류가 발생하거나 다른 이유로 교체해야 하는 경우, 스토리지 어레이에 할당되지 않은 드라이브가 있으면 오류가 발생한 드라이브를 해당 드라이브로 논리적으로 교체할 수 있습니다. 할당되지 않은 드라이브가 없는 경우에는 물리적으로 드라이브를 교체해야 합니다.

기존 드라이브의 데이터가 교체 드라이브로 복사되거나 재구성됩니다.



[[where-can-i-view-the-status-of-a-drive-undergoing-reconstruction]]
== 복구 중인 드라이브의 상태는 어디에서 확인할 수 있습니까?

진행 중인 작업 대시보드에서 드라이브 재구성 상태를 볼 수 있습니다.

홈 페이지에서 오른쪽 상단의 *View Operations in Progress* 링크를 클릭합니다.

드라이브에 따라 전체 재구성에 상당한 시간이 소요될 수 있습니다. 볼륨 소유권이 변경된 경우 빠른 재구성 대신 전체 재구성이 수행될 수 있습니다.
