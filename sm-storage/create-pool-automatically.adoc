= SANtricity System Manager에서 풀을 자동으로 생성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager가 스토리지 어레이에서 할당되지 않은 드라이브를 감지하면 풀 생성이 자동으로 시작됩니다. 자동 풀 생성을 사용하면 스토리지 어레이의 할당되지 않은 모든 드라이브를 하나의 풀로 쉽게 구성하고 기존 풀에 드라이브를 추가할 수 있습니다.

.시작하기 전에
다음 조건 중 하나가 참이면 풀 자동 구성 대화 상자를 실행할 수 있습니다.

* 유사한 드라이브 유형의 기존 풀에 추가할 수 있는 할당되지 않은 드라이브가 하나 이상 감지되었습니다.
* 새 풀을 생성하는 데 사용할 수 있는 할당되지 않은 드라이브가 11개 이상 감지되었습니다(드라이브 유형이 다르기 때문에 기존 풀에 추가할 수 없는 경우).


.이 작업 정보
다음 사항을 유념하십시오.

* 스토리지 어레이에 드라이브를 추가하면 System Manager가 자동으로 드라이브를 감지하고 드라이브 유형 및 현재 구성을 기반으로 단일 풀 또는 여러 풀을 생성하라는 메시지를 표시합니다.
* 이전에 풀이 정의된 경우 System Manager는 호환되는 드라이브를 기존 풀에 추가할지 여부를 자동으로 묻습니다. 새 드라이브가 기존 풀에 추가되면 System Manager는 새 용량(새로 추가된 드라이브 포함) 전체에 데이터를 자동으로 재분배합니다.
* EF600 또는 EF300 스토리지 어레이를 구성할 때 각 컨트롤러가 처음 12개 슬롯과 마지막 12개 슬롯에 동일한 수의 드라이브에 액세스할 수 있도록 설정해야 합니다. 이 구성을 통해 컨트롤러가 두 드라이브 측 PCIe 버스를 더욱 효과적으로 사용할 수 있습니다.


다음 방법 중 하나를 사용하여 풀 자동 구성 대화 상자를 실행할 수 있습니다.

* 할당되지 않은 용량이 감지되면 홈 페이지의 알림 영역에 풀 자동 구성 권장 사항이 표시됩니다. *풀 자동 구성 보기*를 클릭하여 대화 상자를 엽니다.
* 다음 작업에서 설명하는 것처럼 풀 및 볼륨 그룹 페이지에서 풀 자동 구성 대화 상자를 시작할 수도 있습니다.


.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 메뉴: 더보기[풀 자동 구성 시작]를 선택합니다.
+
결과 테이블에는 새 풀, 드라이브가 추가된 기존 풀 또는 둘 다 나열됩니다. 새 풀은 기본적으로 순차 번호로 이름이 지정됩니다.

+
System Manager는 다음 작업을 수행합니다.

+
** 동일한 드라이브 유형(HDD 또는 SSD)을 가진 드라이브가 충분한 수만큼 있고 용량이 비슷한 경우 단일 풀을 생성합니다.
** 할당되지 않은 용량이 서로 다른 드라이브 유형으로 구성된 경우 여러 풀을 생성합니다.
** 스토리지 어레이에 풀이 이미 정의되어 있고 동일한 드라이브 유형의 새 드라이브를 풀에 추가하는 경우 기존 풀에 드라이브를 추가합니다.
** 기존 풀에 동일한 드라이브 유형의 드라이브를 추가하고, 새 드라이브의 드라이브 유형이 다른 경우에는 다른 드라이브 유형을 사용하여 별도의 풀을 생성합니다.


. 새 풀의 이름을 변경하려면 *편집* 아이콘(연필)을 클릭합니다.
. 풀의 추가 특성을 보려면 커서를 *세부 정보* 아이콘(페이지) 위에 놓거나 터치하십시오.
+
드라이브 유형, 보안 기능, 데이터 보증(DA) 기능, 쉘프 손실 방지 및 드로어 손실 방지에 대한 정보가 표시됩니다.

+
EF600 및 EF300 스토리지 어레이의 경우 리소스 프로비저닝 및 볼륨 블록 크기에 대한 설정도 표시됩니다.

. *Accept*를 클릭합니다.
