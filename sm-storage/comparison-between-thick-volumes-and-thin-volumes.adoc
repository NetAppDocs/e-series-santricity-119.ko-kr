= SANtricity 소프트웨어에서 thick 볼륨과 thin 볼륨에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
thick 볼륨은 항상 완전 프로비저닝되며, 이는 볼륨이 생성될 때 모든 용량이 할당됨을 의미합니다. thin 볼륨은 항상 씬 프로비저닝되며, 이는 데이터가 볼륨에 기록될 때 용량이 할당됨을 의미합니다.

[NOTE]
====
System Manager는 씬 볼륨을 생성하는 옵션을 제공하지 않습니다. 씬 볼륨을 생성하려면 명령줄 인터페이스(CLI)를 사용하십시오.

====
[cols="25h,~"]
|===
| 볼륨 유형 | 설명 


 a| 
씩 볼륨
 a| 
* 씩 볼륨은 풀 또는 볼륨 그룹에서 생성됩니다.
* 씩 볼륨의 경우 향후 스토리지 요구 사항을 예상하여 대량의 스토리지 공간이 사전에 제공됩니다.
* 씩 볼륨은 볼륨 생성 시 물리적 스토리지에 볼륨 전체 크기가 미리 할당된 상태로 생성됩니다. 이러한 사전 할당은 100GiB 볼륨을 생성하면 실제로 드라이브에 100GiB의 할당된 용량이 사용됨을 의미합니다. 하지만 이 공간은 사용되지 않은 채로 남아 있어 스토리지 용량의 활용도가 저하될 수 있습니다.
* 두꺼운 볼륨을 생성할 때는 단일 볼륨에 과도하게 용량을 할당하지 않도록 주의해야 합니다. 단일 볼륨에 용량을 과도하게 할당하면 시스템의 모든 물리적 스토리지가 빠르게 소진될 수 있습니다.
* 스냅샷 이미지, 스냅샷 볼륨, 볼륨 복사본 및 비동기 미러링과 같은 복사 서비스에도 스토리지 용량이 필요하므로 씩 볼륨에 모든 용량을 할당하지 마십시오. 공간이 부족하면 풀 또는 볼륨 그룹에 대한 쓰기가 차단될 수 있습니다. 이러한 상황이 발생하면 여유 용량 알림 임계값 경고가 표시됩니다.




 a| 
씬 볼륨
 a| 
* 씬 볼륨은 볼륨 그룹이 아닌 풀에서만 생성됩니다.
* 씬 볼륨은 RAID 6이어야 합니다.
* EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서는 씬 볼륨을 사용할 수 없습니다.
* 씬 볼륨을 생성하려면 CLI를 사용해야 합니다.
* 일반 볼륨과 달리 씬 볼륨에 필요한 공간은 생성 시 할당되지 않고 나중에 필요에 따라 제공됩니다.
* 씬 볼륨을 사용하면 크기를 초과 할당할 수 있습니다. 즉, 볼륨 크기보다 큰 LUN 크기를 할당할 수 있습니다. 그런 다음 필요에 따라 볼륨을 확장할 수 있으며(필요한 경우 프로세스에 드라이브 추가), LUN 크기를 확장하지 않고도 볼륨을 확장할 수 있으므로 사용자 연결을 끊지 않아도 됩니다.
* 씬 프로비저닝 블록 공간 재확보(UNMAP) 기능을 사용하면 호스트에서 발행한 SCSI UNMAP 명령을 통해 스토리지 어레이의 씬 프로비저닝된 볼륨 블록을 재확보할 수 있습니다. 씬 프로비저닝을 지원하는 스토리지 어레이는 재확보된 공간을 동일한 스토리지 어레이 내의 다른 씬 프로비저닝된 볼륨에 대한 할당 요청을 충족하는 데 재사용할 수 있으므로 디스크 공간 사용량을 더 정확하게 보고하고 리소스를 더욱 효율적으로 사용할 수 있습니다.


|===


== 씬 볼륨 제한

씬 볼륨은 다음과 같은 예외 사항을 제외하고 씩 볼륨과 동일한 모든 작업을 지원합니다.

* 씬 볼륨의 세그먼트 크기는 변경할 수 없습니다.
* 씬 볼륨에 대해 사전 읽기 중복 검사를 활성화할 수 없습니다.
* 볼륨 복사 작업에서 씬 볼륨을 타겟 볼륨으로 사용할 수 없습니다.
* 비동기 미러링 쌍의 운영 측에서만 씬 볼륨의 할당된 용량 제한 및 경고 임계값을 변경할 수 있습니다. 운영 측에서 이러한 매개 변수를 변경하면 보조 측에 자동으로 전파됩니다.
