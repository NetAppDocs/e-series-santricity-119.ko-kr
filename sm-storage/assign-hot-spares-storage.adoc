= SANtricity System Manager에서 핫 스페어 할당
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
RAID 1, RAID 5 또는 RAID 6 볼륨 그룹에서 추가적인 데이터 보호를 위해 핫 스페어를 대기 드라이브로 지정할 수 있습니다. 이러한 볼륨 그룹 중 하나에서 드라이브에 오류가 발생하면 컨트롤러는 오류가 발생한 드라이브의 데이터를 핫 스페어로 재구성합니다.

.시작하기 전에
* RAID 1, RAID 5 또는 RAID 6 볼륨 그룹을 생성해야 합니다. (핫 스페어는 풀에 사용할 수 없습니다. 대신 풀은 각 드라이브 내의 여유 용량을 사용하여 데이터를 보호합니다.)
* 다음 조건을 충족하는 드라이브를 사용할 수 있어야 합니다.
+
** 할당되지 않음, 최적 상태.
** 볼륨 그룹의 드라이브와 동일한 미디어 유형(예: SSD)
** 볼륨 그룹의 드라이브와 동일한 인터페이스 유형(예: SAS).
** 볼륨 그룹의 드라이브에서 사용된 용량과 같거나 더 큰 용량.




.이 작업 정보
이 작업에서는 하드웨어 페이지에서 핫 스페어를 수동으로 지정하는 방법을 설명합니다. 드라이브 세트당 핫 스페어는 두 개로 설정하는 것이 좋습니다.

[CAUTION]
====
핫 스페어는 Initial Setup 마법사에서도 지정할 수 있습니다. Hardware 페이지에서 드라이브 베이가 분홍색으로 표시되는지 확인하여 핫 스페어가 이미 지정되었는지 확인할 수 있습니다.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 핫 스페어로 사용할 할당되지 않은 드라이브(회색으로 표시됨)를 선택합니다.
+
드라이브의 컨텍스트 메뉴가 열립니다.

. *핫 스페어 할당*을 선택합니다.
+
드라이브에서 보안이 활성화된 경우 *Secure Erase Drive* 대화 상자가 열립니다. 보안이 활성화된 드라이브를 핫 스페어로 사용하려면 먼저 Secure Erase 작업을 수행하여 모든 데이터를 제거하고 보안 속성을 재설정해야 합니다.

+
[CAUTION]
====
*데이터 손실 가능성 있음* -- 올바른 드라이브를 선택했는지 확인하십시오. 보안 지우기 작업을 완료한 후에는 데이터를 복구할 수 없습니다.

====
+
드라이브에 보안 기능이 활성화되어 있지 않은 경우 핫 스페어 드라이브 할당 확인 대화 상자가 열립니다.

. 대화 상자의 텍스트를 검토한 후 작업을 확인하십시오.
+
하드웨어 페이지에서 해당 드라이브가 분홍색으로 표시되는데, 이는 현재 핫 스페어임을 나타냅니다.





[[results]]
== 결과

RAID 1, RAID 5 또는 RAID 6 볼륨 그룹 내의 드라이브에 오류가 발생하면 컨트롤러는 자동으로 이중화 데이터를 사용하여 오류가 발생한 드라이브의 데이터를 핫 스페어로 재구성합니다.
