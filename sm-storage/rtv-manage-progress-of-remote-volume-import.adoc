= SANtricity System Manager에서 원격 스토리지 가져오기 진행 상황을 관리합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
가져오기 프로세스가 시작되면 진행 상황을 확인하고 필요한 조치를 취할 수 있습니다.

.이 작업 정보
각 가져오기 작업에 대해 진행 중인 작업 대화 상자에는 완료율과 남은 예상 시간이 표시됩니다. 여기에서 가져오기 우선순위 변경, 작업 중지 및 재개, 작업 연결 해제 등의 작업을 수행할 수 있습니다.

홈 페이지에서 진행 중인 작업을 볼 수도 있습니다(menu:Home[Show operations in progress]).

.단계
. 원격 스토리지 페이지에서 *작업 보기*를 선택합니다.
+
진행 중인 작업 대화 상자가 표시됩니다.

. 원하는 경우 *작업* 열의 링크를 사용하여 작업을 중지 및 재개하거나, 우선 순위를 변경하거나, 작업에서 연결을 끊을 수 있습니다.
+
** *Change Priority* -- 진행 중이거나 대기 중인 작업의 처리 우선순위를 변경하려면 *Change Priority*를 선택하십시오. 작업에 우선순위를 적용한 다음 *OK*를 클릭하십시오.
** *중지* -- 원격 스토리지 장치에서 데이터 복사를 일시 중지하려면 *중지*를 선택합니다. 가져오기 쌍 간의 관계는 그대로 유지되며, 가져오기 작업을 계속할 준비가 되면 *재개*를 선택할 수 있습니다.
** *재개* -- 중지되었거나 실패한 프로세스를 중단된 지점부터 다시 시작하려면 *재개*를 선택합니다. 다음으로, 재개 작업에 우선 순위를 지정하고 *확인*을 클릭합니다. 이 작업은 가져오기를 처음부터 다시 시작하는 것이 _아닙니다_. 프로세스를 처음부터 다시 시작하려면 *연결 해제*를 선택한 다음 원격 스토리지 가져오기 마법사를 통해 가져오기를 다시 생성해야 합니다.
** *연결 해제* -- 중지, 완료 또는 실패한 가져오기 작업에 대해 소스 볼륨과 타겟 볼륨 간의 관계를 끊으려면 *연결 해제*를 선택합니다.
