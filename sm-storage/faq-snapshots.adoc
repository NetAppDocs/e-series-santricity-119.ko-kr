= SANtricity System Manager용 스냅샷 FAQ
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 FAQ는 질문에 대한 빠른 답변을 찾고 있을 때 도움이 될 수 있습니다.



[[why-dont-i-see-all-my-volumes-hosts-or-host-clusters]]
== 볼륨, 호스트 또는 호스트 클러스터가 모두 표시되지 않는 이유는 무엇입니까?

Data Assurance(DA)가 활성화된 기본 볼륨을 사용하는 스냅샷 볼륨은 Data Assurance(DA)를 지원하지 않는 호스트에 할당할 수 없습니다. 스냅샷 볼륨을 DA를 지원하지 않는 호스트에 할당하려면 먼저 기본 볼륨에서 DA를 비활성화해야 합니다.

스냅샷 볼륨을 할당할 호스트에 대해 다음 지침을 고려하십시오.

* 호스트가 DA를 지원하지 않는 I/O 인터페이스를 통해 스토리지 어레이에 연결된 경우 해당 호스트는 DA를 지원하지 않습니다.
* 호스트 클러스터에 DA를 지원하지 않는 호스트 구성원이 하나 이상 있으면 DA를 지원하지 않습니다.


[NOTE]
====
스냅샷(일관성 그룹, 스냅샷 그룹, 스냅샷 이미지 및 스냅샷 볼륨), 볼륨 복사본 및 미러와 연결된 볼륨에서는 DA를 비활성화할 수 없습니다. 기본 볼륨에서 DA를 비활성화하려면 연결된 모든 예약 용량 및 스냅샷 개체를 삭제해야 합니다.

====


[[what-is-a-snapshot-image]]
== 스냅샷 이미지란 무엇입니까?

스냅샷 이미지는 특정 시점에 캡처된 볼륨 콘텐츠의 논리적 복사본입니다. 스냅샷 이미지는 최소한의 스토리지 공간을 사용합니다.

스냅샷 이미지 데이터는 다음과 같이 저장됩니다.

* 스냅샷 이미지가 생성되면 기본 볼륨과 정확히 일치합니다. 스냅샷이 생성된 후, 기본 볼륨의 블록 또는 블록 집합에 대한 첫 번째 쓰기 요청이 발생하면, 새 데이터가 기본 볼륨에 기록되기 전에 원본 데이터가 스냅샷 예약 용량으로 복사됩니다.
* 후속 스냅샷에는 첫 번째 스냅샷 이미지가 생성된 이후 변경된 데이터 블록만 포함됩니다. 각 후속 copy-on-write 작업은 새 데이터가 기본 볼륨에 기록되기 전에 기본 볼륨에서 덮어쓰기될 원본 데이터를 스냅샷 예약 용량에 저장합니다.




[[why-use-snapshot-images]]
== 스냅샷 이미지를 사용하는 이유는 무엇입니까?

스냅샷을 사용하면 우발적이거나 악의적인 데이터 손실 또는 데이터 손상으로부터 보호하고 복구할 수 있습니다.

기본 볼륨 또는 스냅샷 일관성 그룹이라고 하는 기본 볼륨 그룹을 선택한 다음 다음 방법 중 하나 이상을 사용하여 스냅샷 이미지를 캡처합니다.

* 단일 기본 볼륨의 스냅샷 이미지 또는 여러 기본 볼륨으로 구성된 스냅샷 일관성 그룹의 스냅샷 이미지를 생성할 수 있습니다.
* 스냅샷을 수동으로 생성하거나 기본 볼륨 또는 스냅샷 일관성 그룹에 대한 스케줄을 생성하여 주기적으로 스냅샷 이미지를 자동으로 캡처할 수 있습니다.
* 스냅샷 이미지의 호스트 액세스 가능 스냅샷 볼륨을 생성할 수 있습니다.
* 롤백 작업을 수행하여 스냅샷 이미지를 복원할 수 있습니다.


이 시스템은 여러 스냅샷 이미지를 복원 지점으로 저장하여 특정 시점의 정상적인 데이터 세트로 되돌릴 수 있도록 합니다. 되돌리기 기능은 데이터의 실수로 인한 삭제 및 데이터 손상에 대한 보호를 제공합니다.



[[what-kinds-of-volumes-can-be-used-for-snapshots]]
== 스냅샷에 사용할 수 있는 볼륨 유형은 무엇입니까?

스냅샷 이미지를 저장하는 데 사용할 수 있는 볼륨 유형은 표준 볼륨과 씬 볼륨뿐입니다. 비표준 볼륨은 사용할 수 없습니다. 기본 볼륨은 풀 또는 볼륨 그룹에 위치할 수 있습니다.



[[why-would-i-create-a-snapshot-consistency-group]]
== 스냅샷 일관성 그룹을 생성하는 이유는 무엇입니까?

여러 볼륨에서 동시에 스냅샷 이미지를 생성하도록 보장하려는 경우 스냅샷 일관성 그룹을 만듭니다.

예를 들어, 복구 목적으로 일관성을 유지해야 하는 여러 볼륨으로 구성된 데이터베이스의 경우, 모든 볼륨의 조정된 스냅샷을 수집하고 이를 사용하여 전체 데이터베이스를 복원하는 스냅샷 일관성 그룹이 필요합니다.

스냅샷 일관성 그룹에 포함된 볼륨을 _멤버 볼륨_이라고 합니다.

스냅샷 일관성 그룹에서 다음 스냅샷 작업을 수행할 수 있습니다.

* 스냅샷 일관성 그룹의 스냅샷 이미지를 생성하여 멤버 볼륨의 동시 이미지를 얻습니다.
* 스냅샷 일관성 그룹에 대한 스케줄을 생성하여 멤버 볼륨의 주기적인 동시 이미지를 자동으로 캡처합니다.
* 스냅샷 일관성 그룹 이미지의 호스트 액세스 가능 스냅샷 볼륨을 생성합니다.
* 스냅샷 일관성 그룹에 대한 롤백 작업을 수행합니다.




[[what-is-a-snapshot-volume-and-when-does-it-need-reserved-capacity]]
== 스냅샷 볼륨이란 무엇이며 언제 예약된 용량이 필요합니까?

스냅샷 볼륨을 사용하면 호스트가 스냅샷 이미지의 데이터에 액세스할 수 있습니다. 스냅샷 볼륨에는 자체 예약된 용량이 포함되어 있어 원본 스냅샷 이미지에 영향을 주지 않고 베이스 볼륨에 대한 수정 사항을 저장합니다. 스냅샷 이미지는 호스트에서 읽기 또는 쓰기 액세스가 불가능합니다. 스냅샷 데이터를 읽거나 쓰려면 스냅샷 볼륨을 생성하여 호스트에 할당하십시오.

스냅샷 볼륨은 두 가지 유형으로 생성할 수 있습니다. 스냅샷 볼륨 유형에 따라 예약 용량을 사용하는지 여부가 결정됩니다.

* *읽기 전용* -- 읽기 전용으로 생성된 스냅샷 볼륨은 호스트 애플리케이션에 스냅샷 이미지에 포함된 데이터의 복사본에 대한 읽기 액세스 권한을 제공합니다. 읽기 전용 스냅샷 볼륨은 예약된 용량을 사용하지 않습니다.
* *읽기-쓰기* -- 읽기-쓰기로 생성된 스냅샷 볼륨을 사용하면 참조된 스냅샷 이미지에 영향을 주지 않고 스냅샷 볼륨을 변경할 수 있습니다. 읽기-쓰기 스냅샷 볼륨은 이러한 변경 사항을 저장하기 위해 예약된 용량을 사용합니다. 읽기 전용 스냅샷 볼륨은 언제든지 읽기-쓰기로 변환할 수 있습니다.




[[what-is-a-snapshot-group]]
== 스냅샷 그룹이란 무엇입니까?

스냅샷 그룹은 단일 관련 기본 볼륨의 특정 시점 스냅샷 이미지 모음입니다.

System Manager는 스냅샷 이미지를 _스냅샷 그룹_으로 구성합니다. 스냅샷 그룹은 사용자 작업이 필요하지 않지만 언제든지 스냅샷 그룹의 예약된 용량을 조정할 수 있습니다. 또한 다음 조건이 충족되면 예약된 용량을 생성하라는 메시지가 표시될 수 있습니다.

* 스냅샷 그룹이 아직 없는 기본 볼륨의 스냅샷을 생성할 때마다 System Manager는 자동으로 스냅샷 그룹을 생성합니다. 이렇게 하면 이후 스냅샷 이미지를 저장하는 데 사용되는 기본 볼륨에 대한 예약 용량이 생성됩니다.
* 기본 볼륨에 대한 스냅샷 일정을 생성할 때마다 System Manager는 자동으로 스냅샷 그룹을 생성합니다.




[[why-would-i-disable-a-snapshot-volume]]
== 스냅샷 볼륨을 비활성화하는 이유는 무엇입니까?

스냅샷 이미지에 다른 스냅샷 볼륨을 할당하려면 스냅샷 볼륨을 비활성화해야 합니다. 비활성화된 스냅샷 볼륨은 나중에 사용할 수 있도록 예약할 수 있습니다.

스냅샷 볼륨이나 일관성 그룹 스냅샷 볼륨이 더 이상 필요하지 않고 나중에 다시 생성할 계획이 없다면 해당 볼륨을 비활성화하는 대신 삭제해야 합니다.



[[what-is-the-disabled-state]]
== 비활성화 상태란 무엇입니까?

사용 안 함 상태의 스냅샷 볼륨은 현재 스냅샷 이미지에 할당되지 않습니다. 스냅샷 볼륨을 활성화하려면 다시 생성 작업을 사용하여 사용 안 함 상태의 스냅샷 볼륨에 새 스냅샷 이미지를 할당해야 합니다.

스냅샷 볼륨의 특성은 해당 볼륨에 할당된 스냅샷 이미지에 따라 정의됩니다. '사용 안 함' 상태의 스냅샷 볼륨에서는 읽기/쓰기 작업이 일시 중단됩니다.



[[why-would-i-suspend-a-snapshot-schedule]]
== 스냅샷 스케줄을 일시 중단해야 하는 이유는 무엇입니까?

스케줄이 일시 중단되면 예약된 스냅샷 이미지 생성이 수행되지 않습니다. 스토리지 공간을 절약하기 위해 스냅샷 스케줄을 일시 중지한 다음 나중에 예약된 스냅샷을 다시 시작할 수 있습니다.

스냅샷 일정이 필요하지 않은 경우 일정을 일시 중지하는 대신 삭제해야 합니다.
