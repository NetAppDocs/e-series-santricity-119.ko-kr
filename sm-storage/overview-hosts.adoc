== 호스트와 호스트 클러스터란 무엇입니까?

_host_는 스토리지 어레이의 볼륨으로 I/O를 전송하는 서버입니다. _host cluster_는 여러 호스트에 동일한 볼륨을 할당하기 위해 생성할 수 있는 호스트 그룹입니다.

자세한 정보:

* link:host-terminology.html["호스트 용어"]
* link:access-volumes.html["볼륨 액세스"]
* link:maximum-number-of-luns.html["최대 LUN 수"]




== 호스트 및 호스트 클러스터를 구성하려면 어떻게 해야 합니까?

호스트 연결을 정의하려면 메뉴:저장소[호스트]로 이동하여 호스트를 수동으로 구성할 수 있습니다. 두 개 이상의 호스트가 동일한 볼륨 세트에 대한 액세스를 공유하도록 하려면 클러스터를 정의하고 해당 클러스터에 볼륨을 할당하면 됩니다.
