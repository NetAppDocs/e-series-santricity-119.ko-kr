= SANtricity 소프트웨어의 최대 LUN 수에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에는 각 호스트에 사용할 수 있는 최대 LUN(논리 유닛 번호) 수가 있습니다.

최대 개수는 호스트의 운영 체제에 따라 다릅니다. 스토리지 어레이는 사용된 LUN 개수를 추적합니다. 최대 LUN 개수를 초과하는 볼륨을 호스트에 할당하려고 하면 호스트가 해당 볼륨에 액세스할 수 없습니다.
