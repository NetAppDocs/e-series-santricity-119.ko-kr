= SANtricity System Manager에서 원격 스토리지 가져오기
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
원격 시스템에서 로컬 E-Series 스토리지 시스템으로 스토리지 가져오기를 시작하려면 원격 스토리지 가져오기 마법사를 사용하십시오.

.시작하기 전에
* E-Series 스토리지 시스템은 원격 스토리지 시스템과 통신하도록 구성되어야 합니다.
+
[NOTE]
====
하드웨어 구성은  https://docs.netapp.com/us-en/e-series/remote-storage-volumes/setup-remote-volumes-concept.html["하드웨어 구성"^]의 E-Series 및 SANtricity 문서 센터와  https://www.netapp.com/pdf.html?item=/media/28697-tr-4893-deploy.pdf["원격 스토리지 기술 보고서"^]에서 제공되는 Remote Storage 기능 사용자 가이드에 설명되어 있습니다.

====
* 원격 스토리지 시스템의 경우 다음 정보를 수집하십시오.
+
** iSCSI IQN
** iSCSI IP 주소
** 원격 스토리지 장치(소스 볼륨)의 LUN 번호


* 로컬 E-Series 스토리지 시스템의 경우 데이터 가져오기에 사용할 볼륨을 생성하거나 선택하십시오. link:create-volumes.html["볼륨 생성"]를 참조하십시오. 타겟 볼륨은 다음 요구 사항을 충족해야 합니다.
+
** 원격 스토리지 장치(소스 볼륨)의 블록 크기와 일치합니다.
** 원격 스토리지 장치보다 크거나 같은 용량을 가지고 있습니다.
** 최적 상태이며 사용 가능합니다.




전체 요구 사항 목록은 link:rtv-remote-storage-volume-requirements.html["원격 스토리지 볼륨 요구 사항"]을 참조하십시오.

* *권장 사항:* 가져오기 프로세스를 시작하기 전에 원격 스토리지 시스템의 볼륨을 백업하십시오.


.이 작업 정보
이 작업에서는 원격 스토리지 장치와 로컬 E-Series 스토리지 시스템의 볼륨 간에 매핑을 생성합니다. 구성을 완료하면 가져오기가 시작됩니다.

[NOTE]
====
가져오기 작업과 완료 시간에 영향을 미치는 변수가 많기 때문에 먼저 소규모 "`test`" 가져오기를 수행하는 것이 좋습니다. 이러한 테스트를 통해 모든 연결이 예상대로 작동하는지, 가져오기 작업이 적절한 시간 내에 완료되는지 확인하십시오.

====
.단계
. 메뉴: Storage[Remote storage]를 선택합니다.
. *원격 스토리지 가져오기*를 클릭합니다.
+
원격 스토리지 가져오기 마법사가 표시됩니다.

. 소스 구성 패널의 *1a단계*에서 연결 정보를 입력합니다. iSCSI 연결을 하나 더 추가하려면 *다른 IP 주소 추가*를 클릭하여 원격 스토리지에 대한 추가 IP 주소를 입력합니다. 완료되면 *다음*을 클릭합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
이름
 a| 
System Manager 인터페이스에서 원격 스토리지 장치를 식별할 수 있도록 이름을 입력하십시오.

이름은 최대 30자까지 가능하며, 문자, 숫자 및 다음 특수 문자(밑줄(_), 하이픈(-), 해시 기호(#))만 포함할 수 있습니다. 이름에는 공백을 사용할 수 없습니다.



 a| 
iSCSI 연결 속성
 a| 
원격 스토리지 장치의 연결 속성을 입력합니다.

** *iSCSI Qualified Name(IQN)*: iSCSI IQN을 입력하십시오.
** *IP 주소*: IPv4 주소를 입력합니다.
** *포트*: 소스 장치와 타겟 장치 간 통신에 사용할 포트 번호를 입력하십시오. 기본적으로 포트 번호는 3260입니다.


|===
====
+
*다음*을 클릭하면 소스 구성 패널의 *1b 단계*가 표시됩니다.

. *LUN* 필드에서 소스로 사용할 원격 스토리지 장치의 LUN 번호를 선택한 다음 *다음*을 클릭합니다.
+
대상 구성 패널이 열리고 가져오기 대상으로 사용할 볼륨 후보가 표시됩니다. 블록 크기, 용량 또는 볼륨 가용성으로 인해 일부 볼륨은 후보 목록에 표시되지 않습니다.

. 표에서 E-Series 스토리지 시스템의 타겟 볼륨을 선택합니다. 필요한 경우 슬라이더를 사용하여 가져오기 우선 순위를 변경합니다. *다음*을 클릭합니다. 다음 대화 상자에서  `continue`를 입력한 다음 *계속*을 클릭하여 작업을 확인합니다.
+
타겟 볼륨의 용량이 소스 볼륨보다 큰 경우, 추가 용량은 E-Series 시스템에 연결된 호스트에 보고되지 않습니다. 새 용량을 사용하려면 가져오기 작업이 완료되고 연결이 해제된 후 호스트에서 파일 시스템 확장 작업을 수행해야 합니다.

+
대화 상자에서 구성을 확인하면 검토 패널이 표시됩니다.

. 검토 패널에서 설정이 정확한지 확인한 다음 *마침*을 클릭하여 가져오기를 시작하십시오.
+
다른 가져오기를 시작할지 묻는 또 다른 대화 상자가 열립니다.

. 필요한 경우 *예*를 클릭하여 다른 원격 스토리지 가져오기를 생성하십시오. *예*를 클릭하면 소스 구성 패널의 *1a단계*로 돌아가 기존 구성을 선택하거나 새 구성을 추가할 수 있습니다. 다른 가져오기를 생성하지 않으려면 *아니요*를 클릭하여 대화 상자를 종료하십시오.
+
가져오기 프로세스가 시작되면 전체 타겟 볼륨이 복사된 데이터로 덮어쓰여집니다. 이 프로세스 중에 호스트가 타겟 볼륨에 새 데이터를 기록하면 해당 새 데이터가 원격 장치(소스 볼륨)로 다시 전파됩니다.

. Remote Storage 패널 아래의 View Operations 대화 상자에서 작업 진행 상황을 확인할 수 있습니다.


.결과
가져오기 작업을 완료하는 데 필요한 시간은 원격 스토리지 시스템의 크기, 가져오기 우선 순위 설정, 그리고 두 스토리지 시스템과 관련 볼륨의 I/O 부하량에 따라 달라집니다.

가져오기가 완료되면 로컬 볼륨은 원격 스토리지 장치의 복제본입니다.

.완료한 후
두 볼륨 간의 관계를 끊을 준비가 되면 진행 중인 작업 보기에서 가져오기 개체의 *연결 해제*를 선택합니다. 관계가 연결 해제되면 로컬 볼륨의 성능이 정상으로 돌아가고 원격 연결의 영향을 더 이상 받지 않습니다.
