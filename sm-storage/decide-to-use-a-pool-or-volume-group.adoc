= SANtricity 소프트웨어의 풀 및 볼륨 그룹에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
풀 또는 볼륨 그룹을 사용하여 볼륨을 생성할 수 있습니다. 최적의 선택은 주로 예상 I/O 워크로드, 성능 요구사항, 데이터 보호 요구사항과 같은 주요 스토리지 요구사항에 따라 달라집니다.



[[reasons-to-choose-a-pool-or-volume-group]]
== 풀 또는 볼륨 그룹을 선택하는 이유

*풀 선택*

* 더 빠른 드라이브 재구축 및 간소화된 스토리지 관리가 필요하거나, 씬 볼륨이 필요하거나, 무작위성이 높은 워크로드가 있는 경우
* 풀을 구성하는 드라이브 세트 전체에 각 볼륨의 데이터를 무작위로 분산시키려는 경우
+
풀 또는 풀에 속한 볼륨의 RAID 레벨을 설정하거나 변경할 수 없습니다. 풀은 RAID 레벨 6을 사용합니다.



*볼륨 그룹 선택*

* 최대 시스템 대역폭, 스토리지 설정 조정 기능 및 순차적 워크로드가 필요한 경우
* RAID 레벨에 따라 데이터를 드라이브에 분산시키려면 볼륨 그룹을 생성할 때 RAID 레벨을 지정할 수 있습니다.
* 볼륨 그룹을 구성하는 드라이브 세트 전체에 걸쳐 각 볼륨의 데이터를 순차적으로 기록하려는 경우


[NOTE]
====
풀은 볼륨 그룹과 공존할 수 있으므로 스토리지 어레이에는 풀과 볼륨 그룹이 모두 포함될 수 있습니다.

====
