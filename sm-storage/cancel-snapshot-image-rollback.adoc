= SANtricity System Manager에서 스냅샷 이미지 롤백을 취소합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
진행 중인 활성 롤백(데이터를 적극적으로 복사 중), 보류 중인 롤백(시작할 리소스를 기다리는 보류 대기열에 있음) 또는 오류로 인해 일시 중지된 롤백을 취소할 수 있습니다.

.이 작업 정보
진행 중인 롤백 작업을 취소하면 기본 볼륨이 사용 불가능한 상태로 되돌아가고 실패로 표시됩니다. 따라서 기본 볼륨의 콘텐츠를 복원할 수 있는 복구 옵션이 있는 경우에만 롤백 작업을 취소하는 것을 고려하십시오.

[NOTE]
====
스냅샷 이미지가 있는 스냅샷 그룹에 자동으로 삭제된 스냅샷 이미지가 하나 이상 있는 경우 롤백 작업에 사용된 스냅샷 이미지를 향후 롤백에 사용할 수 없을 수 있습니다.

====
.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *스냅샷 이미지* 탭을 클릭합니다.
. 활성 또는 일시 중지된 롤백을 선택한 다음 menu:Rollback[Cancel]를 선택합니다.
+
롤백 취소 확인 대화 상자가 나타납니다.

. 확인하려면 *예*를 클릭합니다.


.결과
System Manager가 롤백 작업을 중지합니다. 기본 볼륨은 사용 가능하지만 데이터가 일관되지 않거나 손상되었을 수 있습니다.

.완료한 후
롤백 작업을 취소한 후에는 다음 작업 중 하나를 수행해야 합니다.

* 기본 볼륨의 콘텐츠를 다시 초기화합니다.
* 롤백 취소 작업에 사용된 것과 동일한 스냅샷 이미지 또는 다른 스냅샷 이미지를 사용하여 새 롤백 작업을 수행하여 기본 볼륨을 복원합니다.
