= SANtricity 소프트웨어의 원격 스토리지 기능 요구 사항에 대해 알아보십시오.

[role="lead"]
원격 스토리지 기능을 사용하기 전에 다음 요구 사항 및 제한 사항을 검토하십시오.



== 지원되는 프로토콜

다음 프로토콜이 지원됩니다.

* iSCSI
* IPv4


최신 E-Series 지원 및 구성 정보는 다음을 참조하십시오 https://imt.netapp.com/matrix/#welcome["NetApp 상호 운용성 매트릭스 도구"^].



== 하드웨어 요구 사항

E-Series 스토리지 시스템에는 다음이 포함되어야 합니다.

* 컨트롤러 2개(이중 모드)
* E-Series 컨트롤러 두 개 모두 하나 이상의 iSCSI 연결을 통해 원격 스토리지 시스템과 통신하기 위한 iSCSI 연결
* SANtricity OS 11.71 이상
* 서브모델 ID(SMID)에서 원격 스토리지 기능이 활성화되었습니다


원격 시스템은 E-Series 스토리지 시스템이거나 다른 공급업체의 시스템일 수 있습니다. 다음 사항을 반드시 포함해야 합니다.

* iSCSI 지원 인터페이스




== 제한 사항

원격 스토리지 기능에는 다음과 같은 제한 사항이 있습니다.

* 미러링을 비활성화해야 합니다.
* E-Series 시스템의 타겟 볼륨에는 스냅샷이 없어야 합니다.
* 가져오기를 시작하기 전에 E-Series 시스템의 타겟 볼륨이 어떤 호스트에도 매핑되어 있지 않아야 합니다.
* E-Series 시스템의 타겟 볼륨은 리소스 프로비저닝이 비활성화되어 있어야 합니다.
* 원격 스토리지 볼륨을 호스트 또는 여러 호스트에 직접 매핑하는 것은 지원되지 않습니다.
* Web Services Proxy는 지원되지 않습니다.
* iSCSI CHAP 암호는 지원되지 않습니다.
* SMcli는 지원되지 않습니다.
* VMware Datastore는 지원되지 않습니다.
* 가져오기 쌍이 있는 경우 관계/가져오기 쌍의 스토리지 시스템 중 하나만 한 번에 업그레이드할 수 있습니다.
