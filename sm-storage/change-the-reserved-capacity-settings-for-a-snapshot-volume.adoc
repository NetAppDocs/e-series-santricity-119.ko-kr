= SANtricity System Manager에서 스냅샷 볼륨의 예약 용량 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 볼륨 설정을 변경하여 스냅샷 볼륨에 예약된 용량이 거의 다 찼을 때 시스템에서 알림을 보내는 시점을 백분율로 조정할 수 있습니다.

.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. *예약된 용량* 탭을 클릭합니다.
. 편집할 스냅샷 볼륨을 선택한 다음 *설정 보기/편집* 을 클릭합니다.
+
스냅샷 볼륨 예약 용량 설정 대화 상자가 나타납니다.

. 스냅샷 볼륨의 예약 용량 설정을 필요에 따라 변경하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
다음의 경우 알림...
 a| 
스피너 상자를 사용하여 구성원 볼륨의 예약된 용량이 거의 찼을 때 시스템에서 알림 통지를 보내는 백분율 지점을 조정하십시오.

스냅샷 볼륨에 예약된 용량이 지정된 임계값을 초과하면 시스템에서 경고를 보내 예약 용량을 늘리거나 불필요한 객체를 삭제할 시간을 줍니다.

|===
====
. 스냅샷 볼륨 예약 용량 설정에 대한 변경 사항을 적용하려면 *저장*을 클릭하십시오.
