= SANtricity System Manager에서 표 형식의 성능 데이터를 보고 저장할 수 있습니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 그래프 데이터를 표 형식으로 보고 저장할 수 있습니다. 이를 통해 표시하려는 데이터만 필터링할 수 있습니다.

.단계
. 성능 데이터 그래프에서 *테이블 보기 실행*을 클릭합니다.
+
선택한 객체에 대한 모든 성능 데이터가 나열된 표가 나타납니다.

. 필요에 따라 개체 선택 풀다운 메뉴와 필터를 사용하십시오.
. 표에 포함할 열을 선택하려면 *열 표시/숨기기* 버튼을 클릭합니다.
+
각 확인란을 클릭하여 항목을 선택하거나 선택 해제할 수 있습니다.

. 화면 하단의 *내보내기*를 선택하여 표 형식 보기를 쉼표로 구분된 값(CSV) 파일로 저장합니다.
+
테이블 내보내기 대화 상자가 나타나며, 내보낼 행 수와 내보내기 파일 형식(쉼표로 구분된 값 또는 CSV 형식)이 표시됩니다.

. 다운로드를 진행하려면 *Export*를 클릭하고, 그렇지 않으면 *Cancel*을 클릭하십시오.
+
브라우저 설정에 따라 파일이 저장되거나 파일 이름과 저장 위치를 선택하라는 메시지가 표시됩니다.

+
기본 파일 이름 형식은  `performanceStatistics-yyyy-mm-dd_hh-mm-ss.csv`이며, 여기에는 파일이 내보내진 날짜와 시간이 포함됩니다.
