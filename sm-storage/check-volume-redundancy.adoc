= SANtricity System Manager에서 볼륨 이중화를 확인하십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기술 지원의 안내에 따라 또는 Recovery Guru의 지시에 따라 풀 또는 볼륨 그룹의 볼륨에 대한 이중화를 확인하여 해당 볼륨의 데이터가 일관적인지 판단할 수 있습니다.

중복 데이터는 풀 또는 볼륨 그룹의 드라이브 중 하나에 장애가 발생할 경우 교체 드라이브에서 정보를 신속하게 재구성하는 데 사용됩니다.

.시작하기 전에
* 풀 또는 볼륨 그룹의 상태는 최적이어야 합니다.
* 풀 또는 볼륨 그룹에는 진행 중인 볼륨 수정 작업이 없어야 합니다.
* RAID 0에는 데이터 이중화가 없으므로 RAID 0을 제외한 모든 RAID 레벨에서 이중화를 확인할 수 있습니다.


[NOTE]
====
볼륨 이중화 점검은 Recovery Guru의 지시가 있고 기술 지원 담당자의 안내를 받을 때만 수행하십시오.

====
.이 작업 정보
이 검사는 한 번에 하나의 풀 또는 볼륨 그룹에 대해서만 수행할 수 있습니다. 볼륨 이중화 검사는 다음과 같은 작업을 수행합니다.

* RAID 3 볼륨, RAID 5 볼륨 또는 RAID 6 볼륨의 데이터 블록을 스캔하고 각 블록의 이중화 정보를 확인합니다. (RAID 3는 명령줄 인터페이스를 사용하여 볼륨 그룹에만 할당할 수 있습니다.)
* RAID 1 미러링된 드라이브의 데이터 블록을 비교합니다.
* 컨트롤러 펌웨어가 데이터의 일관성이 없다고 판단하면 중복 오류를 반환합니다.


[NOTE]
====
동일한 풀 또는 볼륨 그룹에 대해 즉시 이중화 검사를 실행하면 오류가 발생할 수 있습니다. 이 문제를 방지하려면 동일한 풀 또는 볼륨 그룹에 대해 다른 이중화 검사를 실행하기 전에 1~2분 정도 기다리십시오.

====
.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 메뉴: 일반적이지 않은 작업[볼륨 이중화 확인]을 선택합니다.
+
중복성 확인 대화 상자가 나타납니다.

. 확인할 볼륨을 선택한 다음  `check`를 입력하여 이 작업을 수행할 것인지 확인하십시오.
. *확인*을 클릭합니다.
+
볼륨 이중화 검사 작업이 시작됩니다. 대화 상자의 표 맨 위부터 시작하여 풀 또는 볼륨 그룹의 볼륨이 순차적으로 검사됩니다. 각 볼륨이 검사될 때마다 다음과 같은 작업이 수행됩니다.

+
** 볼륨은 볼륨 테이블에서 선택됩니다.
** 중복성 검사의 상태는 *상태* 열에 표시됩니다.
** 검사 과정에서 미디어 또는 패리티 오류가 발견되면 검사가 중단되고 오류가 보고됩니다.
+
.이중화 점검 상태에 대한 자세한 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 상태 | 설명 


 a| 
보류 중
 a| 
이것은 스캔할 첫 번째 볼륨이며 중복 검사를 시작하기 위해 시작을 클릭하지 않았습니다.

또는

풀 또는 볼륨 그룹의 다른 볼륨에서 이중화 검사 작업이 수행되고 있습니다.



 a| 
확인 중
 a| 
볼륨이 이중화 검사를 진행 중입니다.



 a| 
통과됨
 a| 
볼륨이 이중화 검사를 통과했습니다. 이중화 정보에서 불일치가 감지되지 않았습니다.



 a| 
실패
 a| 
볼륨의 중복성 검사에 실패했습니다. 중복성 정보에서 불일치가 발견되었습니다.



 a| 
미디어 오류
 a| 
드라이브 미디어가 불량하여 읽을 수 없습니다. Recovery Guru에 표시되는 지침을 따르십시오.



 a| 
패리티 오류
 a| 
데이터의 특정 부분에 대한 패리티가 올바르지 않습니다. 패리티 오류는 심각한 문제를 야기할 수 있으며 데이터의 영구적인 손실을 초래할 수 있습니다.

|===
====


. 풀 또는 볼륨 그룹의 마지막 볼륨을 확인한 후 *완료*를 클릭하십시오.
