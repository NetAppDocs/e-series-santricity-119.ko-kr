= SANtricity System Manager에서 풀의 구성 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
풀의 이름, 용량 알림 설정, 수정 우선순위 및 보존 용량을 포함하여 풀의 설정을 편집할 수 있습니다.

.이 작업 정보
이 작업에서는 풀의 구성 설정을 변경하는 방법을 설명합니다.

[NOTE]
====
System Manager 인터페이스를 사용하여 풀의 RAID 레벨을 변경할 수 없습니다. System Manager는 풀을 자동으로 RAID 6으로 구성합니다.

====
.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 편집하려는 풀을 선택한 다음 *View/Edit Settings*를 클릭합니다.
+
풀 설정 대화 상자가 나타납니다.

. *설정* 탭을 선택한 다음 필요에 따라 풀 설정을 편집하세요.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
이름
 a| 
사용자가 지정한 풀 이름을 변경할 수 있습니다. 풀 이름을 지정하는 것은 필수입니다.



 a| 
용량 알림
 a| 
풀의 여유 용량이 지정된 임계값에 도달하거나 초과할 경우 알림을 보낼 수 있습니다. 풀에 저장된 데이터가 지정된 임계값을 초과하면 System Manager가 메시지를 보내므로 스토리지 공간을 추가하거나 불필요한 개체를 삭제할 시간을 확보할 수 있습니다.

경고는 대시보드의 알림 영역에 표시되며 서버에서 관리자에게 이메일 및 SNMP 트랩 메시지로 전송될 수 있습니다.

다음과 같은 용량 알림을 정의할 수 있습니다.

** *심각 경고* -- 이 심각 경고는 풀의 여유 용량이 지정된 임계값에 도달하거나 초과할 때 알려줍니다. 스피너 컨트롤을 사용하여 임계값 비율을 조정할 수 있습니다. 이 알림을 비활성화하려면 확인란을 선택하십시오.
** *조기 알림* -- 이 조기 알림은 풀의 여유 용량이 지정된 임계값에 도달하면 알려줍니다. 스피너 컨트롤을 사용하여 임계값 비율을 조정할 수 있습니다. 이 알림을 비활성화하려면 확인란을 선택하십시오.




 a| 
수정 우선순위
 a| 
시스템 성능을 기준으로 풀의 수정 작업에 대한 우선순위 수준을 지정할 수 있습니다. 풀 내 수정 작업의 우선순위가 높을수록 작업 완료 속도는 빨라지지만 호스트 I/O 성능이 저하될 수 있습니다. 우선순위가 낮을수록 작업 시간은 길어지지만 호스트 I/O 성능에 미치는 영향은 적습니다.

우선순위는 최저, 낮음, 중간, 높음, 최고의 다섯 가지 중에서 선택할 수 있습니다. 우선순위가 높을수록 호스트 I/O 및 시스템 성능에 미치는 영향이 커집니다.

** *중요 재구성 우선순위* -- 이 슬라이더 막대는 여러 드라이브 장애로 인해 일부 데이터에 이중화가 없고 추가 드라이브 장애로 인해 데이터가 손실될 수 있는 상황에서 데이터 재구성 작업의 우선순위를 결정합니다.
** *성능 저하 재구성 우선순위* -- 이 슬라이더 막대는 드라이브 장애가 발생했지만 데이터에 여전히 이중화가 있고 추가 드라이브 장애로 인해 데이터 손실이 발생하지 않는 경우 데이터 재구성 작업의 우선순위를 결정합니다.
** *백그라운드 작업 우선순위* -- 이 슬라이더 막대는 풀이 최적 상태에 있을 때 발생하는 풀 백그라운드 작업의 우선순위를 결정합니다. 이러한 작업에는 Dynamic Volume Expansion(DVE), Instant Availability Format(IAF) 및 교체 또는 추가된 드라이브로의 데이터 마이그레이션이 포함됩니다.




 a| 
보존 용량(EF600 또는 EF300의 경우 "최적화 용량")
 a| 
*보존 용량* -- 드라이브 개수를 정의하여 잠재적인 드라이브 장애를 지원하기 위해 풀에 예약된 용량을 결정할 수 있습니다. 드라이브 장애가 발생하면 보존 용량을 사용하여 재구성된 데이터를 보관합니다. 풀은 볼륨 그룹에서 사용되는 핫 스페어 드라이브 대신 데이터 재구성 프로세스 중에 보존 용량을 사용합니다.

스피너 컨트롤을 사용하여 드라이브 수를 조정합니다. 드라이브 수에 따라 풀의 보존 용량이 스피너 상자 옆에 표시됩니다.

보존 용량에 대해 다음 정보를 유념하십시오.

** 보존 용량은 풀의 총 사용 가능한 용량에서 차감되므로 예약하는 용량의 양은 볼륨 생성에 사용할 수 있는 사용 가능한 용량에 영향을 미칩니다. 보존 용량을 0으로 지정하면 풀의 모든 사용 가능한 용량이 볼륨 생성에 사용됩니다.
** 보존 용량을 줄이면 풀 볼륨에 사용할 수 있는 용량이 늘어납니다.


*추가 최적화 용량* (EF600 및 EF300 어레이에만 해당) -- 풀을 생성할 때 사용 가능한 용량과 성능 및 드라이브 수명 간의 균형을 제공하는 권장 최적화 용량이 생성됩니다. 슬라이더를 오른쪽으로 이동하면 사용 가능한 용량이 증가하는 대신 성능과 드라이브 수명이 향상되고, 왼쪽으로 이동하면 성능과 드라이브 수명이 향상되는 대신 사용 가능한 용량이 증가합니다.

SSD 드라이브는 용량의 일부가 할당되지 않은 상태일 때 수명이 연장되고 최대 쓰기 성능이 향상됩니다. 풀에 연결된 드라이브의 경우, 할당되지 않은 용량은 풀의 보존 용량, 사용 가능한 용량(볼륨에서 사용되지 않는 용량), 그리고 추가 최적화 용량으로 할당된 사용 가능 용량의 일부로 구성됩니다. 추가 최적화 용량은 사용 가능 용량을 줄여 최소한의 최적화 용량을 확보하는 역할을 하며, 따라서 볼륨 생성에는 사용할 수 없습니다.

|===
