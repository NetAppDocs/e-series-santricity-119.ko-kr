= SANtricity System Manager에서 풀 또는 볼륨 그룹을 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
풀 또는 볼륨 그룹을 삭제하여 할당되지 않은 용량을 더 확보할 수 있으며, 이를 재구성하여 애플리케이션 스토리지 요구 사항을 충족할 수 있습니다.

.시작하기 전에
* 풀 또는 볼륨 그룹에 있는 모든 볼륨의 데이터를 백업해야 합니다.
* 모든 입출력(I/O)을 중지해야 합니다.
* 해당 볼륨의 모든 파일 시스템을 마운트 해제해야 합니다.
* 풀 또는 볼륨 그룹에서 미러링 관계를 삭제해야 합니다.
* 풀 또는 볼륨 그룹에 대해 진행 중인 볼륨 복사본 작업을 중지했을 것입니다.
* 풀 또는 볼륨 그룹은 비동기 미러링 작업에 참여하고 있지 않아야 합니다.
* 볼륨 그룹의 드라이브에는 영구 예약이 없어야 합니다.


.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 목록에서 풀 또는 볼륨 그룹 하나를 선택하십시오.
+
한 번에 하나의 풀 또는 볼륨 그룹만 선택할 수 있습니다. 목록을 아래로 스크롤하면 추가 풀 또는 볼륨 그룹을 볼 수 있습니다.

. 메뉴: 일반적이지 않은 작업[삭제]를 선택하고 확인합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 풀 또는 볼륨 그룹의 모든 데이터를 삭제합니다.
* 풀 또는 볼륨 그룹과 연결된 모든 드라이브를 삭제합니다.
* 연결된 드라이브의 할당을 해제하여 새 풀 또는 기존 풀이나 볼륨 그룹에서 해당 드라이브를 재사용할 수 있습니다.
