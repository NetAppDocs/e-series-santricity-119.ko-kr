= SANtricity System Manager에서 호스트 클러스터를 생성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
두 개 이상의 호스트가 동일한 볼륨에 대한 I/O 액세스가 필요한 경우 호스트 클러스터를 생성합니다.

.이 작업 정보
호스트 클러스터를 생성할 때 다음 지침을 염두에 두십시오.

* 이 작업은 클러스터를 생성할 수 있는 호스트가 두 개 이상 있어야 시작됩니다.
* 호스트 클러스터의 호스트는 서로 다른 운영 체제(이기종)를 사용할 수 있습니다.
* 호스트 클러스터의 NVMe 호스트는 비 NVMe 호스트와 혼합할 수 없습니다.
* DA(Data Assurance) 지원 볼륨을 생성하려면 사용하려는 호스트 연결이 DA를 지원해야 합니다.
+
스토리지 어레이의 컨트롤러에 있는 호스트 연결 중 하나라도 DA를 지원하지 않으면 해당 호스트는 DA가 활성화된 볼륨의 데이터에 액세스할 수 없습니다.

* 선택한 이름이 이미 사용 중인 경우 이 작업은 성공하지 않습니다.
* 이름의 길이는 30자를 초과할 수 없습니다.


.단계
. 메뉴:Storage[Hosts]를 선택합니다.
. 메뉴: 생성[호스트 클러스터]를 선택합니다.
+
Create Host Cluster 대화 상자가 나타납니다.

. 호스트 클러스터에 적합한 설정을 선택하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
이름
 a| 
새 호스트 클러스터의 이름을 입력하십시오.



 a| 
볼륨 액세스를 공유할 호스트를 선택합니다
 a| 
드롭다운 목록에서 두 개 이상의 호스트를 선택하십시오. 호스트 클러스터에 이미 속해 있지 않은 호스트만 목록에 표시됩니다.

|===
====
. *Create*를 클릭합니다.
+
선택한 호스트가 서로 다른 Data Assurance(DA) 기능을 가진 인터페이스 유형에 연결된 경우, 호스트 클러스터에서 DA를 사용할 수 없다는 메시지가 포함된 대화 상자가 나타납니다. 이렇게 사용할 수 없으면 DA가 활성화된 볼륨을 호스트 클러스터에 추가할 수 없습니다. 계속하려면 *Yes*를 선택하고 취소하려면 *No*를 선택하십시오.

+
DA는 전체 스토리지 시스템에서 데이터 무결성을 향상시킵니다. DA를 사용하면 스토리지 어레이가 호스트와 드라이브 간에 데이터가 이동할 때 발생할 수 있는 오류를 검사할 수 있습니다. 새 볼륨에 DA를 사용하면 모든 오류를 감지할 수 있습니다.
