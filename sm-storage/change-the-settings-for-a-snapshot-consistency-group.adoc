= SANtricity System Manager에서 스냅샷 일관성 그룹의 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 일관성 그룹의 이름, 자동 삭제 설정 또는 허용되는 최대 스냅샷 이미지 수를 변경하려면 해당 그룹의 설정을 변경하십시오.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. * Snapshot 일관성 그룹* 탭을 클릭합니다.
. 편집할 스냅샷 일관성 그룹을 선택한 다음 *설정 보기/편집*을 클릭합니다.
+
스냅샷 일관성 그룹 설정 대화 상자가 나타납니다.

. 필요에 따라 스냅샷 일관성 그룹의 설정을 변경하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
*스냅샷 정합성 보장 그룹 설정*



 a| 
이름
 a| 
스냅샷 일관성 그룹의 이름을 변경할 수 있습니다.



 a| 
자동 삭제
 a| 
지정된 제한 후 스냅샷 이미지가 자동으로 삭제되도록 하려면 확인란을 선택한 상태로 유지하십시오. 스피너 상자를 사용하여 제한을 변경하십시오. 이 확인란을 선택 취소하면 스냅샷 이미지 생성이 32개 이미지 이후 중단됩니다.



 a| 
스냅샷 이미지 제한
 a| 
스냅샷 그룹에 허용되는 최대 스냅샷 이미지 수를 변경할 수 있습니다.



 a| 
스냅샷 일정
 a| 
이 필드는 일정이 스냅샷 일관성 그룹과 연결되어 있는지 여부를 나타냅니다.



 a| 
*연결된 객체*



 a| 
구성원 볼륨
 a| 
스냅샷 일관성 그룹과 연결된 구성원 볼륨의 수량을 볼 수 있습니다.

|===
====
. *저장*을 클릭합니다.
