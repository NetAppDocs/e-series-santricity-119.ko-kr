= SANtricity System Manager에서 볼륨의 컨트롤러 소유권을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨의 기본 컨트롤러 소유권을 변경하여 호스트 애플리케이션의 I/O가 새 경로를 통해 전달되도록 할 수 있습니다.

.시작하기 전에
다중 경로 드라이버를 사용하지 않는 경우, 현재 해당 볼륨을 사용 중인 호스트 애플리케이션을 모두 종료해야 합니다. 이렇게 하면 I/O 경로가 변경될 때 발생하는 애플리케이션 오류를 방지할 수 있습니다.

.이 작업 정보
풀 또는 볼륨 그룹에서 하나 이상의 볼륨에 대한 컨트롤러 소유권을 변경할 수 있습니다.

.단계
. 메뉴: Storage[Volumes]를 선택합니다.
. 볼륨을 선택한 다음 메뉴: 추가[소유권 변경]를 선택합니다.
+
볼륨 소유권 변경 대화 상자가 나타납니다. 이 대화 상자에는 스토리지 어레이의 모든 볼륨이 표시됩니다.

. 변경하려는 각 볼륨에 대해 기본 컨트롤러를 변경하려면 *기본 소유자* 드롭다운 목록을 사용하고 작업을 수행할지 확인하십시오.


.결과
* System Manager가 볼륨의 컨트롤러 소유권을 변경합니다. 이제 볼륨에 대한 I/O는 이 I/O 경로를 통해 처리됩니다.
* 다중 경로 드라이버가 새 경로를 인식하도록 재구성될 때까지 볼륨이 새 I/O 경로를 사용하지 않을 수 있습니다. 이 작업은 일반적으로 5분 이내에 완료됩니다.
