= SANtricity System Manager에서 SSD Cache를 생성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
시스템 성능을 동적으로 가속화하려면 SSD Cache 기능을 사용하여 가장 자주 액세스하는 데이터("핫" 데이터)를 지연 시간이 짧은 SSD(Solid State Drive)에 캐시할 수 있습니다. SSD Cache는 호스트 읽기 작업에만 사용됩니다.

.시작하기 전에
스토리지 어레이에는 일부 SSD 드라이브가 포함되어 있어야 합니다.

.이 작업 정보
새로운 SSD 캐시를 생성할 때 단일 드라이브 또는 여러 드라이브를 사용할 수 있습니다. 읽기 캐시는 스토리지 어레이에 있으므로 스토리지 어레이를 사용하는 모든 애플리케이션에서 캐싱을 공유할 수 있습니다. 캐싱할 볼륨을 선택하면 캐싱이 자동으로 동적으로 수행됩니다.

새 SSD Cache를 생성할 때는 다음 지침을 따르십시오.

* SSD 캐시에 대한 보안은 캐시를 생성할 때만 활성화할 수 있으며 나중에는 활성화할 수 없습니다.
* 스토리지 어레이당 하나의 SSD 캐시만 지원됩니다.
* 하나의 볼륨에만 SSD 캐시가 활성화되어 있는 경우 전체 SSD 캐시가 해당 볼륨을 소유한 컨트롤러에 할당됩니다.
* 스토리지 어레이에서 사용 가능한 최대 SSD Cache 용량은 컨트롤러의 기본 캐시 용량에 따라 달라집니다.
* 스냅샷 이미지에서는 SSD Cache가 지원되지 않습니다.
* SSD 캐시가 활성화되었거나 비활성화된 볼륨을 가져오거나 내보낼 경우 캐시된 데이터는 가져오거나 내보내지 않습니다.
* 컨트롤러의 SSD Cache를 사용하도록 할당된 볼륨은 자동 로드 밸런스 전송 대상이 아닙니다.
* 연결된 볼륨이 보안 기능이 활성화된 경우 보안 기능이 활성화된 SSD Cache를 생성하십시오.


.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 메뉴: 생성[SSD 캐시]를 클릭합니다.
+
SSD 캐시 생성 대화 상자가 나타납니다.

. SSD Cache의 이름을 입력합니다.
. 다음 특성을 기준으로 사용할 SSD Cache 후보를 선택하십시오.
+
[cols="25h,~"]
|===
| 특성 | 사용 


 a| 
용량
 a| 
사용 가능한 용량을 GiB 단위로 표시합니다. 애플리케이션의 스토리지 요구 사항에 맞는 용량을 선택하십시오.

SSD Cache의 최대 용량은 컨트롤러의 기본 캐시 용량에 따라 달라집니다. 최대 용량보다 더 많은 용량을 SSD Cache에 할당하면 초과 용량은 사용할 수 없습니다.

SSD Cache 용량은 전체 할당된 용량에 포함됩니다.



 a| 
총 드라이브
 a| 
이 SSD 캐시에 사용 가능한 드라이브 수를 표시합니다. 원하는 드라이브 수를 가진 SSD 후보를 선택하십시오.



 a| 
보안 가능
 a| 
SSD Cache 후보가 보안 기능을 갖춘 드라이브(FDE(Full Disk Encryption) 드라이브 또는 FIPS(Federal Information Processing Standard) 드라이브)로만 구성되어 있는지 여부를 나타냅니다.

보안 기능이 활성화된 SSD Cache를 생성하려면 보안 기능 열에서 *예 - FDE* 또는 *예 - FIPS*를 찾으십시오.



 a| 
보안을 활성화하시겠습니까?
 a| 
보안 기능을 지원하는 드라이브에서 드라이브 보안 기능을 활성화할 수 있는 옵션을 제공합니다. 보안 기능이 활성화된 SSD 캐시를 생성하려면 Enable Security 확인란을 선택합니다.

[NOTE]
====
보안 기능은 한 번 활성화하면 비활성화할 수 없습니다. SSD 캐시의 보안은 캐시를 생성할 때만 활성화할 수 있으며, 이후에는 활성화할 수 없습니다.

====


 a| 
DA 지원
 a| 
이 SSD 캐시 후보에 Data Assurance(DA) 기능이 사용 가능한지 여부를 나타냅니다. Data Assurance(DA)는 데이터가 컨트롤러를 거쳐 드라이브로 전송되는 동안 발생할 수 있는 오류를 검사하고 수정합니다.

DA를 사용하려면 DA를 지원하는 SSD Cache 후보를 선택하십시오. 이 옵션은 DA 기능이 활성화된 경우에만 사용할 수 있습니다.

SSD Cache에는 DA 지원 드라이브와 DA 비지원 드라이브가 모두 포함될 수 있지만 DA를 사용하려면 모든 드라이브가 DA 지원이어야 합니다.

|===
. SSD 읽기 캐싱을 구현하려는 볼륨에 SSD 캐시를 연결하십시오. 호스트에 매핑된 기존 호환 볼륨에서 SSD 캐시를 즉시 활성화하려면 *호스트에 매핑된 기존 호환 볼륨에서 SSD 캐시 활성화* 확인란을 선택하십시오.
+
볼륨은 동일한 Drive Security 및 DA 기능을 공유하는 경우 호환됩니다.

. *Create*를 클릭합니다.
