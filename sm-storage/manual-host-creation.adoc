[role="lead"]
호스트 생성은 스토리지 어레이에 연결된 호스트를 알리고 볼륨에 대한 I/O 액세스를 허용하는 데 필요한 단계 중 하나입니다. 호스트는 수동으로만 생성할 수 있습니다.



== 수동 생성

수동 호스트 생성을 통해 스토리지 어레이 컨트롤러에서 감지된 호스트 포트 식별자가 호스트와 올바르게 연결되도록 할 수 있습니다.

호스트를 수동으로 생성할 때, 목록에서 선택하거나 직접 입력하여 호스트 포트 식별자를 연결합니다. 호스트를 생성한 후에는 볼륨을 할당하거나, 볼륨에 대한 액세스를 공유하려는 경우 호스트 클러스터에 추가할 수 있습니다.
