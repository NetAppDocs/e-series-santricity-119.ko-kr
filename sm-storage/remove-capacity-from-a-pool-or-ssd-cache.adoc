= SANtricity System Manager에서 풀 또는 SSD Cache의 용량을 제거합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
드라이브를 제거하여 기존 풀 또는 SSD Cache의 용량을 줄일 수 있습니다.

드라이브를 제거하면 풀 또는 SSD 캐시의 각 볼륨에 있는 데이터가 나머지 드라이브로 재분배됩니다. 제거된 드라이브는 할당 해제되고 해당 용량은 스토리지 어레이의 전체 사용 가능한 용량에 포함됩니다.

.이 작업 정보
용량을 제거할 때는 다음 지침을 따르십시오.

* SSD Cache를 먼저 삭제하지 않고는 SSD Cache의 마지막 드라이브를 제거할 수 없습니다.
* 풀의 드라이브 수를 11개 미만으로 줄일 수 없습니다.
* 한 번에 최대 12개의 드라이브를 제거할 수 있습니다. 12개 이상의 드라이브를 제거해야 하는 경우 절차를 반복하십시오.
* 풀 또는 SSD Cache에 데이터를 포함할 수 있는 충분한 여유 용량이 없는 경우, 해당 데이터가 풀 또는 SSD Cache의 나머지 드라이브로 재분배될 때 드라이브를 제거할 수 없습니다.


.잠재적인 성능 영향에 대해 알아보십시오
[%collapsible]
====
* 풀 또는 SSD Cache에서 드라이브를 제거하면 볼륨 성능이 저하될 수 있습니다.
* 풀 또는 SSD Cache에서 용량을 제거해도 보존 용량은 소모되지 않습니다. 단, 풀 또는 SSD Cache에 남아 있는 드라이브 수에 따라 보존 용량이 감소할 수 있습니다.


====
.보안 기능이 있는 드라이브에 미치는 영향에 대해 알아보십시오
[%collapsible]
====
* 보안 기능을 지원하지 않는 마지막 드라이브를 제거하면 풀에는 보안 기능을 지원하는 드라이브만 남게 됩니다. 이 경우 풀에 대한 보안을 활성화하는 옵션이 제공됩니다.
* 데이터 보증(DA) 기능을 지원하지 않는 마지막 드라이브를 제거하면 풀에는 DA 기능을 지원하는 드라이브만 남게 됩니다.



NOTE: 풀에 새로 생성하는 볼륨은 모두 DA 지원이 가능합니다. 기존 볼륨을 DA 지원이 가능하도록 하려면 해당 볼륨을 삭제한 후 다시 생성해야 합니다.

====
.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 풀 또는 SSD 캐시를 선택한 다음 menu:More[Remove capacity]를 클릭합니다.
+
용량 제거 대화 상자가 나타납니다.

. 목록에서 하나 이상의 드라이브를 선택하십시오.
+
목록에서 드라이브를 선택하거나 선택 해제하면 *선택한 총 용량* 필드가 업데이트됩니다. 이 필드는 선택한 드라이브를 제거한 후 생성되는 풀 또는 SSD Cache의 총 용량을 보여줍니다.

. *제거*를 클릭한 다음 드라이브를 제거할 것인지 확인합니다.
+
풀 또는 SSD Cache의 새로 감소된 용량은 풀 및 볼륨 그룹 보기에 반영됩니다.
