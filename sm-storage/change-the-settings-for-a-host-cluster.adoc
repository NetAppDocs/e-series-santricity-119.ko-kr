= SANtricity System Manager에서 호스트 클러스터 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트 클러스터 이름을 변경하거나 호스트 클러스터에 호스트를 추가 또는 제거할 수 있습니다.

.단계
. 메뉴:Storage[Hosts]를 선택합니다.
. 편집할 호스트 클러스터를 선택한 다음 *설정 보기/편집*을 클릭합니다.
+
현재 호스트 클러스터 설정을 보여주는 대화 상자가 나타납니다.

. 호스트 클러스터 설정을 필요에 따라 변경하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
이름
 a| 
사용자가 직접 지정한 호스트 클러스터 이름을 사용할 수 있습니다. 클러스터 이름을 지정하는 것은 필수입니다.



 a| 
연결된 호스트
 a| 
호스트를 추가하려면 *연결된 호스트* 상자를 클릭한 다음 드롭다운 목록에서 호스트 이름을 선택하십시오. 호스트 이름을 수동으로 입력할 수 없습니다.

호스트를 삭제하려면 호스트 이름 옆에 있는 *X*를 클릭합니다.

|===
====
. *저장*을 클릭합니다.
