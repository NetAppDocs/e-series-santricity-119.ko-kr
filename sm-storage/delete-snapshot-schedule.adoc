= SANtricity System Manager에서 스냅샷 스케줄을 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 이미지 수집을 더 이상 원하지 않는 경우 기존 스냅샷 스케줄을 삭제할 수 있습니다.

.이 작업 정보
스냅샷 일정을 삭제해도 연결된 스냅샷 이미지는 함께 삭제되지 않습니다. 스냅샷 이미지 수집을 나중에 다시 시작할 가능성이 있는 경우 스냅샷 일정을 삭제하는 대신 일시 중지해야 합니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *일정* 탭을 클릭합니다.
. 삭제할 스냅샷 스케줄을 선택하고 작업을 확인합니다.


.결과
이 시스템은 기본 볼륨 또는 스냅샷 일관성 그룹에서 모든 스케줄 속성을 제거합니다.
