= SANtricity System Manager에서 풀 또는 볼륨 그룹에 대한 보안을 활성화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
풀 또는 볼륨 그룹에 드라이브 보안을 활성화하면 해당 풀 또는 볼륨 그룹에 포함된 드라이브의 데이터에 대한 무단 액세스를 방지할 수 있습니다. 드라이브에 대한 읽기 및 쓰기 액세스는 보안 키로 구성된 컨트롤러를 통해서만 가능합니다.

.시작하기 전에
* 드라이브 보안 기능을 활성화해야 합니다.
* 보안 키를 생성해야 합니다.
* 풀 또는 볼륨 그룹은 최적 상태여야 합니다.
* 풀 또는 볼륨 그룹의 모든 드라이브는 보안 가능 드라이브여야 합니다.


.이 작업 정보
Drive Security를 사용하려면 보안 기능을 지원하는 풀 또는 볼륨 그룹을 선택하십시오. 풀 또는 볼륨 그룹에는 보안 기능을 지원하는 드라이브와 지원하지 않는 드라이브가 모두 포함될 수 있지만, 암호화 기능을 사용하려면 모든 드라이브가 보안 기능을 지원해야 합니다.

보안 기능을 활성화한 후에는 풀 또는 볼륨 그룹을 삭제하고 드라이브를 지우는 방법으로만 보안 기능을 제거할 수 있습니다.

.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 보안을 활성화할 풀 또는 볼륨 그룹을 선택한 다음 menu:More[Enable security]를 클릭합니다.
+
보안 활성화 확인 대화 상자가 나타납니다.

. 선택한 풀 또는 볼륨 그룹에 대한 보안을 활성화할 것인지 확인한 다음 *Enable*을 클릭합니다.
