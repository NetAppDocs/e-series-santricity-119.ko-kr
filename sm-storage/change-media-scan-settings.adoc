= SANtricity System Manager에서 볼륨의 미디어 스캔 설정을 변경합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미디어 검사는 볼륨의 모든 데이터와 중복 정보를 검사하는 백그라운드 작업입니다. 이 옵션을 사용하여 하나 이상의 볼륨에 대한 미디어 검사 설정을 활성화 또는 비활성화하거나 검사 기간을 변경할 수 있습니다.

.시작하기 전에
다음 사항을 이해하십시오.

* 미디어 스캔은 스캔할 용량과 스캔 기간을 기준으로 일정한 속도로 지속적으로 실행됩니다. 백그라운드 스캔은 우선순위가 높은 백그라운드 작업(예: 재구성)에 의해 일시적으로 중단될 수 있지만 동일한 일정한 속도로 재개됩니다.
* 볼륨 검사는 스토리지 어레이와 해당 볼륨에 대해 미디어 검사 옵션이 활성화된 경우에만 수행됩니다. 해당 볼륨에 대해 중복 검사도 활성화된 경우, 볼륨에 중복성이 있는 경우 해당 볼륨의 중복 정보가 데이터와의 일관성을 검사합니다. 중복 검사를 포함한 미디어 검사는 각 볼륨이 생성될 때 기본적으로 활성화됩니다.
* 스캔 중 복구할 수 없는 매체 오류가 발생하면 사용 가능한 경우 중복 정보를 사용하여 데이터를 복구합니다.
+
예를 들어, 최적 RAID 5 볼륨 또는 최적 RAID 6 볼륨이나 드라이브 하나만 장애가 발생한 RAID 6 볼륨에서 이중화 정보를 사용할 수 있습니다. 이중화 정보를 사용하여 복구할 수 없는 오류를 복구할 수 없는 경우 데이터 블록이 읽을 수 없는 섹터 로그에 추가됩니다. 수정 가능한 미디어 오류와 수정 불가능한 미디어 오류가 모두 이벤트 로그에 보고됩니다.

+
중복성 검사에서 데이터와 중복성 정보 간에 불일치가 발견되면 이벤트 로그에 보고됩니다.




NOTE: 기본 미디어 검사 주기는 120일로 설정되어 있습니다.

.이 작업 정보
미디어 검사는 애플리케이션에서 자주 읽지 않는 디스크 블록의 미디어 오류를 감지하고 복구합니다. 이를 통해 드라이브 장애 발생 시 데이터 손실을 방지할 수 있습니다. 장애가 발생한 드라이브의 데이터는 중복 정보와 볼륨 그룹 또는 풀에 있는 다른 드라이브의 데이터를 사용하여 재구성됩니다.

다음 작업을 수행할 수 있습니다.

* 전체 스토리지 어레이에 대한 백그라운드 미디어 스캔 활성화 또는 비활성화
* 전체 스토리지 어레이의 스캔 기간을 변경합니다
* 하나 이상의 볼륨에 대해 미디어 스캔을 활성화 또는 비활성화합니다
* 하나 이상의 볼륨에 대한 이중화 검사를 활성화 또는 비활성화합니다


.단계
. 메뉴: Storage[Volumes]를 선택합니다.
. 볼륨을 선택한 다음 메뉴: 추가[미디어 스캔 설정 변경]를 선택합니다.
+
드라이브 미디어 스캔 설정 변경 대화 상자가 나타납니다. 이 대화 상자에는 스토리지 어레이의 모든 볼륨이 표시됩니다.

. 미디어 스캔을 활성화하려면 *...기간 동안 미디어 스캔* 확인란을 선택합니다.
+
미디어 스캔 확인란을 비활성화하면 모든 미디어 스캔 설정이 일시 중지됩니다.

. 미디어 검사를 실행할 기간(일)을 지정하십시오.
. 미디어 검사를 수행할 각 볼륨에 대해 *미디어 검사* 확인란을 선택하십시오.
+
System Manager는 미디어 검사를 실행하도록 선택한 각 볼륨에 대해 중복 검사 옵션을 활성화합니다. 중복 검사를 수행하지 않으려는 개별 볼륨이 있는 경우 *중복 검사* 확인란을 선택 취소합니다.

. *저장*을 클릭합니다.
+
System Manager는 사용자의 선택에 따라 백그라운드 미디어 스캔에 변경 사항을 적용합니다.
