= SANtricity 소프트웨어에서 예약된 용량이 작동하는 방식
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 또는 비동기식 미러링 작업과 같은 복사 서비스 작업이 볼륨에 대해 제공될 때 예약된 용량이 자동으로 생성됩니다.

예약 용량의 목적은 문제가 발생할 경우 해당 볼륨의 데이터 변경 사항을 저장하는 것입니다. 볼륨과 마찬가지로 예약 용량은 풀 또는 볼륨 그룹에서 생성됩니다.



[[copy-service-objects-that-use-reserved-capacity]]
== 예약된 용량을 사용하는 복사 서비스 개체

예약된 용량은 다음 복사 서비스 객체에서 사용하는 기본 스토리지 메커니즘입니다.

* 스냅샷 그룹
* 읽기/쓰기 스냅샷 볼륨
* 일관성 그룹 구성원 볼륨
* 미러링된 쌍 볼륨


이러한 복사 서비스 객체를 생성하거나 확장할 때는 풀 또는 볼륨 그룹에서 새 예약 용량을 생성해야 합니다. 예약 용량은 일반적으로 스냅샷 작업의 경우 기본 볼륨의 40%, 비동기 미러링 작업의 경우 기본 볼륨의 20%입니다. 단, 예약 용량은 원본 데이터의 변경 횟수에 따라 달라집니다.



[[thin-volumes-and-reserved-capacity]]
== 씬 볼륨 및 예약된 용량

씬 볼륨의 경우 보고된 최대 용량인 256TiB에 도달하면 용량을 늘릴 수 없습니다. 씬 볼륨의 예약된 용량이 보고된 최대 용량보다 큰 크기로 설정되어 있는지 확인하십시오. (씬 볼륨은 항상 씬 프로비저닝되며, 이는 데이터가 볼륨에 기록될 때 용량이 할당됨을 의미합니다.)

풀에서 씬 볼륨을 사용하여 예약된 용량을 생성하는 경우 예약된 용량에 대한 다음 작업 및 결과를 검토하십시오.

* 씬 볼륨의 예약된 용량에 장애가 발생해도 씬 볼륨 자체는 자동으로 장애 상태로 전환되지 않습니다. 그러나 씬 볼륨의 모든 I/O 작업에는 예약된 용량 볼륨에 대한 액세스가 필요하므로 I/O 작업은 항상 요청 호스트에 검사 조건이 반환됩니다. 예약된 용량 볼륨의 근본적인 문제가 해결되면 예약된 용량 볼륨은 최적 상태로 복구되고 씬 볼륨은 다시 정상적으로 작동합니다.
* 기존 씬 볼륨을 사용하여 비동기 미러링 쌍을 완성하는 경우, 해당 씬 볼륨은 새 예약 용량 볼륨으로 다시 초기화됩니다. 초기 동기화 프로세스 중에는 운영 측에서 프로비저닝된 블록만 전송됩니다.




[[capacity-alerts]]
== 용량 알림

복사 서비스 객체에는 구성 가능한 용량 경고 및 알림 임계값과 예약된 용량이 가득 찼을 때 구성 가능한 응답이 있습니다.

복사 서비스 객체 볼륨의 예약된 용량이 거의 다 차면 사용자에게 알림이 표시됩니다. 기본적으로 이 알림은 예약된 용량 볼륨이 75% 찼을 때 표시되지만 필요에 따라 이 알림 지점을 위 또는 아래로 조정할 수 있습니다. 이 알림을 받으면 해당 시점에 예약된 용량 볼륨의 용량을 늘릴 수 있습니다. 각 복사 서비스 객체는 이와 관련하여 독립적으로 구성할 수 있습니다.



[[orphaned-reserved-capacity-volumes]]
== 분리된 예약된 용량 볼륨

연결되지 않은 예약 용량 볼륨은 연결된 복사 서비스 객체가 삭제되어 더 이상 복사 서비스 작업에 필요한 데이터를 저장하지 않는 볼륨입니다. 복사 서비스 객체가 삭제될 때 해당 예약 용량 볼륨도 함께 삭제되어야 했습니다. 그러나 예약 용량 볼륨 삭제에 실패했습니다.

고아 예약 용량 볼륨은 호스트에서 액세스하지 않으므로 재확보 대상입니다. 고아 예약 용량 볼륨을 수동으로 삭제하여 다른 작업에 해당 용량을 사용할 수 있도록 하십시오.

System Manager는 홈 페이지의 알림 영역에 "사용되지 않는 용량 회수" 메시지를 표시하여 고아 예약 용량 볼륨이 있음을 알려줍니다. *사용되지 않는 용량 회수*를 클릭하면 사용되지 않는 용량 회수 대화 상자가 나타나고, 여기에서 고아 예약 용량 볼륨을 삭제할 수 있습니다.



[[characteristics-of-reserved-capacity]]
== 예약된 용량의 특징

* 충분한 여유 용량을 유지하려면 볼륨 생성 중에 예약된 용량에 할당된 용량을 고려해야 합니다.
* 예약된 용량은 기본 볼륨보다 작을 수 있습니다(최소 크기는 8MiB입니다).
* 일부 공간은 메타데이터에 의해 소비되지만 그 양은 매우 적기 때문에(192 KiB) 예약된 용량 볼륨의 크기를 결정할 때 고려할 필요가 없습니다.
* 예약된 용량은 호스트에서 직접 읽거나 쓸 수 없습니다.
* 각 읽기/쓰기 스냅샷 볼륨, 스냅샷 그룹, 일관성 그룹 구성원 볼륨 및 미러링된 쌍 볼륨에 대해 예약된 용량이 존재합니다.
