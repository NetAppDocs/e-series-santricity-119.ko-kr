= SANtricity System Manager에서 볼륨 그룹의 구성 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이름 및 RAID 레벨을 포함하여 볼륨 그룹의 설정을 편집할 수 있습니다.

.시작하기 전에
볼륨 그룹에 액세스하는 애플리케이션의 성능 요구 사항을 수용하기 위해 RAID 레벨을 변경하는 경우 다음 사전 요구 사항을 충족해야 합니다.

* 볼륨 그룹은 최적 상태여야 합니다.
* 새로운 RAID 레벨로 변환하려면 볼륨 그룹에 충분한 용량이 있어야 합니다.


.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 편집할 볼륨 그룹을 선택한 다음 *설정 보기/편집*을 클릭합니다.
+
볼륨 그룹 설정 대화 상자가 나타납니다.

. *설정* 탭을 선택한 다음 필요에 따라 볼륨 그룹 설정을 편집합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
이름
 a| 
볼륨 그룹에 사용자가 지정한 이름을 변경할 수 있습니다. 볼륨 그룹에 이름을 지정하는 것은 필수입니다.



 a| 
RAID 레벨
 a| 
드롭다운 메뉴에서 새 RAID 레벨을 선택하십시오.

** *RAID 0 스트라이핑* -- 높은 성능을 제공하지만 데이터 이중화는 제공하지 않습니다. 볼륨 그룹에서 단일 드라이브에 장애가 발생하면 연결된 모든 볼륨이 작동을 멈추고 모든 데이터가 손실됩니다. 스트라이핑 RAID 그룹은 두 개 이상의 드라이브를 하나의 큰 논리 드라이브로 결합합니다.
** *RAID 1 미러링* -- 뛰어난 성능과 최상의 데이터 가용성을 제공하며, 기업 또는 개인 수준에서 민감한 데이터를 저장하는 데 적합합니다. 미러링된 쌍의 두 번째 드라이브에 한 드라이브의 내용을 자동으로 미러링하여 데이터를 보호합니다. 단일 드라이브 장애 시 보호 기능을 제공합니다.
** *RAID 10 스트라이핑/미러링* -- RAID 0(스트라이핑)과 RAID 1(미러링)을 결합한 형태로, 4개 이상의 드라이브를 선택할 때 구현됩니다. RAID 10은 데이터베이스와 같이 높은 성능과 내결함성이 필요한 대용량 트랜잭션 애플리케이션에 적합합니다.
** *RAID 5* -- 일반적인 I/O 크기가 작고 읽기 작업 비율이 높은 다중 사용자 환경(예: 데이터베이스 또는 파일 시스템 스토리지)에 최적입니다.
** *RAID 6* -- RAID 5를 넘어서는 이중화 보호가 필요하지만 높은 쓰기 성능이 필요하지 않은 환경에 최적입니다.


RAID 3는 명령줄 인터페이스(CLI)를 사용하여 볼륨 그룹에만 할당할 수 있습니다.

RAID 레벨을 변경하는 경우, 작업이 시작되면 취소할 수 없습니다. 변경 작업 중에도 데이터는 계속 사용할 수 있습니다.



 a| 
최적화 용량(EF600 어레이만 해당)
 a| 
볼륨 그룹을 생성할 때 사용 가능한 용량과 성능 및 드라이브 마모 수명 간의 균형을 제공하는 권장 최적화 용량이 생성됩니다. 슬라이더를 오른쪽으로 이동하여 사용 가능한 용량이 증가하는 대신 성능과 드라이브 마모 수명을 향상시키거나, 왼쪽으로 이동하여 성능과 드라이브 마모 수명이 감소하는 대신 사용 가능한 용량을 늘릴 수 있습니다.

SSD 드라이브는 용량의 일부가 할당되지 않은 상태일 때 수명이 길어지고 최대 쓰기 성능이 향상됩니다. 볼륨 그룹에 연결된 드라이브의 경우, 할당되지 않은 용량은 그룹의 사용 가능한 용량(볼륨에서 사용되지 않는 용량)과 사용 가능한 용량 중 추가 최적화 용량으로 할당된 부분으로 구성됩니다. 추가 최적화 용량은 사용 가능한 용량을 줄여 최소한의 최적화 용량을 확보하는 역할을 하며, 따라서 볼륨 생성에는 사용할 수 없습니다.

|===
====
. *저장*을 클릭합니다.
+
RAID 레벨 변경으로 인해 용량이 줄어들거나, 볼륨 이중화가 손실되거나, 셸프/드로어 손실 보호 기능이 상실될 경우 확인 대화 상자가 나타납니다. 계속하려면 *Yes*를 선택하고, 그렇지 않으면 *No*를 클릭하십시오.



.결과
볼륨 그룹의 RAID 레벨을 변경하면 System Manager가 해당 볼륨 그룹을 구성하는 모든 볼륨의 RAID 레벨을 변경합니다. 작업 중에 성능이 약간 영향을 받을 수 있습니다.
