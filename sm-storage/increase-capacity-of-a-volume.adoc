= SANtricity System Manager에서 볼륨 용량을 늘립니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
풀 또는 볼륨 그룹에서 사용 가능한 여유 용량을 사용하여 볼륨의 보고된 용량(호스트에 보고된 용량)을 늘릴 수 있습니다.

.시작하기 전에
* 볼륨과 연결된 풀 또는 볼륨 그룹에 충분한 여유 용량을 사용할 수 있습니다.
* 볼륨이 최적 상태이며 수정 상태가 아닙니다.
* 보고된 최대 용량인 256TiB는 씬 볼륨에 대해 도달하지 않았습니다.
* 해당 볼륨에는 사용 중인 핫 스페어 드라이브가 없습니다. (볼륨 그룹에 속한 볼륨에만 적용됩니다.)



NOTE: 한 번에 최대 128TiB까지만 볼륨 용량을 확장할 수 있습니다.

.이 작업 정보
이 풀 또는 볼륨 그룹의 다른 볼륨에 대해 향후 필요한 용량을 고려하십시오. 스냅샷 이미지, 스냅샷 볼륨 또는 원격 미러를 생성할 수 있도록 충분한 여유 용량을 확보해야 합니다.

[NOTE]
====
볼륨 용량 확장은 특정 운영 체제에서만 지원됩니다. 지원되지 않는 호스트 운영 체제에서 볼륨 용량을 확장하면 확장된 용량을 사용할 수 없으며 원래 볼륨 용량으로 복원할 수 없습니다.

====
.단계
. 메뉴: Storage[Volumes]를 선택합니다.
. 용량을 늘릴 볼륨을 선택한 다음 *용량 늘리기*를 선택합니다.
+
용량 증가 확인 대화 상자가 나타납니다.

. 계속하려면 *예*를 선택합니다.
+
보고된 용량 증가 대화 상자가 나타납니다.

+
이 대화 상자에는 볼륨의 현재 보고된 용량과 볼륨과 연결된 풀 또는 볼륨 그룹에서 사용 가능한 여유 용량이 표시됩니다.

. *보고된 용량 증가...* 상자를 사용하여 현재 사용 가능한 보고된 용량에 용량을 추가합니다. 용량 값을 메비바이트(MiB), 기비바이트(GiB) 또는 테비바이트(TiB) 단위로 표시되도록 변경할 수 있습니다.
. *증가*를 클릭합니다.


.결과
* System Manager는 사용자의 선택에 따라 볼륨 용량을 늘립니다.
* 메뉴에서 홈[진행 중인 작업 보기]를 선택하여 선택한 볼륨에 대해 현재 실행 중인 용량 증설 작업의 진행 상황을 확인할 수 있습니다. 이 작업은 시간이 오래 걸릴 수 있으며 시스템 성능에 영향을 줄 수 있습니다.


.완료한 후
볼륨 용량을 확장한 후에는 파일 시스템 크기도 수동으로 그에 맞게 늘려야 합니다. 파일 시스템 크기 조정 방법은 사용 중인 파일 시스템에 따라 다릅니다. 자세한 내용은 호스트 운영 체제 설명서를 참조하십시오.
