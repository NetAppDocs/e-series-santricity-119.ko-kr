= SANtricity System Manager에서 볼륨의 캐시 설정을 변경합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
읽기 캐시 및 쓰기 캐시 설정을 변경하여 볼륨의 전체 I/O 성능에 영향을 줄 수 있습니다.

.이 작업 정보
볼륨의 캐시 설정을 변경할 때는 다음 지침을 염두에 두십시오.

* 캐시 설정 변경 대화 상자를 열면 선택한 캐시 속성 옆에 아이콘이 표시될 수 있습니다. 이 아이콘은 컨트롤러가 캐싱 작업을 일시적으로 중단했음을 나타냅니다.
+
이 작업은 새 배터리 충전 중일 때, 컨트롤러가 제거되었을 때 또는 컨트롤러에서 캐시 크기 불일치가 감지되었을 때 발생할 수 있습니다. 문제가 해결되면 대화 상자에서 선택한 캐시 속성이 활성화됩니다. 선택한 캐시 속성이 활성화되지 않으면 기술 지원 부서에 문의하십시오.

* 스토리지 어레이에서 단일 볼륨 또는 여러 볼륨에 대한 캐시 설정을 변경할 수 있습니다. 모든 표준 볼륨 또는 모든 씬 볼륨에 대한 캐시 설정을 동시에 변경할 수도 있습니다.


.단계
. 메뉴: Storage[Volumes]를 선택합니다.
. 볼륨을 선택한 다음 menu:More[Change cache settings]를 선택합니다.
+
캐시 설정 변경 대화 상자가 나타납니다. 이 대화 상자에는 스토리지 어레이의 모든 볼륨이 표시됩니다.

. 읽기 캐싱 및 쓰기 캐싱 설정을 변경하려면 *Basic* 탭을 선택하세요.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 캐시 설정 | 설명 


 a| 
읽기 캐싱
 a| 
읽기 캐시는 드라이브에서 읽어온 데이터를 저장하는 버퍼입니다. 읽기 작업에 필요한 데이터가 이전 작업에서 이미 캐시에 저장되어 있을 수 있으므로 드라이브에 다시 접근할 필요가 없습니다. 데이터는 캐시에서 비워질 때까지 유지됩니다.



 a| 
쓰기 캐싱
 a| 
쓰기 캐시는 호스트에서 드라이브에 아직 기록되지 않은 데이터를 저장하는 버퍼입니다. 데이터는 드라이브에 기록될 때까지 쓰기 캐시에 보관됩니다. 쓰기 캐싱은 I/O 성능을 향상시킬 수 있습니다.


NOTE: 볼륨에 대해 *쓰기 캐싱*이 비활성화되면 캐시가 자동으로 플러시됩니다.

|===
====
. 씩 볼륨에 대한 고급 설정을 변경하려면 *고급* 탭을 선택하십시오. 고급 캐시 설정은 씩 볼륨에서만 사용할 수 있습니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 캐시 설정 | 설명 


 a| 
동적 읽기 캐시 프리페치
 a| 
동적 캐시 읽기 프리페치를 사용하면 컨트롤러가 드라이브에서 캐시로 데이터 블록을 읽는 동안 추가 순차 데이터 블록을 캐시에 복사할 수 있습니다. 이 캐싱을 통해 향후 데이터 요청을 캐시에서 채울 가능성이 높아집니다. 동적 캐시 읽기 프리페치는 순차 I/O를 사용하는 멀티미디어 애플리케이션에 중요합니다. 캐시로 프리페치되는 데이터의 속도와 양은 호스트 읽기 속도 및 요청 크기에 따라 자동으로 조정됩니다. 임의 액세스로 인해 데이터가 캐시로 프리페치되지 않습니다. 이 기능은 읽기 캐싱이 비활성화된 경우 적용되지 않습니다.

씬 볼륨의 경우 동적 캐시 읽기 프리페치는 항상 비활성화되며 변경할 수 없습니다.



 a| 
배터리 없이 쓰기 캐싱
 a| 
배터리 없이 쓰기 캐싱 설정을 사용하면 배터리가 없거나, 고장났거나, 완전히 방전되었거나, 완전히 충전되지 않은 경우에도 쓰기 캐싱을 계속할 수 있습니다. 하지만 전원이 차단될 경우 데이터 손실이 발생할 수 있으므로 배터리 없이 쓰기 캐싱을 선택하는 것은 일반적으로 권장되지 않습니다. 일반적으로 컨트롤러는 배터리가 충전되거나 고장난 배터리가 교체될 때까지 쓰기 캐싱을 일시적으로 비활성화합니다.


CAUTION: *데이터 손실 가능성 있음* -- 이 옵션을 선택하고 보호용 범용 전원 공급 장치가 없는 경우 데이터가 손실될 수 있습니다. 또한 컨트롤러 배터리가 없는 상태에서 *배터리 없이 쓰기 캐싱* 옵션을 활성화하면 데이터가 손실될 수 있습니다.

이 설정은 쓰기 캐싱을 활성화한 경우에만 사용할 수 있습니다. 씬 볼륨에서는 이 설정을 사용할 수 없습니다.



 a| 
미러링을 사용한 쓰기 캐싱
 a| 
미러링을 사용한 쓰기 캐싱은 한 컨트롤러의 캐시 메모리에 기록된 데이터가 다른 컨트롤러의 캐시 메모리에도 기록될 때 발생합니다. 따라서 한 컨트롤러에 장애가 발생하면 다른 컨트롤러가 미처리된 모든 쓰기 작업을 완료할 수 있습니다. 쓰기 캐시 미러링은 쓰기 캐싱이 활성화되어 있고 두 개의 컨트롤러가 있는 경우에만 사용할 수 있습니다. 미러링을 사용한 쓰기 캐싱은 볼륨 생성 시 기본 설정입니다.

이 설정은 쓰기 캐싱을 활성화한 경우에만 사용할 수 있습니다. 씬 볼륨에서는 이 설정을 사용할 수 없습니다.

|===
====
. 캐시 설정을 변경하려면 *저장*을 클릭합니다.
