= SANtricity System Manager에서 그래픽 성능 데이터를 확인하세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
논리적 객체, 물리적 객체, 애플리케이션 및 워크로드에 대한 그래픽 성능 데이터를 볼 수 있습니다.

.이 작업 정보
성능 그래프는 기간별 데이터와 현재 수집 중인 실시간 데이터를 모두 보여줍니다. 그래프의 세로선(실시간 업데이트 중)은 기간별 데이터와 실시간 데이터를 구분합니다.

*홈 페이지 보기*

홈 페이지에는 스토리지 어레이 수준의 성능을 보여주는 그래프가 있습니다. 이 보기에서 제한된 메트릭을 선택하거나, *View Performance Details*를 클릭하여 사용 가능한 모든 메트릭을 선택할 수 있습니다.

*상세 보기*

상세 성능 보기에서 사용할 수 있는 그래프는 세 개의 탭으로 구성되어 있습니다.

* *논리적 보기* -- 볼륨 그룹 및 풀별로 그룹화된 논리적 객체의 성능 데이터를 표시합니다. 논리적 객체에는 볼륨 그룹, 풀 및 볼륨이 포함됩니다.
* *Physical View* -- 컨트롤러, 호스트 채널, 드라이브 채널 및 드라이브의 성능 데이터를 표시합니다.
* *Applications & Workloads View* -- 사용자가 정의한 애플리케이션 유형 및 워크로드별로 그룹화된 논리적 객체(볼륨) 목록을 표시합니다.


.단계
. * Home * 을 선택합니다.
. 어레이 수준 보기를 선택하려면 IOPS, MiB/s 또는 CPU 버튼을 클릭하십시오.
. 더 자세한 내용을 보려면 *View Performance Details*를 클릭하세요.
. *Logical View* 탭, *Physical View* 탭 또는 *Applications & Workloads View* 탭을 선택하십시오.
+
객체 유형에 따라 각 탭에 다른 그래프가 나타납니다.

+
[cols="25h,~"]
|===
| 탭 보기 | 각 객체 유형에 대해 표시되는 성능 데이터 


 a| 
논리적 뷰
 a| 
** *스토리지 어레이*: IOPS, MiB/s
** *풀*: 지연 시간, IOPS, MiB/s
** * 볼륨 그룹 *: 지연 시간, IOPS, MiB/s
** *볼륨*: 지연 시간, IOPS, MiB/s




 a| 
물리적 뷰
 a| 
** *컨트롤러*: IOPS, MiB/s, CPU, Headroom
** *호스트 채널*: 지연 시간, IOPS, MiB/s, 여유 공간
** *드라이브 채널*: 지연 시간, IOPS, MiB/s
** *드라이브*: 지연 시간, IOPS, MiB/s




 a| 
애플리케이션 및 워크로드 보기
 a| 
** *스토리지 어레이*: IOPS, MiB/s
** *애플리케이션*: 지연 시간, IOPS, MiB/s
** *워크로드*: 지연 시간, IOPS, MiB/s
** *볼륨*: 지연 시간, IOPS, MiB/s


|===
. 옵션을 사용하여 필요한 개체와 정보를 확인하세요.
+
.옵션
[%collapsible]
====
[cols="25h,~"]
|===
| 객체 보기 옵션 | 설명 


 a| 
서랍을 확장하여 객체 목록을 확인합니다.
 a| 
_탐색 서랍_에는 풀, 볼륨 그룹 및 드라이브와 같은 스토리지 개체가 포함되어 있습니다.

서랍을 클릭하여 서랍의 객체 목록을 확인합니다.



 a| 
볼 객체를 선택합니다.
 a| 
각 개체 왼쪽에 있는 확인란을 선택하여 보고자 하는 성능 데이터를 선택하십시오.



 a| 
필터를 사용하여 객체 이름 또는 부분 이름을 찾습니다.
 a| 
필터 상자에 개체의 이름 또는 부분 이름을 입력하여 드로어에 있는 해당 개체만 나열합니다.



 a| 
객체를 선택한 후 * 그래프 새로 고침 * 을 클릭합니다.
 a| 
서랍에서 개체를 선택한 후 *그래프 새로 고침*을 선택하여 선택한 항목에 대한 그래프 데이터를 확인하십시오.



 a| 
그래프 숨기기 또는 표시
 a| 
그래프 제목을 선택하여 그래프를 숨기거나 표시합니다.

|===
====
. 필요에 따라 성능 데이터를 보기 위한 추가 옵션을 사용하십시오.
+
.추가 옵션
[%collapsible]
====
[cols="25h,~"]
|===
| 옵션 | 설명 


 a| 
기간
 a| 
보려는 기간을 선택합니다(5분, 1시간, 8시간, 1일, 7일 또는 30일). 기본값은 1시간입니다.


NOTE: 30일간의 성능 데이터를 불러오는 데 몇 분 정도 소요될 수 있습니다. 데이터가 로드되는 동안 웹 페이지를 벗어나거나, 페이지를 새로고침하거나, 브라우저를 닫지 마십시오.



 a| 
데이터 포인트 세부 정보
 a| 
그래프 위에 마우스 커서를 올리면 특정 데이터 포인트에 대한 메트릭을 볼 수 있습니다.



 a| 
스크롤 바
 a| 
그래프 아래의 스크롤 막대를 사용하여 이전 또는 이후 기간을 봅니다.



 a| 
확대/축소 막대
 a| 
그래프 아래에서 확대/축소 막대 핸들을 드래그하여 시간 범위를 축소합니다. 확대/축소 막대가 넓을수록 그래프의 세부 정보가 덜 세분화됩니다.

그래프를 재설정하려면 시간 프레임 옵션 중 하나를 선택하십시오.



 a| 
드래그 앤 드롭
 a| 
그래프에서 커서를 한 시점에서 다른 시점으로 드래그하면 특정 시간 구간을 확대해서 볼 수 있습니다.

그래프를 재설정하려면 시간 프레임 옵션 중 하나를 선택하십시오.

|===
====
