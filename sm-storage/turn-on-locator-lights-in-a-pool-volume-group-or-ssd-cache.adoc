= SANtricity System Manager에서 풀, 볼륨 그룹 또는 SSD Cache의 위치 표시등을 켭니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
선택한 풀, 볼륨 그룹 또는 SSD Cache를 구성하는 모든 드라이브를 물리적으로 식별하려면 드라이브 위치 찾기 기능을 사용할 수 있습니다. 선택한 풀, 볼륨 그룹 또는 SSD Cache의 각 드라이브에는 LED 표시등이 켜집니다.

.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 찾을 풀, 볼륨 그룹 또는 SSD Cache를 선택한 다음 menu:More[Turn on locator lights]를 클릭합니다.
+
선택한 풀, 볼륨 그룹 또는 SSD Cache를 구성하는 드라이브의 표시등이 켜져 있음을 나타내는 대화 상자가 나타납니다.

. 드라이브를 성공적으로 찾았으면 * 끄기 * 를 클릭하십시오.
