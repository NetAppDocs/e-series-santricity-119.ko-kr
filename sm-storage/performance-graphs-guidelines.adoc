= SANtricity System Manager의 성능 그래프 및 지침에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 페이지는 여러 주요 영역에서 스토리지 어레이의 성능을 평가할 수 있는 그래프 및 데이터 테이블을 제공합니다.

성능 기능을 사용하면 다음과 같은 작업을 수행할 수 있습니다.

* 스토리지 어레이에 문제가 있는지 여부를 판단하는 데 도움이 되도록 거의 실시간으로 성능 데이터를 확인할 수 있습니다.
* 성능 데이터를 내보내 스토리지 어레이의 기록 보기를 구성하고 문제가 시작된 시점 또는 문제의 원인을 파악합니다.
* 보려는 객체, 성능 메트릭 및 기간을 선택합니다.
* 지표를 비교합니다.


성능 데이터는 세 가지 형식으로 볼 수 있습니다.

* *실시간 그래픽* -- 성능 데이터를 거의 실시간으로 그래프에 표시합니다.
* *거의 실시간 표 형식* -- 성능 데이터를 거의 실시간으로 표 형식으로 나열합니다.
* *내보낸 CSV 파일* -- 표 형식의 성능 데이터를 쉼표로 구분된 값 파일로 저장하여 추가 확인 및 분석을 수행할 수 있습니다.

== 성능 데이터 보기 지침

* 성능 데이터 수집은 항상 활성화되어 있습니다. 이를 끌 수 있는 옵션은 없습니다.
* 샘플링 간격이 경과할 때마다 스토리지 어레이가 쿼리되고 데이터가 업데이트됩니다.
* 그래픽 데이터의 경우 5분 시간 프레임은 5분 동안 평균화된 10초 업데이트를 지원합니다. 다른 모든 시간 프레임은 선택한 시간 프레임에 대해 평균화되어 5분마다 업데이트됩니다.
* 그래프 보기의 성능 데이터는 실시간으로 업데이트됩니다. 표 보기의 성능 데이터는 거의 실시간으로 업데이트됩니다.
* 데이터 수집 기간 동안 모니터링 대상 객체가 변경되면 선택한 기간 전체에 걸쳐 완전한 데이터 세트를 확보하지 못할 수 있습니다. 예를 들어 볼륨 세트는 볼륨 생성, 삭제, 할당 또는 할당 해제에 따라 변경될 수 있으며, 드라이브가 추가, 제거 또는 오류가 발생할 수도 있습니다.
