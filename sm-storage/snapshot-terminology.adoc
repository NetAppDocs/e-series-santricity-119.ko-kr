= SANtricity 소프트웨어의 스냅샷 용어에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 용어가 스토리지 어레이에 어떻게 적용되는지 알아보십시오.

[cols="25h,~"]
|===
| 용어 | 설명 


 a| 
스냅샷 기능
 a| 
스냅샷 기능은 볼륨의 이미지를 생성하고 관리하는 데 사용됩니다.



 a| 
스냅샷 이미지
 a| 
스냅샷 이미지는 특정 시점에 캡처된 볼륨 데이터의 논리적 복사본입니다. 복원 지점과 마찬가지로 스냅샷 이미지를 사용하면 알려진 정상 데이터 세트로 롤백할 수 있습니다. 호스트가 스냅샷 이미지에 액세스할 수 있지만 직접 읽거나 쓸 수는 없습니다.



 a| 
기본 볼륨
 a| 
기본 볼륨은 스냅샷 이미지를 생성하는 데 사용되는 소스 볼륨입니다. 기본 볼륨은 두꺼운 볼륨 또는 얇은 볼륨일 수 있으며 일반적으로 호스트에 할당됩니다. 기본 볼륨은 볼륨 그룹 또는 디스크 풀에 위치할 수 있습니다.



 a| 
스냅샷 볼륨
 a| 
스냅샷 볼륨을 사용하면 호스트가 스냅샷 이미지의 데이터에 액세스할 수 있습니다. 스냅샷 볼륨에는 자체 예약된 용량이 포함되어 있어 원본 스냅샷 이미지에 영향을 주지 않고 기본 볼륨에 대한 수정 사항을 저장합니다.



 a| 
스냅샷 그룹
 a| 
스냅샷 그룹은 단일 기본 볼륨의 스냅샷 이미지 모음입니다.



 a| 
예약된 용량 볼륨
 a| 
예약된 용량 볼륨은 기본 볼륨의 어떤 데이터 블록이 덮어쓰기되었는지, 그리고 해당 블록의 보존된 내용을 추적합니다.



 a| 
스냅샷 일정
 a| 
스냅샷 스케줄은 자동 스냅샷 이미지 생성을 위한 시간표입니다. 스케줄을 통해 이미지 생성 빈도를 제어할 수 있습니다.



 a| 
스냅샷 일관성 그룹
 a| 
스냅샷 일관성 그룹은 스냅샷 이미지를 생성할 때 단일 엔티티로 처리되는 볼륨 모음입니다. 각 볼륨에는 자체 스냅샷 이미지가 있지만 모든 이미지는 동일한 시점에 생성됩니다.



 a| 
스냅샷 일관성 그룹 구성원 볼륨
 a| 
스냅샷 일관성 그룹에 속하는 각 볼륨을 멤버 볼륨이라고 합니다. 볼륨을 스냅샷 일관성 그룹에 추가하면 System Manager가 해당 멤버 볼륨에 대응하는 새 스냅샷 그룹을 자동으로 생성합니다.



 a| 
롤백
 a| 
롤백은 기본 볼륨의 데이터를 이전 시점으로 되돌리는 프로세스입니다.



 a| 
예약된 용량
 a| 
예약 용량은 모든 복사 서비스 작업 및 스토리지 객체에 사용되는 물리적으로 할당된 용량입니다. 호스트에서 직접 읽을 수는 없습니다.

|===
