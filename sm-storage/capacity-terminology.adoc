[role="lead"]
스토리지 어레이에 용량 관련 용어가 어떻게 적용되는지 알아보십시오.



== 스토리지 객체

다음 용어는 스토리지 어레이와 상호 작용할 수 있는 다양한 유형의 스토리지 객체를 설명합니다.

[cols="25h,~"]
|===
| 스토리지 객체 | 설명 


 a| 
호스트
 a| 
호스트는 스토리지 어레이의 볼륨으로 I/O를 전송하는 서버입니다.



 a| 
LUN
 a| 
LUN(논리 장치 번호)은 호스트가 볼륨에 액세스하는 데 사용하는 주소 공간에 할당된 번호입니다. 볼륨은 LUN 형태의 용량으로 호스트에 제공됩니다.

각 호스트는 고유한 LUN 주소 공간을 갖습니다. 따라서 동일한 LUN을 여러 호스트에서 사용하여 서로 다른 볼륨에 액세스할 수 있습니다.



 a| 
미러 일관성 그룹
 a| 
미러 일관성 그룹은 하나 이상의 미러링된 쌍을 담는 컨테이너입니다. 비동기 미러링 작업을 수행하려면 미러 일관성 그룹을 생성해야 합니다.



 a| 
미러링된 볼륨 쌍
 a| 
미러링된 쌍은 기본 볼륨과 보조 볼륨의 두 볼륨으로 구성됩니다.



 a| 
풀
 a| 
풀은 논리적으로 그룹화된 드라이브 집합입니다. 풀을 사용하여 호스트에서 액세스할 수 있는 하나 이상의 볼륨을 생성할 수 있습니다. (볼륨은 풀 또는 볼륨 그룹에서 생성합니다.)



 a| 
스냅샷 일관성 그룹
 a| 
스냅샷 일관성 그룹은 스냅샷 이미지를 생성할 때 단일 엔티티로 처리되는 볼륨 모음입니다. 각 볼륨에는 자체 스냅샷 이미지가 있지만 모든 이미지는 동일한 시점에 생성됩니다.



 a| 
스냅샷 그룹
 a| 
스냅샷 그룹은 단일 기본 볼륨의 스냅샷 이미지 모음입니다.



 a| 
스냅샷 볼륨
 a| 
스냅샷 볼륨을 사용하면 호스트가 스냅샷 이미지의 데이터에 액세스할 수 있습니다. 스냅샷 볼륨에는 자체 예약된 용량이 포함되어 있어 원본 스냅샷 이미지에 영향을 주지 않고 기본 볼륨에 대한 수정 사항을 저장합니다.



 a| 
볼륨
 a| 
볼륨은 애플리케이션, 데이터베이스 및 파일 시스템이 데이터를 저장하는 컨테이너입니다. 이는 호스트가 스토리지 어레이의 스토리지에 액세스하기 위해 생성되는 논리적 구성 요소입니다.



 a| 
볼륨 그룹
 a| 
볼륨 그룹은 공통된 특성을 가진 볼륨들을 담는 컨테이너입니다. 볼륨 그룹은 용량과 RAID 레벨이 정의되어 있습니다. 볼륨 그룹을 사용하여 호스트에서 접근 가능한 하나 이상의 볼륨을 생성할 수 있습니다. (볼륨은 볼륨 그룹 또는 풀에서 생성합니다.)

|===


== 스토리지 용량

다음 용어는 스토리지 어레이에서 사용되는 다양한 용량 유형을 설명합니다.

[cols="25h,~"]
|===
| 용량 유형 | 설명 


 a| 
할당된 용량
 a| 
할당된 용량은 풀 또는 볼륨 그룹의 드라이브에서 할당된 물리적 스토리지입니다.

할당된 용량은 볼륨 생성 및 복사 서비스 작업에 사용됩니다.



 a| 
여유 용량
 a| 
사용 가능한 용량은 볼륨 생성 또는 복사 서비스 작업 및 스토리지 객체에 아직 할당되지 않은 풀 또는 볼륨 그룹에서 사용 가능한 용량입니다.



 a| 
풀 또는 볼륨 그룹 용량
 a| 
풀, 볼륨 또는 볼륨 그룹 용량은 스토리지 어레이에서 풀 또는 볼륨 그룹에 할당된 용량입니다. 이 용량은 볼륨을 생성하고 복사 서비스 작업 및 스토리지 객체의 다양한 용량 요구 사항을 충족하는 데 사용됩니다.



 a| 
풀 사용 불가 용량
 a| 
풀 사용 불가능 용량은 드라이브 크기가 일치하지 않아 사용할 수 없는 풀의 공간입니다.



 a| 
보존 용량
 a| 
보존 용량은 잠재적인 드라이브 장애를 지원하기 위해 풀에 예약된 용량(드라이브 수)입니다.



 a| 
보고된 용량
 a| 
보고된 용량은 호스트에 보고되고 호스트에서 액세스할 수 있는 용량입니다.



 a| 
예약된 용량
 a| 
예약 용량은 모든 복사 서비스 작업 및 스토리지 객체에 사용되는 물리적으로 할당된 용량입니다. 호스트에서 직접 읽을 수는 없습니다.



 a| 
SSD 캐시
 a| 
SSD 캐시는 스토리지 어레이에서 논리적으로 그룹화하는 솔리드 스테이트 디스크(SSD) 드라이브 세트입니다. SSD 캐시 기능은 가장 자주 액세스되는 데이터("핫" 데이터)를 지연 시간이 짧은 SSD 드라이브에 캐싱하여 애플리케이션 워크로드를 동적으로 가속화합니다.



 a| 
할당되지 않은 용량
 a| 
할당되지 않은 용량은 스토리지 어레이에서 풀 또는 볼륨 그룹에 할당되지 *않은* 공간입니다.



 a| 
기록된 용량
 a| 
기록된 용량은 씬 볼륨에 할당된 예약된 용량에서 기록된 용량의 양입니다.

|===
