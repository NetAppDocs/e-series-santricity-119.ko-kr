= SANtricity System Manager에서 스냅샷 이미지를 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 이미지를 삭제하면 스냅샷 그룹 또는 스냅샷 일관성 그룹에서 가장 오래된 스냅샷 이미지를 정리할 수 있습니다.

.이 작업 정보
단일 스냅샷 이미지를 삭제하거나 동일한 생성 타임스탬프를 가진 스냅샷 일관성 그룹에서 스냅샷 이미지를 삭제할 수 있습니다. 또한 스냅샷 그룹에서 스냅샷 이미지를 삭제할 수도 있습니다.

연결된 기본 볼륨 또는 스냅샷 일관성 그룹에 대한 가장 오래된 스냅샷 이미지가 아닌 경우 스냅샷 이미지를 삭제할 수 없습니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *스냅샷 이미지* 탭을 클릭합니다.
. 삭제할 스냅샷 이미지를 선택하고 작업을 수행할지 확인하십시오.
+
스냅샷 일관성 그룹의 스냅샷 이미지를 선택한 경우 삭제할 각 멤버 볼륨을 선택하고 작업을 수행할지 확인하십시오.

. *삭제*를 클릭합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 스토리지 어레이에서 스냅샷 이미지를 삭제합니다.
* 스냅샷 그룹 또는 스냅샷 일관성 그룹 내에서 재사용할 수 있도록 예약된 용량을 해제합니다.
* 삭제된 스냅샷 이미지에 대해 존재하는 모든 관련 스냅샷 볼륨을 비활성화합니다.
* 스냅샷 일관성 그룹 삭제에서 삭제된 스냅샷 이미지와 연결된 모든 멤버 볼륨을 중지 상태로 이동합니다.
