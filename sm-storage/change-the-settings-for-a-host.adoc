= SANtricity System Manager에서 호스트 설정을 변경합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트의 이름, 호스트 운영 체제 유형 및 연결된 호스트 클러스터를 변경할 수 있습니다.

.단계
. 메뉴:Storage[Hosts]를 선택합니다.
. 편집할 호스트를 선택한 다음 *설정 보기/편집*을 클릭합니다.
+
현재 호스트 설정을 보여주는 대화 상자가 나타납니다.

. 선택되어 있지 않다면 *속성* 탭을 클릭하십시오.
. 필요에 따라 설정을 변경하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
이름
 a| 
사용자가 지정한 호스트 이름을 변경할 수 있습니다. 호스트 이름을 지정하는 것은 필수입니다.



 a| 
연결된 호스트 클러스터
 a| 
다음 옵션 중 하나를 선택할 수 있습니다.

** *없음* -- 호스트는 독립형 호스트로 유지됩니다. 호스트가 호스트 클러스터에 연결되어 있었던 경우 시스템은 해당 호스트를 클러스터에서 제거합니다.
** *<Host Cluster>* -- 시스템은 호스트를 선택된 클러스터에 연결합니다.




 a| 
호스트 운영 체제 유형
 a| 
정의한 호스트에서 실행되는 운영 체제 유형을 변경할 수 있습니다.

|===
====
. *저장*을 클릭합니다.
