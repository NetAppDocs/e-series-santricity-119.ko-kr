= SANtricity System Manager에서 스냅샷 그룹을 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 그룹을 삭제하면 해당 데이터가 영구적으로 삭제되고 시스템에서 제거됩니다. 스냅샷 그룹을 삭제하면 예약된 용량이 풀 또는 볼륨 그룹에서 재사용하도록 회수됩니다.

.이 작업 정보
스냅샷 그룹을 삭제하면 해당 그룹에 속한 모든 스냅샷 이미지도 함께 삭제됩니다.

.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. *예약된 용량* 탭을 클릭합니다.
. 삭제하려는 스냅샷 그룹을 선택한 다음 메뉴:일반적이지 않은 작업[스냅샷 그룹 삭제]를 클릭합니다.
+
스냅샷 그룹 삭제 확인 대화 상자가 나타납니다.

. 확인하려면  `delete`을(를) 입력하세요.


.결과
System Manager는 다음 작업을 수행합니다.

* 스냅샷 그룹과 연결된 모든 스냅샷 이미지를 삭제합니다.
* 스냅샷 그룹의 이미지와 연결된 모든 스냅샷 볼륨을 비활성화합니다.
* 스냅샷 그룹에 대해 존재하는 예약된 용량을 삭제합니다.
