= SANtricity System Manager의 스냅샷에 대한 요구 사항 및 지침
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷을 생성하고 사용할 때는 다음 요구 사항 및 지침을 검토하십시오.



[[snapshot-images-and-snapshot-groups]]
== 스냅샷 이미지 및 스냅샷 그룹

* 각 스냅샷 이미지는 정확히 하나의 스냅샷 그룹과 연결됩니다.
* 스냅샷 그룹은 연결된 객체에 대해 예약된 스냅샷 이미지 또는 즉시 스냅샷 이미지를 처음 생성할 때 생성됩니다. 이렇게 하면 예약 용량이 생성됩니다.
+
풀 및 볼륨 그룹 페이지에서 스냅샷 그룹을 볼 수 있습니다.

* 스토리지 시스템이 오프라인 상태이거나 전원이 꺼진 경우 예약된 스냅샷 이미지가 생성되지 않습니다.
* 스냅샷 일정이 있는 스냅샷 그룹을 삭제하면 스냅샷 일정도 함께 삭제됩니다.
* 더 이상 필요하지 않은 스냅샷 볼륨이 있는 경우 삭제하는 대신 연결된 예약된 용량과 함께 재사용할 수 있습니다. 이렇게 하면 동일한 기본 볼륨의 다른 스냅샷 볼륨이 생성됩니다. 스냅샷 이미지가 동일한 기본 볼륨에 있는 한 스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨을 동일한 스냅샷 이미지 또는 다른 스냅샷 이미지와 다시 연결할 수 있습니다.




[[snapshot-consistency-group]]
== 스냅샷 일관성 그룹

* 스냅샷 일관성 그룹에는 스냅샷 일관성 그룹의 구성원인 각 볼륨에 대한 스냅샷 그룹이 하나씩 포함되어 있습니다.
* 스냅샷 일관성 그룹을 하나의 스케줄에만 연결할 수 있습니다.
* 스냅샷 일정이 있는 스냅샷 일관성 그룹을 삭제하면 스냅샷 일정도 삭제됩니다.
* 스냅샷 일관성 그룹과 연결된 스냅샷 그룹은 개별적으로 관리할 수 없습니다. 대신 스냅샷 일관성 그룹 수준에서 관리 작업(스냅샷 이미지 생성, 스냅샷 이미지 또는 스냅샷 그룹 삭제, 스냅샷 이미지 롤백)을 수행해야 합니다.




[[base-volume]]
== 기본 볼륨

* 스냅샷 볼륨은 연결된 기본 볼륨과 동일한 Data Assurance(DA) 및 보안 설정을 가져야 합니다.
* 장애가 발생한 기본 볼륨의 스냅샷 볼륨을 생성할 수 없습니다.
* 기본 볼륨이 볼륨 그룹에 있는 경우 연결된 스냅샷 일관성 그룹의 구성원 볼륨은 풀 또는 볼륨 그룹 중 어느 곳에든 있을 수 있습니다.
* 기본 볼륨이 풀에 있는 경우 연결된 스냅샷 일관성 그룹의 모든 구성원 볼륨이 기본 볼륨과 동일한 풀에 있어야 합니다.




[[reserved-capacity]]
== 예약된 용량

* 예약된 용량은 하나의 기본 볼륨과만 연결됩니다.
* 스케줄을 사용하면 스냅샷 이미지 수가 많아질 수 있습니다. 예약된 스냅샷을 위한 충분한 예약된 용량이 있는지 확인하십시오.
* 스냅샷 일관성 그룹의 예약된 용량 볼륨은 스냅샷 일관성 그룹 멤버 볼륨에 연결된 기본 볼륨과 동일한 데이터 보증(DA) 및 보안 설정을 가져야 합니다.




[[pending-snapshot-images]]
== 보류 중인 스냅샷 이미지

다음과 같은 상황에서는 스냅샷 이미지 생성이 대기 중 상태로 유지될 수 있습니다.

* 이 스냅샷 이미지가 포함된 기본 볼륨은 비동기 미러 그룹의 구성원입니다.
* 현재 기본 볼륨이 동기화 작업 중입니다. 동기화 작업이 완료되면 스냅샷 이미지 생성이 완료됩니다.




[[maximum-number-of-snapshot-images]]
== 스냅샷 이미지의 최대 수

* 볼륨이 스냅샷 일관성 그룹의 구성원인 경우 System Manager는 해당 구성원 볼륨에 대한 스냅샷 그룹을 생성합니다. 이 스냅샷 그룹은 기본 볼륨당 허용되는 최대 스냅샷 그룹 수에 포함됩니다.
* 스냅샷 그룹 또는 스냅샷 일관성 그룹에서 스냅샷 이미지를 생성하려고 하지만 연결된 그룹이 최대 스냅샷 이미지 수에 도달한 경우 다음 두 가지 옵션이 있습니다.
+
** 스냅샷 그룹 또는 스냅샷 일관성 그룹에 대한 자동 삭제를 활성화합니다.
** 스냅샷 그룹 또는 스냅샷 일관성 그룹에서 하나 이상의 스냅샷 이미지를 수동으로 삭제한 후 작업을 다시 시도하십시오.






[[auto-deletion]]
== 자동 삭제

스냅샷 그룹 또는 스냅샷 일관성 그룹에 자동 삭제 기능이 활성화된 경우 System Manager는 시스템이 해당 그룹에 대한 새 스냅샷 이미지를 생성할 때 가장 오래된 스냅샷 이미지를 삭제합니다.



[[rollback-operation]]
== 롤백 작업

* 롤백 작업이 진행 중일 때는 다음 작업을 수행할 수 없습니다.
+
** 롤백에 사용 중인 스냅샷 이미지를 삭제합니다.
** 롤백 작업에 참여하는 기본 볼륨에 대한 새 스냅샷 이미지를 생성합니다.
** 연결된 스냅샷 그룹의 Repository-Full Policy를 변경하십시오.


* 다음 작업 중 하나라도 진행 중일 때는 롤백 작업을 시작할 수 없습니다.
+
** 용량 확장(풀 또는 볼륨 그룹에 용량 추가)
** 볼륨 확장(볼륨 용량 증가)
** 볼륨 그룹의 RAID 레벨 변경
** 볼륨의 세그먼트 크기 변경


* 기본 볼륨이 볼륨 복사본에 참여하고 있는 경우 롤백 작업을 시작할 수 없습니다.
* 기본 볼륨이 원격 미러의 보조 볼륨인 경우 롤백 작업을 시작할 수 없습니다.
* 연결된 스냅샷 리포지토리 볼륨의 사용된 용량에 읽을 수 없는 섹터가 있는 경우 롤백 작업이 실패합니다.
