= SANtricity System Manager에서 호스트에 볼륨을 할당합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
I/O 작업에 사용할 수 있도록 호스트 또는 호스트 클러스터에 볼륨을 할당해야 합니다. 이 할당을 통해 호스트 또는 호스트 클러스터는 스토리지 어레이의 하나 이상의 볼륨에 액세스할 수 있습니다.

.이 작업 정보
호스트에 볼륨을 할당할 때 다음 지침을 염두에 두십시오.

* 볼륨은 한 번에 하나의 호스트 또는 호스트 클러스터에만 할당할 수 있습니다.
* 할당된 볼륨은 스토리지 어레이의 컨트롤러 간에 공유됩니다.
* 호스트 또는 호스트 클러스터는 동일한 논리 장치 번호(LUN)를 두 번 사용하여 볼륨에 액세스할 수 없습니다. 고유한 LUN을 사용해야 합니다.
* 새 볼륨 그룹의 경우, 모든 볼륨이 생성 및 초기화될 때까지 기다린 후 호스트에 할당하면 볼륨 초기화 시간이 단축됩니다. 단, 볼륨 그룹과 연결된 볼륨이 매핑되면 _모든_ 볼륨의 초기화 속도가 느려진다는 점에 유의하십시오. 초기화 진행 상황은 메뉴:홈[진행 중인 작업]에서 확인할 수 있습니다.


다음 조건에서 볼륨 할당이 실패합니다.

* 모든 볼륨이 할당되었습니다.
* 볼륨이 이미 다른 호스트 또는 호스트 클러스터에 할당되어 있습니다.


다음 조건에서는 볼륨을 할당할 수 없습니다.

* 유효한 호스트 또는 호스트 클러스터가 없습니다.
* 호스트에 대해 호스트 포트 식별자가 정의되지 않았습니다.
* 모든 볼륨 할당이 정의되었습니다.


이 작업 중에는 할당되지 않은 모든 볼륨이 표시되지만 DA(Data Assurance)가 있거나 없는 호스트에 대한 기능은 다음과 같이 적용됩니다.

* DA 지원 호스트의 경우 DA가 활성화된 볼륨 또는 DA가 활성화되지 않은 볼륨을 선택할 수 있습니다.
* DA 기능을 지원하지 않는 호스트에서 DA 기능이 활성화된 볼륨을 선택하면 해당 볼륨을 호스트에 할당하기 전에 시스템에서 해당 볼륨의 DA 기능을 자동으로 비활성화해야 한다는 경고 메시지가 표시됩니다.


.단계
. 메뉴:Storage[Hosts]를 선택합니다.
. 볼륨을 할당할 호스트 또는 호스트 클러스터를 선택한 다음 *Assign Volumes*를 클릭합니다.
+
할당 가능한 모든 볼륨 목록이 표시되는 대화 상자가 나타납니다. 열을 정렬하거나 *Filter* 상자에 원하는 내용을 입력하여 특정 볼륨을 쉽게 찾을 수 있습니다.

. 할당하려는 각 볼륨 옆의 확인란을 선택하거나 표 헤더의 확인란을 선택하여 모든 볼륨을 선택하십시오.
. 작업을 완료하려면 * 할당 * 을 클릭합니다.


.결과
볼륨을 호스트 또는 호스트 클러스터에 성공적으로 할당한 후 시스템은 다음 작업을 수행합니다.

* 할당된 볼륨은 사용 가능한 다음 LUN 번호를 받습니다. 호스트는 LUN 번호를 사용하여 볼륨에 액세스합니다.
* 사용자가 지정한 볼륨 이름은 호스트와 연결된 볼륨 목록에 나타납니다. 해당되는 경우, 공장에서 구성된 액세스 볼륨도 호스트와 연결된 볼륨 목록에 나타납니다.
