= SANtricity System Manager에서 스냅샷 볼륨을 비활성화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
더 이상 필요하지 않거나 일시적으로 사용을 중지하려는 경우 스냅샷 볼륨 또는 스냅샷 일관성 그룹의 스냅샷 볼륨을 비활성화할 수 있습니다.

.이 작업 정보
다음 조건 중 하나에 해당하는 경우 비활성화 옵션을 사용하십시오.

* 현재로서는 스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨에 대한 작업이 완료되었습니다.
* 나중에 스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨(읽기/쓰기 가능으로 지정됨)을 다시 생성할 예정이며, 관련 예약 용량을 유지하여 다시 생성할 필요가 없도록 하려는 경우입니다.
* 읽기-쓰기 스냅샷 볼륨에 대한 쓰기 작업을 중지하여 스토리지 어레이 성능을 향상시키려고 합니다.


스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨이 읽기/쓰기로 지정된 경우 이 옵션을 사용하면 연결된 예약된 용량 볼륨에 대한 추가 쓰기 작업을 중지할 수도 있습니다. 스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨을 다시 생성하기로 결정한 경우 동일한 기본 볼륨에서 스냅샷 이미지를 선택해야 합니다.

[NOTE]
====
스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨이 온라인 복사본 관계의 일부인 경우 해당 볼륨에서 사용 안 함 옵션을 수행할 수 없습니다.

====
.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *스냅샷 볼륨* 탭을 선택합니다.
+
System Manager는 스토리지 어레이와 연결된 모든 스냅샷 볼륨을 표시합니다.

. 비활성화할 스냅샷 볼륨을 선택한 다음 메뉴:일반적이지 않은 작업[비활성화]를 선택합니다.
. 작업을 수행할 것인지 확인한 다음 * 사용 안 함 * 을 클릭합니다.


.결과
* 스냅샷 볼륨은 기본 볼륨과 연결된 상태로 유지됩니다.
* 스냅샷 볼륨은 World Wide Name(WWN)을 유지합니다.
* 읽기-쓰기인 경우 스냅샷 볼륨은 연결된 예약된 용량을 유지합니다.
* 스냅샷 볼륨에는 호스트 할당 및 액세스 정보가 유지됩니다. 그러나 읽기/쓰기 요청은 실패합니다.
* 스냅샷 볼륨이 스냅샷 이미지와의 연결을 잃습니다.
