= SANtricity System Manager에서 Copy Volume 작업에 대한 조치를 취하십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
진행 중인 볼륨 복사 작업을 확인하고, 볼륨 복사 작업을 중지하거나, 우선 순위를 변경하거나, 다시 복사하거나, 지울 수 있습니다.

.단계
. 메뉴: Home[View Operations in Progress]를 선택합니다.
+
작업 진행 중 대화 상자가 나타납니다.

. 작업을 수행하려는 Copy Volume 작업을 찾은 다음 *Actions* 열의 링크를 클릭하여 다음 작업 중 하나를 수행하십시오.
+
대화 상자에 표시되는 모든 주의 사항, 특히 작업을 중지할 때 표시되는 주의 사항을 읽으십시오.

+
[cols="25h,~"]
|===
| 작업 | 설명 


 a| 
중지
 a| 
복사 볼륨 작업의 상태가 '진행 중', '대기 중' 또는 '실패'인 경우 해당 작업을 중지할 수 있습니다.

볼륨 복사가 중지되면 매핑된 모든 호스트는 소스 볼륨에 대한 쓰기 권한을 갖게 됩니다. 소스 볼륨에 데이터가 기록되면 타겟 볼륨의 데이터가 더 이상 소스 볼륨의 데이터와 일치하지 않습니다.



 a| 
우선 순위 변경
 a| 
Copy Volume 작업의 상태가 진행 중일 때 작업 우선 순위를 변경하여 Copy Volume 작업이 완료되는 속도를 선택할 수 있습니다.



 a| 
다시 복사
 a| 
볼륨 복사 작업을 중지했다가 다시 시작하거나, 볼륨 복사 작업이 실패하거나 중단된 경우 볼륨을 다시 복사할 수 있습니다. 볼륨 복사 작업은 처음부터 다시 시작됩니다.

재복사 작업은 타겟 볼륨의 기존 데이터를 덮어쓰고 타겟 볼륨과 연결된 모든 스냅샷 볼륨(있는 경우)을 실패 처리합니다.



 a| 
지우기
 a| 
작업 상태가 '진행 중', '대기 중' 또는 '실패'인 경우에도 볼륨 복사 작업을 제거할 수 있습니다.

[NOTE]
====
*Clear*를 선택하기 전에 이 작업을 수행할 것인지 확실히 확인하십시오. 확인 대화 상자가 표시되지 않습니다.

====
|===
