= SANtricity 소프트웨어의 씬 볼륨 모니터링에 대해 알아보십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
씬 볼륨의 공간을 모니터링하고 용량 부족 상태를 방지하기 위해 적절한 알림을 생성할 수 있습니다.

씬 프로비저닝 환경에서는 기본 물리적 스토리지보다 더 많은 논리적 공간을 할당할 수 있습니다. 메뉴:스토리지[볼륨 > 씬 볼륨 모니터링] 탭을 선택하여 씬 볼륨이 할당된 용량 최대 한도에 도달하기 전에 얼마나 증가하는지 모니터링할 수 있습니다.

씬 모니터링 보기를 사용하여 다음과 같은 작업을 수행할 수 있습니다.

* 씬 볼륨이 자동으로 확장할 수 있는 할당된 용량을 제한하는 제한을 정의합니다.
* 씬 볼륨이 최대 할당 용량 한도에 근접했을 때 홈 페이지의 알림 영역으로 알림(경고 임계값 초과)이 전송되는 백분율 지점을 설정합니다.


씬 볼륨의 용량을 늘리려면 보고된 용량을 늘리십시오.

[NOTE]
====
System Manager는 씬 볼륨을 생성하는 옵션을 제공하지 않습니다. 씬 볼륨을 생성하려면 명령줄 인터페이스(CLI)를 사용하십시오.

====
[NOTE]
====
EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서는 씬 볼륨을 사용할 수 없습니다.

====
