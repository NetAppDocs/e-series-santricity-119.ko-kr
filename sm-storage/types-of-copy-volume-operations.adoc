= SANtricity 소프트웨어에서 복사 볼륨 작업 유형에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
_오프라인_ 볼륨 복사 작업 또는 _온라인_ 볼륨 복사 작업을 수행할 수 있습니다. 오프라인 작업은 소스 볼륨에서 데이터를 읽어 타겟 볼륨에 복사합니다. 온라인 작업은 스냅샷 볼륨을 소스로 사용하고 해당 데이터를 타겟 볼륨에 복사합니다.

데이터 무결성을 보장하기 위해 두 가지 유형의 볼륨 복사 작업 중 타겟 볼륨에 대한 모든 I/O 활동이 일시 중단됩니다. 이러한 일시 중단은 절차가 완료될 때까지 타겟 볼륨의 데이터 상태가 일관되지 않기 때문에 발생합니다.

오프라인 및 온라인 볼륨 복사 작업에 대한 설명은 다음과 같습니다.



== 오프라인 Copy Volume 작업

오프라인 복사 볼륨 관계는 소스 볼륨과 타겟 볼륨 간의 관계입니다. 오프라인 복사는 소스 볼륨에서 데이터를 읽어 타겟 볼륨에 복사하는 동안 소스 볼륨에 대한 모든 업데이트를 일시 중단합니다. 소스 볼륨에 대한 모든 업데이트가 일시 중단되어 타겟 볼륨에 시간순 불일치가 발생하지 않도록 합니다.

[cols="25h,~"]
|===
2+| 오프라인 복사 작업에 대해 알아야 할 사항 


 a| 
읽기 및 쓰기 요청
 a| 
* 오프라인 복사에 참여하는 소스 볼륨은 Copy Volume 작업 상태가 In Progress 또는 Pending인 동안 읽기 전용 I/O 활동에 사용할 수 있습니다.
* 오프라인 복사가 완료된 후에 쓰기 요청이 허용됩니다.
* 쓰기 방지 오류 메시지가 발생하는 것을 방지하려면 상태가 진행 중인 Copy Volume 작업에 참여하는 소스 볼륨에 액세스하지 마십시오.




 a| 
저널링 파일 시스템
 a| 
* 원본 볼륨이 저널링 파일 시스템으로 포맷된 경우 원본 볼륨에 대한 읽기 요청을 실행하려고 하면 스토리지 어레이 컨트롤러에서 거부될 수 있으며 오류 메시지가 나타날 수 있습니다.
* 저널링 파일 시스템 드라이버는 읽기 요청을 시도하기 전에 쓰기 요청을 보냅니다. 컨트롤러가 쓰기 요청을 거부하면, 거부된 쓰기 요청으로 인해 읽기 요청이 실행되지 않을 수 있습니다. 이러한 상황으로 인해 소스 볼륨이 쓰기 방지되어 있음을 나타내는 오류 메시지가 표시될 수 있습니다.
* 이 문제가 발생하지 않도록 하려면 Copy Volume 작업의 상태가 In Progress인 동안 오프라인 복사에 참여하고 있는 소스 볼륨에 액세스하지 마십시오.


|===


== 온라인 볼륨 복사 작업

온라인 볼륨 복사 관계는 스냅샷 볼륨과 타겟 볼륨 간의 관계입니다. 소스 볼륨이 온라인 상태이고 데이터 쓰기가 가능한 동안 볼륨 복사 작업을 시작할 수 있습니다. 이 기능은 볼륨의 스냅샷을 생성하고 해당 스냅샷을 복사의 실제 소스 볼륨으로 사용함으로써 구현됩니다.

소스 볼륨에 대해 볼륨 복사 작업을 시작하면 System Manager는 기본 볼륨의 스냅샷 이미지와 기본 볼륨의 스냅샷 이미지와 타겟 볼륨 간의 복사 관계를 생성합니다. 스냅샷 이미지를 소스 볼륨으로 사용하면 복사가 진행되는 동안 스토리지 어레이가 소스 볼륨에 계속 쓰기 작업을 수행할 수 있습니다.

온라인 복사 작업 중에는 쓰기 시 복사 절차로 인해 성능 영향이 발생합니다. 온라인 복사가 완료되면 기본 볼륨 성능이 복원됩니다.

[cols="25h,~"]
|===
2+| 온라인 복사 작업에 대해 알아야 할 사항 


 a| 
어떤 종류의 볼륨을 사용할 수 있습니까?
 a| 
* 시점 이미지가 생성되는 볼륨을 기본 볼륨이라고 하며, 스토리지 어레이에서 표준 볼륨 또는 씬 볼륨이어야 합니다.
* 타겟 볼륨은 볼륨 그룹의 표준 볼륨 또는 풀의 표준 볼륨일 수 있습니다. 타겟 볼륨은 씬 볼륨이나 스냅샷 그룹의 기본 볼륨일 수 없습니다.
* 온라인 볼륨 복사 기능을 사용하면 동일한 스토리지 어레이 내의 풀에 있는 씬 볼륨에서 표준 볼륨으로 데이터를 복사할 수 있습니다. 하지만 볼륨 복사 기능을 사용하여 표준 볼륨에서 씬 볼륨으로 데이터를 복사할 수는 없습니다.




 a| 
기본 볼륨 성능
 a| 
* 복사 소스로 사용되는 스냅샷 볼륨이 활성화된 경우, 쓰기 시 복사 작업으로 인해 기본 볼륨의 성능이 저하됩니다. 복사가 완료되면 스냅샷이 비활성화되고 기본 볼륨의 성능이 복원됩니다. 스냅샷이 비활성화되더라도 예약 용량 볼륨과 복사 관계는 그대로 유지됩니다.




 a| 
생성된 볼륨 유형
 a| 
* 온라인 복사 작업 중에 스냅샷 볼륨과 예약된 용량 볼륨이 생성됩니다.
* 스냅샷 볼륨은 데이터가 포함된 실제 볼륨이 아니라 특정 시점에 볼륨에 포함되어 있던 데이터에 대한 참조입니다.
* 스냅샷이 생성될 때마다 스냅샷 데이터를 저장할 예약 용량 볼륨이 생성됩니다. 이 예약 용량 볼륨은 스냅샷 이미지를 관리하는 데에만 사용됩니다.




 a| 
예약된 용량 볼륨
 a| 
* 소스 볼륨의 데이터 블록을 수정하기 전에 수정할 블록의 내용이 안전한 보관을 위해 예약된 용량 볼륨으로 복사됩니다.
* 예약된 용량 볼륨은 해당 데이터 블록에 원본 데이터의 복사본을 저장하므로 해당 데이터 블록에 대한 추가 변경 사항은 소스 볼륨에만 기록됩니다.
* 온라인 복사 작업은 전체 물리적 복사보다 디스크 공간을 적게 사용합니다. 예약된 용량 볼륨에 저장되는 데이터 블록은 스냅샷 시점 이후 변경된 데이터 블록뿐이기 때문입니다.


|===
