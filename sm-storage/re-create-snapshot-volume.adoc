= SANtricity System Manager에서 스냅샷 볼륨을 다시 생성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이전에 사용 중지했던 스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨을 다시 생성할 수 있습니다. 스냅샷 볼륨을 다시 생성하는 데는 새 볼륨을 생성하는 것보다 시간이 적게 걸립니다.

.시작하기 전에
* 스냅샷 볼륨은 최적 상태 또는 사용 안 함 상태여야 합니다.
* 스냅샷 일관성 그룹 스냅샷 볼륨을 다시 생성하려면 모든 구성원 스냅샷 볼륨이 비활성화 상태여야 합니다.


.이 작업 정보
개별 멤버 스냅샷 볼륨은 다시 생성할 수 없으며 전체 스냅샷 일관성 그룹 스냅샷 볼륨만 다시 생성할 수 있습니다.

[NOTE]
====
스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨이 온라인 복사 관계의 일부인 경우 해당 볼륨에 대해 다시 생성 옵션을 수행할 수 없습니다.

====
.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *스냅샷 볼륨* 탭을 선택합니다.
+
스냅샷 볼륨 테이블이 나타나고 스토리지 어레이와 연결된 모든 스냅샷 볼륨이 표시됩니다.

. 다시 생성할 스냅샷 볼륨을 선택한 다음 메뉴: Uncommon Tasks[Recreate]를 선택합니다.
+
스냅샷 볼륨 다시 생성 대화 상자가 나타납니다.

. 다음 옵션 중 하나를 선택하십시오.
+
** *볼륨 <name>에서 생성된 기존 스냅샷 이미지*
+
이 옵션을 선택하여 스냅샷 볼륨을 다시 생성할 기존 스냅샷 이미지를 지정합니다.

** *볼륨의 새로운 (즉시) 스냅샷 이미지 <name>*
+
이 옵션을 선택하면 스냅샷 볼륨을 다시 생성할 새 스냅샷 이미지가 생성됩니다.



. *다시 만들기*를 클릭합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 연결된 스냅샷 저장소 볼륨의 모든 `write` 데이터를 삭제합니다.
* 스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨 매개 변수는 이전에 비활성화된 볼륨 매개 변수와 동일하게 유지됩니다.
* 스냅샷 볼륨 또는 스냅샷 정합성 보장 그룹 스냅샷 볼륨의 원래 이름을 유지합니다.
