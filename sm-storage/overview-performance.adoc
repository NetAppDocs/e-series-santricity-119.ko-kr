[[what-can-i-learn-from-performance-data]]
== 성능 데이터에서 무엇을 알 수 있습니까?

성능 그래프와 표는 거의 실시간으로 성능 데이터를 보여주므로 스토리지 어레이에 문제가 있는지 여부를 파악하는 데 도움이 됩니다. 또한 성능 데이터를 저장하여 스토리지 어레이의 이력 보기를 구축하고 문제가 시작된 시점이나 원인을 확인할 수 있습니다.
