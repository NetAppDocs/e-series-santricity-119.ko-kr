= SANtricity 소프트웨어에서 볼륨이 호스트 및 호스트 클러스터에 할당되는 방식
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트 또는 호스트 클러스터가 볼륨으로 I/O를 전송하려면 해당 볼륨을 호스트 또는 호스트 클러스터에 할당해야 합니다.

볼륨을 생성할 때 호스트 또는 호스트 클러스터를 선택하거나, 나중에 볼륨을 호스트 또는 호스트 클러스터에 할당할 수 있습니다. 호스트 클러스터는 호스트 그룹입니다. 호스트 클러스터를 생성하면 동일한 볼륨을 여러 호스트에 쉽게 할당할 수 있습니다.

호스트에 볼륨을 할당하는 것은 유연하여 특정 스토리지 요구사항을 충족할 수 있습니다.

* *호스트 클러스터의 일부가 아닌 독립형 호스트* -- 개별 호스트에 볼륨을 할당할 수 있습니다. 해당 볼륨은 지정된 호스트에서만 액세스할 수 있습니다.
* *호스트 클러스터* -- 볼륨을 호스트 클러스터에 할당할 수 있습니다. 해당 볼륨은 호스트 클러스터에 속한 모든 호스트에서 액세스할 수 있습니다.
* *호스트 클러스터 내의 호스트* -- 호스트 클러스터에 속한 개별 호스트에 볼륨을 할당할 수 있습니다. 호스트가 호스트 클러스터의 일부이더라도 해당 볼륨은 해당 호스트에서만 액세스할 수 있으며, 호스트 클러스터 내의 다른 호스트에서는 액세스할 수 없습니다.


볼륨을 생성할 때 논리 장치 번호(LUN)가 자동으로 할당됩니다. LUN은 I/O 작업 중에 호스트와 컨트롤러 간의 "주소" 역할을 합니다. 볼륨 생성 후에도 LUN을 변경할 수 있습니다.
