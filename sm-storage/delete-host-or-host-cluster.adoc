= SANtricity System Manager에서 호스트 또는 호스트 클러스터를 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트 또는 호스트 클러스터를 삭제할 수 있습니다.

.이 작업 정보
호스트 또는 호스트 클러스터를 삭제할 때는 다음 지침을 염두에 두십시오.

* 특정 볼륨 할당은 모두 삭제되고 해당 볼륨은 새로운 할당에 사용할 수 있게 됩니다.
* 호스트가 자체적으로 특정 할당이 있는 호스트 클러스터의 일부인 경우 해당 호스트 클러스터에는 영향을 미치지 않습니다. 그러나 호스트가 다른 할당이 없는 호스트 클러스터의 일부인 경우 해당 호스트 클러스터와 연결된 다른 호스트 또는 호스트 포트 식별자는 기본 할당을 상속받습니다.
* 호스트와 연결된 모든 호스트 포트 식별자가 정의되지 않습니다.


.단계
. 메뉴:Storage[Hosts]를 선택합니다.
. 삭제하려는 호스트 또는 호스트 클러스터를 선택한 다음 * 삭제 * 를 클릭합니다.
+
확인 대화 상자가 나타납니다.

. 작업을 수행할 것인지 확인한 다음 * 삭제 * 를 클릭합니다.


.결과
호스트를 삭제하면 시스템은 다음 작업을 수행합니다.

* 호스트를 삭제하고 해당하는 경우 호스트 클러스터에서 제거합니다.
* 할당된 볼륨에 대한 액세스를 제거합니다.
* 연결된 볼륨을 할당되지 않은 상태로 되돌립니다.
* 호스트와 연결된 모든 호스트 포트 식별자를 연결 해제 상태로 반환합니다.


호스트 클러스터를 삭제하면 시스템은 다음 작업을 수행합니다.

* 호스트 클러스터와 해당 클러스터에 연결된 호스트(있는 경우)를 삭제합니다.
* 할당된 볼륨에 대한 액세스를 제거합니다.
* 연결된 볼륨을 할당되지 않은 상태로 되돌립니다.
* 호스트와 연결된 모든 호스트 포트 식별자를 연결 해제 상태로 반환합니다.
