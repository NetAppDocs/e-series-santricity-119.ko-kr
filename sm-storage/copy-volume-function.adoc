= SANtricity System Manager의 볼륨 복사본에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨 복사 기능을 사용하면 동일한 스토리지 어레이에 소스 볼륨과 타겟 볼륨이라는 두 개의 개별 볼륨을 생성하여 볼륨의 시점 복사본을 생성할 수 있습니다.

이 함수는 소스 볼륨에서 타겟 볼륨으로 바이트 단위 복사를 수행하여 타겟 볼륨의 데이터를 소스 볼륨의 데이터와 동일하게 만듭니다.



[[data-copying-for-greater-access]]
== 액세스 향상을 위한 데이터 복사

볼륨에 필요한 스토리지 요구 사항이 변경될 경우 볼륨 복사본 기능을 사용하여 용량이 작은 드라이브를 사용하는 풀 또는 볼륨 그룹에서 용량이 큰 드라이브를 사용하는 풀 또는 볼륨 그룹으로 데이터를 복사할 수 있습니다. 예를 들어 볼륨 복사본 기능을 사용하여 다음을 수행할 수 있습니다.

* 데이터를 더 큰 드라이브로 이동합니다.
* 더 높은 데이터 전송 속도를 가진 드라이브로 변경합니다.
* 더 높은 성능을 위해 새로운 기술을 사용하는 드라이브로 변경하십시오.
* 씬 볼륨을 씩 볼륨으로 변경합니다.


복사 소스 및 타겟 볼륨은 보고된 호스트 주소 지정 가능/논리 블록 크기(섹터 크기)가 동일해야 합니다.

보고된 볼륨 블록 크기는 다음과 같습니다.

* *Native block size* – 볼륨의 블록 크기가 드라이브 블록 크기(512 또는 4K)와 일치합니다.
* *에뮬레이션된 512 블록 크기* - 드라이브는 4K이지만 보고된 블록 크기는 512입니다.




[[change-a-thin-volume-to-a-thick-volume]]
== 씬 볼륨을 씩 볼륨으로 변경합니다

씬 볼륨을 씩 볼륨으로 변경하려면 볼륨 복사본 작업을 사용하여 씬 볼륨의 복사본을 만드십시오. 볼륨 복사본 작업의 타겟 볼륨은 항상 씩 볼륨입니다.

[NOTE]
====
System Manager는 씬 볼륨을 생성하는 옵션을 제공하지 않습니다. 씬 볼륨을 생성하려면 명령줄 인터페이스(CLI)를 사용하십시오.

====


[[backup-data]]
== 백업 데이터

볼륨 복사본 기능을 사용하면 동일한 스토리지 시스템의 한 볼륨에서 다른 볼륨으로 데이터를 복사하여 볼륨을 백업할 수 있습니다. 타겟 볼륨을 소스 볼륨의 백업, 시스템 테스트 또는 테이프 드라이브와 같은 다른 장치에 백업하는 용도로 사용할 수 있습니다.



[[restore-snapshot-volume-data-to-the-base-volume]]
== 스냅샷 볼륨 데이터를 기본 볼륨으로 복원합니다

연결된 스냅샷 볼륨에서 기본 볼륨으로 데이터를 복원해야 하는 경우 볼륨 복사본 기능을 사용하여 스냅샷 볼륨에서 기본 볼륨으로 데이터를 복사할 수 있습니다. 스냅샷 볼륨의 데이터에 대한 볼륨 복사본을 생성한 다음 해당 데이터를 기본 볼륨으로 복사할 수 있습니다.
