= SANtricity System Manager에서 스냅샷 이미지 예약
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 일정을 생성하면 기본 볼륨에 문제가 발생했을 때 복구를 수행하고 예약된 백업을 실행할 수 있습니다. 기본 볼륨 또는 스냅샷 일관성 그룹의 스냅샷은 일별, 주별 또는 월별 일정으로, 하루 중 언제든지 생성할 수 있습니다.

.시작하기 전에
기본 볼륨은 최적이어야 합니다.

.이 작업 정보
이 작업에서는 기존 스냅샷 일관성 그룹 또는 기본 볼륨에 대한 스냅샷 일정을 생성하는 방법을 설명합니다.

[NOTE]
====
기본 볼륨 또는 스냅샷 일관성 그룹의 스냅샷 이미지를 생성할 때 동시에 스냅샷 일정을 생성할 수도 있습니다.

====
.단계
. 스냅샷 일정을 생성하려면 다음 작업 중 하나를 수행하십시오.
+
** 메뉴: Storage[Volumes]를 선택합니다.
+
이 스냅샷 일정에 사용할 개체(볼륨 또는 스냅샷 일관성 그룹)를 선택한 다음 메뉴: Copy Services[스냅샷 일정 생성]를 선택합니다.

** 메뉴: Storage[Snapshots]를 선택합니다.
+
*Schedules* 탭을 선택한 다음 *Create*를 클릭합니다.



. 이 스냅샷 일정에 사용할 개체(볼륨 또는 스냅샷 일관성 그룹)를 선택한 다음 *다음*을 클릭합니다.
+
스냅샷 일정 생성 대화 상자가 나타납니다.

. 다음 작업 중 하나를 수행합니다.
+
** *다른 스냅샷 객체에서 이전에 정의된 스냅샷 일정을 사용합니다*.
+
고급 옵션이 표시되는지 확인하십시오. *추가 옵션 표시*를 클릭합니다. *일정 가져오기*를 클릭하고 가져올 일정이 있는 개체를 선택한 다음 *가져오기*를 클릭합니다.

** *기본 또는 고급 옵션을 수정합니다*.
+
대화 상자 오른쪽 상단에서 *더 많은 옵션 표시*를 클릭하여 모든 옵션을 표시한 다음 다음 표를 참조하십시오.



+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 필드 | 설명 


 a| 
*기본 설정*



 a| 
날짜 선택
 a| 
스냅샷 이미지의 요일을 개별적으로 선택합니다.



 a| 
시작 시간
 a| 
드롭다운 목록에서 일일 스냅샷의 새 시작 시간을 선택하세요(30분 단위로 선택 가능). 시작 시간은 기본적으로 현재 시간보다 30분 앞선 시간으로 설정됩니다.



 a| 
시간대
 a| 
드롭다운 목록에서 어레이의 시간대를 선택합니다.



 a| 
*고급 설정*



 a| 
일 / 월
 a| 
다음 옵션 중 하나를 선택하십시오.

** *일별/주별* -- 동기화 스냅샷을 저장할 특정 날짜를 선택하세요. 매일 일정을 저장하려면 오른쪽 상단의 *모든 날짜 선택* 확인란을 선택할 수도 있습니다.
** *월별/연간* -- 동기화 스냅샷을 저장할 특정 월을 선택하세요. *일* 필드에 동기화할 날짜를 입력하세요. 유효한 입력값은 *1*부터 *31*까지, 그리고 *마지막*입니다. 여러 날짜는 쉼표 또는 세미콜론으로 구분할 수 있습니다. 포함 날짜에는 하이픈을 사용하세요. 예: 1,3,4,10-15,마지막. 월별 스냅샷 일정을 원하시면 오른쪽 상단의 *모든 월 선택* 확인란을 선택하세요.




 a| 
시작 시간
 a| 
드롭다운 목록에서 일일 스냅샷의 새 시작 시간을 선택하세요(30분 단위로 선택 가능). 시작 시간은 기본적으로 현재 시간보다 30분 앞선 시간으로 설정됩니다.



 a| 
시간대
 a| 
드롭다운 목록에서 어레이의 시간대를 선택합니다.



 a| 
일일 스냅샷 수 / 스냅샷 간 시간
 a| 
하루에 생성할 스냅샷 이미지 수를 선택합니다. 둘 이상을 선택하는 경우 스냅샷 이미지 사이의 시간도 선택합니다. 여러 스냅샷 이미지의 경우 적절한 예약된 용량이 있는지 확인하십시오.



 a| 
지금 스냅샷 이미지를 생성하시겠습니까?
 a| 
예약된 자동 이미지 외에 즉석 이미지를 추가로 생성하려면 이 확인란을 선택하십시오.



 a| 
시작/종료 날짜 또는 종료 날짜 없음
 a| 
동기화를 시작할 시작 날짜를 입력합니다. 종료 날짜를 입력하거나 *종료 날짜 없음*을 선택합니다.

|===
====
. 다음 작업 중 하나를 수행합니다.
+
** 해당 개체가 스냅샷 일관성 그룹인 경우 *만들기*를 클릭하여 설정을 적용하고 일정을 생성합니다.
** 객체가 볼륨인 경우 *다음*을 클릭하여 스냅샷 이미지에 대한 예약된 용량을 할당합니다.
+
볼륨 후보 테이블에는 지정된 예약 용량을 지원하는 후보만 표시됩니다. 예약 용량은 모든 복사 서비스 작업 및 스토리지 객체에 사용되는 물리적으로 할당된 용량입니다. 호스트에서 직접 읽을 수는 없습니다.



. 스피너 상자를 사용하여 스냅샷 이미지에 대해 예약된 용량을 할당합니다. 다음 작업 중 하나를 수행합니다.
+
** *기본 설정을 그대로 사용하세요.*
+
스냅샷 이미지에 대한 예약된 용량을 기본 설정으로 할당하려면 이 권장 옵션을 사용하십시오.

** *데이터 스토리지 요구사항을 충족하도록 예약된 용량 설정을 할당하십시오.*
+
기본 예약 용량 설정을 변경한 경우 * 후보 새로 고침 * 을 클릭하여 지정한 예약 용량에 대한 후보 목록을 새로 고치십시오.

+
다음 지침에 따라 예약된 용량을 할당하십시오.

+
*** 예약된 용량의 기본 설정은 기본 볼륨 용량의 40%입니다. 일반적으로 이 용량이면 충분합니다.
*** 필요한 용량은 볼륨에 대한 I/O 쓰기의 빈도 및 크기와 스냅샷 이미지 수집의 양 및 기간에 따라 달라집니다.




. * 다음 * 을 클릭합니다.
+
설정 편집 대화 상자가 나타납니다.

. 필요에 따라 스냅샷 일정 설정을 편집한 다음 *마침*을 클릭합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
*스냅샷 이미지 제한*



 a| 
다음과 같은 경우 스냅샷 이미지 자동 삭제를 활성화합니다...
 a| 
지정된 제한 후 스냅샷 이미지가 자동으로 삭제되도록 하려면 확인란을 선택한 상태로 유지하십시오. 스피너 상자를 사용하여 제한을 변경하십시오. 이 확인란을 선택 취소하면 스냅샷 이미지 생성이 32개 이미지 이후 중단됩니다.



 a| 
*예약된 용량 설정*



 a| 
다음의 경우 알림...
 a| 
스피너 상자를 사용하여 스케줄의 예약된 용량이 거의 다 찼을 때 시스템에서 알림을 보내는 시점을 백분율로 조정할 수 있습니다.

일정에 대해 예약된 용량이 지정된 임계값을 초과하면 사전 알림을 사용하여 남은 공간이 소진되기 전에 예약된 용량을 늘리거나 불필요한 객체를 삭제하십시오.



 a| 
전체 예약 용량에 대한 정책
 a| 
다음 정책 중 하나를 선택하십시오.

** *가장 오래된 스냅샷 이미지 삭제* -- 시스템은 가장 오래된 스냅샷 이미지를 자동으로 삭제하여 스냅샷 그룹 내에서 재사용할 수 있도록 스냅샷 이미지 예약 용량을 해제합니다.
** *기본 볼륨에 대한 쓰기 거부* -- 예약된 용량이 정의된 최대 비율에 도달하면 시스템은 예약된 용량 액세스를 트리거한 기본 볼륨에 대한 모든 I/O 쓰기 요청을 거부합니다.
