= SANtricity System Manager에서 스냅샷 볼륨을 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
백업이나 소프트웨어 애플리케이션 테스트 목적으로 더 이상 필요하지 않은 스냅샷 볼륨 또는 스냅샷 일관성 그룹 스냅샷 볼륨을 삭제할 수 있습니다.

 `read-write` 스냅샷 볼륨과 연결된 스냅샷 예약 용량 볼륨을 삭제할지 아니면 스냅샷 예약 용량 볼륨을 할당되지 않은 볼륨으로 유지할지 여부를 지정할 수도 있습니다.

.이 작업 정보
기본 볼륨을 삭제하면 연결된 스냅샷 볼륨 또는 일관성 그룹 스냅샷 볼륨도 자동으로 삭제됩니다. *진행 중* 상태인 볼륨 복사본에 있는 스냅샷 볼륨은 삭제할 수 없습니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. *스냅샷 볼륨* 탭을 선택합니다.
+
System Manager는 스토리지 어레이와 연결된 모든 스냅샷 볼륨을 표시합니다.

. 삭제하려는 스냅샷 볼륨을 선택한 다음 menu:Uncommon Tasks[Delete]를 선택합니다.
. 작업을 수행할 것인지 확인한 다음 * 삭제 * 를 클릭합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 모든 구성원 스냅샷 볼륨을 삭제합니다(스냅샷 일관성 그룹 스냅샷 볼륨의 경우).
* 연결된 모든 호스트 할당을 제거합니다.
