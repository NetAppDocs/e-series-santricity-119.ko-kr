= SANtricity System Manager의 액세스 볼륨
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
액세스 볼륨은 스토리지 어레이에 공장에서 구성된 볼륨으로, 호스트 I/O 연결을 통해 스토리지 어레이 및 호스트와 통신하는 데 사용됩니다. 액세스 볼륨에는 LUN(논리 장치 번호)이 필요합니다.

액세스 볼륨은 다음 인스턴스에서 사용됩니다.

* *인밴드 관리* -- 액세스 볼륨은 스토리지 어레이를 관리하기 위한 인밴드 연결에 사용됩니다. 이는 명령줄 인터페이스(CLI)를 사용하여 스토리지 어레이를 관리하는 경우에만 수행할 수 있습니다.
+
[NOTE]
====
E4000, EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서는 Access 볼륨을 사용한 인밴드 관리가 지원되지 않습니다.

====


액세스 볼륨은 호스트에 볼륨을 처음 할당할 때 자동으로 생성됩니다. 예를 들어, Volume_1과 Volume_2를 호스트에 할당하면 할당 결과를 볼 때 세 개의 볼륨(Volume_1, Volume_2, Access)이 표시됩니다.

호스트를 자동으로 생성하거나 CLI를 사용하여 인밴드 방식으로 스토리지 어레이를 관리하지 않는 경우 액세스 볼륨이 필요하지 않으므로 액세스 볼륨을 삭제하여 LUN을 해제할 수 있습니다. 이 작업을 수행하면 볼륨과 LUN 간의 할당 및 호스트에 대한 모든 인밴드 관리 연결이 제거됩니다.
