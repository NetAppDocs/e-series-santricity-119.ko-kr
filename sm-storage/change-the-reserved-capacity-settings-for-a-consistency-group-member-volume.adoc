= SANtricity System Manager에서 일관성 그룹 구성원 볼륨의 예약 용량 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일관성 그룹 구성원 볼륨에 대한 설정을 변경하여 구성원 볼륨의 예약된 용량이 거의 가득 찼을 때 SANtricity System Manager가 알림 통지를 보내는 백분율 지점을 조정하고 예약된 용량이 정의된 최대 백분율에 도달했을 때 사용할 정책을 변경할 수 있습니다.

.이 작업 정보
개별 멤버 볼륨의 예약 용량 설정을 변경하면 일관성 그룹과 연결된 모든 멤버 볼륨의 예약 용량 설정도 변경됩니다.

.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. *예약된 용량* 탭을 클릭합니다.
. 편집하려는 일관성 그룹 멤버 볼륨을 선택한 다음 *설정 보기/편집*을 클릭합니다.
+
구성원 볼륨 예약된 용량 설정 대화 상자가 나타납니다.

. 구성원 볼륨에 대한 예약된 용량 설정을 적절하게 변경하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
다음의 경우 알림...
 a| 
스피너 상자를 사용하여 멤버 볼륨의 예약된 용량이 거의 가득 찼을 때 System Manager가 알림 통지를 보내는 백분율 지점을 조정합니다.

멤버 볼륨에 예약된 용량이 지정된 임계값을 초과하면 System Manager가 경고를 보내 예약 용량을 늘리거나 불필요한 객체를 삭제할 시간을 줍니다.


NOTE: 하나의 멤버 볼륨에 대한 알림 설정을 변경하면 동일한 일관성 그룹에 속한 _모든_ 멤버 볼륨에 대한 알림 설정이 변경됩니다.



 a| 
전체 예약 용량에 대한 정책
 a| 
다음 정책 중 하나를 선택할 수 있습니다.

** *가장 오래된 스냅샷 이미지 삭제* -- System Manager는 일관성 그룹에서 가장 오래된 스냅샷 이미지를 자동으로 삭제하여 그룹 내에서 재사용할 수 있도록 구성원의 예약된 용량을 해제합니다.
** *기본 볼륨에 대한 쓰기 거부* -- 예약된 용량이 정의된 최대 비율에 도달하면 System Manager는 예약된 용량 액세스를 유발한 기본 볼륨에 대한 모든 I/O 쓰기 요청을 거부합니다.


|===
====
. 변경 사항을 적용하려면 *저장*을 클릭합니다.


.결과
System Manager는 구성원 볼륨에 대한 예약된 용량 설정과 일관성 그룹의 모든 구성원 볼륨에 대한 예약된 용량 설정을 변경합니다.
