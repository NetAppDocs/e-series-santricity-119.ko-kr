= SANtricity System Manager에서 원격 스토리지 객체 제거
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
가져오기가 완료되면 로컬 장치와 원격 장치 간에 더 이상 데이터를 복사하지 않으려는 경우 원격 스토리지 객체를 제거할 수 있습니다.

.시작하기 전에
제거하려는 원격 스토리지 객체와 연결된 가져오기가 없는지 확인하십시오.

.이 작업 정보
원격 스토리지 개체를 제거하면 로컬 장치와 원격 장치 간의 연결이 제거됩니다.

.단계
. 메뉴: Storage[Remote storage]를 선택합니다.
. 목록에서 제거할 원격 스토리지 객체를 선택합니다.
. *제거*를 클릭합니다.
+
원격 스토리지 연결 제거 확인 대화 상자가 표시됩니다.

.  `remove`을(를) 입력한 다음 *제거*를 클릭하여 작업을 확인합니다.
+
선택한 원격 스토리지 객체가 제거되었습니다.
