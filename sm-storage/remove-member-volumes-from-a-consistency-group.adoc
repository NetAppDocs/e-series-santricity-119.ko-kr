= SANtricity System Manager에서 스냅샷 일관성 그룹에서 멤버 볼륨을 제거합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기존 스냅샷 일관성 그룹에서 구성원 볼륨을 제거할 수 있습니다.

.이 작업 정보
스냅샷 일관성 그룹에서 구성원 볼륨을 제거하면 System Manager가 해당 구성원 볼륨과 연결된 스냅샷 객체를 자동으로 삭제합니다.

.단계
. 메뉴: Storage[Snapshots]를 선택합니다.
. * Snapshot 일관성 그룹* 탭을 클릭합니다.
. 수정하려는 스냅샷 일관성 그룹 옆에 있는 더하기(+) 기호를 선택하여 확장합니다.
. 제거하려는 멤버 볼륨을 선택한 다음 *Remove*를 클릭하십시오.
. 작업을 수행할 것인지 확인한 다음 * 제거 * 를 클릭합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 멤버 볼륨과 연결된 모든 스냅샷 이미지 및 스냅샷 볼륨을 삭제합니다.
* 멤버 볼륨과 연결된 스냅샷 그룹을 삭제합니다.
* 멤버 볼륨은 그 외에는 변경되거나 삭제되지 않습니다.
