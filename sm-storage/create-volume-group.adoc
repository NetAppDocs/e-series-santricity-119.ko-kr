= SANtricity System Manager에서 볼륨 그룹을 생성합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨 그룹을 사용하여 호스트에서 액세스할 수 있는 하나 이상의 볼륨을 생성합니다. 볼륨 그룹은 RAID 레벨 및 용량과 같은 공유 특성을 가진 볼륨의 컨테이너입니다.

대용량 드라이브와 컨트롤러 간 볼륨 분산 기능을 활용하면 볼륨 그룹당 여러 볼륨을 생성하여 스토리지 용량을 활용하고 데이터를 보호할 수 있습니다.

.시작하기 전에
볼륨 그룹을 생성하기 전에 다음 지침을 검토하십시오.

* 할당되지 않은 드라이브가 최소 하나 필요합니다.
* 단일 볼륨 그룹에 포함할 수 있는 드라이브 수에는 제한이 있습니다. 이러한 제한은 RAID 레벨에 따라 다릅니다.
* 셸프/드로어 손실 방지 기능을 활성화하려면 RAID 1을 사용하는 경우를 제외하고 최소 3개의 셸프 또는 드로어에 있는 드라이브를 사용하는 볼륨 그룹을 생성해야 합니다. 여기서 RAID 1의 경우 최소 2개의 셸프/드로어가 필요합니다.
* EF600 또는 EF300 스토리지 어레이를 사용 중이고 볼륨 그룹을 수동으로 생성하려는 경우, 각 컨트롤러가 처음 12개 슬롯과 마지막 12개 슬롯에 동일한 수의 드라이브에 액세스할 수 있도록 설정해야 합니다. 이 구성을 통해 컨트롤러가 두 드라이브 측 PCIe 버스를 보다 효과적으로 사용할 수 있습니다. 현재 System Manager에서는 볼륨 그룹 생성 시 고급 기능에서 드라이브를 선택할 수 있습니다.
* 선택한 RAID 레벨이 볼륨 그룹의 최종 용량에 어떤 영향을 미치는지 검토하십시오.
+
** RAID 1을 선택하는 경우, 미러링된 드라이브 쌍이 구성되도록 한 번에 두 개의 드라이브를 추가해야 합니다. 미러링과 스트라이핑(RAID 10 또는 RAID 1+0이라고도 함)은 네 개 이상의 드라이브를 선택할 때 구현됩니다.
** RAID 5를 선택하는 경우 볼륨 그룹을 생성하려면 최소 3개의 드라이브를 추가해야 합니다.
** RAID 6을 선택하는 경우 볼륨 그룹을 생성하려면 최소 5개의 드라이브를 추가해야 합니다.




.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. 메뉴: 생성[볼륨 그룹]을 클릭합니다.
+
볼륨 그룹 생성 대화 상자가 나타납니다.

. 볼륨 그룹의 이름을 입력합니다.
. 데이터 스토리지 및 보호 요구 사항에 가장 적합한 RAID 레벨을 선택하십시오.
+
볼륨 그룹 후보 테이블이 나타나고 선택한 RAID 레벨을 지원하는 후보만 표시됩니다.

. *선택 사항:* 스토리지 어레이에 두 가지 이상의 드라이브 유형이 있는 경우 사용할 드라이브 유형을 선택하십시오.
+
볼륨 그룹 후보 테이블이 나타나고 선택한 드라이브 유형 및 RAID 레벨을 지원하는 후보만 표시됩니다.

. *선택 사항:* 볼륨 그룹에 사용할 드라이브를 정의하는 방법으로 자동 또는 수동 방식을 선택할 수 있습니다. 자동 방식이 기본 선택 사항입니다.
+
드라이브를 수동으로 선택하려면 *드라이브 수동 선택(고급)* 링크를 클릭하십시오. 클릭하면 *드라이브 자동 선택(고급)* 으로 변경됩니다.

+
수동 방식을 사용하면 볼륨 그룹을 구성할 특정 드라이브를 선택할 수 있습니다. 할당되지 않은 특정 드라이브를 선택하여 필요한 용량을 확보할 수 있습니다. 스토리지 어레이에 미디어 유형이나 인터페이스 유형이 다른 드라이브가 포함된 경우, 단일 드라이브 유형에 대한 구성되지 않은 용량만 선택하여 새 볼륨 그룹을 생성할 수 있습니다.

+
[NOTE]
====
드라이브 이중화 및 최적 드라이브 구성을 이해하는 전문가만 수동 방법을 사용해야 합니다.

====
. 표시된 드라이브 특성을 기반으로 볼륨 그룹에 사용할 드라이브를 선택한 다음 *Create*를 클릭합니다.
+
표시되는 드라이브 특성은 자동 방법을 선택했는지 수동 방법을 선택했는지에 따라 달라집니다.

.자동 방식 드라이브 특성

| 특성 | 사용 


 a| 
여유 용량
 a| 
사용 가능한 용량을 GiB 단위로 표시합니다. 애플리케이션의 스토리지 요구 사항에 맞는 용량의 볼륨 그룹 후보를 선택하십시오.



 a| 
총 드라이브
 a| 
이 볼륨 그룹에 사용할 수 있는 드라이브 수를 표시합니다. 원하는 드라이브 수를 가진 볼륨 그룹 후보를 선택하십시오.



 a| 
드라이브 블록 크기(EF300 및 EF600만 해당)
 a| 
그룹 내 드라이브가 쓸 수 있는 블록 크기(섹터 크기)를 보여줍니다. 값에는 다음이 포함될 수 있습니다.

** 512 -- 512바이트 섹터 크기
** 4K -- 4,096바이트 섹터 크기.




 a| 
보안 가능
 a| 
이 볼륨 그룹 후보가 FDE(Full Disk Encryption) 드라이브 또는 FIPS(Federal Information Processing Standard) 드라이브와 같은 보안 기능을 갖춘 드라이브로만 구성되어 있는지 여부를 나타냅니다.

** 드라이브 보안 기능을 사용하여 볼륨 그룹을 보호할 수 있지만, 이 기능을 사용하려면 모든 드라이브가 보안 기능을 지원해야 합니다.
** FDE 전용 볼륨 그룹을 생성하려면 Secure-Capable 열에서 *Yes - FDE*를 찾으십시오. FIPS 전용 볼륨 그룹을 생성하려면 *Yes - FIPS* 또는 *Yes - FIPS (Mixed)*를 찾으십시오. "Mixed"는 140-2 및 140-3 레벨 드라이브가 혼합되어 있음을 나타냅니다. 이러한 레벨을 혼합하여 사용하는 경우 볼륨 그룹은 더 낮은 보안 레벨(140-2)로 작동하게 됩니다.
** 보안 기능을 지원하거나 지원하지 않는 드라이브 또는 다양한 보안 수준의 드라이브가 혼합된 드라이브로 볼륨 그룹을 생성할 수 있습니다. 볼륨 그룹에 보안 기능을 지원하지 않는 드라이브가 포함된 경우 해당 볼륨 그룹을 보안 그룹으로 설정할 수 없습니다.




 a| 
보안을 활성화하시겠습니까?
 a| 
보안 기능을 지원하는 드라이브에서 드라이브 보안 기능을 활성화할 수 있는 옵션을 제공합니다. 볼륨 그룹이 보안 기능을 지원하고 보안 키를 설정한 경우 확인란을 선택하여 드라이브 보안을 활성화할 수 있습니다.


NOTE: 드라이브 보안을 활성화한 후 제거하는 유일한 방법은 볼륨 그룹을 삭제하고 드라이브를 지우는 것입니다.



 a| 
DA 지원
 a| 
이 그룹에 데이터 보증(DA) 기능이 제공되는지 여부를 나타냅니다. 데이터 보증(DA)은 데이터가 컨트롤러를 거쳐 드라이브로 전송되는 동안 발생할 수 있는 오류를 검사하고 수정합니다.

DA를 사용하려면 DA를 지원하는 볼륨 그룹을 선택하십시오. (DA 지원 드라이브의 경우, 풀에 생성된 볼륨에서 DA가 자동으로 활성화됩니다.)

볼륨 그룹에는 DA 지원 드라이브 또는 DA 비지원 드라이브가 포함될 수 있지만 이 기능을 사용하려면 모든 드라이브가 DA를 지원해야 합니다.



 a| 
Resource Provisioning Capable(EF300 및 EF600만 해당)
 a| 
이 그룹에 대해 리소스 프로비저닝을 사용할 수 있는지 여부를 표시합니다. 리소스 프로비저닝은 EF300 및 EF600 스토리지 어레이에서 사용할 수 있는 기능으로, 백그라운드 초기화 프로세스 없이 볼륨을 즉시 사용할 수 있도록 합니다.



 a| 
쉘프 손실 보호
 a| 
쉘프 손실 보호 기능이 사용 가능한지 여부를 표시합니다. 쉘프 손실 보호 기능은 쉘프와의 통신이 완전히 두절되더라도 볼륨 그룹 내 볼륨의 데이터에 대한 접근성을 보장합니다.



 a| 
드로어 손실 방지
 a| 
드로어 손실 방지 기능 사용 가능 여부를 표시합니다. 이 기능은 드로어가 포함된 드라이브 셸프를 사용하는 경우에만 제공됩니다. 드로어 손실 방지 기능은 드라이브 셸프의 단일 드로어와의 통신이 완전히 두절되더라도 볼륨 그룹의 볼륨에 있는 데이터에 대한 접근을 보장합니다.



 a| 
지원되는 볼륨 블록 크기(EF300 및 EF600만 해당)
 a| 
그룹 내 볼륨에 대해 생성할 수 있는 블록 크기를 보여줍니다.

** 512n -- 512바이트 네이티브.
** 512e -- 512바이트 에뮬레이션.
** 4K -- 4,096바이트

미디어 유형

** 하드 드라이브
** SSD(Solid State Disk)


볼륨 그룹의 모든 드라이브는 동일한 미디어 유형이어야 합니다(모두 SSD이거나 모두 하드 드라이브). 볼륨 그룹에는 미디어 유형이나 인터페이스 유형이 혼합되어 있을 수 없습니다.



 a|

** 512 -- 512바이트 섹터 크기
** 4K -- 4,096바이트 섹터 크기.

드라이브 용량
 a| 
드라이브 용량을 나타냅니다.

** 가능하면 볼륨 그룹에 있는 현재 드라이브의 스토리지 용량과 동일한 스토리지 용량의 드라이브를 선택하십시오.
** 용량이 더 작은 할당되지 않은 드라이브를 추가해야 하는 경우, 현재 볼륨 그룹에 있는 각 드라이브의 사용 가능한 용량이 줄어든다는 점에 유의하십시오. 따라서 볼륨 그룹 전체의 드라이브 용량은 동일합니다.
** 용량이 더 큰 할당되지 않은 드라이브를 추가해야 하는 경우, 추가하는 할당되지 않은 드라이브의 사용 가능한 용량이 볼륨 그룹의 드라이브 현재 용량과 일치하도록 줄어든다는 점에 유의하십시오.

보안 가능
 a|

** 드라이브 보안 기능을 사용하여 볼륨 그룹을 보호할 수 있지만, 이 기능을 사용하려면 모든 드라이브가 보안 기능을 지원해야 합니다.
** FDE 전용 볼륨 그룹을 생성하려면 Secure-Capable 열에서 *Yes - FDE*를 찾으십시오. FIPS 전용 볼륨 그룹을 생성하려면 *Yes - FIPS* 또는 *Yes - FIPS (Mixed)*를 찾으십시오. "Mixed"는 140-2 및 140-3 레벨 드라이브가 혼합되어 있음을 나타냅니다. 이러한 레벨을 혼합하여 사용하는 경우 볼륨 그룹은 더 낮은 보안 레벨(140-2)로 작동하게 됩니다.
** 보안 기능을 지원하거나 지원하지 않는 드라이브 또는 다양한 보안 수준의 드라이브가 혼합된 드라이브로 볼륨 그룹을 생성할 수 있습니다. 볼륨 그룹에 보안 기능을 지원하지 않는 드라이브가 포함된 경우 해당 볼륨 그룹을 보안 그룹으로 설정할 수 없습니다.




 a| 
DA 지원
 a| 
이 그룹에 데이터 보증(DA) 기능이 제공되는지 여부를 나타냅니다. 데이터 보증(DA)은 컨트롤러를 통해 드라이브로 데이터가 전송되는 과정에서 발생할 수 있는 오류를 검사하고 수정합니다.

DA를 사용하려면 DA를 지원하는 볼륨 그룹을 선택하십시오. (DA 지원 드라이브의 경우, 풀에 생성된 볼륨에서 DA가 자동으로 활성화됩니다.)

볼륨 그룹에는 DA 지원 드라이브 또는 DA 비지원 드라이브가 포함될 수 있지만 이 기능을 사용하려면 모든 드라이브가 DA를 지원해야 합니다.
