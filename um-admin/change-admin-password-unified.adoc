= SANtricity Unified Manager에서 관리자 암호를 변경하세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager에 액세스하는 데 사용되는 관리자 암호를 변경할 수 있습니다.

.시작하기 전에
* Root 관리자 권한을 포함한 로컬 관리자로 로그인해야 합니다.
* 현재 관리자 비밀번호를 알고 있어야 합니다.


.이 작업 정보
비밀번호를 선택할 때 다음 지침을 염두에 두십시오.

* 비밀번호는 대소문자를 구분합니다.
* 비밀번호를 설정할 때 끝부분의 공백은 제거되지 않습니다. 비밀번호에 공백이 포함된 경우 공백을 포함해야 합니다.
* 보안 강화를 위해 최소 15자의 영숫자를 사용하고 비밀번호를 자주 변경하십시오.


.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. *로컬 사용자 역할* 탭을 선택합니다.
. 표에서 *admin* 사용자를 선택합니다.
+
비밀번호 변경 버튼이 활성화됩니다.

. *Change Password*를 선택합니다.
+
암호 변경 대화 상자가 열립니다.

. 로컬 사용자 암호에 최소 암호 길이가 설정되어 있지 않은 경우 확인란을 선택하여 사용자가 시스템에 액세스하기 위해 암호를 입력하도록 요구합니다.
. 두 필드에 새 암호를 입력합니다.
. 이 작업을 확인하려면 로컬 관리자 암호를 입력한 다음 *변경*을 클릭하십시오.
