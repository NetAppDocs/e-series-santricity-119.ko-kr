[role="lead"]
무단 액세스로부터 보호하려면 SANtricity Unified Manager를 관리자 암호로 구성해야 합니다.



== 관리자 암호 및 사용자 프로필

Unified Manager를 처음 시작할 때 관리자 암호를 설정하라는 메시지가 표시됩니다. 관리자 암호를 가진 사용자는 스토리지 어레이의 구성을 변경할 수 있습니다.

Unified Manager 인터페이스에는 관리자 암호 외에도 하나 이상의 역할이 매핑된 사전 구성된 사용자 프로필이 포함되어 있습니다. 자세한 내용은 link:../um-certificates/how-access-management-works-unified.html["Access Management 작동 방식"]를 참조하십시오.

사용자 및 매핑은 변경할 수 없습니다. 비밀번호만 수정할 수 있습니다. 비밀번호를 변경하려면 다음을 참조하십시오.

* link:change-admin-password-unified.html["관리자 비밀번호 변경"]
* link:../um-certificates/change-passwords-unified.html["로컬 사용자 프로필의 암호를 변경합니다"]




== 세션 시간 초과

소프트웨어는 단일 관리 세션 동안 한 번만 암호를 입력하라는 메시지를 표시합니다. 기본적으로 30분 동안 활동이 없으면 세션이 시간 초과되며, 이때 암호를 다시 입력해야 합니다. 다른 사용자가 다른 관리 클라이언트에서 소프트웨어에 액세스하여 세션이 진행 중인 동안 암호를 변경하면 다음에 구성 작업이나 보기 작업을 시도할 때 암호를 입력하라는 메시지가 표시됩니다.

보안상의 이유로 소프트웨어가 "잠금" 상태가 되기 전에 암호를 입력할 수 있는 횟수는 5회입니다. 이 상태에서는 소프트웨어가 후속 암호 시도를 거부합니다. 암호를 다시 입력하려면 "정상" 상태로 재설정하기 위해 10분을 기다려야 합니다.

세션 시간 제한을 조정하거나 세션 시간 제한을 완전히 비활성화할 수 있습니다. 자세한 내용은 link:manage-session-timeouts-unified.html["세션 시간 초과 관리"]를 참조하십시오.
