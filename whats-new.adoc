[cols="35h,~"]

[[new-features-in-version-11-90r1]]
== 버전 11.90R1의 새로운 기능

[cols="35h,~"]
|===
| 새로운 기능 | 설명 


 a| 
새로운 스토리지 시스템 모델 – EF300C 및 EF600C
 a| 
이번 릴리스에서는 EF300C 및 EF600C 올플래시 NVMe 스토리지 시스템이 새롭게 출시되었습니다. EF300C 및 EF600C는 기존 EF300 및 EF600 스토리지 시스템의 고용량 플래시 버전입니다. EF300C 및 EF600C는 30TB 또는 60TB 용량의 고용량 NVMe SSD 드라이브를 지원합니다. EF300C/EF600C는 Dynamic Disk Pool 사용과만 호환되며 레거시 RAID는 지원되지 않습니다.



 a| 
EF4000에서 12Gb SAS 인터페이스 지원
 a| 
E4000 컨트롤러는 이제 12Gb SAS 호스트 인터페이스 카드를 지원합니다.

|===


[[new-features-in-version-11-90]]
== 버전 11.90의 새로운 기능

[cols="35h,~"]
|===
| 새로운 기능 | 설명 


 a| 
새로운 스토리지 시스템 모델 – E4000
 a| 
이번 릴리스에서는 E4000 저가형 스토리지 시스템을 소개합니다. E4000은 12개 및 60개의 드라이브와 컨트롤러당 단일 호스트 인터페이스 카드(HIC)를 지원합니다. 초기 릴리스의 경우 지원되는 호스트 인터페이스 카드에는 iSCSI 및 Fibre Channel이 포함됩니다. E4000 스토리지 시스템 및 기타 E-Series 스토리지 시스템은 Unified Manager에서 확인하고 관리할 수 있습니다.



 a| 
Dynamic Disk Pool의 용량 증가
 a| 
동적 디스크 풀(DDP)의 용량이 풀 내 개별 드라이브 각각의 용량이 23TB를 초과하는 경우 12PB로 증가했습니다. 개별 드라이브 용량이 23TB 미만인 경우 DDP 용량은 6PB입니다.



 a| 
기본 미디어 스캔 설정이 증가했습니다
 a| 
기본 미디어 스캔 속도가 120일로 증가했습니다.



 a| 
이제 외부 키 관리에 개인 키가 허용됩니다
 a| 
이제 System Manager를 통해 개인 키와 공개 키 쌍을 사용하여 외부에서 생성된 인증서 서명 요청(CSR) 파일을 가져올 수 있습니다.



 a| 
Web Services에 로그인 잠금 기능이 추가되었습니다.
 a| 
REST API를 통해서만 구성 가능한 새로운 로그인 잠금 설정이 내장형 및 프록시 Web Services에 사용할 수 있게 되었습니다.

|===
