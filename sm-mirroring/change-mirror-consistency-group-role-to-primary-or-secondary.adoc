= SANtricity System Manager에서 미러 일관성 그룹 역할을 운영 또는 보조로 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
관리 목적으로 또는 로컬 스토리지 어레이에 재해가 발생한 경우 미러 일관성 그룹 간의 역할을 변경할 수 있습니다.

.이 작업 정보
로컬 스토리지 어레이에 생성된 미러 일관성 그룹은 기본 역할을 수행합니다. 원격 스토리지 어레이에 생성된 미러 일관성 그룹은 보조 역할을 수행합니다. 로컬 미러 일관성 그룹을 보조 역할로 강등하거나 원격 미러 일관성 그룹을 기본 역할로 승격할 수 있습니다.

.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러 일관성 그룹* 탭을 선택합니다.
+
미러 일관성 그룹 테이블이 나타나고 스토리지 어레이와 연결된 모든 미러 일관성 그룹이 표시됩니다.

. 역할을 변경하려는 미러 일관성 그룹을 선택한 다음 menu:More[Change role to <Primary | Secondary>]*>*를 선택합니다.
+
시스템에 확인 메시지가 표시됩니다.

. 미러 일관성 그룹의 역할을 변경할 것인지 확인한 다음 *역할 변경*을 클릭하십시오.
+
[NOTE]
====
역할 변경을 요청했지만 원격 스토리지 어레이에 연결할 수 없는 경우 시스템에서 "스토리지 어레이에 연결할 수 없음" 대화 상자가 표시됩니다. 역할 변경을 강제로 수행하려면 *예*를 클릭하십시오.

====


.결과
System Manager는 다음 작업을 수행합니다.

* 미러 일관성 그룹 표에는 역할 변경이 진행 중인 미러 일관성 그룹 옆에 "대기 중" 또는 "진행 중" 상태가 표시됩니다. 표 셀에 있는 *취소* 링크를 클릭하여 보류 중인 역할 변경 작업을 취소할 수 있습니다.
* 연결된 미러 일관성 그룹에 연결할 수 있는 경우 미러 일관성 그룹 간의 역할이 변경됩니다. System Manager는 사용자의 선택에 따라 보조 미러 일관성 그룹을 운영 역할로 승격시키거나 운영 미러 일관성 그룹을 보조 역할로 강등시킵니다. 역할 변경은 선택한 미러 일관성 그룹 내의 모든 미러링된 쌍에 영향을 줍니다.
