= SANtricity 소프트웨어의 비동기 미러링에서 볼륨 소유권에 대해 알아보십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러링된 쌍에서 기본 컨트롤러 소유자를 변경할 수 있습니다.

미러링된 쌍의 운영 볼륨이 컨트롤러 A의 소유인 경우, 2차 볼륨 또한 원격 스토리지 시스템의 컨트롤러 A의 소유가 됩니다. 운영 볼륨의 소유자를 변경하면 2차 볼륨의 소유자도 자동으로 변경되어 두 볼륨이 동일한 컨트롤러의 소유가 됩니다. 운영 측의 현재 소유권 변경 사항은 2차 측의 해당 현재 소유권 변경 사항에 자동으로 전파됩니다.

예를 들어, 기본 볼륨의 소유자가 컨트롤러 A인 상태에서 컨트롤러 소유자를 컨트롤러 B로 변경한다고 가정해 보겠습니다. 이 경우, 다음 원격 쓰기 작업 시 보조 볼륨의 컨트롤러 소유자도 컨트롤러 A에서 B로 변경됩니다. 보조 볼륨 측의 컨트롤러 소유권 변경은 기본 볼륨 측에서 제어되므로 스토리지 관리자의 특별한 개입이 필요하지 않습니다.



== 컨트롤러 재설정

컨트롤러 재설정을 수행하면 운영 측에서 스토리지 어레이의 기본 컨트롤러 소유자에서 대체 컨트롤러로 볼륨 소유권이 변경됩니다.

원격 쓰기 작업은 보조 볼륨에 기록되기 전에 컨트롤러 재설정이나 스토리지 어레이 전원 재인가로 인해 중단될 수 있습니다. 이 경우 컨트롤러는 미러링된 쌍의 전체 동기화를 수행할 필요가 없습니다.

컨트롤러 재설정 중에 원격 쓰기 작업이 중단되면 기본 측의 새 컨트롤러 소유자는 선호 컨트롤러 소유자의 예약 용량 볼륨에 있는 로그 파일에 저장된 정보를 읽습니다. 그런 다음 새 컨트롤러 소유자는 영향을 받는 데이터 블록을 기본 볼륨에서 보조 볼륨으로 복사하여 미러링된 볼륨의 전체 동기화를 수행할 필요가 없도록 합니다.
