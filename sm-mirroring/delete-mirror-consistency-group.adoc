= SANtricity System Manager에서 미러 일관성 그룹 삭제
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
로컬 스토리지 어레이와 원격 스토리지 어레이에서 더 이상 필요하지 않은 미러 일관성 그룹을 삭제할 수 있습니다.

.시작하기 전에
모든 미러링된 쌍은 미러 일관성 그룹에서 제거되어야 합니다.

.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러 일관성 그룹* 탭을 선택합니다.
+
미러 일관성 그룹 테이블이 나타나고 스토리지 어레이와 연결된 모든 미러 일관성 그룹이 표시됩니다.

. 삭제하려는 미러 일관성 그룹을 선택한 다음 메뉴: 일반적이지 않은 작업[삭제]를 선택합니다.
+
시스템에 확인 메시지가 표시됩니다.

. *예*를 선택하여 미러 일관성 그룹을 삭제합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 먼저 로컬 스토리지 어레이에서 미러 일관성 그룹을 삭제한 다음 원격 스토리지 어레이에서 미러 일관성 그룹을 삭제합니다.
* 미러 일관성 그룹 테이블에서 미러 일관성 그룹을 제거합니다.


.완료한 후
간혹 미러 일관성 그룹이 로컬 스토리지 어레이에서는 성공적으로 삭제되었지만, 통신 오류로 인해 미러 일관성 그룹이 원격 스토리지 어레이에서 삭제되지 않는 경우가 발생할 수 있습니다. 이 경우 원격 스토리지 어레이에 직접 접근하여 해당 미러 일관성 그룹을 삭제해야 합니다.
