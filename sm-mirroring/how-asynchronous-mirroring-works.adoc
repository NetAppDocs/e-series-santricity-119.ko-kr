= SANtricity System Manager에서 비동기 미러링이 작동하는 방식
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
비동기 미러링은 요청 시 또는 예약된 시간에 데이터 볼륨을 복사하여 데이터 손상이나 손실로 인해 발생할 수 있는 다운타임을 최소화하거나 방지합니다.

비동기 미러링은 특정 시점의 기본 볼륨 상태를 캡처하고 마지막 이미지 캡처 이후 변경된 데이터만 복사합니다. 기본 사이트는 즉시 업데이트할 수 있으며 보조 사이트는 대역폭이 허용하는 대로 업데이트할 수 있습니다. 정보는 캐시되었다가 네트워크 리소스가 사용 가능해지면 나중에 전송됩니다.

이러한 유형의 미러링은 중단 없는 운영 요구 사항을 충족하는 데 이상적이며, 일반적으로 백업 및 아카이브와 같은 주기적인 프로세스에 훨씬 더 네트워크 효율적입니다. 비동기 미러링을 사용하는 이유는 다음과 같습니다.

* 원격 백업 통합.
* 로컬 또는 광역 재해로부터 보호하십시오.
* 실시간 데이터의 시점 이미지를 기반으로 애플리케이션 개발 및 테스트를 수행합니다.




== 비동기식 미러링 세션

비동기 미러링은 특정 시점의 운영 볼륨 상태를 캡처하고 마지막 이미지 캡처 이후 변경된 데이터만 복사합니다. 비동기 미러링을 통해 운영 사이트는 즉시 업데이트되고 보조 사이트는 대역폭이 허용하는 범위 내에서 업데이트될 수 있습니다. 정보는 캐시되었다가 네트워크 리소스가 사용 가능해지면 나중에 전송됩니다.

활성 비동기 미러링 세션에는 네 가지 주요 단계가 있습니다.

image::../media/sam-1130-dwg-async-mirroring-session.gif[비동기식 미러링 세션]

. 쓰기 작업이 먼저 운영 볼륨의 스토리지 어레이에서 발생합니다.
. 작업 상태가 호스트에 반환됩니다.
. 운영 볼륨의 모든 변경 사항은 기록되고 추적됩니다.
. 모든 변경 사항은 백그라운드 프로세스로 2차 볼륨의 스토리지 어레이로 전송됩니다.


이러한 단계는 정의된 동기화 간격에 따라 반복되거나, 간격이 정의되지 않은 경우 수동으로 반복될 수 있습니다.

비동기 미러링은 설정된 간격으로만 원격 사이트로 데이터를 전송하므로 로컬 I/O는 느린 네트워크 연결의 영향을 거의 받지 않습니다. 이러한 데이터 전송은 로컬 I/O와 연관되지 않으므로 애플리케이션 성능에 영향을 주지 않습니다. 따라서 비동기 미러링은 iSCSI와 같은 속도가 느린 연결을 사용할 수 있으며 로컬 스토리지 시스템과 원격 스토리지 시스템 간의 거리가 더 멀어도 실행할 수 있습니다.

스토리지 어레이는 최소 펌웨어 버전 7.84가 있어야 합니다. (각각 다른 OS 버전을 실행할 수 있습니다.)



== 미러 일관성 그룹 및 미러링된 쌍

미러 일관성 그룹을 생성하여 로컬 스토리지 어레이와 원격 스토리지 어레이 간의 미러링 관계를 설정합니다. 비동기 미러링 관계는 미러링된 쌍, 즉 한 스토리지 어레이의 기본 볼륨과 다른 스토리지 어레이의 보조 볼륨으로 구성됩니다.

주 볼륨이 포함된 스토리지 어레이는 일반적으로 기본 사이트에 위치하며 활성 호스트에 서비스를 제공합니다. 보조 볼륨이 포함된 스토리지 어레이는 일반적으로 보조 사이트에 위치하며 데이터 복제본을 저장합니다. 보조 볼륨은 일반적으로 데이터의 백업 복사본을 포함하며 재해 복구에 사용됩니다.



== 동기화 설정

미러링된 쌍을 생성할 때 통신 중단 후 재동기화 작업을 완료하기 위해 미러링된 쌍이 사용하는 동기화 우선 순위 및 재동기화 정책도 정의합니다.

미러 일관성 그룹을 생성할 때 그룹 내의 모든 미러링된 쌍에 대한 동기화 우선순위와 재동기화 정책을 정의합니다. 미러링된 쌍은 동기화 우선순위와 재동기화 정책을 사용하여 통신 중단 후 재동기화 작업을 완료합니다.

미러링된 쌍의 기본 볼륨과 보조 볼륨은 기본 볼륨의 스토리지 어레이가 보조 볼륨에 데이터를 쓸 수 없을 때 동기화되지 않을 수 있습니다. 이러한 현상은 다음과 같은 문제로 인해 발생할 수 있습니다.

* 로컬 스토리지 어레이와 원격 스토리지 어레이 간의 네트워크 문제
* 장애가 발생한 보조 볼륨.
* 미러링된 쌍에서 동기화가 수동으로 일시 중단되는 중입니다.
* 미러 그룹 역할 충돌.


원격 스토리지 어레이의 데이터는 수동 또는 자동으로 동기화할 수 있습니다.



== 예약된 용량 및 비동기식 미러링

예약 용량은 동기화가 발생하지 않을 때 운영 볼륨과 보조 볼륨 간의 차이를 추적하는 데 사용됩니다. 또한 각 미러링 쌍에 대한 동기화 통계도 추적합니다.

미러링된 쌍의 각 볼륨에는 자체 예약된 용량이 필요합니다.



== 구성 및 관리

두 어레이 간의 미러링을 활성화하고 구성하려면 Unified Manager 인터페이스를 사용해야 합니다. 미러링이 활성화되면 System Manager에서 미러링된 쌍과 동기화 설정을 관리할 수 있습니다.
