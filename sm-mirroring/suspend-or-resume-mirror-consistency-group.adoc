= SANtricity System Manager에서 미러 일관성 그룹의 동기화를 일시 중지하거나 다시 시작합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러 일관성 그룹 내의 모든 미러링된 쌍에서 데이터 동기화를 일시 중지하거나 재개할 수 있으며, 이는 개별 미러링된 쌍에 대해 동기화를 일시 중지하거나 재개하는 것보다 효율적입니다.

.이 작업 정보
그룹 동기화를 일시 중단했다가 다시 시작하면 로컬 스토리지 어레이의 변경된 데이터가 원격 스토리지 어레이로 복사되는 동안 호스트 애플리케이션에 발생할 수 있는 성능 영향을 줄이는 데 도움이 됩니다.

미러 일관성 그룹과 해당 미러 쌍의 상태는 동기화 활동을 재개하기 위해 Resume 옵션을 사용할 때까지 일시 중단된 상태로 유지됩니다.

.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러 일관성 그룹* 탭을 선택합니다.
+
미러링된 일관성 그룹 테이블이 나타나고 스토리지 어레이와 연결된 모든 미러 일관성 그룹이 표시됩니다.

. 일시 중지하거나 다시 시작할 미러 일관성 그룹을 선택한 다음 menu:More[Suspend] 또는 menu:More[Resume]을 선택합니다.
+
시스템에 확인 메시지가 표시됩니다.

. 확인하려면 *예*를 선택합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 미러 관계를 제거하지 않고 미러 일관성 그룹의 모든 미러링된 쌍 간의 데이터 전송을 일시 중지하거나 재개합니다.
* 미러 그룹이 일시 중단된 동안 미러 일관성 그룹의 운영 측에 기록된 모든 데이터를 로그에 기록하고, 미러 그룹이 다시 시작될 때 해당 데이터를 미러 일관성 그룹의 2차 측에 자동으로 기록합니다. 전체 동기화는 필요하지 않습니다.
* _일시 중단된_ 미러 일관성 그룹의 경우, 미러 일관성 그룹 테이블에 *사용자 일시 중단됨*으로 표시됩니다.
* _재개된_ 미러 일관성 그룹의 경우, 미러 일관성 그룹이 일시 중단된 동안 운영 볼륨에 기록된 데이터는 즉시 2차 볼륨에 기록됩니다. 자동 동기화 간격이 설정된 경우 주기적인 동기화가 재개됩니다.
