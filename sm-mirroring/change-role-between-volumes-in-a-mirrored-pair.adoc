= SANtricity System Manager에서 미러링된 볼륨 쌍 간의 역할을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
동기식 미러링에 참여하는 미러링 쌍의 두 볼륨 간에 역할 반전을 수행할 수 있습니다. 이 작업은 관리 목적이나 로컬 스토리지 어레이에 재해가 발생한 경우에 필요할 수 있습니다.

.이 작업 정보
기본 볼륨을 보조 볼륨으로 강등하거나 보조 볼륨을 기본 볼륨으로 승격시킬 수 있습니다. 기본 볼륨에 액세스하는 모든 호스트는 해당 볼륨에 대한 읽기/쓰기 권한을 갖습니다. 기본 볼륨이 보조 볼륨이 되면 기본 컨트롤러에서 시작된 원격 쓰기 작업만 해당 볼륨에 기록됩니다.

.단계
. 메뉴: 스토리지[동기식 미러링]를 선택합니다.
. 역할을 변경하려는 볼륨이 포함된 미러링된 쌍을 선택한 다음 menu:More[Change Role]를 선택합니다.
+
시스템에 확인 메시지가 표시됩니다.

. 볼륨의 역할을 변경할 것인지 확인한 다음 *역할 변경*을 선택합니다.
+
[NOTE]
====
로컬 스토리지 어레이가 원격 스토리지 어레이와 통신할 수 없는 경우, 역할 변경이 요청되었지만 원격 스토리지 어레이에 연결할 수 없을 때 시스템에 스토리지 어레이에 연결할 수 없음 대화 상자가 표시됩니다. *예*를 클릭하여 역할 변경을 강제로 수행합니다.

====


.결과
System Manager는 다음 작업을 수행합니다.

* 미러링된 쌍의 연결된 볼륨에 연결할 수 있는 경우 볼륨 간의 역할이 변경됩니다. System Manager는 미러링된 쌍의 보조 볼륨을 운영 역할로 승격시키거나 미러링된 쌍의 운영 볼륨을 보조 역할로 강등시킵니다(선택에 따라 다름).
