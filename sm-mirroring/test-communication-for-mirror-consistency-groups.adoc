= SANtricity System Manager에서 미러 일관성 그룹에 대한 통신 테스트
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러 일관성 그룹과 연결된 로컬 스토리지 시스템과 원격 스토리지 시스템 간의 통신 문제를 진단하기 위해 통신 링크를 테스트할 수 있습니다.

.시작하기 전에
테스트하려는 미러 일관성 그룹은 로컬 및 원격 스토리지 어레이에 존재해야 합니다.

.이 작업 정보
네 가지 테스트를 실행할 수 있습니다.

* *연결성* -- 두 컨트롤러 간에 통신 경로가 있는지 확인합니다. 연결성 테스트는 스토리지 어레이 간에 어레이 간 메시지를 전송한 다음 원격 스토리지 어레이에 해당 미러 일관성 그룹이 존재하는지 검증합니다. 또한 원격 스토리지 어레이의 미러 일관성 그룹 구성원 볼륨이 로컬 스토리지 어레이의 미러 일관성 그룹 구성원 볼륨과 일치하는지 검증합니다.
* *지연 시간* -- 미러 일관성 그룹과 연결된 원격 스토리지 시스템의 각 미러링된 볼륨에 SCSI Test Unit 명령을 전송하여 최소, 평균 및 최대 지연 시간을 테스트합니다.
* *대역폭* -- 원격 스토리지 어레이로 두 개의 어레이 간 메시지를 전송하여 최소, 평균 및 최대 대역폭과 테스트를 수행하는 어레이의 포트에 대한 협상된 링크 속도를 테스트합니다.
* *포트 연결* -- 로컬 스토리지 어레이에서 미러링에 사용되는 포트와 원격 스토리지 어레이에서 미러링된 데이터를 수신하는 포트를 보여줍니다.


.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러 일관성 그룹* 탭을 선택한 다음 테스트할 미러 일관성 그룹을 선택합니다.
. *Test Communication*을 선택합니다.
+
테스트 통신 대화 상자가 나타납니다.

. 선택한 미러 일관성 그룹과 연결된 로컬 및 원격 스토리지 시스템 간에 수행할 통신 테스트를 하나 이상 선택한 다음 *테스트*를 클릭합니다.
. Results 창에 표시된 정보를 검토하십시오.
+
[cols="35h,~"]
|===
| 통신 테스트 상태 | 설명 


 a| 
오류 없이 정상
 a| 
미러 일관성 그룹이 정상적으로 통신하고 있습니다.



 a| 
통과 상태(정상은 아님)
 a| 
네트워크 또는 연결 문제를 확인하고 테스트를 다시 시도하십시오.



 a| 
실패 상태
 a| 
오류의 원인이 표시되어 있습니다. 문제를 해결하려면 Recovery Guru를 참조하십시오.



 a| 
포트 연결 오류
 a| 
로컬 스토리지 어레이가 연결되지 않았거나 원격 스토리지 어레이에 연결할 수 없기 때문일 수 있습니다. 문제 해결을 위해 Recovery Guru를 참조하십시오.

|===


.결과
통신 테스트가 완료되면 이 대화 상자에 Normal 상태, Passed 상태 또는 Failed 상태가 표시됩니다.

통신 테스트에서 Failed 상태가 반환되면 미러 일관성 그룹 간의 통신이 복원될 때까지 이 대화 상자를 닫은 후에도 테스트가 계속 실행됩니다.
