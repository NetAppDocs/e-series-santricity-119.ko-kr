= SANtricity System Manager에서 동기식 미러링 상태에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
동기식 미러링된 쌍의 상태는 운영 볼륨과 2차 볼륨의 데이터가 동기화되었는지 여부를 나타냅니다. 미러 상태는 미러링된 쌍의 볼륨 구성요소 상태와는 무관합니다.

[NOTE]
====
이 기능은 EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서 사용할 수 없습니다.

====
동기식 미러링된 쌍은 다음 상태 중 하나를 가질 수 있습니다.

* *최적*
+
미러링된 쌍의 볼륨이 동기화되었음을 나타냅니다. 즉, 스토리지 어레이 간의 패브릭 연결이 작동 중이며 각 볼륨이 원하는 작동 상태임을 의미합니다.

* *동기화 중*
+
미러링된 쌍 간의 데이터 동기화 진행 상황을 표시합니다. 이 상태는 초기 동기화 중에도 표시됩니다.

+
통신 링크가 중단된 후에는 링크 중단 시간 동안 운영 볼륨에서 변경된 데이터 블록만 2차 볼륨으로 복사됩니다.

* *동기화되지 않음*
+
운영 볼륨의 스토리지 어레이가 수신 데이터를 원격 어레이에 쓸 수 없음을 나타냅니다. 로컬 호스트는 운영 볼륨에 계속 쓸 수 있지만 원격 쓰기는 수행되지 않습니다. 운영 볼륨의 스토리지 어레이가 수신 데이터를 2차 볼륨에 쓰지 못하게 하는 다양한 조건이 있을 수 있으며, 다음과 같은 경우가 있습니다.

+
** 보조 볼륨에 액세스할 수 없습니다.
** 원격 스토리지 어레이에 액세스할 수 없습니다.
** 스토리지 어레이 간의 패브릭 연결에 액세스할 수 없습니다.
** 보조 볼륨은 새 WWID(World Wide Identifier)로 업데이트할 수 없습니다.


* *일시 중단됨*
+
사용자가 동기식 미러링 작업을 일시 중단했음을 나타냅니다. 미러링된 쌍이 일시 중단되면 2차 볼륨에 대한 연결을 시도하지 않습니다. 운영 볼륨에 대한 모든 쓰기 작업은 미러 예약 용량 볼륨에 영구적으로 기록됩니다.

* *실패*
+
기본 볼륨, 보조 볼륨 또는 미러 예약 용량의 장애로 인해 동기식 미러링 작업이 정상적으로 작동할 수 없음을 나타냅니다.
