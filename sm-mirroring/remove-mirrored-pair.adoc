= SANtricity System Manager에서 비동기 미러 관계를 제거합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러링된 쌍을 제거하면 로컬 스토리지 시스템의 운영 볼륨과 원격 스토리지 시스템의 2차 볼륨 간의 미러 관계가 제거됩니다.

.이 작업 정보
고아 미러링된 쌍에 대한 다음 정보를 검토하십시오.

* 일관성 미러 그룹의 멤버 볼륨이 한쪽(로컬 스토리지 시스템 측 또는 원격 스토리지 시스템 측)에서는 제거되었지만 다른 쪽에서는 제거되지 않은 경우 고아 미러링된 쌍이 존재합니다.
* 고립된 미러링된 쌍은 어레이 간 통신이 복원되고 미러 구성의 양쪽이 미러 매개변수를 조정할 때 감지됩니다.
* 미러링된 쌍을 제거하여 고립된 미러링된 쌍 상태를 수정할 수 있습니다.


.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러링된 쌍* 탭을 선택합니다.
+
미러링된 쌍 테이블이 나타나고 스토리지 어레이와 연결된 모든 미러링된 쌍이 표시됩니다.

. 제거하려는 미러링된 쌍을 선택한 다음 *제거* 를 클릭합니다.
. 미러링된 쌍을 제거할 것인지 확인한 다음 *제거*를 클릭합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 로컬 스토리지 어레이와 원격 스토리지 어레이의 미러 일관성 그룹에서 미러 관계를 제거하고 예약된 용량을 삭제합니다.
* 운영 볼륨과 2차 볼륨을 호스트에서 액세스할 수 있는 미러링되지 않은 볼륨으로 반환합니다.
* 비동기 미러링된 쌍을 제거하여 비동기 미러링 타일을 업데이트합니다.
