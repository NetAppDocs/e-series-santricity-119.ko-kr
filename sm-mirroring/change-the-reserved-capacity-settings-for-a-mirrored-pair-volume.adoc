= SANtricity System Manager에서 미러링된 쌍 볼륨의 예약된 용량 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러링된 페어 볼륨에 대한 설정을 변경하여 미러링된 페어 볼륨의 예약된 용량이 거의 가득 찼을 때 SANtricity System Manager가 알림을 보내는 백분율 지점을 조정할 수 있습니다.

.단계
. 메뉴: 스토리지[풀 및 볼륨 그룹]를 선택합니다.
. *예약된 용량* 탭을 선택합니다.
. 편집할 미러링된 쌍 볼륨을 선택한 다음 *설정 보기/편집*을 클릭합니다.
+
미러링된 쌍 볼륨 예약된 용량 설정 대화 상자가 나타납니다.

. 미러링된 페어 볼륨의 예약 용량 설정을 필요에 따라 변경하십시오.
+
.필드 세부 정보

====
[cols="25h,~"]

스피너 상자를 사용하여 미러링된 쌍의 예약된 용량이 거의 가득 찼을 때 System Manager가 알림을 보내는 백분율 지점을 조정합니다.

미러링된 쌍에 대해 예약된 용량이 지정된 임계값을 초과하면 System Manager가 알림을 전송하여 예약된 용량을 늘릴 시간을 제공합니다.


NOTE: 하나의 미러링된 쌍에 대한 알림 설정을 변경하면 동일한 미러 일관성 그룹에 속한 모든 미러링된 쌍에 대한 알림 설정이 변경됩니다.

|===
====
. 변경 사항을 적용하려면 *저장*을 클릭합니다.
