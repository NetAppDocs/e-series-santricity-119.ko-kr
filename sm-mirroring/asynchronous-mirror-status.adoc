= SANtricity System Manager에서 비동기식 미러 상태 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러 상태는 미러 일관성 그룹 및 미러링된 볼륨 쌍의 상태를 정의합니다.



[[status-for-mirror-consistency-groups]]
== 미러 일관성 그룹의 상태

[cols="25h,~"]
|===
| 상태 | 설명 


 a| 
동기화 중(초기 동기화)
 a| 
미러링된 볼륨 쌍 간에 완료된 초기 데이터 동기화의 진행률입니다.

초기 동기화 중에 볼륨은 성능 저하/실패/최적/알 수 없음 상태로 전환될 수 있습니다.



 a| 
동기화(간격 동기화)
 a| 
미러링된 볼륨 쌍 간에 완료된 주기적인 데이터 동기화의 진행률입니다.



 a| 
시스템 일시 중단됨
 a| 
스토리지 시스템으로 인해 미러 일관성 그룹 수준에서 모든 미러링된 쌍의 데이터 동기화가 일시 중단되었습니다.

미러 일관성 그룹의 미러링된 쌍 중 하나 이상이 중지됨 또는 실패 상태입니다.



 a| 
사용자 일시 중단됨
 a| 
미러 일관성 그룹 수준에서 모든 미러링된 쌍의 데이터 동기화를 사용자가 일시 중단합니다.

이 상태는 로컬 스토리지 어레이의 변경된 데이터가 원격 스토리지 어레이로 복사되는 동안 호스트 애플리케이션에 발생할 수 있는 성능 영향을 줄이는 데 도움이 됩니다.



 a| 
일시 중지됨
 a| 
원격 스토리지 어레이에 액세스하는 중 오류가 발생하여 데이터 동기화 프로세스가 일시적으로 일시 중지되었습니다.



 a| 
고아
 a| 
고아 미러링된 쌍 볼륨은 일관성 미러 그룹의 멤버 볼륨이 일관성 미러 그룹의 한쪽(운영 측 또는 2차 측)에서는 제거되었지만 다른 쪽에서는 제거되지 않은 경우 존재합니다.

고립된 미러링된 쌍 볼륨은 어레이 간 통신이 복원되고 미러 구성의 양쪽이 미러 매개변수를 조정할 때 감지됩니다.

미러링된 쌍을 제거하여 고립된 미러링된 쌍 상태를 수정할 수 있습니다.



 a| 
역할 변경 보류 중/진행 중
 a| 
미러 일관성 그룹 간의 역할 변경이 보류 중이거나 진행 중입니다.

역할 반전 변경(운영 역할 또는 보조 역할로의 변경)은 선택된 미러 일관성 그룹 내의 모든 비동기식 미러링된 쌍에 영향을 줍니다.

보류 중인 역할 변경은 취소할 수 있지만 진행 중인 역할 변경은 취소할 수 없습니다.



 a| 
역할 충돌
 a| 
역할 변경 작업 중 로컬 스토리지 어레이와 원격 스토리지 어레이 간의 통신 문제로 인해 미러 일관성 그룹 간에 역할 충돌이 발생했습니다.

통신 문제가 해결되면 역할 충돌이 발생합니다. 이 오류를 해결하려면 Recovery Guru를 사용하십시오.

역할 충돌을 해결할 때 강제 승격은 허용되지 않습니다.

|===


[[status-for-mirrored-pairs]]
== 미러링된 쌍의 상태

미러링된 쌍의 상태는 운영 볼륨과 보조 볼륨의 데이터가 동기화되었는지 여부를 나타냅니다.

[cols="25h,~"]
|===
| 상태 | 설명 


 a| 
동기화 중
 a| 
미러링된 볼륨 쌍 간에 완료된 초기 또는 주기적 데이터 동기화의 진행 상황입니다.

동기화에는 초기 동기화와 주기적 동기화의 두 가지 유형이 있습니다. 초기 동기화 진행 상황은 장기 실행 작업 대화 상자에도 표시됩니다.



 a| 
최적
 a| 
미러링된 쌍의 볼륨이 동기화되었습니다. 이는 스토리지 어레이 간의 연결이 정상적으로 작동하고 있으며 각 볼륨이 원하는 작동 상태임을 나타냅니다.



 a| 
불완전
 a| 
원격 스토리지 어레이에서 비동기 미러링 쌍이 불완전합니다. 미러링 쌍 생성 시퀀스가 System Manager에서 지원되지 않는 스토리지 어레이에서 시작되었고 보조 스토리지에서 미러링 쌍이 완료되지 않았기 때문입니다.

미러링된 쌍 생성 프로세스는 원격 스토리지 어레이의 미러 일관성 그룹에 볼륨이 추가되면 완료됩니다. 이 볼륨은 비동기 미러링된 쌍의 보조 볼륨이 됩니다.

원격 스토리지 어레이가 System Manager에 의해 관리되는 경우 미러링된 쌍이 자동으로 완료됩니다.



 a| 
실패
 a| 
운영 볼륨, 보조 볼륨 또는 미러 예약 용량에 장애가 발생하여 비동기 미러링 작업이 정상적으로 작동할 수 없습니다.



 a| 
고아
 a| 
고아 미러링된 쌍 볼륨은 일관성 미러 그룹의 멤버 볼륨이 일관성 미러 그룹의 한쪽(운영 측 또는 2차 측)에서는 제거되었지만 다른 쪽에서는 제거되지 않은 경우 존재합니다.

미러링된 쌍에서 고립된 볼륨은 두 스토리지 어레이 간의 통신이 복원되고 미러 구성의 양쪽이 미러 매개변수를 조정할 때 감지됩니다.

미러링된 쌍을 제거하여 고립된 미러링된 쌍 상태를 수정할 수 있습니다.



 a| 
중지됨
 a| 
미러링된 쌍은 미러 일관성 그룹이 시스템 일시 중단 상태이므로 중지된 상태입니다.

|===
