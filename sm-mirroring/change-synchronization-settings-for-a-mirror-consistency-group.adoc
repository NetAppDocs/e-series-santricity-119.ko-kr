= SANtricity System Manager에서 미러 일관성 그룹의 동기화 설정을 변경합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
로컬 스토리지 어레이의 미러 일관성 그룹이 데이터를 처음 동기화하거나 비동기 미러링 작업 중에 데이터를 다시 동기화할 때 사용하는 동기화 설정 및 경고 임계값을 변경할 수 있습니다.

.이 작업 정보
동기화 설정을 변경하면 미러 일관성 그룹 내의 모든 미러링된 쌍의 동기화 작업에 영향을 줍니다.

.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러 일관성 그룹* 탭을 선택합니다.
+
미러링된 일관성 그룹 테이블이 나타나고 스토리지 어레이와 연결된 모든 미러 일관성 그룹이 표시됩니다.

. 편집할 미러 일관성 그룹을 선택한 다음 메뉴:More[Edit Settings]를 선택합니다.
+
시스템에 설정 편집 대화 상자가 표시됩니다.

. 동기화 및 알림 설정을 적절하게 편집한 다음 * 저장 * 을 클릭합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 필드 | 설명 


 a| 
미러링된 쌍을 동기화합니다...
 a| 
원격 스토리지 어레이의 미러링된 쌍을 수동으로 또는 자동으로 동기화할지 여부를 지정하십시오.

** **수동** – 원격 스토리지 어레이에서 미러링된 쌍을 수동으로 동기화하려면 이 옵션을 선택합니다.
** **자동으로, 매** – 이 옵션을 선택하면 이전 업데이트 시작 시점부터 다음 업데이트 시작 시점까지의 시간 간격을 지정하여 원격 스토리지 어레이의 미러링된 쌍을 자동으로 동기화합니다. 기본 간격은 10분입니다.




 a| 
알림 요청...
 a| 
동기화 방법을 자동으로 설정한 경우 다음 알림을 설정하십시오.

** **동기화** – System Manager가 동기화가 완료되지 않았음을 알리는 알림을 보내는 시간 간격을 설정합니다.
** **원격 복구 지점** – System Manager가 원격 스토리지 어레이의 복구 지점 데이터가 정의된 시간 제한보다 오래되었음을 나타내는 알림을 보내는 시간 제한을 설정합니다. 이전 업데이트 종료 시점부터 시간 제한을 정의합니다.
** **예약 용량 임계값** – System Manager가 예약 용량 임계값에 근접했음을 알리는 알림을 보내는 예약 용량을 정의합니다. 남은 용량의 백분율로 임계값을 정의합니다.


|===
====


.결과
System Manager는 미러 일관성 그룹의 모든 미러링된 쌍에 대한 동기화 설정을 변경합니다.
