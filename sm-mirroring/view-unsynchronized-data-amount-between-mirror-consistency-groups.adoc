= SANtricity System Manager에서 미러 일관성 그룹 간의 동기화되지 않은 데이터 양을 확인합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
로컬 스토리지 어레이와 원격 스토리지 어레이의 미러 일관성 그룹 간에 동기화되지 않은 데이터 양을 확인할 수 있습니다. 미러 일관성 그룹이 동기화되지 않은 상태인 동안에는 미러링 작업이 수행되지 않습니다.

.이 작업 정보
선택한 미러 일관성 그룹에 미러링된 쌍이 포함되어 있고 동기화가 현재 진행 중이 아닌 경우 이 작업을 수행할 수 있습니다.

.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러 일관성 그룹* 탭을 선택합니다.
+
미러 일관성 그룹 테이블이 나타나고 스토리지 어레이와 연결된 모든 미러 일관성 그룹이 표시됩니다.

. 메뉴:더보기[동기화되지 않은 데이터 양 보기]를 클릭합니다.
+
동기화되지 않은 데이터가 있는 경우 테이블 값에 해당 내용이 반영됩니다. 데이터 양 열에는 동기화되지 않은 데이터의 양이 MiB 단위로 표시됩니다.
