= SANtricity 소프트웨어에서 미러 일관성 그룹 역할 변경
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러링된 쌍 간의 역할을 미러 일관성 그룹에서 변경할 수 있습니다. 기본 미러 일관성 그룹을 보조 역할로 강등하거나 보조 미러 일관성 그룹을 기본 역할로 승격하여 이 작업을 수행할 수 있습니다.

역할 변경 작업에 대한 다음 정보를 검토하십시오.

* 역할 변경은 선택된 미러 일관성 그룹 내의 모든 미러링된 쌍에 영향을 줍니다.
* 미러 일관성 그룹이 보조 역할로 강등되면 해당 미러 일관성 그룹 내의 모든 미러링된 쌍도 보조 역할로 강등되며, 그 반대의 경우도 마찬가지입니다.
* 운영 미러 일관성 그룹이 보조 역할로 강등되면 해당 그룹 내 멤버 볼륨에 할당된 호스트는 더 이상 해당 볼륨에 대한 쓰기 액세스 권한을 갖지 못합니다.
* 미러 일관성 그룹이 기본 역할로 승격되면 해당 그룹 내의 멤버 볼륨에 액세스하는 모든 호스트는 이제 해당 볼륨에 쓰기 작업을 수행할 수 있습니다.
* 로컬 스토리지 어레이가 원격 스토리지 어레이와 통신할 수 없는 경우 로컬 스토리지 어레이에서 역할 변경을 강제로 수행할 수 있습니다.




== 역할 변경 강제 실행

로컬 스토리지 어레이와 원격 스토리지 어레이 간의 통신 문제로 인해 보조 미러 일관성 그룹 내의 멤버 볼륨 승격 또는 기본 미러 일관성 그룹 내의 멤버 볼륨 강등이 불가능한 경우 미러 일관성 그룹 간의 역할 변경을 강제로 수행할 수 있습니다.

보조 측의 미러 일관성 그룹을 강제로 운영 역할로 전환할 수 있습니다. 그러면 복구 호스트가 해당 미러 일관성 그룹 내에서 새로 승격된 구성원 볼륨에 액세스할 수 있으며 비즈니스 운영을 계속할 수 있습니다.



== 강제 승격은 언제 허용되고 언제 허용되지 않습니까?

미러 일관성 그룹의 강제 승격은 미러 일관성 그룹의 모든 구성원 볼륨이 동기화되었고 일관된 복구 지점을 가진 경우에만 허용됩니다.

다음 조건에서는 미러 일관성 그룹의 강제 승격이 허용되지 않습니다.

* 미러 일관성 그룹의 멤버 볼륨이 초기 동기화를 진행 중입니다.
* 미러 일관성 그룹의 구성원 볼륨 중 복구 시점의 시점 이미지를 가지고 있지 않습니다(예: 예약된 용량 전체 오류로 인해).
* 미러 일관성 그룹에 멤버 볼륨이 포함되어 있지 않습니다.
* 미러 일관성 그룹이 실패, 역할 변경 대기 중 또는 역할 변경 진행 중 상태이거나 연결된 멤버 볼륨 또는 예약된 용량 볼륨 중 하나라도 실패한 경우입니다.




== 미러 그룹 역할 충돌

로컬 스토리지 어레이와 원격 스토리지 어레이 간의 통신 문제가 해결되면 미러 그룹 역할 충돌 오류가 발생합니다. 이 오류를 복구하려면 Recovery Guru를 사용하십시오. 이중 역할 충돌을 해결할 때 강제 승격은 허용되지 않습니다.

Mirror Group Role Conflict 상황 및 그에 따른 복구 단계를 방지하려면 스토리지 어레이 간의 연결이 정상적으로 작동할 때까지 기다린 후 역할 변경을 강제로 수행하십시오.



== 역할 변경 진행 중 상태

미러링 구성의 두 스토리지 어레이의 연결이 끊어지고 미러 일관성 그룹의 운영 측이 강제로 보조 역할로 강등되고 미러 일관성 그룹의 보조 측이 강제로 운영 역할로 승격되는 경우, 통신이 복구되면 두 스토리지 어레이의 미러 일관성 그룹은 모두 역할 변경 진행 중(Role-Change-In-Progress) 상태로 전환됩니다.

시스템은 변경 로그를 전송하고, 재동기화하고, 미러 일관성 그룹 상태를 정상 작동 상태로 되돌리고, 주기적인 동기화를 계속함으로써 역할 변경 프로세스를 완료합니다.
