= SANtricity 소프트웨어에서 동기식 미러링을 사용하기 위한 요구 사항
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
동기식 미러링을 사용하려는 경우 다음 요구 사항을 염두에 두십시오.



== Unified Manager

두 어레이 간 미러링을 활성화하고 구성하려면 Unified Manager 인터페이스를 사용해야 합니다. Unified Manager는 Web Services Proxy와 함께 호스트 시스템에 설치됩니다.

* Web Services Proxy 서비스가 실행 중이어야 합니다.
* Unified Manager는 HTTPS 연결을 통해 로컬 호스트에서 실행되어야 합니다.
* Unified Manager에 스토리지 어레이에 대한 유효한 SSL 인증서가 표시되어야 합니다. Unified Manager에서 메뉴:인증서[인증서 관리]로 이동하여 자체 서명 인증서를 허용하거나 자체 보안 인증서를 설치할 수 있습니다.




== 스토리지 어레이

[NOTE]
====
EF300/EF300C 또는 EF600/EF600C 스토리지 어레이에서는 동기식 미러링을 사용할 수 없습니다.

====
* 스토리지 어레이가 두 개 있어야 합니다.
* 각 스토리지 어레이에는 2개의 컨트롤러가 있어야 합니다.
* 두 스토리지 시스템은 Unified Manager에서 검색되어야 합니다.
* 기본 어레이와 보조 어레이의 각 컨트롤러에는 이더넷 관리 포트가 구성되어 있어야 하며 네트워크에 연결되어 있어야 합니다.
* 스토리지 어레이의 최소 펌웨어 버전은 7.84입니다. (각각 다른 OS 버전을 실행할 수 있습니다.)
* 로컬 및 원격 스토리지 어레이의 암호를 알고 있어야 합니다.
* 미러링할 운영 볼륨과 같거나 그보다 큰 보조 볼륨을 생성하려면 원격 스토리지 어레이에 충분한 여유 용량이 있어야 합니다.
* 로컬 및 원격 스토리지 어레이는 Fibre Channel 패브릭을 통해 연결됩니다.




== 지원되는 연결

동기식 미러링을 위한 통신은 Fibre Channel(FC) 호스트 포트가 있는 컨트롤러에서만 지원됩니다.

동기식 미러링은 로컬 스토리지 어레이와 원격 스토리지 어레이 모두에서 각 컨트롤러의 가장 높은 번호의 호스트 포트를 사용합니다. 컨트롤러 호스트 버스 어댑터(HBA) 호스트 포트 4는 일반적으로 미러 데이터 전송을 위해 예약되어 있습니다.



== 미러링된 볼륨 후보

* 동기식 미러링 쌍의 운영 볼륨과 보조 볼륨에서 RAID 레벨, 캐싱 매개변수 및 세그먼트 크기가 서로 다를 수 있습니다.
* 동기식 미러링 쌍의 운영 볼륨과 2차 볼륨은 표준 볼륨이어야 합니다. 씬 볼륨이나 스냅샷 볼륨은 사용할 수 없습니다.
* 보조 볼륨의 크기는 운영 볼륨의 크기와 최소한 같아야 합니다.
* 기본 볼륨만 스냅샷을 연결할 수 있으며 볼륨 복사본 작업에서 소스 또는 타겟 볼륨으로 사용될 수 있습니다.
* 볼륨은 하나의 미러 관계에만 참여할 수 있습니다.
* 스토리지 어레이에서 지원되는 볼륨 수에는 제한이 있습니다. 스토리지 어레이에 구성된 볼륨 수가 지원되는 제한보다 적은지 확인하십시오. 동기식 미러링이 활성화된 경우 생성되는 두 개의 예약 용량 볼륨도 볼륨 제한에 포함됩니다.




== 예약된 용량

* 컨트롤러 재설정 및 기타 일시적인 중단으로부터 복구하기 위해 쓰기 정보를 로깅하는 운영 볼륨과 2차 볼륨에 예약된 용량이 필요합니다.
* 예약 용량 볼륨은 동기식 미러링이 활성화될 때 자동으로 생성됩니다. 미러링된 쌍의 운영 볼륨과 2차 볼륨 모두에 예약 용량이 필요하므로 동기식 미러 관계에 참여하는 두 스토리지 어레이 모두에 충분한 여유 용량이 있는지 확인해야 합니다.




== 드라이브 보안 기능

* 보안 기능을 지원하는 드라이브를 사용하는 경우, 기본 볼륨과 보조 볼륨의 보안 설정이 호환되어야 합니다. 이 제한 사항은 강제 적용되지 않으므로 사용자가 직접 확인해야 합니다.
* 보안 기능을 지원하는 드라이브를 사용하는 경우 기본 볼륨과 보조 볼륨은 동일한 드라이브 유형을 사용해야 합니다. 이 제한 사항은 강제 사항이 아니므로 사용자가 직접 확인해야 합니다.
+
** 기본 볼륨에서 FDE(Full Disk Encryption) 드라이브를 사용하는 경우 보조 볼륨에서도 FDE 드라이브를 사용해야 합니다.
** 기본 볼륨에 Federal Information Processing Standards 140-2(FIPS) 인증 드라이브가 사용되는 경우 보조 볼륨에도 FIPS 140-2 인증 드라이브가 사용되어야 합니다.


* Data Assurance(DA)를 사용하는 경우 운영 볼륨과 2차 볼륨의 DA 설정이 동일해야 합니다.
