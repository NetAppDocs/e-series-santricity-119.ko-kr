= SANtricity 소프트웨어에서 미러링된 쌍의 볼륨 역할 변경에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러링된 쌍의 볼륨 간에 역할을 변경할 수 있습니다. 기본 볼륨을 보조 역할로 강등하거나 보조 볼륨을 기본 역할로 승격시키면 됩니다.

[NOTE]
====
EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서는 동기식 미러링을 사용할 수 없습니다.

====
역할 변경 작업에 대한 다음 정보를 검토하십시오.

* 운영 볼륨이 보조 역할로 강등되면 해당 미러링된 쌍의 보조 볼륨이 운영 역할로 승격되며 그 반대의 경우도 마찬가지입니다.
* 기본 볼륨이 보조 역할로 강등되면 해당 볼륨에 할당된 호스트는 더 이상 해당 볼륨에 대한 쓰기 액세스 권한을 갖지 못합니다.
* 보조 볼륨이 운영 역할로 승격되면 해당 볼륨에 액세스하는 모든 호스트가 이제 해당 볼륨에 쓰기를 수행할 수 있습니다.
* 로컬 스토리지 어레이가 원격 스토리지 어레이와 통신할 수 없는 경우 로컬 스토리지 어레이에서 역할 변경을 강제로 수행할 수 있습니다.




[[force-role-change]]
== 역할 변경 강제 실행

로컬 스토리지 어레이와 원격 스토리지 어레이 간의 통신 문제로 인해 2차 볼륨의 승격 또는 운영 볼륨의 강등이 방지되는 경우 미러링된 쌍의 볼륨 간에 역할 변경을 강제할 수 있습니다.

보조 측의 볼륨을 강제로 운영 역할로 전환할 수 있습니다. 그러면 복구 호스트가 새로 승격된 볼륨에 액세스할 수 있고 비즈니스 운영을 계속할 수 있습니다.

[NOTE]
====
원격 스토리지 어레이가 복구되고 통신 문제가 해결되면 동기식 미러링 - 기본 볼륨 충돌 조건이 발생합니다. 복구 단계에는 볼륨 재동기화가 포함됩니다. 이 오류를 복구하려면 Recovery Guru를 사용하십시오.

====


[[when-is-a-forced-promotion-allowed-and-not-allowed]]
== 강제 승격은 언제 허용되고 언제 허용되지 않습니까?

다음 조건에서는 미러링된 쌍의 볼륨을 강제로 승격할 수 없습니다.

* 미러링된 쌍의 볼륨 중 하나가 초기 동기화 과정에 있습니다.
* 미러링된 쌍이 Failed, Role-Change-Pending 또는 Role-Change-In-Progress 상태이거나 연결된 예약된 용량 볼륨이 실패한 경우입니다.




[[role-change-in-progress-state]]
== 역할 변경 진행 중 상태

미러링 구성의 두 스토리지 어레이의 연결이 끊어지고 미러링된 쌍의 운영 볼륨이 강제로 2차 역할로 강등되고 미러링된 쌍의 2차 볼륨이 강제로 운영 역할로 승격되면 통신이 복원될 때 두 스토리지 어레이의 볼륨이 모두 역할 변경 진행 중 상태가 됩니다.

시스템은 변경 로그를 전송하고, 재동기화하고, 미러링된 쌍 상태를 정상 작동 상태로 되돌리고, 동기화를 계속 진행함으로써 역할 변경 프로세스를 완료합니다.
