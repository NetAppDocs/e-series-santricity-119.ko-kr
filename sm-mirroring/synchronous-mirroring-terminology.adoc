= SANtricity 소프트웨어의 동기식 미러링 용어에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
동기식 미러링 용어가 스토리지 시스템에 어떻게 적용되는지 알아보십시오.

[cols="25h,~"]
|===
| 용어 | 설명 


 a| 
로컬 스토리지 어레이
 a| 
로컬 스토리지 어레이는 사용자가 작업하고 있는 스토리지 어레이입니다.

로컬 역할 열에 *Primary*가 표시되면 해당 스토리지 어레이에 미러링 관계에서 기본 역할을 하는 볼륨이 포함되어 있음을 나타냅니다. 로컬 역할 열에 *Secondary*가 표시되면 해당 스토리지 어레이에 미러링 관계에서 보조 역할을 하는 볼륨이 포함되어 있음을 나타냅니다.



 a| 
미러링된 쌍
 a| 
미러링된 쌍은 기본 볼륨과 보조 볼륨의 두 볼륨으로 구성됩니다.



 a| 
운영 볼륨
 a| 
미러링된 쌍의 운영 볼륨은 미러링할 소스 볼륨입니다.



 a| 
복구 시점 목표(RPO)
 a| 
복구 시점 목표(RPO)는 미러링된 쌍에서 운영 볼륨과 2차 볼륨 간의 허용 가능한 차이를 나타내는 목표값입니다. RPO가 0이면 운영 볼륨과 2차 볼륨 간의 차이가 전혀 허용되지 않음을 의미합니다. RPO가 0보다 크면 2차 볼륨이 운영 볼륨보다 최신 상태가 아니거나 지연됨을 나타냅니다.



 a| 
원격 스토리지 어레이
 a| 
원격 스토리지 어레이는 일반적으로 보조 사이트로 지정되며, 일반적으로 미러링 구성에서 데이터의 복제본을 보유합니다.



 a| 
예약된 용량
 a| 
예약 용량은 모든 복사 서비스 작업 및 스토리지 객체에 사용되는 물리적으로 할당된 용량입니다. 호스트에서 직접 읽을 수는 없습니다.



 a| 
역할 변경
 a| 
역할 변경은 운영 역할을 보조 볼륨에 할당하고 그 반대로 하는 것입니다.



 a| 
보조 볼륨
 a| 
미러링된 쌍의 보조 볼륨은 일반적으로 보조 사이트에 있으며 데이터의 복제본을 보유합니다.



 a| 
동기화
 a| 
동기화는 로컬 스토리지 어레이와 원격 스토리지 어레이 간의 초기 동기화 시에 발생합니다. 또한 통신 중단 후 기본 볼륨과 보조 볼륨의 동기화가 해제될 때도 동기화가 발생합니다. 통신 링크가 다시 작동하면 복제되지 않은 모든 데이터가 보조 볼륨의 스토리지 어레이로 동기화됩니다.

|===
