= SANtricity System Manager에서 원격 스토리지 어레이 IP 주소를 업데이트합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
원격 스토리지 어레이의 iSCSI IP 주소를 업데이트하여 로컬 스토리지 어레이와의 연결을 다시 설정할 수 있습니다.

.시작하기 전에
로컬 스토리지 어레이와 원격 스토리지 어레이 모두 iSCSI 연결을 사용하여 비동기 미러링용으로 구성되어야 합니다.

.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러 일관성 그룹* 탭을 선택합니다.
+
미러 일관성 그룹 테이블에는 스토리지 시스템과 연결된 모든 미러 일관성 그룹이 표시됩니다.

. 업데이트할 미러 일관성 그룹을 선택한 다음 메뉴:더보기[원격 IP 주소 업데이트]를 선택합니다.
+
시스템에 원격 IP 주소 업데이트 대화 상자가 표시됩니다.

. 원격 스토리지 어레이의 iSCSI IP 주소를 업데이트하려면 *업데이트*를 선택하십시오.


.결과
시스템은 로컬 스토리지 어레이와의 연결을 다시 설정하기 위해 원격 스토리지 어레이의 IP 주소를 재설정합니다.
