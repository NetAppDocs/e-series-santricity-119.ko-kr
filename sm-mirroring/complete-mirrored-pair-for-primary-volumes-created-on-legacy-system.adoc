= SANtricity System Manager에서 기존 시스템에 생성된 운영 볼륨에 대한 미러링된 쌍을 완료합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager로 관리할 수 없는 기존 스토리지 어레이에 운영 볼륨을 생성한 경우, SANtricity System Manager를 사용하여 해당 어레이에 보조 볼륨을 생성할 수 있습니다.

.이 작업 정보
서로 다른 인터페이스를 사용하는 기존 스토리지 어레이와 System Manager로 관리할 수 있는 최신 어레이 간에 비동기 미러링을 수행할 수 있습니다.

* System Manager를 사용하는 두 스토리지 어레이 간에 미러링하는 경우 미러링된 쌍 생성 시퀀스에서 미러링된 쌍을 이미 완료했으므로 이 작업을 건너뛸 수 있습니다.
* 원격 스토리지 어레이에서 이 작업을 수행하십시오.


.단계
. 메뉴: 스토리지[비동기 미러링]를 선택합니다.
. *미러링된 쌍* 탭을 선택합니다.
+
미러링된 쌍 테이블이 나타나고 스토리지 어레이와 연결된 모든 미러링된 쌍이 표시됩니다.

. 상태가 Incomplete인 미러링 쌍 볼륨을 찾은 다음 미러링 쌍 열에 표시된 *미러링 쌍 완료* 링크를 클릭합니다.
. 다음 라디오 버튼 중 하나를 선택하여 미러링된 쌍 생성 시퀀스를 자동으로 완료할지 수동으로 완료할지 선택하십시오.
+
** *자동* -- 새 보조 볼륨을 생성합니다.
+
미러링된 쌍의 원격 측에 대한 기본 설정을 그대로 사용하려면 보조 볼륨을 생성할 기존 풀 또는 볼륨 그룹을 선택하십시오. 이 권장 옵션을 사용하면 기본 설정으로 보조 볼륨에 필요한 용량을 할당할 수 있습니다.

** *수동* -- 기존 볼륨을 선택합니다.
+
보조 볼륨에 대한 고유한 매개변수를 정의합니다.

+
... *다음*을 클릭하여 보조 볼륨을 선택합니다.
... 보조 볼륨으로 사용할 기존 볼륨을 선택한 다음 *다음*을 클릭하여 예약된 용량을 할당합니다.
... 예약된 용량을 할당하십시오. 다음 중 하나를 수행하십시오.
+
**** 기본 설정을 적용합니다.
+
예약된 용량의 기본 설정은 기본 볼륨 용량의 20%이며 일반적으로 이 용량으로 충분합니다.

**** 비동기 미러링과 관련된 데이터 스토리지 요구 사항을 충족하도록 자체 예약 용량 설정을 할당하십시오.
+
필요한 용량은 기본 볼륨에 대한 I/O 쓰기 빈도 및 크기, 그리고 용량을 유지해야 하는 기간에 따라 달라집니다. 일반적으로 다음 조건 중 하나 또는 둘 다에 해당하는 경우 예약 용량을 더 크게 선택하는 것이 좋습니다.

+
***** 미러링된 쌍을 장기간 유지하려고 합니다.
***** 기본 볼륨에서는 과도한 I/O 활동으로 인해 상당수의 데이터 블록이 변경될 수 있습니다. 과거 성능 데이터 또는 기타 운영 체제 유틸리티를 사용하여 기본 볼륨에 대한 일반적인 I/O 활동을 파악하십시오.








. *완료*를 선택합니다.


.결과
System Manager는 다음 작업을 수행합니다.

* 원격 스토리지 어레이에 보조 볼륨을 생성하고 미러링된 쌍의 원격 측에 예약된 용량을 할당합니다.
* 로컬 스토리지 어레이와 원격 스토리지 어레이 간의 초기 동기화를 시작합니다.
* 미러링 대상 볼륨이 씬 볼륨인 경우, 초기 동기화 시 할당된 블록만 보조 볼륨으로 전송됩니다. 이러한 전송 방식은 초기 동기화를 완료하는 데 필요한 데이터 양을 줄여줍니다.
* 로컬 스토리지 어레이와 원격 스토리지 어레이에 미러링된 쌍에 대한 예약된 용량을 생성합니다.
