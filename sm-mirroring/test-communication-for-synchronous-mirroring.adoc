= SANtricity System Manager에서 동기식 미러링을 위한 통신 테스트
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
동기식 미러링에 참여하는 미러링된 쌍에서 발생할 수 있는 통신 문제를 진단하기 위해 로컬 스토리지 시스템과 원격 스토리지 시스템 간의 통신을 테스트할 수 있습니다.

.이 작업 정보
두 가지 다른 테스트가 실행됩니다.

* *통신* -- 두 스토리지 어레이 간에 통신 경로가 있는지 확인합니다. 통신 테스트는 로컬 스토리지 어레이가 원격 스토리지 어레이와 통신할 수 있는지, 그리고 미러링된 쌍과 연결된 보조 볼륨이 원격 스토리지 어레이에 존재하는지 검증합니다.
* *지연 시간* -- 미러링된 쌍과 연결된 원격 스토리지 어레이의 보조 볼륨으로 SCSI 테스트 유닛 명령을 전송하여 최소, 평균 및 최대 지연 시간을 테스트합니다.


.단계
. 메뉴: 스토리지[동기식 미러링]를 선택합니다.
. 테스트할 미러링된 쌍을 선택한 다음 *Test Communication*을 선택합니다.
. 결과 창에 표시된 정보를 검토하고 필요한 경우 표시된 수정 조치를 따르십시오.
+
[NOTE]
====
통신 테스트에 실패하면 이 대화 상자를 닫은 후에도 미러링된 쌍 간의 통신이 복원될 때까지 테스트가 계속 실행됩니다.
