= SANtricity System Manager에서 AutoSupport 로그 보기
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AutoSupport 로그는 AutoSupport 디스패치 전송 중에 발생한 상태, 디스패치 기록 및 오류에 대한 정보를 제공합니다.

.이 작업 정보
여러 개의 로그 파일이 존재할 수 있습니다. 현재 로그 파일 크기가 200KB에 도달하면 해당 파일은 보관 처리되고 새 로그 파일이 생성됩니다. 보관된 로그 파일 이름은 `ASUPMessages.n`이며, 여기서 _n_은 1부터 9까지의 정수입니다. 여러 개의 로그 파일이 있는 경우 가장 최근 로그 또는 이전 로그를 선택하여 볼 수 있습니다.

* *현재 로그* -- 최근에 캡처된 이벤트 목록을 표시합니다.
* *보관된 로그* -- 이전 이벤트 목록을 표시합니다.


.단계
. 메뉴에서 지원[지원 센터 > AutoSupport] 탭을 선택하세요.
. *View AutoSupport Log*를 선택합니다.
+
현재 AutoSupport 로그 목록이 표시되는 대화 상자가 나타납니다.

. 이전 AutoSupport 로그를 보려면 *보관됨* 라디오 버튼을 선택한 다음 *AutoSupport 로그 선택* 드롭다운 목록에서 로그를 선택하십시오.
+
보관됨 옵션은 스토리지 어레이에 보관된 로그가 있는 경우에만 나타납니다.

+
선택한 AutoSupport 로그가 대화 상자에 나타납니다.

. *선택 사항:* AutoSupport 로그를 검색하려면 *찾기* 상자에 용어를 입력하고 *찾기*를 클릭하십시오.
+
*찾기*를 다시 클릭하여 해당 용어가 추가로 나타나는 부분을 검색합니다.
