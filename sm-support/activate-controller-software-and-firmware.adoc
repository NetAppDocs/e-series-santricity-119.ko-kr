= SANtricity System Manager에서 컨트롤러 소프트웨어 및 펌웨어를 활성화하십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
업그레이드 파일을 즉시 활성화하거나 더 편리한 시간까지 기다릴 수 있습니다.

.이 작업 정보
파일을 활성화하지 않고도 다운로드 및 전송할 수 있습니다. 다음과 같은 이유로 나중에 활성화하도록 선택할 수 있습니다.

* *시간대* -- 소프트웨어 및 펌웨어를 활성화하는 데 시간이 오래 걸릴 수 있으므로 I/O 부하가 적은 시간대에 진행하는 것이 좋습니다. 활성화 과정 중에는 컨트롤러가 페일오버되므로 업그레이드가 완료될 때까지 성능이 평소보다 저하될 수 있습니다.
* *패키지 유형* -- 다른 스토리지 어레이의 파일을 업그레이드하기 전에 하나의 스토리지 어레이에서 새 소프트웨어 및 펌웨어를 테스트해 보는 것이 좋습니다.


전송되었지만 활성화되지 않은 소프트웨어 또는 펌웨어가 있는 경우 System Manager 홈 페이지의 알림 영역과 Upgrade Center 페이지에 알림이 표시됩니다.

[CAUTION]
====
활성화 프로세스가 시작된 후에는 중지할 수 없습니다.

====
.단계
. 메뉴:지원[업그레이드 센터]를 선택합니다.
. SANtricity OS Controller Software 업그레이드라고 표시된 영역에서 *Activate*를 클릭하고 작업을 수행할 것인지 확인하십시오.
+
업그레이드 전 상태 점검 중에는 작업을 취소할 수 있지만 활성화 중에는 취소할 수 없습니다.

+
업그레이드 전 상태 점검이 시작됩니다. 업그레이드 전 상태 점검에 통과하면 파일 활성화 단계로 업그레이드 프로세스가 진행됩니다. 업그레이드 전 상태 점검에 실패하면 Recovery Guru를 사용하거나 기술 지원에 문의하여 문제를 해결하십시오. 특정 상황에서는 기술 지원팀에서 오류가 발생하더라도 *업그레이드 허용* 확인란을 선택하여 업그레이드를 계속 진행하도록 안내할 수 있습니다.

+
사전 업그레이드 상태 점검이 성공적으로 완료되면 활성화가 진행됩니다. 활성화에 소요되는 시간은 스토리지 어레이 구성 및 활성화할 구성 요소에 따라 달라집니다.

. *선택 사항:* 업그레이드된 항목 목록을 보려면 *로그 저장*을 클릭하십시오.
+
해당 파일은 브라우저의 다운로드 폴더에 `drive_upgrade_log-timestamp.txt`이라는 이름으로 저장됩니다.



.완료한 후
* 하드웨어 페이지에 모든 구성 요소가 표시되는지 확인하십시오.
* 새 소프트웨어 및 펌웨어 버전을 확인하려면 소프트웨어 및 펌웨어 인벤토리 대화 상자를 확인하십시오(메뉴:지원[업그레이드 센터]로 이동한 다음 *소프트웨어 및 펌웨어 인벤토리* 링크를 클릭).
* 컨트롤러 NVSRAM을 업그레이드한 경우, 기존 NVSRAM에 적용했던 사용자 지정 설정이 활성화 과정에서 모두 손실됩니다. 활성화 과정이 완료된 후 NVSRAM에 사용자 지정 설정을 다시 적용해야 합니다.
