= E-Series용 AutoSupport에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AutoSupport 기능은 스토리지 어레이의 상태를 모니터링하고 기술 지원 부서에 자동 발송을 전송합니다.

기술 지원 부서에서는 AutoSupport 데이터를 사용하여 고객 문제의 진단 및 해결 속도를 높이고 잠재적 문제를 사전에 감지하고 방지합니다.

AutoSupport 데이터에는 스토리지 어레이의 구성, 상태, 성능 및 시스템 이벤트에 대한 정보가 포함됩니다. AutoSupport 데이터에는 사용자 데이터가 포함되지 않습니다. 알림은 즉시 또는 예약된 일정(매일 및 매주)에 따라 전송될 수 있습니다.



== 주요 이점

AutoSupport 기능의 주요 이점은 다음과 같습니다.

* 신속한 케이스 해결 시간
* 신속한 사고 관리를 위한 정교한 모니터링
* 일정에 따른 자동 보고 및 중요 이벤트에 대한 자동 보고
* 드라이브와 같은 선택한 구성 요소에 대한 자동화된 하드웨어 교체 요청
* 문제 발생 시 사용자에게 알리고 기술 지원 팀이 시정 조치를 취할 수 있도록 필요한 정보를 제공하는 비침해적 알림 기능입니다.
* AutoSupport 분석 도구는 알려진 구성 문제에 대한 디스패치를 모니터링합니다




== 개별 AutoSupport 기능

AutoSupport 기능은 세 가지 개별 기능으로 구성되어 있으며, 각 기능은 별도로 활성화해야 합니다.

* *기본 AutoSupport* -- 스토리지 어레이가 자동으로 데이터를 수집하여 기술 지원 부서로 전송할 수 있습니다.
* *AutoSupport OnDemand* -- 기술 지원 부서에서 문제 해결에 필요한 경우 이전 AutoSupport 디스패치의 재전송을 요청할 수 있습니다. 모든 전송은 AutoSupport 서버가 아닌 스토리지 어레이에서 시작됩니다. 스토리지 어레이는 주기적으로 AutoSupport 서버에 접속하여 보류 중인 재전송 요청이 있는지 확인하고 그에 따라 응답합니다.
* *원격 진단* -- 기술 지원 부서에서 문제 해결에 필요한 경우 최신 AutoSupport 발송을 요청할 수 있습니다. 모든 전송은 AutoSupport 서버가 아닌 스토리지 어레이에서 시작됩니다. 스토리지 어레이는 주기적으로 AutoSupport 서버에 접속하여 보류 중인 새 요청이 있는지 확인하고 그에 따라 응답합니다.




== AutoSupport와 지원 데이터 수집의 차이점

스토리지 어레이에는 지원 데이터를 수집하는 두 가지 방법이 있습니다.

* *AutoSupport 기능* -- 데이터가 자동으로 수집됩니다.
* *지원 데이터 수집 옵션* -- 데이터를 수동으로 수집하여 전송해야 합니다.


AutoSupport 기능은 데이터가 자동으로 수집 및 전송되므로 사용이 간편합니다. AutoSupport 데이터는 문제가 발생하기 전에 사전에 예방하는 데 활용될 수 있습니다. AutoSupport 기능은 기술 지원 부서에서 이미 해당 데이터에 액세스할 수 있으므로 문제 해결 속도가 향상됩니다. 이러한 이유로 AutoSupport 기능은 권장되는 데이터 수집 방법입니다.
