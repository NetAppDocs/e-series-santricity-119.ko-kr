= SANtricity System Manager에서 복구 지원 파일을 검색합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기술 지원 부서에서 복구 지원 파일을 사용하여 문제를 해결할 수 있습니다. SANtricity System Manager는 이러한 파일을 자동으로 저장합니다.

.시작하기 전에
기술 지원 부서에서 문제 해결을 위해 추가 파일을 보내달라고 요청했습니다.

.이 작업 정보
복구 지원 파일에는 다음과 같은 유형의 파일이 포함됩니다.

* 지원 데이터 파일
* AutoSupport 기록
* AutoSupport 로그
* SAS/RLS diagnostics 파일
* 복구 프로필 데이터
* 데이터베이스 캡처 파일


.단계
. 메뉴:Support[Support Center > Diagnostics] 탭을 선택합니다.
. *Retrieve Recovery Support Files*를 선택하십시오.
+
대화 상자에는 스토리지 어레이가 수집한 모든 복구 지원 파일이 나열됩니다. 특정 파일을 찾으려면 열을 정렬하거나 *Filter* 상자에 문자를 입력할 수 있습니다.

. 파일을 선택한 다음 *Download*를 클릭합니다.
+
해당 파일은 브라우저의 Downloads 폴더에 저장됩니다.

. 추가 파일을 저장해야 하는 경우 이전 단계를 반복하십시오.
. *닫기*를 클릭합니다.
. 기술 지원 부서에서 제공하는 지침에 따라 파일을 보내십시오.
