= SANtricity System Manager에서 AutoSupport 디스패치 전송
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager를 사용하면 예약된 발송을 기다리지 않고 AutoSupport 발송을 기술 지원팀에 보낼 수 있습니다.

.시작하기 전에
AutoSupport 기능이 활성화되어 있어야 합니다. AutoSupport 페이지에서 활성화 여부를 확인할 수 있습니다.

.이 작업 정보
이 작업은 지원 데이터를 수집하여 기술 지원 부서로 자동으로 전송하므로 문제를 해결할 수 있습니다.

.단계
. 메뉴에서 지원[지원 센터 > AutoSupport] 탭을 선택하세요.
. *Send AutoSupport Dispatch*를 선택합니다.
+
Send AutoSupport 전송 대화 상자가 나타납니다.

. *보내기*를 선택하여 작업을 확인합니다.
