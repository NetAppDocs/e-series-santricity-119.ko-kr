= SANtricity System Manager의 이벤트 로그를 사용하여 이벤트를 확인하십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에서 발생한 이벤트의 기록을 제공하는 이벤트 로그를 볼 수 있습니다.

.단계
. 메뉴: 지원[이벤트 로그]를 선택합니다.
+
이벤트 로그 페이지가 나타납니다.

+
.페이지 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 항목 | 설명 


 a| 
모든 필드 보기
 a| 
모든 이벤트 표시와 중요 및 경고 이벤트만 표시 사이를 전환합니다.



 a| 
필터 필드
 a| 
이벤트를 필터링합니다. 특정 구성 요소, 특정 이벤트 등과 관련된 이벤트만 표시하는 데 유용합니다.



 a| 
열 아이콘을 선택합니다.
 a| 
다른 열을 선택하여 볼 수 있습니다. 다른 열에는 이벤트에 대한 추가 정보가 표시됩니다.



 a| 
확인란
 a| 
저장할 이벤트를 선택할 수 있습니다. 표 헤더의 확인란을 선택하면 모든 이벤트가 선택됩니다.



 a| 
날짜/시간 열
 a| 
컨트롤러 시계에 따른 이벤트의 날짜 및 시간 스탬프입니다.


NOTE: 이벤트 로그는 처음에 시퀀스 번호를 기준으로 이벤트를 정렬합니다. 일반적으로 이 시퀀스는 날짜 및 시간과 일치합니다. 그러나 스토리지 어레이의 두 컨트롤러 클록이 동기화되지 않을 수 있습니다. 이 경우 이벤트 로그에서 이벤트와 표시된 날짜 및 시간과 관련하여 일부 불일치가 나타날 수 있습니다.



 a| 
우선순위 열
 a| 
다음과 같은 우선순위 값이 존재합니다.

** *심각* -- 스토리지 어레이에 문제가 있습니다. 그러나 즉시 조치를 취하면 데이터 액세스 손실을 방지할 수 있습니다. 심각 이벤트는 알림 통지에 사용됩니다. 모든 심각 이벤트는 네트워크 관리 클라이언트(SNMP 트랩을 통해) 또는 구성한 이메일 수신자에게 전송됩니다.
** *경고* -- 스토리지 어레이의 성능과 다른 오류로부터 복구하는 기능을 저하시키는 오류가 발생했습니다.
** *정보* -- 스토리지 어레이와 관련된 중요하지 않은 정보입니다.




 a| 
구성 요소 유형 열
 a| 
이벤트의 영향을 받는 구성 요소입니다. 이 구성 요소는 드라이브나 컨트롤러와 같은 하드웨어일 수도 있고, 컨트롤러 펌웨어와 같은 소프트웨어일 수도 있습니다.



 a| 
구성 요소 위치 열
 a| 
스토리지 어레이 내 구성 요소의 물리적 위치입니다.



 a| 
설명 열
 a| 
이벤트에 대한 설명입니다.

*예* -- `Drive write failure - retries exhausted`



 a| 
시퀀스 번호 열
 a| 
스토리지 어레이의 특정 로그 항목을 고유하게 식별하는 64비트 숫자입니다. 이 숫자는 새 이벤트 로그 항목이 추가될 때마다 1씩 증가합니다. 이 정보를 표시하려면 *열 선택* 아이콘을 클릭하십시오.



 a| 
이벤트 유형 열
 a| 
기록된 각 이벤트 유형을 식별하는 4자리 숫자입니다. 이 정보를 표시하려면 *열 선택* 아이콘을 클릭하십시오.



 a| 
이벤트별 코드 열
 a| 
이 정보는 기술 지원에서 사용됩니다. 이 정보를 표시하려면 *열 선택* 아이콘을 클릭하십시오.



 a| 
이벤트 카테고리 열
 a| 
** **장애** – 스토리지 어레이의 구성 요소에 장애가 발생했습니다(예: 드라이브 장애 또는 배터리 장애).
** **상태 변경** – 상태가 변경된 스토리지 어레이의 요소입니다. 예를 들어 볼륨이 최적 상태로 전환되었거나 컨트롤러가 오프라인 상태로 전환된 경우입니다.
** **내부** – 사용자 조치가 필요하지 않은 내부 컨트롤러 작업입니다. 예를 들어 컨트롤러가 업무 시작을 완료한 경우입니다.
** **명령** – 스토리지 어레이에 실행된 명령입니다. 예를 들어, 핫 스페어가 할당되었습니다.
** **오류** – 스토리지 어레이에서 오류 상태가 감지되었습니다. 예를 들어 컨트롤러가 캐시를 동기화 및 삭제할 수 없거나 스토리지 어레이에서 이중화 오류가 감지된 경우입니다.
** **일반** – 다른 어떤 범주에도 명확하게 속하지 않는 모든 이벤트입니다. 이 정보를 표시하려면 **열 선택** 아이콘을 클릭하십시오.




 a| 
로그인한 사용자 열
 a| 
이벤트를 기록한 컨트롤러의 이름입니다. 이 정보를 표시하려면 **열 선택** 아이콘을 클릭하십시오.

|===
====
. 스토리지 어레이에서 새 이벤트를 가져오려면 **새로 고침**을 클릭하십시오.
+
이벤트가 기록되어 이벤트 로그 페이지에 표시되기까지 몇 분이 소요될 수 있습니다.

. 이벤트 로그를 파일에 저장하려면:
+
.. 저장하려는 각 이벤트 옆의 확인란을 선택하세요.
.. *저장*을 클릭합니다.
+
해당 파일은 브라우저의 다운로드 폴더에 `major-event-log-timestamp.log`이라는 이름으로 저장됩니다.



. 이벤트 로그에서 이벤트를 지우려면:
+
이벤트 로그는 이벤트를 새 이벤트로 교체하기 전에 약 8,000개의 이벤트를 저장합니다. 이벤트를 보관하려면 이벤트를 저장하고 이벤트 로그에서 지울 수 있습니다.

+
.. 먼저 이벤트 로그를 저장합니다.
.. *모두 지우기*를 클릭하고 작업을 수행할 것인지 확인합니다.
