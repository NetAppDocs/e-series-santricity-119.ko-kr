= SANtricity System Manager에서 구성 데이터를 수집합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
컨트롤러에서 RAID 구성 데이터를 저장할 수 있으며, 여기에는 볼륨 그룹 및 디스크 풀에 대한 모든 데이터가 포함됩니다. 그런 다음 기술 지원 팀에 문의하여 데이터 복원에 대한 도움을 받을 수 있습니다.

.이 작업 정보
이 작업은 RAID 구성 데이터베이스의 현재 상태를 저장하는 방법을 설명합니다. 이 데이터는 컨트롤러의 RPA 메모리 위치에서 가져옵니다.

[NOTE]
====
구성 데이터 수집 기능은 `save storageArray dbmDatabase`에 대한 CLI 명령과 동일한 정보를 저장합니다.

====
이 작업은 Recovery Guru 작업 또는 기술 지원 팀의 지시가 있을 때만 수행해야 합니다.

.단계
. 메뉴:Support[Support Center > Diagnostics] 탭을 선택합니다.
. *Collect Configuration Data*를 선택합니다.
. 대화 상자에서 *수집*을 클릭합니다.
+
파일 `configurationData-<arrayName>-<dateTime>.7z`은 브라우저의 다운로드 폴더에 저장됩니다.

. 파일을 기술 지원팀에 보내는 방법 및 데이터를 시스템에 다시 로드하는 방법에 대한 자세한 내용은 기술 지원팀에 문의하십시오.
