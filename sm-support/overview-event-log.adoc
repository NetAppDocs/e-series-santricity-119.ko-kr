= SANtricity 소프트웨어의 이벤트 로그에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 로그는 스토리지 어레이에서 발생한 이벤트에 대한 기록을 제공하므로 기술 지원 부서에서 장애 발생으로 이어지는 이벤트 문제를 해결하는 데 도움이 됩니다.

이벤트 로그는 스토리지 어레이 이벤트 추적을 위한 Recovery Guru의 보조 진단 도구로 사용할 수 있습니다. 스토리지 어레이 구성 요소 오류 복구를 시도할 때는 항상 Recovery Guru를 먼저 참조하십시오.



== 이벤트 범주

이벤트 로그의 이벤트는 다양한 상태로 분류됩니다. 조치가 필요한 이벤트는 다음과 같은 상태를 가집니다.

* 심각
* 경고


정보 제공 목적이며 즉각적인 조치가 필요하지 않은 이벤트는 다음과 같습니다.

* 정보




== 중요 이벤트

심각한 이벤트는 스토리지 어레이에 문제가 있음을 나타냅니다. 심각한 이벤트를 즉시 해결하면 데이터 액세스 손실을 방지할 수 있습니다.

중요 이벤트가 발생하면 이벤트 로그에 기록됩니다. 모든 중요 이벤트는 SNMP 관리 콘솔 또는 알림 수신을 위해 구성된 이메일 수신자에게 전송됩니다. 이벤트 발생 시점에 셸프 ID를 알 수 없는 경우 셸프 ID는 "Shelf unknown"으로 표시됩니다.

심각한 이벤트가 발생하면 Recovery Guru 절차를 참조하여 심각한 이벤트에 대한 자세한 설명을 확인하십시오. Recovery Guru 절차를 완료하여 심각한 이벤트를 해결하십시오. 특정 심각한 이벤트를 해결하려면 기술 지원 부서에 문의해야 할 수 있습니다.
