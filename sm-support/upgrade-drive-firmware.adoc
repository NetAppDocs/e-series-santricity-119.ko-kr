= SANtricity System Manager에서 드라이브 펌웨어 업그레이드
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
드라이브 펌웨어를 업그레이드하여 모든 최신 기능과 버그 수정 사항을 활용할 수 있습니다.

.시작하기 전에
* 디스크 간 백업, 볼륨 복사본(계획된 펌웨어 업그레이드의 영향을 받지 않는 볼륨 그룹으로) 또는 원격 미러를 사용하여 데이터를 백업했습니다.
* 스토리지 어레이의 상태가 최적입니다.
* 모든 드라이브의 상태가 최적입니다.
* 스토리지 어레이에서 실행 중인 구성 변경 사항이 없습니다.
* 드라이브가 오프라인 업그레이드만 가능한 경우 드라이브와 연결된 모든 볼륨에 대한 I/O 작업이 중지됩니다.


.단계
. 메뉴:지원[업그레이드 센터]를 선택합니다.
. Support 사이트에서 새 파일을 관리 클라이언트로 다운로드하십시오.
. 드라이브 펌웨어 업그레이드에서 *업그레이드 시작*을 클릭합니다.
+
현재 사용 중인 드라이브 펌웨어 파일 목록이 표시되는 대화 상자가 나타납니다.

. 지원 사이트에서 다운로드한 파일의 압축을 해제합니다.
. * 찾아보기 * 를 클릭하고 지원 사이트에서 다운로드한 새 드라이브 펌웨어 파일을 선택합니다.
+
드라이브 펌웨어 파일의 파일 이름은  `D_HUC101212CSS600_30602291_MS01_2800_0002`과(와) 유사하며 확장자는  `.dlp`입니다.

+
최대 4개의 드라이브 펌웨어 파일을 한 번에 하나씩 선택할 수 있습니다. 동일한 드라이브에 호환되는 드라이브 펌웨어 파일이 두 개 이상 있는 경우 파일 충돌 오류가 발생합니다. 업그레이드에 사용할 드라이브 펌웨어 파일을 선택하고 나머지 하나는 제거하십시오.

. * 다음 * 을 클릭합니다.
+
선택한 파일로 업그레이드할 수 있는 드라이브가 나열된 *드라이브 선택* 대화 상자가 나타납니다.

+
호환되는 드라이브만 표시됩니다.

+
드라이브에 대해 선택한 펌웨어가 제안된 펌웨어 정보 영역에 표시됩니다. 펌웨어를 변경해야 하는 경우 *뒤로*를 클릭하여 이전 대화 상자로 돌아가십시오.

. 수행할 업그레이드 유형을 선택하십시오.
+
** *온라인(기본값)* -- _스토리지 어레이가 I/O를 처리하는 동안_ 펌웨어 다운로드를 지원할 수 있는 드라이브를 표시합니다. 이 업그레이드 방법을 선택하면 해당 드라이브를 사용하는 관련 볼륨에 대한 I/O를 중지할 필요가 없습니다. 스토리지 어레이가 해당 드라이브에 대한 I/O를 처리하는 동안 드라이브가 하나씩 업그레이드됩니다.
** *오프라인(병렬)* -- 드라이브를 사용하는 모든 볼륨에서 _모든 I/O 활동이 중지된 상태에서만_ 펌웨어 다운로드를 지원하는 드라이브를 표시합니다. 이 업그레이드 방법을 선택할 경우, 업그레이드하려는 드라이브를 사용하는 모든 볼륨에서 모든 I/O 활동을 중지해야 합니다. 이중화가 없는 드라이브는 오프라인 작업으로 처리해야 합니다. 여기에는 SSD 캐시, RAID 0 볼륨 그룹 또는 성능이 저하된 풀이나 볼륨 그룹과 관련된 모든 드라이브가 포함됩니다. 오프라인(병렬) 업그레이드는 일반적으로 온라인(기본) 방법보다 빠릅니다.


. 표의 첫 번째 열에서 업그레이드할 드라이브를 선택하십시오.
. *시작*을 클릭하고 작업을 수행할 것인지 확인합니다.
+
업그레이드를 중지하려면 *중지*를 클릭하십시오. 현재 진행 중인 펌웨어 다운로드가 모두 완료됩니다. 아직 시작되지 않은 펌웨어 다운로드는 취소됩니다.

+
[CAUTION]
====
드라이브 펌웨어 업그레이드를 중단하면 데이터가 손실되거나 드라이브를 사용할 수 없게 될 수 있습니다.

====
. *선택 사항:* 업그레이드된 항목 목록을 보려면 *로그 저장*을 클릭하십시오.
+
해당 파일은 브라우저의 다운로드 폴더에 `drive_upgrade_log-timestamp.txt`이라는 이름으로 저장됩니다.

. 업그레이드 절차 중에 다음 오류가 발생하면 적절한 권장 조치를 수행하십시오.


.오류 및 권장 조치
[%collapsible]
====
[cols="40h,~"]
|===
| 이 펌웨어 다운로드 오류가 발생하는 경우... | 그런 다음 다음을 수행합니다. 


 a| 
할당된 드라이브 실패
 a| 
오류 발생 원인 중 하나는 드라이브에 적절한 서명이 없기 때문일 수 있습니다. 해당 드라이브가 인증된 드라이브인지 확인하십시오. 자세한 내용은 기술 지원팀에 문의하십시오.

드라이브를 교체할 때는 교체 드라이브의 용량이 교체하려는 장애가 발생한 드라이브의 용량과 같거나 더 큰지 확인하십시오.

스토리지 어레이가 I/O를 수신하는 동안에도 고장난 드라이브를 교체할 수 있습니다.



 a| 
스토리지 어레이 확인
 a| 
* 각 컨트롤러에 IP 주소가 할당되었는지 확인하십시오.
* 컨트롤러에 연결된 모든 케이블이 손상되지 않았는지 확인하십시오.
* 모든 케이블이 단단히 연결되어 있는지 확인하십시오.




 a| 
통합 핫 스페어 드라이브
 a| 
펌웨어를 업그레이드하려면 먼저 이 오류 조건을 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
불완전한 볼륨 그룹
 a| 
볼륨 그룹이나 디스크 풀이 하나 이상 불완전한 경우 펌웨어를 업그레이드하기 전에 이 오류 조건을 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
현재 볼륨 그룹에서 실행 중인 독점 작업(백그라운드 미디어/패리티 스캔 제외)
 a| 
하나 이상의 전용 작업이 진행 중인 경우 펌웨어를 업그레이드하기 전에 해당 작업이 완료되어야 합니다. System Manager를 사용하여 작업 진행 상황을 모니터링하십시오.



 a| 
누락된 볼륨
 a| 
펌웨어를 업그레이드하기 전에 누락된 볼륨 상태를 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
컨트롤러 중 하나라도 Optimal 상태가 아닌 경우
 a| 
스토리지 어레이 컨트롤러 중 하나에 문제가 있습니다. 펌웨어를 업그레이드하기 전에 이 상태를 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
컨트롤러 객체 그래프 간 스토리지 파티션 정보 불일치
 a| 
컨트롤러의 데이터 유효성 검사 중 오류가 발생했습니다. 이 문제를 해결하려면 기술 지원 부서에 문의하십시오.



 a| 
SPM Verify Database Controller 확인 실패
 a| 
컨트롤러에서 스토리지 파티션 매핑 데이터베이스 오류가 발생했습니다. 이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
구성 데이터베이스 유효성 검사(스토리지 어레이의 컨트롤러 버전에서 지원하는 경우)
 a| 
컨트롤러에서 구성 데이터베이스 오류가 발생했습니다. 이 문제를 해결하려면 기술 지원 팀에 문의하십시오.



 a| 
MEL 관련 점검
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 10건 이상의 DDE Informational 또는 Critical MEL 이벤트가 보고되었습니다
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 2개 이상의 Page 2C Critical MEL 이벤트가 보고되었습니다
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 2개 이상의 성능 저하된 드라이브 채널 위험 MEL 이벤트가 보고되었습니다
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 4개 이상의 중요 MEL 항목
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.

|===
====
.완료한 후
드라이브 펌웨어 업그레이드가 완료되었습니다. 이제 정상적으로 사용하실 수 있습니다.
