= SANtricity 소프트웨어의 복구 모드 초기화
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이 구성을 복원한 후 '복구 모드 초기화' 작업을 사용하여 스토리지 어레이의 I/O를 재개하고 정상 작동 상태로 되돌리십시오.

.시작하기 전에
* 스토리지 어레이를 이전 구성으로 되돌리려면 복구 모드를 해제하기 전에 백업에서 구성을 복원해야 합니다.
* 복원 작업이 성공적으로 완료되었는지 확인하려면 유효성 검사를 수행하거나 기술 지원 팀에 문의해야 합니다. 복원 작업이 성공적으로 완료된 것을 확인한 후에는 복구 모드를 해제할 수 있습니다.


.이 작업 정보
스토리지 어레이에는 논리적 구성(풀, 볼륨 그룹, 볼륨 등)의 레코드가 포함된 구성 데이터베이스가 있습니다. 스토리지 어레이 구성을 의도적으로 지우거나 구성 데이터베이스가 손상된 경우 스토리지 어레이는 복구 모드로 진입합니다. 복구 모드는 I/O를 중지하고 구성 데이터베이스를 고정하여 다음 중 하나를 수행할 시간을 제공합니다.

* 컨트롤러의 플래시 장치에 저장된 자동 백업에서 구성을 복원하십시오. 이를 위해서는 기술 지원팀에 문의해야 합니다.
* 이전 구성 데이터베이스 저장 작업에서 구성을 복원합니다. 구성 데이터베이스 저장 작업은 명령줄 인터페이스(CLI)를 통해 수행됩니다.
* 스토리지 어레이를 처음부터 다시 구성합니다.


스토리지 어레이 구성이 복원되거나 재정의되었고 모든 것이 정상인지 확인한 후에는 복구 모드를 수동으로 해제해야 합니다.

[NOTE]
====
복구 모드 초기화 작업은 시작 후에는 취소할 수 없습니다. 복구 모드 초기화에는 상당한 시간이 소요될 수 있습니다. 기술 지원 부서에서 지시한 경우에만 이 작업을 수행하십시오.

====
.단계
. 메뉴:Support[Support Center > Diagnostics] 탭을 선택합니다.
. *Clear Recovery Mode*를 선택하고 이 작업을 수행할 것인지 확인하십시오.
+
이 옵션은 스토리지 어레이가 복구 모드일 때만 나타납니다.
