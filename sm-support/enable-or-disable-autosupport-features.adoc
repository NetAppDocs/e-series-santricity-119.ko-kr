= SANtricity System Manager에서 AutoSupport 기능 활성화 또는 비활성화
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
초기 설정 중에 AutoSupport 기능 및 개별 AutoSupport 기능을 활성화하거나 나중에 활성화 또는 비활성화할 수 있습니다.

.시작하기 전에
AutoSupport OnDemand 또는 Remote Diagnostics를 활성화하려면 AutoSupport 전달 방식을 HTTPS로 설정해야 합니다.

.이 작업 정보
AutoSupport 기능은 언제든지 비활성화할 수 있지만, 활성화 상태로 유지하는 것이 좋습니다. AutoSupport 기능을 활성화하면 스토리지 어레이에서 문제가 발생할 경우 문제 진단 및 해결 속도를 크게 향상시킬 수 있습니다.

AutoSupport 기능은 세 가지 개별 기능으로 구성되어 있으며, 각 기능은 별도로 활성화해야 합니다.

* *기본 AutoSupport* -- 스토리지 어레이가 자동으로 데이터를 수집하여 기술 지원 부서로 전송할 수 있습니다.
* *AutoSupport OnDemand* -- 기술 지원 부서에서 문제 해결에 필요한 경우 이전 AutoSupport 디스패치의 재전송을 요청할 수 있습니다. 모든 전송은 AutoSupport 서버가 아닌 스토리지 어레이에서 시작됩니다. 스토리지 어레이는 주기적으로 AutoSupport 서버에 접속하여 보류 중인 재전송 요청이 있는지 확인하고 그에 따라 응답합니다.
* *원격 진단* -- 기술 지원 부서에서 문제 해결에 필요한 경우 최신 AutoSupport 발송을 요청할 수 있습니다. 모든 전송은 AutoSupport 서버가 아닌 스토리지 어레이에서 시작됩니다. 스토리지 어레이는 주기적으로 AutoSupport 서버에 접속하여 보류 중인 새 요청이 있는지 확인하고 그에 따라 응답합니다.


.단계
. 메뉴에서 지원[지원 센터 > AutoSupport] 탭을 선택하세요.
. *Enable/Disable AutoSupport Features*를 선택합니다.
. 활성화하려는 AutoSupport 기능 옆의 확인란을 선택하십시오.
+
대화 상자의 항목 들여쓰기에서 알 수 있듯이 기능들은 서로 연관되어 있습니다. 예를 들어 원격 진단을 활성화하려면 먼저 AutoSupport OnDemand를 활성화해야 합니다.

. *저장*을 클릭합니다.
+
AutoSupport를 비활성화하면 홈 페이지에 알림이 표시됩니다. *무시*를 클릭하여 알림을 닫을 수 있습니다.
