= SANtricity 소프트웨어 및 펌웨어 업그레이드 오류에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
컨트롤러 소프트웨어 업그레이드 또는 드라이브 펌웨어 업그레이드 중에 오류가 발생할 수 있습니다.

[cols="25h,~,~"]
|===
| 펌웨어 다운로드 오류 | 설명 | 권장 조치 


 a| 
할당된 드라이브 실패
 a| 
스토리지 어레이에서 할당된 드라이브를 업그레이드하는 데 실패했습니다.
 a| 
오류 발생 원인 중 하나는 드라이브에 적절한 서명이 없기 때문일 수 있습니다. 해당 드라이브가 인증된 드라이브인지 확인하십시오. 자세한 내용은 기술 지원팀에 문의하십시오.

드라이브를 교체할 때는 교체 드라이브의 용량이 교체하려는 장애가 발생한 드라이브의 용량과 같거나 더 큰지 확인하십시오.

스토리지 어레이가 I/O를 수신하는 동안에도 고장난 드라이브를 교체할 수 있습니다.



 a| 
통합 핫 스페어 드라이브
 a| 
드라이브가 핫 스페어로 표시되어 있고 볼륨 그룹에 사용 중인 경우 펌웨어 업그레이드 프로세스가 실패합니다.
 a| 
펌웨어를 업그레이드하려면 먼저 이 오류 조건을 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
불완전한 볼륨 그룹
 a| 
볼륨 그룹에 속한 드라이브 중 하나라도 우회되거나, 제거되거나, 응답하지 않는 경우 해당 볼륨 그룹은 불완전한 것으로 간주됩니다. 불완전한 볼륨 그룹은 펌웨어 업그레이드를 방해합니다.
 a| 
볼륨 그룹이나 디스크 풀이 하나 이상 불완전한 경우 펌웨어를 업그레이드하기 전에 이 오류 조건을 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
현재 볼륨 그룹에서 실행 중인 독점 작업(백그라운드 미디어/패리티 스캔 제외)
 a| 
볼륨에서 단독 작업이 진행 중인 경우 펌웨어를 업그레이드할 수 없습니다.
 a| 
하나 이상의 전용 작업이 진행 중인 경우 펌웨어를 업그레이드하기 전에 해당 작업이 완료되어야 합니다. System Manager를 사용하여 작업 진행 상황을 모니터링하십시오.



 a| 
누락된 볼륨
 a| 
볼륨이 하나라도 누락된 경우 펌웨어를 업그레이드할 수 없습니다.
 a| 
펌웨어를 업그레이드하기 전에 누락된 볼륨 상태를 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
컨트롤러 중 하나라도 Optimal 상태가 아닌 경우
 a| 
컨트롤러 중 하나라도 최적 상태가 아닌 경우 펌웨어를 업그레이드할 수 없습니다.
 a| 
스토리지 어레이 컨트롤러 중 하나에 문제가 있습니다. 펌웨어를 업그레이드하기 전에 이 상태를 수정해야 합니다. System Manager를 실행하고 Recovery Guru를 사용하여 문제를 해결하십시오.



 a| 
SPM Verify Database Controller 확인 실패
 a| 
스토리지 파티션 매핑 데이터베이스가 손상되어 펌웨어를 업그레이드할 수 없습니다.
 a| 
컨트롤러에서 스토리지 파티션 매핑 데이터베이스 오류가 발생했습니다. 이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
구성 데이터베이스 유효성 검사(스토리지 어레이의 컨트롤러 버전에서 지원하는 경우)
 a| 
구성 데이터베이스가 손상되어 펌웨어를 업그레이드할 수 없습니다.
 a| 
컨트롤러에서 구성 데이터베이스 오류가 발생했습니다. 이 문제를 해결하려면 기술 지원 팀에 문의하십시오.



 a| 
MEL 관련 점검
 a| 
이벤트 로그에 오류가 포함되어 있어 펌웨어를 업그레이드할 수 없습니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 10건 이상의 DDE Informational 또는 Critical MEL 이벤트가 보고되었습니다
 a| 
지난 7일 동안 10건 이상의 DDE 정보 또는 심각한 MEL 이벤트가 보고되었으므로 펌웨어를 업그레이드할 수 없습니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 2개 이상의 Page 2C Critical MEL 이벤트가 보고되었습니다
 a| 
지난 7일 동안 2개 이상의 페이지 2C 심각한 MEL 이벤트가 보고되었기 때문에 펌웨어를 업그레이드할 수 없습니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 2개 이상의 성능 저하된 드라이브 채널 위험 MEL 이벤트가 보고되었습니다
 a| 
지난 7일 동안 성능이 저하된 드라이브 채널 심각 MEL 이벤트가 2개 이상 보고되었기 때문에 펌웨어를 업그레이드할 수 없습니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
지난 7일 동안 4개 이상의 중요 MEL 항목
 a| 
지난 7일 동안 중요 이벤트 로그 항목이 4개 이상 보고되었으므로 펌웨어를 업그레이드할 수 없습니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
유효한 관리 IP 주소가 필요합니다.
 a| 
이 작업을 수행하려면 유효한 컨트롤러 IP 주소가 필요합니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
이 명령을 실행하려면 각 컨트롤러에 대한 활성 관리 IP 주소를 제공해야 합니다.
 a| 
이 작업을 위해서는 스토리지 어레이와 연결된 각 컨트롤러의 IP 주소가 필요합니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
처리되지 않은 다운로드 파일 유형이 반환되었습니다.
 a| 
지정된 다운로드 파일은 지원되지 않습니다.
 a| 
이 문제를 해결하려면 기술 지원팀에 문의하십시오.



 a| 
펌웨어 다운로드 업로드 절차 중 오류가 발생했습니다.
 a| 
컨트롤러가 요청을 처리할 수 없어 펌웨어 다운로드에 실패했습니다. 스토리지 어레이가 최적 상태인지 확인하고 작업을 다시 시도하십시오.
 a| 
스토리지 어레이가 최적 상태임을 확인한 후에도 이 오류가 다시 발생하면 기술 지원 부서에 문의하여 이 문제를 해결하십시오.



 a| 
펌웨어 활성화 절차 중 오류가 발생했습니다.
 a| 
컨트롤러가 요청을 처리할 수 없어 펌웨어 활성화에 실패했습니다. 스토리지 어레이가 최적 상태인지 확인하고 작업을 다시 시도하십시오.
 a| 
스토리지 어레이가 최적 상태임을 확인한 후에도 이 오류가 다시 발생하면 기술 지원 부서에 문의하여 이 문제를 해결하십시오.



 a| 
컨트롤러 {0} 재부팅을 기다리는 동안 시간 초과가 발생했습니다.
 a| 
관리 소프트웨어가 재부팅 후 컨트롤러 {0}에 다시 연결할 수 없습니다. 스토리지 어레이에 대한 정상적인 연결 경로가 있는지 확인하고 작업이 성공적으로 완료되지 않은 경우 다시 시도하십시오.
 a| 
스토리지 어레이가 최적 상태임을 확인한 후에도 이 오류가 다시 발생하면 기술 지원 부서에 문의하여 이 문제를 해결하십시오.

|===
System Manager의 Recovery Guru를 사용하면 이러한 문제 중 일부를 해결할 수 있습니다. 하지만 일부 문제의 경우 기술 지원 부서에 문의해야 할 수 있습니다. 최신 컨트롤러 펌웨어 다운로드에 대한 정보는 스토리지 어레이에서 확인할 수 있습니다. 이 정보는 기술 지원 부서가 펌웨어 업그레이드 및 다운로드를 방해한 오류 상황을 파악하는 데 도움이 됩니다.
