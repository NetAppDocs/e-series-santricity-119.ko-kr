= SANtricity System Manager에서 컨트롤러 소프트웨어 및 펌웨어 업그레이드
:allow-uri-read: 


[role="lead"]
스토리지 어레이의 소프트웨어를 업그레이드하고, 선택적으로 IOM 펌웨어와 비휘발성 정적 랜덤 액세스 메모리(NVSRAM)를 업그레이드하여 모든 최신 기능과 버그 수정 사항을 활용할 수 있습니다.

.시작하기 전에
* IOM 펌웨어를 업그레이드할지 여부를 알고 있습니다.
+
일반적으로 모든 구성 요소를 동시에 업그레이드해야 합니다. 그러나 SANtricity OS 소프트웨어 업그레이드의 일부로 IOM 펌웨어를 업그레이드하고 싶지 않거나 기술 지원 부서에서 IOM 펌웨어를 다운그레이드하라고 지시한 경우(명령줄 인터페이스를 통해서만 펌웨어를 다운그레이드할 수 있음) IOM 펌웨어를 업그레이드하지 않기로 결정할 수도 있습니다.

* 컨트롤러 NVSRAM 파일을 업그레이드할지 여부를 알고 있습니다.
+
일반적으로 모든 구성 요소를 동시에 업그레이드해야 합니다. 하지만 컨트롤러의 NVSRAM 파일이 패치되었거나 사용자 지정 버전인 경우, 덮어쓰기를 원하지 않는다면 해당 파일만 업그레이드하지 않기로 결정할 수도 있습니다.

* 지금 또는 나중에 OS 업그레이드를 활성화할지 여부를 알고 있습니다.
+
나중에 활성화하는 이유는 다음과 같습니다.

+
** *시간대* -- 소프트웨어 및 펌웨어를 활성화하는 데 시간이 오래 걸릴 수 있으므로 I/O 부하가 적은 시간대에 진행하는 것이 좋습니다. 활성화 과정 중에는 컨트롤러가 페일오버되므로 업그레이드가 완료될 때까지 성능이 평소보다 저하될 수 있습니다.
** *패키지 유형* -- 다른 스토리지 어레이의 파일을 업그레이드하기 전에 하나의 스토리지 어레이에서 새 소프트웨어 및 펌웨어를 테스트해 보는 것이 좋습니다.


* 보안되지 않은 드라이브 또는 내부적으로 보안된 드라이브에서 드라이브 보안을 위해 외부 키 관리 서버(KMS)를 사용하도록 전환할지 여부를 알고 있습니다.
* 스토리지 어레이에서 역할 기반 액세스 제어를 사용할지 여부를 알고 있습니다.


.이 작업 정보
OS 소프트웨어 파일만 업그레이드하거나 Controller NVSRAM 파일만 업그레이드하거나 또는 두 파일 모두 업그레이드하도록 선택할 수 있습니다.

기술 지원 부서에서 지시한 경우에만 이 작업을 수행하십시오.

[CAUTION]
====
*데이터 손실 또는 스토리지 어레이 손상 위험* -- 업그레이드가 진행되는 동안 스토리지 어레이를 변경하지 마십시오. 스토리지 어레이에 전원을 계속 공급하십시오.

====
.단계
. 스토리지 어레이에 컨트롤러가 하나만 있거나 다중 경로 드라이버가 설치되어 있지 않은 경우 애플리케이션 오류를 방지하기 위해 스토리지 어레이에 대한 I/O 작업을 중지하십시오. 스토리지 어레이에 컨트롤러가 두 개 있고 다중 경로 드라이버가 설치되어 있는 경우에는 I/O 작업을 중지할 필요가 없습니다.
. 메뉴:지원[업그레이드 센터]를 선택합니다.
. 지원 사이트에서 관리 클라이언트로 새 파일을 다운로드합니다.
+
.. *NetApp Support*를 클릭하여 Support 웹 사이트를 시작합니다.
.. Support 웹 사이트에서 *Downloads* 탭을 클릭한 다음 *Downloads*를 선택합니다.
.. *E-Series SANtricity OS Controller Software*를 선택하십시오.
.. 나머지 지침을 따르십시오.


+
[NOTE]
====
버전 8.42 이상에서는 디지털 서명된 펌웨어가 필요합니다. 서명되지 않은 펌웨어를 다운로드하려고 하면 오류가 표시되고 다운로드가 중단됩니다.

====
. 지금 IOM 펌웨어를 업그레이드하지 않으려면 *IOM 자동 동기화 일시 중지*를 클릭하십시오.
+
컨트롤러가 하나인 스토리지 어레이를 사용하는 경우 IOM 펌웨어가 업그레이드되지 않습니다.

. SANtricity OS 소프트웨어 업그레이드에서 * 업그레이드 시작 * 을 클릭합니다.
+
SANtricity OS 소프트웨어 업그레이드 대화 상자가 나타납니다.

. 업그레이드 프로세스를 시작하려면 하나 이상의 파일을 선택하십시오.
+
.. *찾아보기*를 클릭하고 지원 웹 사이트에서 다운로드한 OS 소프트웨어 파일로 이동하여 SANtricity OS 소프트웨어 파일을 선택하십시오.
.. *찾아보기*를 클릭하고 Support 사이트에서 다운로드한 NVSRAM 파일로 이동하여 Controller NVSRAM 파일을 선택합니다. Controller NVSRAM 파일의 파일 이름은 `N2800-830000-000.dlp`과 유사합니다.


+
다음 작업이 수행됩니다.

+
** 기본적으로 현재 스토리지 어레이 구성과 호환되는 파일만 표시됩니다.
** 업그레이드할 파일을 선택하면 파일 이름과 크기가 표시됩니다.


. *선택 사항:* 업그레이드할 SANtricity OS 소프트웨어 파일을 선택한 경우 *지금 파일을 전송하되 업그레이드는 하지 않음(나중에 업그레이드 활성화)* 확인란을 선택하여 파일을 활성화하지 않고 컨트롤러로 전송할 수 있습니다.
. *시작*을 클릭하고 작업을 수행할 것인지 확인합니다.
+
업그레이드 전 상태 점검 중에는 작업을 취소할 수 있지만 전송 또는 활성화 중에는 취소할 수 없습니다.

. *선택 사항:* 업그레이드된 항목 목록을 보려면 *로그 저장*을 클릭하십시오.
+
해당 파일은 브라우저의 다운로드 폴더에 `drive_upgrade_log-timestamp.txt`이라는 이름으로 저장됩니다.



.완료한 후
* 하드웨어 페이지에 모든 구성 요소가 표시되는지 확인하십시오.
* 새 소프트웨어 및 펌웨어 버전을 확인하려면 소프트웨어 및 펌웨어 인벤토리 대화 상자를 확인하십시오(메뉴:지원[업그레이드 센터]로 이동한 다음 *소프트웨어 및 펌웨어 인벤토리* 링크를 클릭).
* 컨트롤러 NVSRAM을 업그레이드한 경우, 기존 NVSRAM에 적용했던 사용자 지정 설정이 활성화 과정에서 모두 손실됩니다. 활성화 과정이 완료된 후 NVSRAM에 사용자 지정 설정을 다시 적용해야 합니다.
