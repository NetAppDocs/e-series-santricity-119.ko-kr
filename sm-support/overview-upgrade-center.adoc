[role="lead"]
업그레이드 센터를 사용하여 최신 소프트웨어 및 펌웨어를 다운로드하고 컨트롤러와 드라이브를 업그레이드하십시오.



== 컨트롤러 업그레이드 개요

최신 기능과 버그 수정 사항을 모두 이용하기 위해 스토리지 어레이의 소프트웨어와 펌웨어를 업그레이드할 수 있습니다.



=== OS 컨트롤러 업그레이드에 포함된 구성요소

스토리지 어레이의 여러 구성 요소에는 때때로 업그레이드해야 할 수 있는 소프트웨어 또는 하드웨어가 포함되어 있습니다.

* *관리 소프트웨어* -- System Manager는 스토리지 어레이를 관리하는 소프트웨어입니다.
* *컨트롤러 펌웨어* -- 컨트롤러 펌웨어는 호스트와 볼륨 간의 I/O를 관리합니다.
* *컨트롤러 NVSRAM* -- 컨트롤러 NVSRAM은 컨트롤러의 기본 설정을 지정하는 컨트롤러 파일입니다.
* *IOM 펌웨어* -- I/O 모듈(IOM) 펌웨어는 컨트롤러와 드라이브 셸프 간의 연결을 관리합니다. 또한 구성 요소의 상태를 모니터링합니다.
* *Supervisor 소프트웨어* -- Supervisor 소프트웨어는 소프트웨어가 실행되는 컨트롤러의 가상 머신입니다.


image::../media/sam1130-dwg-upgrade-firmware-locations.gif[펌웨어 업그레이드 위치]

^1^ 컨트롤러 셸프; ^2^ 드라이브 셸프; ^3^ 소프트웨어, 컨트롤러 펌웨어, 컨트롤러 NVSRAM, 슈퍼바이저 소프트웨어; ^4^ 드라이브 펌웨어; ^5^ IOM 펌웨어; ^6^ 드라이브 펌웨어

소프트웨어 및 펌웨어 버전은 소프트웨어 및 펌웨어 인벤토리 대화 상자에서 확인할 수 있습니다. 메뉴에서 지원[업그레이드 센터]를 선택한 다음 *소프트웨어 및 펌웨어 인벤토리* 링크를 클릭하십시오.

업그레이드 프로세스의 일부로, 호스트가 컨트롤러와 올바르게 상호 작용할 수 있도록 호스트의 다중 경로/페일오버 드라이버 및/또는 HBA 드라이버도 업그레이드해야 할 수 있습니다. 이 경우인지 확인하려면  https://imt.netapp.com/matrix/#welcome["NetApp Interoperability Matrix Tool"^]을 참조하십시오.



=== I/O를 중지해야 하는 경우

스토리지 어레이에 컨트롤러가 두 개 있고 다중 경로 드라이버가 설치되어 있는 경우, 업그레이드가 진행되는 동안에도 스토리지 어레이는 I/O 처리를 계속할 수 있습니다. 업그레이드 과정에서 컨트롤러 A는 모든 볼륨을 컨트롤러 B로 페일오버하고, 업그레이드를 완료한 후, 자신의 볼륨과 컨트롤러 B의 모든 볼륨을 다시 가져온 다음 컨트롤러 B를 업그레이드합니다.



=== 업그레이드 전 상태 점검

업그레이드 프로세스의 일부로 사전 업그레이드 상태 점검이 실행됩니다. 사전 업그레이드 상태 점검은 모든 스토리지 어레이 구성 요소를 평가하여 업그레이드를 진행할 수 있는지 확인합니다. 다음과 같은 조건은 업그레이드를 방해할 수 있습니다.

* 할당된 드라이브 실패
* 사용 중인 핫 스페어
* 불완전한 볼륨 그룹
* 독점 작업 실행 중
* 누락된 볼륨
* 컨트롤러가 최적 상태가 아닙니다
* 이벤트 로그 이벤트 수가 과도하게 많습니다
* 구성 데이터베이스 유효성 검사 실패
* 이전 버전의 DACstore가 있는 드라이브


업그레이드를 수행하지 않고 업그레이드 전 상태 점검을 별도로 실행할 수도 있습니다.



== 드라이브 업그레이드 개요

드라이브 펌웨어는 드라이브의 저수준 작동 특성을 제어합니다. 드라이브 제조업체는 주기적으로 드라이브 펌웨어 업데이트를 릴리스하여 새로운 기능을 추가하고 성능을 개선하며 결함을 수정합니다.



=== 온라인 및 오프라인 드라이브 펌웨어 업그레이드

드라이브 펌웨어 업그레이드 방법에는 온라인과 오프라인의 두 가지 유형이 있습니다.



==== 온라인

온라인 업그레이드 중에는 드라이브가 순차적으로 하나씩 업그레이드됩니다. 스토리지 어레이는 업그레이드가 진행되는 동안에도 I/O 처리를 계속합니다. I/O를 중지할 필요가 없습니다. 드라이브가 온라인 업그레이드를 지원하는 경우 온라인 업그레이드 방식이 자동으로 사용됩니다.

온라인 업그레이드를 수행할 수 있는 드라이브는 다음과 같습니다.

* 최적 풀의 드라이브
* 최적의 중복 볼륨 그룹(RAID 1, RAID 5 및 RAID 6)의 드라이브
* 할당되지 않은 드라이브
* 대기 핫 스페어 드라이브


온라인 드라이브 펌웨어 업그레이드는 몇 시간이 소요될 수 있으며, 이로 인해 스토리지 어레이에 볼륨 오류가 발생할 가능성이 있습니다. 볼륨 오류는 다음과 같은 경우에 발생할 수 있습니다.

* RAID 1 또는 RAID 5 볼륨 그룹에서 볼륨 그룹의 다른 드라이브가 업그레이드되는 동안 한 드라이브에 장애가 발생합니다.
* RAID 6 풀 또는 볼륨 그룹에서 풀 또는 볼륨 그룹의 다른 드라이브를 업그레이드하는 동안 두 개의 드라이브에 장애가 발생합니다.




==== 오프라인(병렬)

오프라인 업그레이드 시에는 동일한 드라이브 유형의 모든 드라이브가 동시에 업그레이드됩니다. 이 방식은 선택한 드라이브와 연결된 볼륨의 I/O 작업을 중지해야 합니다. 여러 드라이브를 동시에(병렬로) 업그레이드할 수 있으므로 전체 다운타임이 크게 줄어듭니다. 드라이브가 오프라인 업그레이드만 가능한 경우 오프라인 방식이 자동으로 사용됩니다.

다음 드라이브는 오프라인 방식을 사용해야 합니다.

* 비중복 볼륨 그룹(RAID 0)의 드라이브
* 최적화되지 않은 풀 또는 볼륨 그룹의 드라이브
* SSD 캐시의 드라이브




=== 호환성

각 드라이브 펌웨어 파일에는 펌웨어가 실행되는 드라이브 유형에 대한 정보가 포함되어 있습니다. 지정된 펌웨어 파일은 호환되는 드라이브에만 다운로드할 수 있습니다. System Manager는 업그레이드 프로세스 중에 호환성을 자동으로 확인합니다.
