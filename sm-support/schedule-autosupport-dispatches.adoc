= SANtricity System Manager에서 AutoSupport 디스패치 예약
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager는 AutoSupport 발송을 위한 기본 일정을 자동으로 생성합니다. 원하는 경우 자체 일정을 지정할 수 있습니다.

.시작하기 전에
AutoSupport 기능이 활성화되어 있어야 합니다. AutoSupport 페이지에서 활성화 여부를 확인할 수 있습니다.

.이 작업 정보
* *일일 시간* -- 지정한 시간 범위 내에서 매일 일일 전송이 수집되어 전송됩니다. System Manager는 해당 범위 내에서 임의의 시간을 선택합니다. 모든 시간은 협정 세계시(UTC) 기준이며, 스토리지 어레이의 현지 시간과 다를 수 있습니다. 스토리지 어레이의 현지 시간을 UTC로 변환해야 합니다.
* *주간 발송일* -- 주간 발송은 일주일에 한 번 수집되어 전송됩니다. System Manager는 사용자가 지정한 요일 중에서 임의로 하루를 선택합니다. 주간 발송을 원하지 않는 요일은 선택 해제하십시오. System Manager는 사용자가 허용한 요일 중에서 임의로 하루를 선택합니다.
* *주간 시간* -- 주간 디스패치는 사용자가 지정한 시간 범위 내에서 매주 한 번씩 수집되어 전송됩니다. System Manager는 해당 범위 내에서 임의의 시간을 선택합니다. 모든 시간은 협정 세계시(UTC) 기준이며, 스토리지 어레이의 현지 시간과 다를 수 있습니다. 스토리지 어레이의 현지 시간을 UTC로 변환해야 합니다.


.단계
. 메뉴에서 지원[지원 센터 > AutoSupport] 탭을 선택하세요.
. *Schedule AutoSupport Dispatches*를 선택합니다.
