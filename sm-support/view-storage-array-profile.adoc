= SANtricity System Manager에서 스토리지 어레이의 프로필을 확인하세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이 프로필은 스토리지 어레이의 모든 구성 요소와 속성에 대한 설명을 제공합니다.

.이 작업 정보
스토리지 어레이 프로파일은 복구 과정에서 도움이 되거나 스토리지 어레이의 현재 구성을 한눈에 파악하는 데 사용할 수 있습니다. 관리 클라이언트에 스토리지 어레이 프로파일 사본을 저장하고 스토리지 어레이와 함께 하드 카피를 보관하는 것이 좋습니다. 구성이 변경되면 스토리지 어레이 프로파일의 새 사본을 생성하십시오.

.단계
. 메뉴:Support[Support Center > Support Resources] 탭을 선택합니다.
. 아래로 스크롤하여 *상세 스토리지 어레이 정보 시작*을 찾은 다음 *스토리지 어레이 프로필*을 선택합니다.
+
보고서가 화면에 나타납니다.

+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 섹션 | 설명 


 a| 
스토리지 어레이
 a| 
스토리지 어레이에 대해 구성할 수 있는 모든 옵션과 시스템 정적 옵션을 표시합니다. 이러한 옵션에는 컨트롤러, 드라이브 셸프, 드라이브, 디스크 풀, 볼륨 그룹, 볼륨 및 핫 스페어 드라이브 수, 허용되는 최대 드라이브 셸프, 드라이브, SSD(Solid State Disk) 및 볼륨 수, 스냅샷 그룹, 스냅샷 이미지, 스냅샷 볼륨 및 일관성 그룹 수, 기능 정보, 펌웨어 버전 정보, 섀시 일련 번호 정보, AutoSupport 상태 및 AutoSupport 일정 정보, 자동 지원 데이터 수집 및 예약된 지원 데이터 수집 설정, 스토리지 어레이 WWID(World-Wide Identifier), 미디어 스캔 및 캐시 설정이 포함됩니다.



 a| 
스토리지
 a| 
스토리지 어레이에 있는 모든 스토리지 장치 목록을 표시합니다. 스토리지 어레이 구성에 따라 스토리지 섹션에 다음 하위 섹션이 표시될 수 있습니다.

** *디스크 풀* -- 스토리지 어레이에 있는 모든 디스크 풀 목록을 표시합니다.
** *볼륨 그룹* -- 스토리지 어레이에 있는 모든 볼륨 그룹 목록을 표시합니다. 볼륨과 사용 가능한 용량은 생성 순서대로 나열됩니다.
** *볼륨* -- 스토리지 어레이에 있는 모든 볼륨 목록을 표시합니다. 표시되는 정보에는 볼륨 이름, 볼륨 상태, 용량, RAID 레벨, 볼륨 그룹 또는 디스크 풀, 드라이브 유형 및 추가 세부 정보가 포함됩니다.
** *누락된 볼륨* -- 스토리지 어레이에서 현재 누락된 상태인 모든 볼륨 목록을 표시합니다. 나열된 정보에는 각 누락된 볼륨의 WWID(World Wide Identifier)가 포함됩니다.




 a| 
복사 서비스
 a| 
스토리지 어레이에 사용되는 모든 복사 서비스 목록을 표시합니다. 스토리지 어레이 구성에 따라 복사 서비스 섹션에는 다음과 같은 하위 섹션이 표시될 수 있습니다.

** *볼륨 복사본* -- 스토리지 어레이에 있는 모든 복사본 쌍 목록을 표시합니다. 표시되는 정보에는 복사본 수, 복사본 쌍 이름, 상태, 시작 타임스탬프 및 추가 세부 정보가 포함됩니다.
** *스냅샷 그룹* -- 스토리지 어레이에 있는 모든 스냅샷 그룹 목록을 표시합니다.
** *스냅샷 이미지* -- 스토리지 어레이에 있는 모든 스냅샷 목록을 표시합니다.
** *스냅샷 볼륨* -- 스토리지 어레이에 있는 모든 스냅샷 볼륨 목록을 표시합니다.
** *일관성 그룹* -- 스토리지 어레이에 있는 모든 일관성 그룹 목록을 표시합니다.
** *멤버 볼륨* -- 스토리지 어레이에 있는 모든 일관성 그룹 멤버 볼륨 목록을 표시합니다.
** *미러 그룹* -- 미러링된 모든 볼륨의 목록을 표시합니다.
** *예약된 용량* -- 스토리지 어레이의 예약된 모든 용량 볼륨 목록을 표시합니다.




 a| 
호스트 할당
 a| 
스토리지 어레이의 호스트 할당 목록을 표시합니다. 나열된 정보에는 볼륨 이름, 논리 유닛 번호(LUN), 컨트롤러 ID, 호스트 이름 또는 호스트 클러스터 이름 및 볼륨 상태가 포함됩니다. 나열된 추가 정보에는 토폴로지 정의 및 호스트 유형 정의가 포함됩니다.



 a| 
하드웨어
 a| 
스토리지 어레이에 있는 모든 하드웨어 목록을 표시합니다. 스토리지 어레이 구성에 따라 하드웨어 섹션에 다음 하위 섹션이 표시될 수 있습니다.

** *컨트롤러* -- 스토리지 어레이에 있는 모든 컨트롤러 목록을 표시하며, 컨트롤러의 위치, 상태 및 구성이 포함됩니다. 또한 드라이브 채널 정보, 호스트 채널 정보 및 이더넷 포트 정보도 포함됩니다.
** *드라이브* -- 스토리지 어레이에 있는 모든 드라이브 목록을 표시합니다. 드라이브는 셸프 ID, 드로어 ID, 슬롯 ID 순으로 나열됩니다. 표시되는 정보에는 각 드라이브의 셸프 ID, 드로어 ID, 슬롯 ID, 상태, 원시 용량, 미디어 유형, 인터페이스 유형, 현재 데이터 전송률, 제품 ID 및 펌웨어 버전이 포함됩니다. 드라이브 섹션에는 드라이브 채널 정보, 핫 스페어 적용 범위 정보 및 마모 수명 정보(SSD 드라이브에만 해당)도 표시됩니다. 마모 수명 정보는 사용된 내구성 비율(%)을 나타내는데, 이는 SSD 드라이브에 현재까지 기록된 데이터 양을 드라이브의 총 이론적 쓰기 한도로 나눈 값입니다.
** *드라이브 채널* -- 스토리지 어레이의 모든 드라이브 채널에 대한 정보를 표시합니다. 표시되는 정보에는 채널 상태, 링크 상태(해당하는 경우), 드라이브 개수 및 누적 오류 횟수가 포함됩니다.
** *셸프* -- 스토리지 어레이의 모든 셸프에 대한 정보를 표시합니다. 표시되는 정보에는 드라이브 유형과 셸프의 각 구성 요소에 대한 상태 정보가 포함됩니다. 셸프 구성 요소에는 배터리 팩, SFP(Small Form-factor Pluggable) 트랜시버, 전원 팬 캐니스터 또는 IOM(입출력 모듈) 캐니스터가 포함될 수 있습니다. 하드웨어 섹션에는 스토리지 어레이에서 보안 키를 사용하는 경우 보안 키 식별자도 표시됩니다.




 a| 
기능
 a| 
설치된 기능 팩 목록과 호스트 또는 호스트 클러스터당 허용되는 최대 스냅샷 그룹 수, 스냅샷(레거시) 수 및 볼륨 수를 표시합니다. 기능 섹션의 정보에는 드라이브 보안, 즉 스토리지 어레이의 보안 활성화 또는 비활성화 여부도 포함됩니다.

|===
====
. 스토리지 어레이 프로필을 검색하려면 *찾기* 텍스트 상자에 검색어를 입력한 다음 *찾기*를 클릭합니다.
+
일치하는 모든 용어가 강조 표시됩니다. 모든 결과를 하나씩 스크롤하려면 *찾기*를 계속 클릭하십시오.

. 스토리지 어레이 프로필을 저장하려면 *저장*을 클릭하십시오.
+
해당 파일은 브라우저의 다운로드 폴더에 `storage-array-profile.txt`이라는 이름으로 저장됩니다.
