= 신뢰할 수 없는 인증서 해결
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
신뢰할 수 없는 인증서는 스토리지 어레이가 SANtricity Unified Manager에 대한 보안 연결을 설정하려고 시도하지만 연결이 안전한 것으로 확인되지 않을 때 발생합니다.

인증서 페이지에서 스토리지 어레이에서 자체 서명된 인증서를 가져오거나 신뢰할 수 있는 타사에서 발급한 인증 기관(CA) 인증서를 가져와 신뢰할 수 없는 인증서를 해결할 수 있습니다.

.시작하기 전에
* Security Admin 권한이 포함된 사용자 프로필로 로그인해야 합니다.
* CA 서명 인증서를 가져오려는 경우:
+
** 스토리지 어레이의 각 컨트롤러에 대한 인증서 서명 요청(.CSR 파일)을 생성하여 CA로 전송했습니다.
** CA가 신뢰할 수 있는 인증서 파일을 반환했습니다.
** 인증서 파일은 로컬 시스템에서 사용할 수 있습니다.




.이 작업 정보
다음 중 하나라도 해당되는 경우 추가 신뢰할 수 있는 CA 인증서를 설치해야 할 수 있습니다.

* 최근에 스토리지 어레이를 추가했습니다.
* 인증서 중 하나 또는 둘 다 만료되었습니다.
* 하나 또는 두 인증서가 모두 해지되었습니다.
* 하나 또는 두 인증서 모두에 루트 또는 중간 인증서가 없습니다.


.단계
. *인증서 관리*를 선택합니다.
. *신뢰할 수 있음* 탭을 선택합니다.
+
이 페이지에는 스토리지 어레이에 대해 보고된 모든 인증서가 표시됩니다.

. CA 인증서를 가져오려면 menu:Import[Certificates]를 선택하고, 자체 서명 인증서를 가져오려면 menu:Import[Self-Signed storage array certificates]를 선택하십시오.
+
보기를 제한하려면 * 다음 인증서 표시...* 필터링 필드를 사용하거나 열 머리글 중 하나를 클릭하여 인증서 행을 정렬할 수 있습니다.

. 대화 상자에서 인증서를 선택한 다음 *가져오기*를 클릭합니다.
+
인증서가 업로드되고 유효성이 검증되었습니다.
