= SANtricity Unified Manager에서 로컬 사용자 암호 설정을 변경합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
새로운 로컬 사용자 암호 또는 업데이트된 로컬 사용자 암호에 필요한 최소 길이를 설정할 수 있습니다. 또한 로컬 사용자가 암호를 입력하지 않고 시스템에 액세스할 수 있도록 허용할 수도 있습니다.

.시작하기 전에
Root 관리자 권한을 포함한 로컬 관리자로 로그인해야 합니다.

.이 작업 정보
로컬 사용자 암호의 최소 길이를 설정할 때 다음 지침을 염두에 두십시오:

* 설정 변경은 기존 로컬 사용자 암호에 영향을 미치지 않습니다.
* 로컬 사용자 암호의 최소 필수 길이 설정은 0~30자 사이여야 합니다.
* 새로운 로컬 사용자 암호는 현재 설정된 최소 길이 이상이어야 합니다.
* 로컬 사용자가 비밀번호를 입력하지 않고 시스템에 액세스하도록 하려면 비밀번호의 최소 길이를 설정하지 마십시오.


.단계
. *Access Management*를 선택하세요.
. *로컬 사용자 역할* 탭을 선택합니다.
. *View/Edit Settings*를 선택합니다.
+
로컬 사용자 암호 설정 대화 상자가 열립니다.

. 다음 중 하나를 수행합니다.
+
** 로컬 사용자가 암호를 입력하지 _않고_ 시스템에 액세스할 수 있도록 하려면 "모든 로컬 사용자 암호는 최소한" 확인란을 선택 해제하십시오.
** 모든 로컬 사용자 암호에 최소 암호 길이를 설정하려면 "모든 로컬 사용자 암호는 최소한 다음 길이 이상이어야 함" 확인란을 선택한 다음 스피너 상자를 사용하여 모든 로컬 사용자 암호에 필요한 최소 길이를 설정하십시오.
+
새로운 로컬 사용자 암호는 현재 설정을 충족하거나 초과해야 합니다.



. *저장*을 클릭합니다.
