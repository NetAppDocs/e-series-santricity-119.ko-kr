= SANtricity Unified Manager에서 어레이용 인증서를 가져옵니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
필요한 경우 스토리지 어레이가 SANtricity Unified Manager를 호스팅하는 시스템과 인증할 수 있도록 인증서를 가져올 수 있습니다. 인증서는 인증 기관(CA)에서 서명했거나 자체 서명할 수 있습니다.

.시작하기 전에
* 보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 인증서 관련 기능이 표시되지 않습니다.
* 신뢰할 수 있는 인증서를 가져오는 경우 System Manager를 사용하여 스토리지 어레이 컨트롤러에 대한 인증서를 가져와야 합니다.


.단계
. *인증서 관리*를 선택합니다.
. *신뢰할 수 있음* 탭을 선택합니다.
+
이 페이지에는 스토리지 어레이에 대해 보고된 모든 인증서가 표시됩니다.

. CA 인증서를 가져오려면 menu:Import[Certificates]를 선택하고, 자체 서명 인증서를 가져오려면 menu:Import[Self-signed storage array certificates]를 선택하십시오.
+
보기를 제한하려면 * 다음 인증서 표시...* 필터링 필드를 사용하거나 열 머리글 중 하나를 클릭하여 인증서 행을 정렬할 수 있습니다.

. 대화 상자에서 인증서를 선택한 다음 *가져오기*를 클릭합니다.
+
인증서가 업로드되고 유효성이 검증되었습니다.
