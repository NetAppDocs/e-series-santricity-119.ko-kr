= SANtricity Unified Manager에서 신뢰할 수 있는 인증서를 삭제합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
만료된 인증서와 같이 더 이상 필요하지 않은 인증서를 하나 이상 삭제할 수 있습니다.

.시작하기 전에
기존 인증서를 삭제하기 전에 새 인증서를 가져오십시오.

[CAUTION]
====
루트 또는 중간 인증서를 삭제하면 여러 스토리지 어레이에 영향을 미칠 수 있습니다. 이러한 어레이는 동일한 인증서 파일을 공유할 수 있기 때문입니다.

====
.단계
. *인증서 관리*를 선택합니다.
. *신뢰할 수 있음* 탭을 선택합니다.
. 표에서 하나 이상의 인증서를 선택한 다음 *Delete*를 클릭합니다.
+
[NOTE]
====
사전 설치된 인증서에 대해서는 *삭제* 기능을 사용할 수 없습니다.

====
+
신뢰할 수 있는 인증서 삭제 확인 대화 상자가 열립니다.

. 삭제를 확인한 후 *삭제*를 클릭합니다.
+
인증서가 테이블에서 제거됩니다.
