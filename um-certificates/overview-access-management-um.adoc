액세스 관리는 SANtricity Unified Manager에서 사용자 인증을 구성하는 방법입니다.



[[what-authentication-methods-are-available]]
== 사용 가능한 인증 방법에는 어떤 것들이 있습니까?

다음 인증 방법을 사용할 수 있습니다.

* *로컬 사용자 역할* -- 인증은 RBAC(역할 기반 액세스 제어) 기능을 통해 관리됩니다. 로컬 사용자 역할에는 특정 액세스 권한을 가진 사전 정의된 사용자 프로필과 역할이 포함됩니다.
* *디렉터리 서비스* -- 인증은 LDAP(Lightweight Directory Access Protocol) 서버와 Microsoft의 Active Directory와 같은 디렉터리 서비스를 통해 관리됩니다.
* *SAML* -- 인증은 SAML 2.0을 사용하는 ID 공급자(IdP)를 통해 관리됩니다.

== 액세스 관리는 어떻게 구성합니까?

SANtricity 소프트웨어는 로컬 사용자 역할을 사용하도록 사전 구성되어 있습니다. LDAP를 사용하려면 액세스 관리 페이지에서 구성할 수 있습니다.
