= SANtricity Unified Manager에서 로컬 사용자 역할을 사용한 액세스 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
관리자는 SANtricity Unified Manager에서 적용되는 RBAC(역할 기반 액세스 제어) 기능을 사용할 수 있습니다. 이러한 기능은 "로컬 사용자 역할"이라고 합니다.



== 구성 워크플로우

로컬 사용자 역할은 시스템에 미리 구성되어 있습니다. 인증에 로컬 사용자 역할을 사용하려면 관리자는 다음을 수행할 수 있습니다.

. 관리자가 Security admin 권한이 포함된 사용자 프로필로 Unified Manager에 로그인합니다.
+
[NOTE]
====
 `admin` 사용자는 시스템의 모든 기능에 대한 완전한 액세스 권한을 가지고 있습니다.

====
. 관리자는 미리 정의되어 있고 수정할 수 없는 사용자 프로필을 검토합니다.
. 선택적으로 관리자는 각 사용자 프로필에 새 비밀번호를 할당합니다.
. 사용자는 할당된 자격 증명을 사용하여 시스템에 로그인합니다.




== 관리

인증에 로컬 사용자 역할만 사용하는 경우 관리자는 다음 관리 작업을 수행할 수 있습니다.

* 암호를 변경합니다.
* 비밀번호의 최소 길이를 설정합니다.
* 사용자가 비밀번호 없이 로그인할 수 있도록 허용합니다.
