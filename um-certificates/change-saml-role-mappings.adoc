= SANtricity Unified Manager에서 SAML 역할 매핑 변경
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이전에 Access Management를 위해 SAML을 구성한 경우 IdP 그룹과 스토리지 어레이의 사전 정의된 역할 간의 역할 매핑을 변경할 수 있습니다.

.시작하기 전에
* 보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 액세스 관리 기능이 표시되지 않습니다.
* IdP 관리자가 IdP 시스템에서 사용자 속성 및 그룹 멤버십을 구성했습니다.
* SAML이 구성 및 활성화되었습니다.


.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. *SAML* 탭을 선택합니다.
. *역할 매핑*을 선택합니다.
+
역할 매핑 대화 상자가 열립니다.

. IdP 사용자 속성과 그룹을 미리 정의된 역할에 할당합니다. 하나의 그룹에는 여러 개의 역할을 할당할 수 있습니다.
+
[CAUTION]
====
SAML이 활성화된 상태에서 권한을 제거하지 않도록 주의하십시오. 권한을 제거하면 Unified Manager에 대한 액세스 권한을 잃게 됩니다.

====
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
*매핑*



 a| 
사용자 속성
 a| 
매핑할 SAML 그룹의 속성(예: "member of")을 지정합니다.



 a| 
속성 값
 a| 
매핑할 그룹의 속성 값을 지정합니다.



 a| 
역할
 a| 
필드를 클릭하고 속성에 매핑할 스토리지 어레이의 역할 중 하나를 선택합니다. 이 그룹에 포함할 각 역할을 개별적으로 선택해야 합니다. Monitor 역할은 Unified Manager에 로그인하기 위해 다른 역할과 함께 필요합니다. Security Admin 역할은 하나 이상의 그룹에 할당되어야 합니다. 매핑된 역할에는 다음 권한이 포함됩니다.

** *Storage admin* -- 스토리지 객체(예: 볼륨 및 디스크 풀)에 대한 전체 읽기/쓰기 액세스 권한이 있지만 보안 구성에 대한 액세스 권한은 없습니다.
** *보안 관리자* -- Access Management의 보안 구성, 인증서 관리, 감사 로그 관리 및 레거시 관리 인터페이스(SYMbol)를 켜거나 끌 수 있는 기능에 대한 액세스 권한.
** *지원 관리자* -- 스토리지 어레이의 모든 하드웨어 리소스, 장애 데이터, MEL 이벤트 및 컨트롤러 펌웨어 업그레이드에 액세스할 수 있습니다. 스토리지 객체 또는 보안 구성에 대한 액세스 권한이 없습니다.
** *모니터* -- 모든 스토리지 객체에 대한 읽기 전용 액세스 권한이 있지만 보안 구성에 대한 액세스 권한은 없습니다.


|===
====
+

NOTE: 관리자를 포함한 모든 사용자에게 모니터 역할이 필요합니다. 모니터 역할이 없는 사용자는 Unified Manager를 정상적으로 사용할 수 없습니다.

. 필요에 따라 *다른 매핑 추가*를 클릭하여 그룹-역할 매핑을 추가로 입력합니다.
. *저장*을 클릭합니다.


.결과
이 작업을 완료하면 활성 사용자 세션이 모두 종료됩니다. 현재 사용자 세션만 유지됩니다.
