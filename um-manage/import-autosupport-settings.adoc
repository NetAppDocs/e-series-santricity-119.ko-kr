= SANtricity Unified Manager에서 AutoSupport 설정 가져오기
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
한 스토리지 어레이에서 다른 스토리지 어레이로 AutoSupport 구성을 가져올 수 있습니다. 이 일괄 작업을 통해 네트워크에서 여러 어레이를 구성해야 할 때 시간을 절약할 수 있습니다.

.시작하기 전에
* AutoSupport는 소스로 사용할 스토리지 어레이에 대해 System Manager에서 구성됩니다(메뉴:Support[Support Center]).
* 대상 스토리지 어레이의 기존 구성은 System Manager(메뉴: Settings[System > Save Storage Array Configuration])에 백업됩니다.


.이 작업 정보
가져온 설정에는 개별 기능(기본 AutoSupport, AutoSupport OnDemand 및 원격 진단), 유지보수 윈도우, 전달 방법 및 배송 일정이 포함됩니다.

.단계
. 관리 페이지에서 *설정 가져오기*를 클릭합니다.
+
가져오기 설정 마법사가 열립니다.

. 설정 선택 대화 상자에서 *AutoSupport*을 선택한 다음 *다음*을 클릭합니다.
+
소스 배열을 선택하기 위한 대화 상자가 열립니다.

. 소스 선택 대화 상자에서 가져올 설정이 포함된 배열을 선택한 다음 *Next*를 클릭합니다.
. 대상 선택 대화 상자에서 새 설정을 받을 하나 이상의 어레이를 선택합니다.
+
[NOTE]
====
펌웨어가 8.50 미만인 스토리지 어레이는 선택할 수 없습니다. 또한 Unified Manager가 해당 어레이와 통신할 수 없는 경우(예: 오프라인 상태이거나 인증서, 암호 또는 네트워킹 문제가 있는 경우) 해당 어레이는 이 대화 상자에 표시되지 않습니다.

====
. *완료*를 클릭합니다.
+
작업 페이지에는 가져오기 작업 결과가 표시됩니다. 작업이 실패한 경우 해당 행을 클릭하여 자세한 정보를 확인할 수 있습니다.



.결과
대상 스토리지 어레이는 이제 소스 어레이와 동일한 AutoSupport 설정으로 구성되었습니다.
