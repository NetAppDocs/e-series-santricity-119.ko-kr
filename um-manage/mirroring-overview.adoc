= SANtricity 미러링에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager에는 관리자가 데이터 보호를 위해 두 스토리지 어레이 간에 데이터를 복제할 수 있도록 하는 SANtricity 미러링 기능에 대한 구성 옵션이 포함되어 있습니다.

[NOTE]
====
EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서는 동기식 미러링을 사용할 수 없습니다.

====


[[types-of-mirroring]]
== 미러링 유형

SANtricity 애플리케이션에는 비동기 및 동기의 두 가지 유형의 미러링이 포함됩니다.

비동기 미러링은 요청 시 또는 예약된 일정에 따라 데이터 볼륨을 복사하여 데이터 손상이나 손실로 인한 다운타임을 최소화하거나 방지합니다. 비동기 미러링은 특정 시점의 기본 볼륨 상태를 캡처하고 마지막 이미지 캡처 이후 변경된 데이터만 복사합니다. 기본 사이트는 즉시 업데이트할 수 있으며, 보조 사이트는 대역폭이 허용하는 대로 업데이트할 수 있습니다. 정보는 캐시되었다가 네트워크 리소스가 사용 가능해지면 나중에 전송됩니다. 이러한 유형의 미러링은 백업 및 아카이브와 같은 주기적인 프로세스에 이상적입니다.

동기식 미러링은 데이터 볼륨을 실시간으로 복제하여 지속적인 가용성을 보장합니다. 이 방식의 목적은 두 스토리지 어레이 중 하나에서 재해가 발생하더라도 중요한 데이터의 복사본을 사용할 수 있도록 하여 데이터 손실 제로라는 복구 시점 목표(RPO)를 달성하는 것입니다. 기본 볼륨에 쓰기 작업이 수행될 때마다 보조 볼륨에도 쓰기 작업이 수행되므로 복사본은 항상 운영 데이터와 동일합니다. 호스트는 보조 볼륨이 기본 볼륨의 변경 사항으로 업데이트될 때까지 쓰기 작업 성공 확인을 받지 못합니다. 이러한 유형의 미러링은 재해 복구와 같은 비즈니스 연속성 목적에 이상적입니다.



[[differences-between-mirroring-types]]
== 미러링 유형 간의 차이점

다음 표는 두 가지 유형의 미러링 간의 주요 차이점을 설명합니다.

[cols="1a,1a,1a"]
|===
| 속성 | 비동기 | 동기식 


 a| 
복제 방법
 a| 
특정 시점 -- 미러링은 요청 시 또는 사용자가 정의한 일정에 따라 자동으로 수행됩니다.
 a| 
연속 -- 미러링은 모든 호스트 쓰기의 데이터를 복사하여 자동으로 지속적으로 실행됩니다.



 a| 
거리
 a| 
어레이 간 장거리 연결을 지원합니다. 일반적으로 거리는 네트워크 기능과 채널 확장 기술에 의해서만 제한됩니다.
 a| 
어레이 간 거리는 단거리로 제한됩니다. 일반적으로 지연 시간 및 애플리케이션 성능 요구 사항을 충족하려면 로컬 스토리지 어레이에서 약 10km(6.2마일) 이내의 거리에 있어야 합니다.



 a| 
통신 방법
 a| 
표준 IP 또는 파이버 채널 네트워크
 a| 
Fibre Channel 네트워크만 해당됩니다.



 a| 
볼륨 유형
 a| 
표준 또는 씬.
 a| 
표준만 해당됩니다.

|===
