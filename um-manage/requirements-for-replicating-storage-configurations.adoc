= SANtricity Unified Manager에서 스토리지 어레이 구성을 복제하기 위한 요구 사항
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
한 스토리지 어레이에서 다른 스토리지 어레이로 스토리지 구성을 가져오기 전에 요구 사항 및 지침을 검토하십시오.



[[shelves]]
== 쉘프

* 컨트롤러가 있는 쉘프는 소스 어레이와 타겟 어레이에서 동일해야 합니다.
* 소스 및 타겟 어레이의 쉘프 ID는 동일해야 합니다.
* 확장 셸프는 동일한 드라이브 유형의 동일한 슬롯에 장착해야 합니다(드라이브가 구성에 사용되는 경우, 사용되지 않는 드라이브의 위치는 중요하지 않습니다).




[[controllers]]
== 컨트롤러

* 소스 어레이와 타겟 어레이 간에 컨트롤러 유형은 다를 수 있지만(예: E2800에서 E5700으로 가져오기), RBOD 엔클로저 유형은 동일해야 합니다.
* 호스트의 DA 기능을 포함한 HIC는 소스 어레이와 타겟 어레이 간에 동일해야 합니다.
* duplex에서 simplex 구성으로 가져오기는 지원되지 않지만, simplex에서 duplex로 가져오기는 허용됩니다.
* FDE 설정은 가져오기 프로세스에 포함되지 않습니다.




[[status]]
== 상태

* 대상 어레이는 Optimal 상태여야 합니다.
* 소스 어레이가 최적 상태일 필요는 없습니다.




[[storage]]
== 스토리지

* 원본 어레이와 대상 어레이의 드라이브 용량은 다를 수 있지만, 대상 어레이의 볼륨 용량이 원본 어레이보다 커야 합니다. (대상 어레이에는 복제 작업에서 볼륨으로 완전히 구성되지 않은 최신 대용량 드라이브가 있을 수 있습니다.)
* 소스 어레이의 64TB 이상의 디스크 풀 볼륨은 타겟에서 가져오기 프로세스를 방해합니다.
* 씬 볼륨은 가져오기 프로세스에 포함되지 않습니다.
