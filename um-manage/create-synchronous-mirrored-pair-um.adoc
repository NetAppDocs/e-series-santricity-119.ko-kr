= SANtricity Unified Manager에서 동기식 미러링 쌍을 생성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
동기식 미러링을 구성하려면 로컬 어레이의 운영 볼륨과 원격 어레이의 보조 볼륨을 포함하는 미러링된 쌍을 생성합니다.

[NOTE]
====
이 기능은 EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서 사용할 수 없습니다.

====
.시작하기 전에
미러링된 쌍을 생성하기 전에 Unified Manager에 대한 다음 요구 사항을 충족하십시오.

* Web Services Proxy 서비스가 실행 중이어야 합니다.
* Unified Manager는 HTTPS 연결을 통해 로컬 호스트에서 실행되어야 합니다.
* Unified Manager에 스토리지 어레이에 대한 유효한 SSL 인증서가 표시되어야 합니다. Unified Manager에서 메뉴:인증서[인증서 관리]로 이동하여 자체 서명 인증서를 허용하거나 자체 보안 인증서를 설치할 수 있습니다.


또한 스토리지 어레이 및 볼륨에 대해 다음 요구 사항을 충족해야 합니다.

* 미러링에 사용할 두 개의 스토리지 어레이가 Unified Manager에서 검색됩니다.
* 각 스토리지 어레이에는 2개의 컨트롤러가 있어야 합니다.
* 기본 어레이와 보조 어레이의 각 컨트롤러에는 이더넷 관리 포트가 구성되어 있어야 하며 네트워크에 연결되어 있어야 합니다.
* 스토리지 어레이의 최소 펌웨어 버전은 7.84입니다. (각각 다른 OS 버전을 실행할 수 있습니다.)
* 로컬 및 원격 스토리지 어레이의 암호를 알고 있어야 합니다.
* 로컬 및 원격 스토리지 어레이는 Fibre Channel 패브릭을 통해 연결됩니다.
* 동기식 미러 관계에 사용할 운영 볼륨과 2차 볼륨을 모두 생성했습니다.
* 기본 볼륨은 표준 볼륨이어야 합니다. 씬 볼륨이나 스냅샷 볼륨은 사용할 수 없습니다.
* 보조 볼륨은 표준 볼륨이어야 합니다. 씬 볼륨이나 스냅샷 볼륨은 사용할 수 없습니다.
* 보조 볼륨은 운영 볼륨만큼 커야 합니다.


.이 작업 정보
동기식 미러링 쌍을 생성하는 프로세스는 다단계 절차입니다.



[[step-1-select-the-primary-volume]]
== 1단계: 기본 볼륨을 선택합니다

이 단계에서는 동기식 미러링 관계에서 사용할 운영 볼륨을 선택합니다. 로컬 스토리지 어레이에서 운영 볼륨을 선택하면 시스템에 해당 미러링 쌍에 사용할 수 있는 모든 볼륨 목록이 표시됩니다. 사용할 수 없는 볼륨은 목록에 표시되지 않습니다. 선택한 볼륨이 미러링 관계에서 운영 역할을 수행합니다.

.단계
. *관리* 페이지에서 소스로 사용할 로컬 스토리지 어레이를 선택합니다.
. 메뉴: 작업[동기화된 미러링 쌍 생성]을 선택합니다.
+
동기식 미러링 쌍 생성 마법사가 열립니다.

. 사용 가능한 볼륨 목록에서 미러의 운영 볼륨으로 사용할 볼륨을 선택하십시오.
. *다음*을 선택하고 <<2단계: 보조 볼륨을 선택합니다>>(으)로 이동합니다.




[[step-2-select-the-secondary-volume]]
== 2단계: 보조 볼륨을 선택합니다

이 단계에서는 미러링 관계에 사용할 보조 볼륨을 선택합니다. 원격 스토리지 어레이에서 보조 볼륨을 선택하면 시스템에 해당 미러링 쌍에 사용할 수 있는 모든 볼륨 목록이 표시됩니다. 사용할 수 없는 볼륨은 목록에 표시되지 않습니다. 선택한 볼륨이 미러링 관계에서 보조 역할을 수행하게 됩니다.

.단계
. 로컬 스토리지 어레이와 미러 관계를 설정할 원격 스토리지 어레이를 선택합니다.
+
[NOTE]
====
원격 스토리지 어레이가 암호로 보호되어 있는 경우 시스템에서 암호를 입력하라는 메시지가 표시됩니다.

====
+
** 스토리지 어레이는 스토리지 어레이 이름으로 나열됩니다. 스토리지 어레이에 이름을 지정하지 않은 경우 "unnamed"로 표시됩니다.
** 사용하려는 스토리지 어레이가 목록에 없는 경우 Unified Manager에서 검색되었는지 확인하십시오.


. 적격 볼륨 목록에서 미러의 보조 볼륨으로 사용할 볼륨을 선택합니다.
+
[NOTE]
====
보조 볼륨이 운영 볼륨보다 큰 용량으로 선택된 경우 사용 가능한 용량은 운영 볼륨의 크기로 제한됩니다.

====
. *다음*을 클릭하고 <<3단계: 동기화 설정 선택>>(으)로 이동합니다.




[[step-3-select-synchronization-settings]]
== 3단계: 동기화 설정 선택

이 단계에서는 통신 중단 후 데이터 동기화 방식을 결정하는 설정을 선택합니다. 기본 볼륨의 컨트롤러 소유자가 통신 중단 후 보조 볼륨과 데이터를 다시 동기화하는 우선순위를 설정할 수 있습니다. 또한 재동기화 정책을 수동 또는 자동으로 선택해야 합니다.

.단계
. 슬라이더 막대를 사용하여 동기화 우선 순위를 설정합니다.
+
동기화 우선순위는 서비스 I/O 요청과 비교하여 초기 동기화 및 통신 중단 후 재동기화 작업을 완료하는 데 사용되는 시스템 리소스의 양을 결정합니다.

+
이 대화 상자에서 설정한 우선 순위는 기본 볼륨과 보조 볼륨 모두에 적용됩니다. 나중에 기본 볼륨의 전송 속도를 수정하려면 System Manager로 이동하여 menu:Storage[Synchronous Mirroring > More > Edit Settings]를 선택하십시오.

+
동기화 우선 순위는 다섯 가지입니다.

+
** 최저
** 낮음
** 중간
** 높음
** 최고
+
동기화 우선순위를 가장 낮은 속도로 설정하면 I/O 작업이 우선시되어 재동기화 작업에 더 오랜 시간이 걸립니다. 동기화 우선순위를 가장 높은 속도로 설정하면 재동기화 작업이 우선시되지만 스토리지 어레이의 I/O 작업에 영향을 미칠 수 있습니다.



. 원격 스토리지 어레이의 미러링된 쌍을 수동으로 또는 자동으로 다시 동기화할지 여부를 선택하십시오.
+
** *수동* (권장 옵션) -- 미러링된 쌍과의 통신이 복원된 후 동기화를 수동으로 재개해야 하는 경우 이 옵션을 선택하십시오. 이 옵션은 데이터 복구에 가장 좋은 기회를 제공합니다.
** *자동* -- 미러링된 쌍과의 통신이 복원된 후 자동으로 재동기화를 시작하려면 이 옵션을 선택하십시오.
+
동기화를 수동으로 재개하려면 System Manager로 이동하여 menu:Storage[Synchronous Mirroring]를 선택하고 표에서 미러링된 쌍을 강조 표시한 다음 *More* 아래의 *Resume*을 선택합니다.



. *완료*를 클릭하여 동기식 미러링 시퀀스를 완료합니다.


.결과
미러링이 활성화되면 시스템은 다음 작업을 수행합니다.

* 로컬 스토리지 어레이와 원격 스토리지 어레이 간의 초기 동기화를 시작합니다.
* 동기화 우선순위와 재동기화 정책을 설정합니다.
* 컨트롤러의 HIC에서 가장 높은 번호의 포트를 미러 데이터 전송용으로 예약합니다.
+
이 포트로 수신되는 I/O 요청은 미러링된 쌍의 보조 볼륨을 소유한 원격 기본 컨트롤러에서만 허용됩니다. (기본 볼륨에 대한 예약은 허용됩니다.)

* 컨트롤러 재설정 및 기타 일시적인 중단으로부터 복구하기 위해 쓰기 정보를 로깅하는 데 사용되는 두 개의 예약된 용량 볼륨(각 컨트롤러당 하나씩)을 생성합니다.
+
각 볼륨의 용량은 128 MiB입니다. 하지만 볼륨을 풀에 배치하면 각 볼륨에 4 GiB가 예약됩니다.



.완료한 후
System Manager로 이동하여 menu:Home[View Operations in Progress]을 선택하면 동기식 미러링 작업의 진행 상황을 확인할 수 있습니다. 이 작업은 시간이 오래 걸릴 수 있으며 시스템 성능에 영향을 줄 수 있습니다.
