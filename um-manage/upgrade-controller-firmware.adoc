= SANtricity 운영 체제 업그레이드
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
최신 소프트웨어와 NVSRAM으로 하나 이상의 스토리지 어레이를 업그레이드하여 모든 최신 기능과 버그 수정 사항을 적용하십시오. 컨트롤러 NVSRAM은 컨트롤러의 기본 설정을 지정하는 컨트롤러 파일입니다.

.시작하기 전에
* 최신 SANtricity OS 파일은 SANtricity Web Services Proxy 및 Unified Manager가 실행 중인 호스트 시스템에서 사용할 수 있습니다.
* 소프트웨어 업그레이드를 지금 활성화할지 나중에 활성화할지 여부를 알고 있습니다.
+
다음과 같은 이유로 나중에 활성화하도록 선택할 수 있습니다.

+
** *시간대* -- 소프트웨어 활성화에는 시간이 오래 걸릴 수 있으므로 I/O 부하가 적은 시간대에 시도하는 것이 좋습니다. 활성화 과정 중에는 컨트롤러가 페일오버되므로 업그레이드가 완료될 때까지 성능이 평소보다 저하될 수 있습니다.
** *패키지 유형* -- 다른 스토리지 어레이의 파일을 업그레이드하기 전에 하나의 스토리지 어레이에서 새 OS 소프트웨어를 테스트할 수 있습니다.





IMPORTANT: 시스템에서 11.80.x 이상으로 업그레이드하려면 SANtricity OS 11.70.5를 실행하고 있어야 합니다.

.이 작업 정보
++ ++

[NOTE]
====
데이터 손실 또는 스토리지 시스템 손상 위험이 있습니다. 업그레이드가 진행되는 동안 스토리지 시스템을 변경하지 마십시오. 스토리지 시스템에 전원을 계속 공급하십시오.

====
.단계
. 스토리지 어레이에 컨트롤러가 하나만 있거나 다중 경로 드라이버를 사용하지 않는 경우, 애플리케이션 오류를 방지하기 위해 스토리지 어레이에 대한 I/O 작업을 중지해야 합니다. 스토리지 어레이에 컨트롤러가 두 개 있고 다중 경로 드라이버가 설치된 경우에는 I/O 작업을 중지할 필요가 없습니다.
. 메인 화면에서 *관리*를 선택한 다음 업그레이드할 스토리지 시스템을 하나 이상 선택합니다.
. 메뉴: 업그레이드 센터[SANtricity OS 소프트웨어 업그레이드]를 선택합니다.
+
SANtricity OS 소프트웨어 업그레이드 페이지가 나타납니다.

. NetApp Support 사이트에서 최신 SANtricity OS 소프트웨어 패키지를 로컬 컴퓨터로 다운로드하십시오.
+
.. *소프트웨어 저장소에 새 파일 추가*를 클릭합니다.
.. 최신 *SANtricity OS 다운로드*를 찾으려면 링크를 클릭하십시오.
.. *최신 릴리스 다운로드* 링크를 클릭합니다.
.. 나머지 지침에 따라 SANtricity OS 파일과 NVSRAM 파일을 로컬 시스템에 다운로드하십시오.


+
[NOTE]
====
버전 8.42 이상에서는 디지털 서명된 펌웨어가 필요합니다. 서명되지 않은 펌웨어를 다운로드하려고 하면 오류가 표시되고 다운로드가 중단됩니다.

====
. 컨트롤러를 업그레이드하는 데 사용할 OS 소프트웨어 파일과 NVSRAM 파일을 선택합니다.
+
.. *SANtricity OS 소프트웨어 파일 선택* 드롭다운에서 로컬 시스템에 다운로드한 OS 파일을 선택합니다.
+
파일이 여러 개 있는 경우 최신 날짜부터 오래된 날짜 순으로 정렬됩니다.

+
[NOTE]
====
소프트웨어 리포지토리에는 Web Services Proxy와 관련된 모든 소프트웨어 파일이 나열됩니다. 사용하려는 파일이 표시되지 않으면 *소프트웨어 리포지토리에 새 파일 추가* 링크를 클릭하여 추가하려는 OS 파일이 있는 위치를 찾아볼 수 있습니다.

====
.. *NVSRAM 파일 선택* 드롭다운에서 사용할 컨트롤러 파일을 선택합니다.
+
파일이 여러 개인 경우 최신 날짜부터 오래된 날짜 순으로 정렬됩니다.



. 호환 스토리지 어레이 표에서 선택한 OS 소프트웨어 파일과 호환되는 스토리지 어레이를 검토한 다음 업그레이드할 어레이를 선택합니다.
+
** 관리 보기에서 선택한 스토리지 어레이 중 선택한 펌웨어 파일과 호환되는 어레이가 호환 스토리지 어레이 표에 기본적으로 선택됩니다.
** 선택한 펌웨어 파일로 업데이트할 수 없는 스토리지 어레이는 상태 *호환되지 않음*으로 표시된 대로 호환 가능한 스토리지 어레이 표에서 선택할 수 없습니다.


. *선택 사항:* 스토리지 어레이를 활성화하지 않고 소프트웨어 파일을 스토리지 어레이로 전송하려면 *OS 소프트웨어를 스토리지 어레이로 전송하고, 준비 상태로 표시한 다음 나중에 활성화* 확인란을 선택합니다.
. *시작*을 클릭합니다.
. 지금 활성화할지 나중에 활성화할지 여부에 따라 다음 중 하나를 수행합니다.
+
** 업그레이드하도록 선택한 어레이에 제안된 OS 소프트웨어 버전을 전송할 것인지 확인하려면 *TRANSFER*를 입력한 다음 *전송*을 클릭하십시오.
+
전송된 소프트웨어를 활성화하려면 menu:Upgrade Center[Activate Staged OS Software]를 선택하십시오.

** 선택한 어레이에 제안된 OS 소프트웨어 버전을 전송하고 활성화하려면 *UPGRADE*를 입력한 다음 *Upgrade*를 클릭하십시오.
+
시스템은 업그레이드하도록 선택한 각 스토리지 시스템으로 소프트웨어 파일을 전송한 다음 재부팅을 시작하여 해당 파일을 활성화합니다.



+
업그레이드 작업 중에 다음 작업이 수행됩니다.

+
** 업그레이드 프로세스의 일부로 사전 업그레이드 상태 점검이 실행됩니다. 사전 업그레이드 상태 점검은 모든 스토리지 어레이 구성 요소를 평가하여 업그레이드를 진행할 수 있는지 확인합니다.
** 스토리지 어레이의 상태 점검에 실패하면 업그레이드가 중지됩니다. 점 세 개(...)를 클릭하고 *로그 저장*을 선택하여 오류를 검토할 수 있습니다. 또는 상태 점검 오류를 무시하고 *계속*을 클릭하여 업그레이드를 진행할 수도 있습니다.
** 업그레이드 전 상태 점검 후 업그레이드 작업을 취소할 수 있습니다.


. *선택 사항:* 업그레이드가 완료되면 줄임표(...)를 클릭한 다음 *Save Log*를 선택하여 특정 스토리지 어레이에 대해 업그레이드된 항목 목록을 볼 수 있습니다.
+
해당 파일은 브라우저의 다운로드 폴더에 `upgrade_log-<date>.json`이라는 이름으로 저장됩니다.
