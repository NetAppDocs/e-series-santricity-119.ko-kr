= SANtricity Unified Manager에서 검색 기능에 대해 알아보세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 리소스를 관리하려면 먼저 네트워크에서 스토리지 어레이를 검색해야 합니다.



== 어레이를 검색하려면 어떻게 해야 합니까?

추가/검색 페이지를 사용하여 조직 네트워크에서 관리할 스토리지 어레이를 찾아 추가할 수 있습니다. 여러 어레이를 검색하거나 단일 어레이를 검색할 수 있습니다. 이를 위해 네트워크 IP 주소를 입력하면 Unified Manager가 해당 범위 내의 각 IP 주소에 개별적으로 연결을 시도합니다.

자세한 정보:

* link:considerations-for-discovering-arrays.html["어레이 검색 시 고려 사항"]
* link:discover-multiple-arrays.html["여러 스토리지 어레이 검색"]
* link:discover-single-array.html["단일 어레이 검색"]




== 어레이를 관리하려면 어떻게 해야 합니까?

어레이를 검색한 후 *관리 - 모두* 페이지로 이동합니다. 이 페이지에서 네트워크에서 검색된 스토리지 어레이 목록을 스크롤하고 상태를 확인하며 단일 어레이 또는 어레이 그룹에 대한 작업을 수행할 수 있습니다.

단일 어레이를 관리하려면 해당 어레이를 선택하고 System Manager를 열면 됩니다.

자세한 정보:

* link:launch-considerations.html["System Manager 액세스 시 고려 사항"]
* link:launch-system-manager.html["개별 스토리지 어레이 관리"]
* link:storage-array-status.html["스토리지 배열 상태 보기"]
