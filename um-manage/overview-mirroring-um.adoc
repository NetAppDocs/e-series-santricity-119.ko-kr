[role="lead"]
미러링 기능을 사용하여 로컬 스토리지 어레이와 원격 스토리지 어레이 간에 데이터를 비동기식 또는 동기식으로 복제합니다.

[NOTE]
====
EF600/EF600C 또는 EF300/EF300C 스토리지 시스템에서는 동기식 미러링을 사용할 수 없습니다.

====


== 미러링이란 무엇입니까?

SANtricity 애플리케이션에는 비동기식과 동기식의 두 가지 유형의 미러링이 있습니다. 비동기식 미러링은 요청 시 또는 일정에 따라 데이터 볼륨을 복사하여 데이터 손상이나 손실로 인한 다운타임을 최소화하거나 방지합니다. 동기식 미러링은 실시간으로 데이터 볼륨을 복제하여 지속적인 가용성을 보장합니다.

자세한 정보:

* link:mirroring-overview.html["미러링 작동 방식"]
* link:mirroring-terminology.html["미러링 용어"]

Unified Manager에서 비동기 또는 동기 미러링을 구성한 다음 System Manager를 사용하여 동기화를 관리합니다.
