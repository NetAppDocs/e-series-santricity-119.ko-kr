= SANtricity Unified Manager에서 여러 스토리지 어레이를 구성하는 방법에 대해 알아보세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager를 사용하면 하나의 스토리지 어레이에서 여러 스토리지 어레이로 설정을 가져올 수 있습니다. 설정 가져오기 기능은 네트워크에서 여러 어레이를 구성해야 할 때 시간을 절약해주는 일괄 작업입니다.



== 가져오기에 사용할 수 있는 설정

다음 구성은 여러 어레이로 가져올 수 있습니다.

* *경고* -- 이메일, syslog 서버 또는 SNMP 서버를 사용하여 관리자에게 중요한 이벤트를 전송하는 경고 방법입니다.
* *AutoSupport* -- 스토리지 어레이의 상태를 모니터링하고 기술 지원에 자동 디스패치를 전송하는 기능입니다.
* *디렉터리 서비스* -- LDAP(Lightweight Directory Access Protocol) 서버와 Microsoft Active Directory와 같은 디렉터리 서비스를 통해 관리되는 사용자 인증 방식입니다.
* *스토리지 구성* -- 다음 사항과 관련된 구성:
+
** 볼륨(씩 볼륨 및 비리포지토리 볼륨만 해당)
** 볼륨 그룹 및 풀
** 핫 스페어 드라이브 할당


* *시스템 설정* -- 다음 사항과 관련된 구성:
+
** 볼륨에 대한 미디어 스캔 설정
** SSD 설정
** 자동 로드 밸런싱(호스트 연결 보고 기능은 포함되지 않음)






== 구성 워크플로우

설정을 가져오려면 다음 워크플로를 따르십시오.

. 소스로 사용할 스토리지 어레이에서 System Manager를 사용하여 설정을 구성하십시오.
. 대상으로 사용할 스토리지 어레이에서 System Manager를 사용하여 구성을 백업하십시오.
. Unified Manager에서 *관리* 페이지로 이동하여 설정을 가져옵니다.
. *Operations* 페이지에서 Import Settings 작업 결과를 검토하십시오.
