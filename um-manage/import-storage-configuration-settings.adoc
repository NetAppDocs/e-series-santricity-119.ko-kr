= SANtricity Unified Manager에서 스토리지 구성 설정 가져오기
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
한 스토리지 어레이의 스토리지 구성을 다른 스토리지 어레이로 가져올 수 있습니다. 이 일괄 작업은 네트워크에서 여러 어레이를 구성해야 할 때 시간을 절약해 줍니다.

.시작하기 전에
* 스토리지는 소스로 사용할 스토리지 어레이에 대해 SANtricity System Manager에서 구성됩니다.
* 대상 스토리지 어레이의 기존 구성은 System Manager(메뉴: Settings[System > Save Storage Array Configuration])에 백업됩니다.
* 소스 및 타겟 어레이는 다음 요구 사항을 충족해야 합니다.
+
** 컨트롤러가 있는 쉘프는 동일해야 합니다.
** 쉘프 ID는 동일해야 합니다.
** 확장 셸프는 동일한 드라이브 유형으로 동일한 슬롯에 장착해야 합니다.
** RBOD 엔클로저 유형은 동일해야 합니다.
** 호스트의 Data Assurance 기능을 포함한 HIC는 모두 동일해야 합니다.
** 대상 어레이는 Optimal 상태여야 합니다.
** 타겟 어레이의 볼륨 용량이 소스 어레이의 용량보다 큽니다.


* 다음 제한 사항을 이해합니다.
+
** duplex에서 simplex 구성으로 가져오기는 지원되지 않지만, simplex에서 duplex로 가져오기는 허용됩니다.
** 소스 어레이의 64TB 이상의 디스크 풀 볼륨은 타겟에서 가져오기 프로세스를 방해합니다.
** 씬 볼륨은 가져오기 프로세스에 포함되지 않습니다.




.이 작업 정보
가져온 설정에는 구성된 볼륨(씩 볼륨 및 비리포지토리 볼륨만 해당), 볼륨 그룹, 풀 및 핫 스페어 드라이브 할당이 포함됩니다.

.단계
. 관리 페이지에서 *설정 가져오기*를 클릭합니다.
+
가져오기 설정 마법사가 열립니다.

. 설정 선택 대화 상자에서 *스토리지 구성*을 선택한 다음 *다음*을 클릭합니다.
+
소스 배열을 선택하기 위한 대화 상자가 열립니다.

. 소스 선택 대화 상자에서 가져올 설정이 포함된 배열을 선택한 다음 *Next*를 클릭합니다.
. 대상 선택 대화 상자에서 새 설정을 받을 하나 이상의 어레이를 선택합니다.
+
[NOTE]
====
펌웨어가 8.50 미만인 스토리지 어레이는 선택할 수 없습니다. 또한 Unified Manager가 해당 어레이와 통신할 수 없는 경우(예: 오프라인 상태이거나 인증서, 암호 또는 네트워킹 문제가 있는 경우) 해당 어레이는 이 대화 상자에 표시되지 않습니다.

====
. *완료*를 클릭합니다.
+
작업 페이지에는 가져오기 작업 결과가 표시됩니다. 작업이 실패한 경우 해당 행을 클릭하여 자세한 정보를 확인할 수 있습니다.



.결과
이제 타겟 스토리지 어레이가 소스 어레이와 동일한 스토리지 구성으로 구성되었습니다.
