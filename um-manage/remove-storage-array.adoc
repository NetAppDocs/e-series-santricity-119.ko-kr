= SANtricity Unified Manager에서 스토리지 어레이를 제거합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager에서 더 이상 관리하지 않으려면 하나 이상의 스토리지 시스템을 제거할 수 있습니다.

.이 작업 정보
제거한 스토리지 어레이에는 접근할 수 없습니다. 하지만 브라우저에서 해당 스토리지 어레이의 IP 주소 또는 호스트 이름을 직접 지정하여 제거된 스토리지 어레이에 대한 연결을 설정할 수 있습니다.

스토리지 어레이를 제거해도 스토리지 어레이나 그 안에 저장된 데이터에는 아무런 영향을 미치지 않습니다. 스토리지 어레이가 실수로 제거된 경우에도 다시 추가할 수 있습니다.

.단계
. *관리* 페이지를 선택합니다.
. 제거할 스토리지 어레이를 하나 이상 선택하십시오.
. 메뉴: 일반적이지 않은 작업[스토리지 시스템 제거]를 선택합니다.
+
스토리지 어레이가 SANtricity Unified Manager의 모든 보기에서 제거됩니다.
