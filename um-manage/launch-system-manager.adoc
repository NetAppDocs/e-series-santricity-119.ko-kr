= SANtricity Unified Manager에서 개별 스토리지 어레이를 관리합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
관리 작업을 수행하려는 경우 실행 옵션을 사용하여 하나 이상의 스토리지 어레이에 대해 브라우저 기반 SANtricity System Manager를 열 수 있습니다.

.단계
. 관리 페이지에서 관리할 스토리지 어레이를 하나 이상 선택합니다.
. *Launch*를 클릭합니다.
+
시스템이 새 창을 열고 System Manager 로그인 페이지를 표시합니다.

. 사용자 이름과 비밀번호를 입력한 다음 * 로그인 * 을 클릭합니다.
