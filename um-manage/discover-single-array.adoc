= SANtricity Unified Manager에서 단일 어레이를 찾아보세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
단일 스토리지 어레이 추가/검색 옵션을 사용하여 조직 네트워크에 단일 스토리지 어레이를 수동으로 검색하고 추가할 수 있습니다.

.시작하기 전에
* 스토리지 어레이를 올바르게 설정하고 구성해야 합니다.
* 스토리지 어레이 암호는 System Manager의 Access Management 타일을 사용하여 설정해야 합니다.


.단계
. 관리 페이지에서 *추가/검색*을 선택합니다.
+
추가/검색 대화 상자가 나타납니다.

. *단일 스토리지 어레이 검색* 라디오 버튼을 선택합니다.
. 스토리지 어레이에 있는 컨트롤러 중 하나의 IP 주소를 입력한 다음 *검색 시작*을 클릭합니다.
+
Unified Manager가 지정된 스토리지 어레이에 연결하는 데 몇 분 정도 걸릴 수 있습니다.

+
[NOTE]
====
"저장소 어레이에 액세스할 수 없음" 메시지는 지정된 컨트롤러의 IP 주소에 대한 연결에 실패했을 때 나타납니다.

====
. 메시지가 표시되면 자체 서명된 인증서를 해결하십시오.
+
검색 과정의 일부로, 시스템은 검색된 스토리지 어레이가 신뢰할 수 있는 출처에서 발급한 인증서를 사용하고 있는지 확인합니다. 스토리지 어레이에 대한 디지털 인증서를 찾을 수 없는 경우, 시스템은 보안 예외를 추가하여 인정된 인증 기관(CA)에서 서명하지 않은 인증서를 해결하도록 사용자에게 안내합니다.

. 메시지가 표시되면 신뢰할 수 없는 인증서를 해결하십시오.
+
신뢰할 수 없는 인증서는 스토리지 어레이가 Unified Manager에 대한 보안 연결을 설정하려고 시도하지만 연결이 안전한 것으로 확인되지 않을 때 발생합니다. 신뢰할 수 있는 타사에서 발급한 인증 기관(CA) 인증서를 가져와 신뢰할 수 없는 인증서를 해결하십시오.

. * 다음 * 을 클릭합니다.
. *선택 사항:* 검색된 스토리지 어레이를 그룹에 연결: 드롭다운 목록에서 스토리지 어레이와 연결할 원하는 그룹을 선택합니다.
+
기본적으로 "All" 그룹이 선택되어 있습니다.

. 관리 도메인에 추가할 스토리지 어레이의 관리자 암호를 입력한 다음 *확인*을 클릭합니다.


.완료한 후
스토리지 어레이가 Unified Manager에 추가되고, 지정된 경우 선택한 그룹에도 추가됩니다.

자동 지원 데이터 수집이 활성화된 경우, 추가하는 스토리지 어레이에 대한 지원 데이터가 자동으로 수집됩니다.
