= SANtricity Unified Manager에서 스토리지 어레이를 검색하는 방법에 대해 알아보세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager가 스토리지 리소스를 표시하고 관리하려면 먼저 조직 네트워크에서 관리하려는 스토리지 어레이를 검색해야 합니다. 여러 어레이를 검색하거나 단일 어레이를 검색할 수 있습니다.



== 여러 스토리지 어레이 검색

여러 스토리지 어레이를 검색하도록 선택한 경우 네트워크 IP 주소 범위를 입력해야 하며, Unified Manager는 해당 범위 내의 각 IP 주소에 개별적으로 연결을 시도합니다. 연결에 성공한 스토리지 어레이는 검색 페이지에 표시되며 관리 도메인에 추가할 수 있습니다.



== 단일 스토리지 어레이 검색

단일 어레이를 검색하도록 선택한 경우 스토리지 어레이의 컨트롤러 중 하나에 대한 단일 IP 주소를 입력하면 개별 스토리지 어레이가 추가됩니다.

[NOTE]
====
Unified Manager는 컨트롤러에 할당된 단일 IP 주소 또는 IP 주소 범위 내의 IP 주소만 검색하여 표시합니다. 해당 단일 IP 주소 또는 IP 주소 범위에 속하지 않는 다른 컨트롤러 또는 이러한 컨트롤러에 할당된 IP 주소가 있는 경우 Unified Manager는 해당 IP 주소를 검색하거나 표시하지 않습니다. 하지만 스토리지 어레이를 추가하면 연결된 모든 IP 주소가 검색되어 Manage 보기에 표시됩니다.

====


== 사용자 자격 증명

검색 과정의 일부로, 추가하려는 각 스토리지 어레이에 대한 관리자 암호를 제공해야 합니다.



== 웹 서비스 인증서

검색 프로세스의 일부로 Unified Manager는 검색된 스토리지 어레이가 신뢰할 수 있는 소스의 인증서를 사용하고 있는지 확인합니다. Unified Manager는 브라우저와 설정하는 모든 연결에 대해 두 가지 유형의 인증서 기반 인증을 사용합니다.

* *신뢰할 수 있는 인증서*
+
Unified Manager에서 검색된 어레이의 경우 인증 기관에서 제공하는 추가 신뢰할 수 있는 인증서를 설치해야 할 수 있습니다.

+
*가져오기* 버튼을 사용하여 이러한 인증서를 가져오십시오. 이전에 이 어레이에 연결한 적이 있는 경우 컨트롤러 인증서 중 하나 또는 둘 다 만료되었거나, 해지되었거나, 인증서 체인에 루트 인증서 또는 중간 인증서가 누락되었을 수 있습니다. 스토리지 어레이를 관리하기 전에 만료되었거나 해지된 인증서를 교체하거나 누락된 루트 인증서 또는 중간 인증서를 추가해야 합니다.

* *자체 서명된 인증서*
+
자체 서명된 인증서도 사용할 수 있습니다. 관리자가 서명된 인증서를 가져오지 않고 어레이를 검색하려고 하면 Unified Manager는 관리자가 자체 서명된 인증서를 수락할 수 있는 오류 대화 상자를 표시합니다. 스토리지 어레이의 자체 서명된 인증서는 신뢰할 수 있는 것으로 표시되고 스토리지 어레이는 Unified Manager에 추가됩니다.

+
스토리지 어레이와의 연결을 신뢰하지 않는 경우 *취소*를 선택하고 스토리지 어레이를 Unified Manager에 추가하기 전에 스토리지 어레이의 보안 인증서 전략을 확인하십시오.
