= SANtricity Unified Manager에서 알림 설정을 가져오기
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
하나의 스토리지 어레이에서 다른 스토리지 어레이로 알림 구성을 가져올 수 있습니다. 이 일괄 작업을 통해 네트워크에서 여러 어레이를 구성해야 할 때 시간을 절약할 수 있습니다.

.시작하기 전에
* 알림은 소스로 사용할 스토리지 어레이에 대해 System Manager에서 구성합니다(메뉴: Settings[Alerts]).
* 대상 스토리지 어레이의 기존 구성은 System Manager(메뉴: Settings[System > Save Storage Array Configuration])에 백업됩니다.


.이 작업 정보
가져오기 작업에 대해 이메일, SNMP 또는 syslog 알림을 선택할 수 있습니다. 가져온 설정에는 다음이 포함됩니다.

* *이메일 알림* -- 메일 서버 주소 및 알림 수신자의 이메일 주소입니다.
* *Syslog 알림* -- syslog 서버 주소 및 UDP 포트.
* *SNMP 경고* -- SNMP 서버의 커뮤니티 이름과 IP 주소입니다.


.단계
. 관리 페이지에서 *설정 가져오기*를 클릭합니다.
+
가져오기 설정 마법사가 열립니다.

. 설정 선택 대화 상자에서 *이메일 알림*, *SNMP 알림* 또는 *Syslog 알림* 중 하나를 선택한 다음 *다음*을 클릭합니다.
+
소스 배열을 선택하기 위한 대화 상자가 열립니다.

. 소스 선택 대화 상자에서 가져올 설정이 포함된 배열을 선택한 다음 *Next*를 클릭합니다.
. 대상 선택 대화 상자에서 새 설정을 받을 하나 이상의 어레이를 선택합니다.
+
[NOTE]
====
펌웨어가 8.50 미만인 스토리지 어레이는 선택할 수 없습니다. 또한 Unified Manager가 해당 어레이와 통신할 수 없는 경우(예: 오프라인 상태이거나 인증서, 암호 또는 네트워킹 문제가 있는 경우) 해당 어레이는 이 대화 상자에 표시되지 않습니다.

====
. *완료*를 클릭합니다.
+
작업 페이지에는 가져오기 작업 결과가 표시됩니다. 작업이 실패한 경우 해당 행을 클릭하여 자세한 정보를 확인할 수 있습니다.



.결과
대상 스토리지 어레이는 이제 이메일, SNMP 또는 syslog를 통해 관리자에게 알림을 보내도록 구성되었습니다.
