= SANtricity Unified Manager에서 업그레이드 전 상태 점검을 수행하십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
업그레이드 프로세스의 일부로 상태 점검이 실행되지만, 업그레이드를 시작하기 전에 별도로 상태 점검을 실행할 수도 있습니다. 상태 점검은 스토리지 어레이의 구성 요소를 평가하여 업그레이드를 진행할 수 있는지 확인합니다.

.단계
. 메인 화면에서 *관리*를 선택한 다음 menu:Upgrade Center[Pre-Upgrade Health Check]를 선택합니다.
+
업그레이드 전 상태 점검 대화 상자가 열리고 검색된 모든 스토리지 시스템이 나열됩니다.

. 필요한 경우 목록에서 스토리지 시스템을 필터링하거나 정렬하여 현재 최적 상태가 아닌 모든 시스템을 볼 수 있습니다.
. 상태 점검을 실행할 스토리지 시스템의 확인란을 선택하십시오.
. *시작*을 클릭합니다.
+
상태 점검이 수행되는 동안 진행 상황이 대화 상자에 표시됩니다.

. 상태 점검이 완료되면 각 행 오른쪽에 있는 줄임표(...)를 클릭하여 자세한 정보를 확인하고 다른 작업을 수행할 수 있습니다.
+
[NOTE]
====
어레이 중 하나라도 상태 검사에 실패하면 해당 어레이를 건너뛰고 나머지 어레이에 대해 업그레이드를 계속하거나 전체 프로세스를 중지하고 통과하지 못한 어레이의 문제를 해결할 수 있습니다.

====
