= SANtricity Unified Manager에서 스토리지 어레이 그룹을 구성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 그룹을 생성한 다음 해당 그룹에 스토리지 어레이를 추가합니다.

그룹 구성은 두 단계 절차입니다.



== 1단계: 그룹 생성

먼저 그룹을 생성합니다. 스토리지 그룹은 볼륨을 구성하는 스토리지를 제공하는 드라이브를 정의합니다.

.단계
. 관리 페이지에서 menu:그룹 관리[스토리지 어레이 그룹 생성]을 선택합니다.
. *Name* 필드에 새 그룹의 이름을 입력합니다.
. 새 그룹에 추가할 스토리지 어레이를 선택하십시오.
. *Create*를 클릭합니다.




== 2단계: 스토리지 어레이를 그룹에 추가합니다

사용자가 생성한 그룹에 하나 이상의 스토리지 어레이를 추가할 수 있습니다.

.단계
. 메인 화면에서 *관리*를 선택한 다음 스토리지 어레이를 추가할 그룹을 선택합니다.
. 메뉴: 그룹 관리[그룹에 스토리지 어레이 추가]를 선택합니다.
. 그룹에 추가할 스토리지 어레이를 선택하십시오.
. *Add*를 클릭하세요.
