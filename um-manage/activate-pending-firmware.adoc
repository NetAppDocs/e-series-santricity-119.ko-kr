= SANtricity Unified Manager에서 스테이징된 OS 소프트웨어를 활성화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
소프트웨어 파일을 즉시 활성화하거나 나중에 편리한 시간에 활성화할 수 있습니다. 이 절차는 소프트웨어 파일을 나중에 활성화하기로 선택한 경우를 가정합니다.

.이 작업 정보
펌웨어 파일은 활성화하지 않고도 전송할 수 있습니다. 다음과 같은 이유로 나중에 활성화하도록 선택할 수 있습니다.

* *시간대* -- 소프트웨어 활성화에는 시간이 오래 걸릴 수 있으므로 I/O 부하가 적은 시간대에 시도하는 것이 좋습니다. 활성화 과정 중에 컨트롤러가 재부팅되고 장애 조치가 진행되므로 업그레이드가 완료될 때까지 성능이 평소보다 저하될 수 있습니다.
* *패키지 유형* -- 다른 스토리지 어레이의 파일을 업그레이드하기 전에 하나의 스토리지 어레이에서 새 소프트웨어 및 펌웨어를 테스트해 보는 것이 좋습니다.


[NOTE]
====
활성화 프로세스가 시작된 후에는 중지할 수 없습니다.

====
.단계
. 메인 화면에서 *Manage*를 선택합니다. 필요한 경우, 페이지 상단의 상태 열을 클릭하여 "OS Upgrade (awaiting activation)" 상태인 모든 스토리지 어레이를 정렬합니다.
. 소프트웨어를 활성화할 스토리지 어레이를 하나 이상 선택한 다음 menu:Upgrade Center[Activate Staged OS Software]를 선택합니다.
+
업그레이드 작업 중에 다음 작업이 수행됩니다.

+
** 업그레이드 전 상태 점검은 활성화 프로세스의 일부로 실행됩니다. 업그레이드 전 상태 점검은 모든 스토리지 어레이 구성 요소를 평가하여 활성화를 진행할 수 있는지 확인합니다.
** 스토리지 어레이의 상태 점검에 실패하면 활성화가 중단됩니다. 점 세 개(...)를 클릭하고 *로그 저장*을 선택하여 오류를 검토할 수 있습니다. 또는 상태 점검 오류를 무시하고 *계속*을 클릭하여 활성화를 진행할 수도 있습니다.
** 사전 업그레이드 상태 점검 후 활성화 작업을 취소할 수 있습니다. 사전 업그레이드 상태 점검이 성공적으로 완료되면 활성화가 진행됩니다. 활성화에 소요되는 시간은 스토리지 어레이 구성 및 활성화할 구성 요소에 따라 달라집니다.


. *선택 사항:* 활성화가 완료되면 줄임표(...)를 클릭한 다음 *로그 저장*을 선택하여 특정 스토리지 어레이에 대해 활성화된 항목 목록을 볼 수 있습니다.
+
해당 파일은 브라우저의 다운로드 폴더에 `activate_log-<date>.json`이라는 이름으로 저장됩니다.
