= SANtricity 구성 워크플로 미러링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager에서 비동기 또는 동기 미러링을 구성한 다음 SANtricity System Manager를 사용하여 동기화를 관리합니다.



== 비동기식 미러링 워크플로우

비동기 미러링에는 다음 워크플로가 포함됩니다.

. Unified Manager에서 초기 구성을 수행하십시오.
+
.. 데이터 전송 소스로 로컬 스토리지 어레이를 선택하십시오.
.. 로컬 어레이의 운영 볼륨과 원격 어레이의 2차 볼륨을 담는 컨테이너인 미러 일관성 그룹을 생성하거나 기존 미러 일관성 그룹을 선택합니다. 운영 볼륨과 2차 볼륨을 "미러링된 쌍"이라고 합니다. 미러 일관성 그룹을 처음 생성하는 경우 수동 동기화를 수행할지 예약된 동기화를 수행할지 지정합니다.
.. 로컬 스토리지 어레이에서 운영 볼륨을 선택한 다음 해당 볼륨의 예약된 용량을 확인합니다. 예약된 용량은 복사 작업에 사용할 물리적으로 할당된 용량입니다.
.. 전송 대상으로 원격 스토리지 어레이, 보조 볼륨을 선택한 다음 예약된 용량을 확인합니다.
.. 운영 볼륨에서 2차 볼륨으로 초기 데이터 전송을 시작합니다. 볼륨 크기에 따라 이 초기 전송에는 몇 시간이 소요될 수 있습니다.


. 초기 동기화 진행 상황을 확인하십시오.
+
.. Unified Manager에서 로컬 어레이용 System Manager를 실행합니다.
.. System Manager에서 미러링 작업의 상태를 확인합니다. 미러링이 완료되면 미러링된 쌍의 상태가 "최적"입니다.


. 필요에 따라 System Manager에서 후속 데이터 전송 일정을 다시 예약하거나 수동으로 수행할 수 있습니다. 기본 볼륨에서 보조 볼륨으로 전송되는 블록은 새로 추가되거나 변경된 블록뿐입니다.
+
[NOTE]
====
비동기 복제는 주기적으로 이루어지기 때문에 시스템은 변경된 블록을 통합하고 네트워크 대역폭을 절약할 수 있습니다. 쓰기 처리량과 쓰기 지연 시간에 미치는 영향은 최소화됩니다.

====




== 동기식 미러링 워크플로우

동기식 미러링에는 다음 워크플로우가 포함됩니다.

. Unified Manager에서 초기 구성을 수행하십시오.
+
.. 데이터 전송 소스로 로컬 스토리지 어레이를 선택하십시오.
.. 로컬 스토리지 어레이에서 운영 볼륨을 선택합니다.
.. 데이터 전송 대상으로 원격 스토리지 어레이를 선택한 다음 보조 볼륨을 선택합니다.
.. 동기화 및 재동기화 우선순위를 선택하십시오.
.. 운영 볼륨에서 2차 볼륨으로 초기 데이터 전송을 시작합니다. 볼륨 크기에 따라 이 초기 전송에는 몇 시간이 소요될 수 있습니다.


. 초기 동기화 진행 상황을 확인하십시오.
+
.. Unified Manager에서 로컬 어레이용 System Manager를 실행합니다.
.. System Manager에서 미러링 작업의 상태를 확인합니다. 미러링이 완료되면 미러링된 쌍의 상태가 "최적"입니다. 두 어레이는 정상 작업을 통해 동기화 상태를 유지하려고 시도합니다. 새 블록과 변경된 블록만 운영 볼륨에서 2차 볼륨으로 전송됩니다.


. 필요에 따라 System Manager에서 동기화 설정을 변경할 수 있습니다.
+
[NOTE]
====
동기식 복제는 지속적으로 이루어지기 때문에 두 사이트 간의 복제 링크는 충분한 대역폭 기능을 제공해야 합니다.

====
