= SANtricity Unified Manager에서 스토리지 어레이 그룹 이름 변경
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
현재 이름이 더 이상 의미가 없거나 적절하지 않은 경우 스토리지 어레이 그룹의 이름을 변경할 수 있습니다.

.이 작업 정보
다음 지침을 염두에 두십시오.

* 이름은 문자, 숫자, 그리고 특수 문자인 밑줄(_), 하이픈(-), 파운드(#)로 구성될 수 있습니다. 다른 문자를 선택하면 오류 메시지가 나타납니다. 다른 이름을 선택하라는 메시지가 표시됩니다.
* 이름은 30자 이내로 제한합니다. 이름의 앞뒤 공백은 모두 삭제됩니다.
* 독창적이고 의미 있으면서 이해하기 쉽고 기억하기 쉬운 이름을 사용하세요.
* 임의적인 이름이나 미래에 의미를 빠르게 잃을 수 있는 이름은 피하십시오.


.단계
. 메인 화면에서 *관리*를 선택한 다음 이름을 변경할 스토리지 배열 그룹을 선택합니다.
. 메뉴: 그룹 관리[스토리지 배열 그룹 이름 바꾸기]를 선택합니다.
. *그룹 이름* 필드에 그룹의 새 이름을 입력합니다.
. *이름 바꾸기*를 클릭합니다.
