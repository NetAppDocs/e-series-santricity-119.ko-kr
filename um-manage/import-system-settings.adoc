= SANtricity Unified Manager에서 시스템 설정을 가져옵니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
한 스토리지 어레이의 시스템 구성을 다른 스토리지 어레이로 가져올 수 있습니다. 이 일괄 작업은 네트워크에서 여러 어레이를 구성해야 할 때 시간을 절약해 줍니다.

.시작하기 전에
* 시스템 설정은 소스로 사용할 스토리지 어레이에 대해 System Manager에서 구성합니다.
* 대상 스토리지 어레이의 기존 구성은 System Manager(메뉴: Settings[System > Save Storage Array Configuration])에 백업됩니다.


.이 작업 정보
가져온 설정에는 볼륨에 대한 미디어 스캔 설정, 컨트롤러에 대한 SSD 설정 및 자동 로드 밸런싱(호스트 연결 보고는 포함되지 않음)이 포함됩니다.

.단계
. 관리 페이지에서 *설정 가져오기*를 클릭합니다.
+
가져오기 설정 마법사가 열립니다.

. 설정 선택 대화 상자에서 *System*을 선택한 다음 *Next*를 클릭합니다.
+
소스 배열을 선택하기 위한 대화 상자가 열립니다.

. 소스 선택 대화 상자에서 가져올 설정이 포함된 배열을 선택한 다음 *Next*를 클릭합니다.
. 대상 선택 대화 상자에서 새 설정을 받을 하나 이상의 어레이를 선택합니다.
+
[NOTE]
====
펌웨어가 8.50 미만인 스토리지 어레이는 선택할 수 없습니다. 또한 Unified Manager가 해당 어레이와 통신할 수 없는 경우(예: 오프라인 상태이거나 인증서, 암호 또는 네트워킹 문제가 있는 경우) 해당 어레이는 이 대화 상자에 표시되지 않습니다.

====
. *완료*를 클릭합니다.
+
작업 페이지에는 가져오기 작업 결과가 표시됩니다. 작업이 실패한 경우 해당 행을 클릭하여 자세한 정보를 확인할 수 있습니다.



.결과
이제 타겟 스토리지 어레이가 소스 어레이와 동일한 시스템 설정으로 구성되었습니다.
