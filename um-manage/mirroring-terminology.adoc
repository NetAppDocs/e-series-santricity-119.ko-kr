= SANtricity Unified Manager의 미러링 용어에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미러링 용어가 스토리지 어레이에 어떻게 적용되는지 알아보십시오.

[cols="25h,~"]
|===
| 용어 | 설명 


 a| 
로컬 스토리지 어레이
 a| 
로컬 스토리지 어레이는 사용자가 작업하고 있는 스토리지 어레이입니다.



 a| 
미러 일관성 그룹
 a| 
미러 일관성 그룹은 하나 이상의 미러링된 쌍을 담는 컨테이너입니다. 비동기 미러링 작업을 수행하려면 미러 일관성 그룹을 생성해야 합니다. 그룹 내의 모든 미러링된 쌍은 동시에 재동기화되므로 일관된 복구 지점이 유지됩니다.

동기식 미러링은 미러 일관성 그룹을 사용하지 않습니다.



 a| 
미러링된 쌍
 a| 
미러링된 쌍은 기본 볼륨과 보조 볼륨의 두 볼륨으로 구성됩니다.

비동기 미러링에서 미러링된 쌍은 항상 미러 일관성 그룹에 속합니다. 쓰기 작업은 먼저 기본 볼륨에서 수행된 다음 보조 볼륨으로 복제됩니다. 미러 일관성 그룹의 각 미러링된 쌍은 동일한 동기화 설정을 공유합니다.



 a| 
운영 볼륨
 a| 
미러링된 쌍의 운영 볼륨은 미러링할 소스 볼륨입니다.



 a| 
원격 스토리지 어레이
 a| 
원격 스토리지 어레이는 일반적으로 보조 사이트로 지정되며, 일반적으로 미러링 구성에서 데이터의 복제본을 보유합니다.



 a| 
예약된 용량
 a| 
예약 용량은 모든 복사 서비스 작업 및 스토리지 객체에 사용되는 물리적으로 할당된 용량입니다. 호스트에서 직접 읽을 수는 없습니다.

이러한 볼륨은 컨트롤러가 미러링을 운영 상태로 유지하는 데 필요한 정보를 영구적으로 저장할 수 있도록 하기 위해 필요합니다. 여기에는 델타 로그 및 쓰기 시 복사 데이터와 같은 정보가 포함됩니다.



 a| 
보조 볼륨
 a| 
미러링된 쌍의 보조 볼륨은 일반적으로 보조 사이트에 있으며 데이터의 복제본을 보유합니다.



 a| 
동기화
 a| 
동기화는 로컬 스토리지 어레이와 원격 스토리지 어레이 간의 초기 동기화 시에 발생합니다. 또한 통신 중단 후 기본 볼륨과 보조 볼륨의 동기화가 해제될 때도 동기화가 발생합니다. 통신 링크가 다시 작동하면 복제되지 않은 모든 데이터가 보조 볼륨의 스토리지 어레이로 동기화됩니다.

|===
