= SANtricity Unified Manager에서 스토리지 어레이 상태를 확인하세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager는 검색된 각 스토리지 시스템의 상태를 표시합니다.

*관리 - 전체* 페이지로 이동하세요. 이 페이지에서 Web Services Proxy와 해당 스토리지 시스템 간의 연결 상태를 확인할 수 있습니다.

상태 표시기는 다음 표에 설명되어 있습니다.

[cols="25h,~"]
|===
| 상태 | 나타냅니다 


 a| 
최적
 a| 
스토리지 어레이가 최적 상태입니다. 인증서 문제가 없으며 암호가 유효합니다.



 a| 
잘못된 비밀번호입니다
 a| 
잘못된 스토리지 배열 암호가 제공되었습니다.



 a| 
신뢰할 수 없는 인증서
 a| 
HTTPS 인증서가 자체 서명되어 가져오지 않았거나 CA 서명 인증서이지만 루트 및 중간 CA 인증서를 가져오지 않았기 때문에 스토리지 어레이와의 연결 중 하나 이상을 신뢰할 수 없습니다.



 a| 
주의가 필요합니다
 a| 
스토리지 시스템에 문제가 발생하여 수정하려면 사용자의 조치가 필요합니다.



 a| 
잠금
 a| 
스토리지 어레이가 잠금 상태입니다.



 a| 
알 수 없음
 a| 
스토리지 어레이에 한 번도 연결되지 않았습니다. 이는 Web Services Proxy가 시작 중이어서 스토리지 어레이에 아직 연결되지 않았거나, 스토리지 어레이가 오프라인 상태이고 Web Services Proxy가 시작된 이후로 한 번도 연결되지 않은 경우에 발생할 수 있습니다.



 a| 
오프라인
 a| 
웹 서비스 프록시는 이전에 스토리지 시스템과 연결되었지만, 현재는 해당 시스템과의 모든 연결이 끊어졌습니다.

|===
