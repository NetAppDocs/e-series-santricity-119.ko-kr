[[what-settings-will-be-imported]]
== 어떤 설정을 가져올 수 있습니까?

설정 가져오기 기능은 하나의 스토리지 어레이에서 여러 스토리지 어레이로 구성을 일괄 로드하는 작업입니다. 이 작업 중에 가져오는 설정은 SANtricity System Manager에서 소스 스토리지 어레이가 구성된 방식에 따라 달라집니다.

다음 설정은 여러 스토리지 어레이로 가져올 수 있습니다.

* *이메일 알림* -- 설정에는 메일 서버 주소와 알림 수신자의 이메일 주소가 포함됩니다.
* *Syslog 알림* -- 설정에는 syslog 서버 주소와 UDP 포트가 포함됩니다.
* *SNMP 알림* -- 설정에는 SNMP 서버의 커뮤니티 이름과 IP 주소가 포함됩니다.
* *AutoSupport* -- 설정에는 개별 기능(기본 AutoSupport, AutoSupport OnDemand 및 원격 진단), 유지보수 윈도우, 전달 방법 및 파견 일정이 포함됩니다.
* *디렉터리 서비스* -- 구성에는 LDAP(Lightweight Directory Access Protocol) 서버의 도메인 이름과 URL, 그리고 LDAP 서버의 사용자 그룹과 스토리지 어레이의 사전 정의된 역할 간의 매핑이 포함됩니다.
* *스토리지 구성* -- 구성에는 볼륨(씩 볼륨만 해당, 리포지토리가 아닌 볼륨만 해당), 볼륨 그룹, 풀 및 핫 스페어 드라이브 할당이 포함됩니다.
* *시스템 설정* -- 구성에는 볼륨의 미디어 스캔 설정, 컨트롤러의 SSD 캐시 및 자동 로드 밸런싱이 포함됩니다(호스트 연결 보고는 포함되지 않음).




[[why-dont-i-see-all-of-my-storage-arrays]]
== 내 스토리지 어레이가 모두 표시되지 않는 이유는 무엇입니까?

설정 가져오기 작업 중에 일부 스토리지 어레이가 대상 선택 대화 상자에서 사용할 수 없을 수 있습니다.

스토리지 어레이가 다음과 같은 이유로 표시되지 않을 수 있습니다.

* 펌웨어 버전이 8.50 미만입니다.
* 스토리지 어레이가 오프라인 상태입니다.
* 시스템이 해당 어레이와 통신할 수 없습니다(예: 어레이에 인증서, 암호 또는 네트워킹 문제가 있음).
