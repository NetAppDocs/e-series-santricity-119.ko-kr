[[what-are-array-groups]]
== 어레이 그룹이란 무엇입니까?

스토리지 어레이 세트를 그룹화하여 물리적 및 가상화된 인프라를 관리할 수 있습니다. 스토리지 어레이를 그룹화하면 모니터링 또는 보고 작업을 더 쉽게 실행할 수 있습니다.

그룹에는 두 가지 유형이 있습니다.

* *모든 그룹* -- 모든 그룹은 기본 그룹이며 조직에서 검색된 모든 스토리지 어레이를 포함합니다. 모든 그룹은 기본 보기에서 액세스할 수 있습니다.
* *사용자 생성 그룹* -- 사용자 생성 그룹에는 사용자가 직접 선택하여 해당 그룹에 추가하는 스토리지 어레이가 포함됩니다. 사용자 생성 그룹은 기본 보기에서 액세스할 수 있습니다.
