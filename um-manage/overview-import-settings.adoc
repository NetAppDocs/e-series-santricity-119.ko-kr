= SANtricity Unified Manager에서 스토리지 어레이 설정을 가져오는 방법에 대해 알아보세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
설정 가져오기 기능을 사용하면 하나의 어레이에서 여러 어레이로 설정을 일괄적으로 가져올 수 있습니다. 이 기능은 네트워크에서 여러 어레이를 구성해야 할 때 시간을 절약해 줍니다.



[[what-settings-can-be-imported]]
== 어떤 설정을 가져올 수 있습니까?

알림 방법, AutoSupport 구성, 디렉터리 서비스 구성, 스토리지 구성(볼륨 그룹 및 풀 등) 및 시스템 설정(자동 로드 밸런싱 등)을 가져올 수 있습니다.

자세한 정보:

* link:how-import-settings-works.html["설정 가져오기 작동 방식"]
* link:requirements-for-replicating-storage-configurations.html["스토리지 구성 복제 요구 사항"]




[[how-do-i-perform-a-batch-import]]
== 일괄 가져오기는 어떻게 수행합니까?

소스로 사용할 스토리지 어레이에서 System Manager를 열고 원하는 설정을 구성합니다. 그런 다음 Unified Manager에서 Manage 페이지로 이동하여 하나 이상의 어레이에 설정을 가져옵니다.

자세한 정보:

* link:import-autosupport-settings.html["AutoSupport 설정 가져오기"]
* link:import-directory-services-settings.html["디렉터리 서비스 설정 가져오기"]
* link:import-storage-configuration-settings.html["스토리지 구성 설정 가져오기"]
* link:import-system-settings.html["시스템 설정 가져오기"]
