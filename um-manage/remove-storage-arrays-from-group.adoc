= SANtricity Unified Manager에서 그룹에서 스토리지 어레이를 제거합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
특정 스토리지 그룹에서 더 이상 관리하지 않으려면 그룹에서 하나 이상의 관리형 스토리지 어레이를 제거할 수 있습니다.

.이 작업 정보
그룹에서 스토리지 어레이를 제거해도 스토리지 어레이 또는 해당 데이터에는 어떤 식으로든 영향을 주지 않습니다. 스토리지 어레이가 System Manager에서 관리되는 경우 브라우저를 사용하여 계속 관리할 수 있습니다. 스토리지 어레이가 실수로 그룹에서 제거된 경우 다시 추가할 수 있습니다.

.단계
. 관리 페이지에서 menu:그룹 관리[그룹에서 스토리지 어레이 제거]를 선택합니다.
. 드롭다운 메뉴에서 제거할 스토리지 어레이가 포함된 그룹을 선택한 다음 해당 그룹에서 제거할 각 스토리지 어레이 옆의 확인란을 클릭합니다.
. *제거*를 클릭합니다.
