= SANtricity System Manager에서 스토리지 어레이 클록을 동기화합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
네트워크 시간 프로토콜(NTP)이 활성화되어 있지 않은 경우 컨트롤러의 시계를 수동으로 설정하여 관리 클라이언트(SANtricity System Manager에 액세스하는 브라우저를 실행하는 데 사용되는 시스템)와 동기화할 수 있습니다.

.이 작업 정보
동기화는 이벤트 로그의 이벤트 타임스탬프가 호스트 로그 파일에 기록된 타임스탬프와 일치하도록 보장합니다. 동기화 과정 중에도 컨트롤러는 계속해서 사용 가능하고 정상적으로 작동합니다.

[NOTE]
====
System Manager에서 NTP가 활성화된 경우 이 옵션을 사용하여 시계를 동기화하지 마십시오. 대신 NTP는 SNTP(Simple Network Time Protocol)를 사용하여 외부 호스트와 자동으로 시계를 동기화합니다.

====
[NOTE]
====
동기화 후 성능 통계가 손실되거나 왜곡되고, 일정(ASUP, 스냅샷 등)에 영향을 미치며, 로그 데이터의 타임스탬프가 왜곡될 수 있습니다. NTP를 사용하면 이러한 문제를 방지할 수 있습니다.

====
.단계
. 메뉴:Settings[System]를 선택합니다.
. *일반*에서 *스토리지 어레이 클록 동기화*를 클릭합니다.
+
스토리지 어레이 시계 동기화 대화 상자가 열립니다. 이 상자에는 컨트롤러와 관리 클라이언트로 사용되는 컴퓨터의 현재 날짜와 시간이 표시됩니다.

+
[NOTE]
====
simplex 스토리지 어레이의 경우 컨트롤러는 하나만 표시됩니다.

====
. 대화 상자에 표시된 시간이 일치하지 않으면 *동기화*를 클릭하십시오.


.결과
동기화가 성공하면 이벤트 로그와 호스트 로그의 이벤트 타임스탬프가 동일합니다.
