= SANtricity System Manager에서 트랩 대상을 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이의 이벤트 모니터가 더 이상 해당 주소로 SNMP 트랩을 보내지 않도록 트랩 대상 주소를 삭제할 수 있습니다.

.단계
. 메뉴:Settings[Alerts]를 선택합니다.
. *SNMP* 탭을 선택합니다.
+
트랩 대상 주소가 표에 나타납니다.

. 트랩 대상을 선택한 다음 페이지 오른쪽 상단의 *Delete*를 클릭합니다.
. 작업을 확인한 다음 *삭제*를 클릭합니다.
+
대상 주소가 더 이상 알림 페이지에 표시되지 않습니다.



.결과
삭제된 트랩 대상은 더 이상 스토리지 어레이의 이벤트 모니터에서 SNMP 트랩을 수신하지 않습니다.
