= SANtricity System Manager에서 iSCSI 세션을 종료합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
더 이상 필요하지 않은 iSCSI 세션을 종료할 수 있습니다. iSCSI 세션은 비동기식 미러 관계에 있는 호스트 또는 원격 스토리지 시스템에서 발생할 수 있습니다.

.이 작업 정보
다음과 같은 이유로 iSCSI 세션을 종료할 수 있습니다.

* *무단 액세스* -- iSCSI 이니시에이터가 로그인했는데 액세스 권한이 없어야 하는 경우, iSCSI 세션을 종료하여 iSCSI 이니시에이터를 스토리지 어레이에서 강제로 제거할 수 있습니다. iSCSI 이니시에이터가 로그인한 이유는 None 인증 방법을 사용할 수 있었기 때문일 수 있습니다.
* *시스템 다운타임* -- 스토리지 어레이를 중단해야 하는데 iSCSI 이니시에이터가 여전히 로그온되어 있는 경우 iSCSI 세션을 종료하여 스토리지 어레이에서 iSCSI 이니시에이터를 제거할 수 있습니다.


.단계
. 메뉴:Settings[System]를 선택합니다.
. *View/End iSCSI Sessions*를 선택하십시오.
+
현재 iSCSI 세션 목록이 표시됩니다.

. 종료할 세션을 선택합니다.
. *세션 종료*를 클릭하고 작업을 수행할 것인지 확인합니다.
