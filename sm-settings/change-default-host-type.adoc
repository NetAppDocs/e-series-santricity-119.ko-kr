= SANtricity System Manager에서 기본 호스트 유형을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이 수준에서 기본 호스트 유형을 변경하려면 기본 호스트 운영 체제 변경 설정을 사용하십시오. 일반적으로 스토리지 어레이에 호스트를 연결하기 전이나 추가 호스트를 연결할 때 기본 호스트 유형을 변경합니다.

.이 작업 정보
다음 지침을 염두에 두십시오.

* 스토리지 어레이에 연결할 모든 호스트의 운영 체제가 동일한 경우(동질적인 호스트 환경) 호스트 유형을 운영 체제에 맞게 변경하십시오.
* 스토리지 어레이에 연결할 계획인 서로 다른 운영 체제를 사용하는 호스트가 있는 경우(이기종 호스트 환경), 호스트 유형을 대부분의 호스트 운영 체제와 일치하도록 변경하십시오.
+
예를 들어, 8개의 서로 다른 호스트를 스토리지 어레이에 연결하고 그중 6개의 호스트에서 Windows 운영 체제를 실행하는 경우 기본 호스트 운영 체제 유형으로 Windows를 선택해야 합니다.

* 연결된 호스트의 대부분이 서로 다른 운영 체제를 사용하는 경우 호스트 유형을 Factory Default로 변경하십시오.
+
예를 들어, 8개의 서로 다른 호스트를 스토리지 어레이에 연결하고 그중 2개는 Windows 운영 체제를, 3개는 VMware 운영 체제를, 나머지 3개는 Linux 운영 체제를 실행하는 경우 기본 호스트 운영 체제 유형으로 Factory Default를 선택해야 합니다.



.단계
. 메뉴:Settings[System]를 선택합니다.
. *Additional Settings*로 스크롤한 다음 *Change Default Host Operating System Type*을 클릭합니다.
. 기본값으로 사용할 호스트 운영 체제 유형을 선택하십시오.
. *변경*을 클릭합니다.
