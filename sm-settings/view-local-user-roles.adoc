= SANtricity System Manager에서 로컬 사용자 역할을 확인하세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
로컬 사용자 역할 탭에서 사용자 프로필과 기본 역할 간의 매핑을 확인할 수 있습니다. 이러한 매핑은 스토리지 어레이에 적용되는 RBAC(역할 기반 액세스 관리)의 일부입니다.

.시작하기 전에
보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 액세스 관리 기능이 표시되지 않습니다.

.이 작업 정보
사용자 프로필 및 매핑은 변경할 수 없습니다. 비밀번호만 수정할 수 있습니다.

.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. *로컬 사용자 역할* 탭을 선택합니다.
+
사용자 프로필은 표에 나와 있습니다.

+
** *Root admin*(admin) -- 시스템의 모든 기능에 액세스할 수 있는 최고 관리자입니다. 이 사용자 프로필에는 모든 역할이 포함됩니다.
** *스토리지 관리자*(storage) -- 모든 스토리지 프로비저닝을 담당하는 관리자입니다. 이 사용자 프로필에는 스토리지 관리자, 지원 관리자 및 모니터 역할이 포함됩니다.
** *보안 관리자*(Security admin) -- 액세스 관리, 인증서 관리 및 보안 지원 드라이브 기능을 포함한 보안 구성을 담당하는 사용자입니다. 이 사용자 프로필에는 Security Admin 및 Monitor 역할이 포함됩니다.
** *지원 관리자* (support) -- 하드웨어 리소스, 오류 데이터 및 펌웨어 업그레이드를 담당하는 사용자입니다. 이 사용자 프로필에는 Support Admin 및 Monitor 역할이 포함됩니다.
** *Monitor*(monitor) -- 시스템에 대한 읽기 전용 액세스 권한을 가진 사용자입니다. 이 사용자 프로필에는 Monitor 역할만 포함됩니다.
