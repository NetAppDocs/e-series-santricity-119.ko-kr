= SANtricity System Manager에서 감사 로그 활동을 확인하세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
감사 로그를 확인하여 Security Admin 권한이 있는 사용자는 사용자 작업, 인증 실패, 잘못된 로그인 시도 및 사용자 세션 수명을 모니터링할 수 있습니다.

.시작하기 전에
보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 액세스 관리 기능이 표시되지 않습니다.

.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. **감사 로그** 탭을 선택합니다.
+
감사 로그 활동은 표 형식으로 표시되며 다음 정보 열을 포함합니다.

+
** *Date/Time* -- 스토리지 어레이가 이벤트를 감지한 시점의 타임스탬프(GMT 기준).
** *Username* -- 이벤트와 연결된 사용자 이름입니다. 스토리지 어레이에 대한 인증되지 않은 작업의 경우 사용자 이름으로 "N/A"가 표시됩니다. 인증되지 않은 작업은 내부 프록시 또는 다른 메커니즘에 의해 트리거될 수 있습니다.
** *상태 코드* -- 작업의 HTTP 상태 코드(200, 400 등) 및 이벤트와 관련된 설명 텍스트입니다.
** *URL 액세스* -- 전체 URL(호스트 포함) 및 쿼리 문자열.
** *클라이언트 IP 주소* -- 이벤트와 연결된 클라이언트의 IP 주소입니다.
** *출처* -- 이벤트와 관련된 로깅 소스로, System Manager, CLI, Web Services 또는 Support Shell일 수 있습니다.
** *설명* -- 해당되는 경우 이벤트에 대한 추가 정보입니다.


. 감사 로그 페이지의 선택 항목을 사용하여 이벤트를 보고 관리합니다.
+
.선택 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 선택 | 설명 


 a| 
다음에서 이벤트 표시...
 a| 
표시되는 이벤트를 날짜 범위(지난 24시간, 지난 7일, 지난 30일 또는 사용자 지정 날짜 범위)로 제한합니다.



 a| 
필터
 a| 
필드에 입력된 문자로 표시되는 이벤트를 제한합니다. 정확한 단어 일치를 위해 따옴표("")를 사용하고,  `OR`를 입력하여 하나 이상의 단어를 반환하거나 대시(--)를 입력하여 단어를 생략합니다.



 a| 
새로 고침
 a| 
페이지를 최신 이벤트로 업데이트하려면 *새로 고침*을 선택하십시오.



 a| 
설정 보기/편집
 a| 
*View/Edit Settings*를 선택하면 전체 로그 정책과 로깅할 작업 수준을 지정할 수 있는 대화 상자가 열립니다.



 a| 
이벤트 삭제
 a| 
페이지에서 오래된 이벤트를 제거할 수 있는 대화 상자를 열려면 *Delete*를 선택하십시오.



 a| 
열 표시/숨기기
 a| 
*표시/숨기기* 열 아이콘 image:../media/sam-1140-ss-access-columns.gif["열 표시/숨기기"]을 클릭하여 표에 표시할 추가 열을 선택합니다. 추가 열은 다음과 같습니다.

** *메서드* -- HTTP 메서드(예: POST, GET, DELETE 등)입니다.
** *CLI 명령 실행됨* -- Secure CLI 요청에 대해 실행된 CLI 명령(문법)입니다.
** *CLI Return Status* -- CLI 상태 코드 또는 클라이언트의 입력 파일 요청입니다.
** *SYMbol 프로시저* -- SYMbol 프로시저가 실행되었습니다.
** *SSH 이벤트 유형* -- 로그인, 로그아웃 및 login_fail과 같은 SSH(Secure Shell) 이벤트 유형입니다.
** *SSH Session PID* -- SSH 세션의 프로세스 ID 번호입니다.
** *SSH Session Duration(s)* -- 사용자가 로그인한 시간(초)입니다.
** *인증 유형* -- 유형에는 로컬 사용자, LDAP, SAML 및 Access token이 포함될 수 있습니다.
** *Authentication ID* -- 인증된 Session ID입니다.




 a| 
열 필터 전환
 a| 
*Toggle* 아이콘 image:../media/sam-1140-ss-access-toggle.gif["토글"]을 클릭하여 각 열에 대한 필터링 필드를 엽니다. 열 필드에 문자를 입력하면 해당 문자로 표시되는 이벤트가 제한됩니다. 아이콘을 다시 클릭하면 필터링 필드가 닫힙니다.



 a| 
변경 내용 취소
 a| 
*실행 취소* 아이콘 image:../media/sam-1140-ss-access-undo.gif["실행 취소"]을 클릭하여 테이블을 기본 구성으로 되돌립니다.



 a| 
내보내기
 a| 
테이블 데이터를 쉼표로 구분된 값(CSV) 파일로 저장하려면 *Export*를 클릭하십시오.
