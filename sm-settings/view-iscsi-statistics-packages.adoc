= SANtricity System Manager에서 iSCSI 통계 패키지를 확인하세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에 대한 iSCSI 연결 정보를 확인할 수 있습니다.

.이 작업 정보
System Manager는 다음과 같은 유형의 iSCSI 통계를 표시합니다. 모든 통계는 읽기 전용이며 설정할 수 없습니다.

* *이더넷 MAC 통계* -- 미디어 액세스 제어(MAC)에 대한 통계를 제공합니다. MAC는 물리적 주소 또는 MAC 주소라고 하는 주소 지정 메커니즘도 제공합니다. MAC 주소는 각 네트워크 어댑터에 할당된 고유 주소입니다. MAC 주소는 서브넷 내의 목적지까지 데이터 패킷을 전달하는 데 도움이 됩니다.
* *이더넷 TCP/IP 통계* -- iSCSI 장치의 TCP/IP(전송 제어 프로토콜(TCP) 및 인터넷 프로토콜(IP)) 통계를 제공합니다. TCP를 통해 네트워크 호스트의 애플리케이션은 서로 연결을 생성하고 패킷 단위로 데이터를 교환할 수 있습니다. IP는 패킷 교환 방식의 네트워크를 통해 데이터를 전송하는 데이터 중심 프로토콜입니다. IPv4 통계와 IPv6 통계는 별도로 표시됩니다.
* *로컬 타겟/이니시에이터(프로토콜) 통계* -- 스토리지 미디어에 대한 블록 수준 액세스를 제공하는 iSCSI 타겟에 대한 통계를 표시하고, 비동기 미러링 작업에서 이니시에이터로 사용될 때 스토리지 어레이에 대한 iSCSI 통계를 표시합니다.
* *DCBX 운영 상태 통계* -- 다양한 Data Center Bridging Exchange(DCBX) 기능의 운영 상태를 표시합니다.
* *LLDP TLV 통계* -- Link Layer Discovery Protocol(LLDP) Type Length Value(TLV) 통계를 표시합니다.
* *DCBX TLV 통계* -- Data Center Bridging(DCB) 환경에서 스토리지 어레이 호스트 포트를 식별하는 정보를 표시합니다. 이 정보는 식별 및 기능 목적으로 네트워크 피어와 공유됩니다.


각 통계는 원시 통계 또는 기준 통계로 볼 수 있습니다. 원시 통계는 컨트롤러가 시작된 이후 수집된 모든 통계입니다. 기준 통계는 기준 시점을 설정한 이후 수집된 특정 시점의 통계입니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. *View iSCSI Statistics Packages*를 선택합니다.
. 탭을 클릭하여 다양한 통계 세트를 확인하십시오.
. *선택 사항:* 기준선을 설정하려면 *Set new baseline*을 클릭하십시오.
+
기준선을 설정하면 통계 수집을 위한 새로운 시작점이 설정됩니다. 모든 iSCSI 통계에 동일한 기준선이 사용됩니다.



다양한 통계 유형에 대한 자세한 내용은 다음 섹션을 참조하십시오.

 a|

 a|

== DCBX TLV 통계

Data Center Bridging Exchange(DCBX) Type Length Value(TLV) 통계를 선택하면 다음과 같은 통계가 표시됩니다.

* *로컬 통계* -- 공장에서 컨트롤러에 구성된 DCBX 매개 변수입니다.
* *운영 통계* -- DCBX 협상 결과로 나타나는 DCBX 매개변수입니다.
* *원격 통계* -- 컨트롤러가 연결된 피어 장치(일반적으로 스위치)의 DCBX 매개 변수입니다.


.DCBX TLV 통계:
[%collapsible]
====
[cols="25h,~"]
|===
| 통계 | 정의 


 a| 
iSCSI 호스트 포트
 a| 
감지된 호스트 포트의 위치를 컨트롤러 번호, 포트 번호 형식으로 나타냅니다.



 a| 
흐름 제어 모드
 a| 
전체 포트의 흐름 제어 모드입니다. 유효한 값은 Disabled, Standard, Per Priority 또는 Indeterminate입니다.



 a| 
프로토콜
 a| 
통신 프로토콜입니다. 유효한 값은 FCoE, FIP, iSCSI 또는 UNKNOWN입니다.



 a| 
우선순위
 a| 
통신의 우선 순위 번호를 나타내는 정수 값입니다.



 a| 
우선 순위 그룹
 a| 
프로토콜이 할당된 우선순위 그룹을 나타내는 정수 값입니다.



 a| 
우선 순위 그룹 % 대역폭
 a| 
우선순위 그룹에 할당된 대역폭의 양을 나타내는 백분율 값입니다.



 a| 
DCBX PFC 상태
 a| 
특정 포트의 우선순위 기반 흐름 제어(PFC) 상태입니다. 값은 활성화 또는 비활성화 중 하나입니다.

|===
====

NOTE: 상태 캡처 파일에서 추가 DCBX TLV 통계를 확인할 수 있습니다.
