= SANtricity System Manager에서 외부 키 관리에서 내부 키 관리로 전환
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
드라이브 보안 관리 방식을 외부 키 서버에서 스토리지 어레이에서 사용하는 내부 방식으로 변경할 수 있습니다. 그러면 이전에 외부 키 관리에 대해 정의했던 보안 키가 내부 키 관리에 사용됩니다.

.이 작업 정보
이 작업에서는 외부 키 관리를 비활성화하고 새 백업 복사본을 로컬 호스트에 다운로드합니다. 기존 키는 드라이브 보안에 계속 사용되지만 스토리지 어레이 내부에서 관리됩니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. * 보안 키 관리 * 에서 * 외부 키 관리 비활성화 * 를 선택합니다.
+
외부 키 관리 사용 안 함 대화 상자가 열립니다.

. *암호 정의/암호 재입력*에서 키 백업에 사용할 암호를 입력하고 확인하십시오. 값은 8~32자이며 다음 항목을 모두 포함해야 합니다.
+
** 대문자(하나 이상). 암호는 대소문자를 구분한다는 점에 유의하십시오.
** 숫자(하나 이상).
** !, *, @와 같은 영숫자가 아닌 문자(하나 이상).


+
[CAUTION]
====
_나중에 사용할 수 있도록 입력 내용을 기록해 두십시오_. 보안이 활성화된 드라이브를 스토리지 어레이에서 이동해야 하는 경우 드라이브 데이터 잠금을 해제하려면 식별자와 암호를 알아야 합니다.

====
. *비활성화*를 클릭합니다.
+
백업 키가 로컬 호스트로 다운로드됩니다.

. 키 식별자, 암호, 다운로드한 키 파일의 위치를 기록해 둔 다음 *닫기*를 클릭하십시오.


.결과
드라이브 보안은 이제 스토리지 어레이를 통해 내부적으로 관리됩니다.

.완료한 후
키 파일이 손상되지 않았는지 확인하려면 보안 키를 검증해야 합니다.
