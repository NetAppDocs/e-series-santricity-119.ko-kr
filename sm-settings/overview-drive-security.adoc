[[what-is-drive-security]]
== 드라이브 보안이란 무엇입니까?

_Drive Security_는 스토리지 어레이에서 제거될 때 보안 지원 드라이브의 데이터에 대한 무단 액세스를 방지하는 기능입니다. 이러한 드라이브는 FDE(Full Disk Encryption) 드라이브 또는 FIPS(Federal Information Processing Standard) 드라이브일 수 있습니다. FDE 또는 FIPS 드라이브가 어레이에서 물리적으로 제거되면 다른 어레이에 설치될 때까지 작동할 수 없으며, 이 경우 올바른 보안 키가 제공될 때까지 드라이브가 Security Locked 상태가 됩니다. _보안 키_는 이러한 유형의 드라이브와 스토리지 어레이의 컨트롤러 간에 공유되는 문자열입니다.

[[how-do-i-configure-key-management]]
== 키 관리는 어떻게 구성하나요?

드라이브 보안을 구현하려면 어레이에 FDE 드라이브 또는 FIPS 드라이브가 설치되어 있어야 합니다. 이러한 드라이브의 키 관리를 구성하려면 menu:Settings[System > Security key management]로 이동하여 컨트롤러의 영구 메모리에서 내부 키를 생성하거나 키 관리 서버에서 외부 키를 생성할 수 있습니다. 마지막으로 볼륨 설정에서 "secure-capable"을 선택하여 풀 및 볼륨 그룹에 대한 드라이브 보안을 활성화합니다.

자세한 정보:

* link:create-internal-security-key.html["내부 보안 키 생성"]
* link:create-external-security-key.html["외부 보안 키 생성"]
* link:../sm-storage/create-pool-manually.html["수동으로 풀 생성"]
* link:../sm-storage/create-volume-group.html["볼륨 그룹 생성"]




[[how-do-i-unlock-drives]]
== 드라이브 잠금을 해제하려면 어떻게 해야 합니까?

키 관리를 구성한 후 보안이 활성화된 드라이브를 한 스토리지 어레이에서 다른 스토리지 어레이로 이동하는 경우 드라이브의 암호화된 데이터에 액세스하려면 새 스토리지 어레이에 보안 키를 다시 할당해야 합니다.

자세한 정보:

* link:unlock-drives-using-an-internal-security-key.html["내부 키 관리를 사용할 때 드라이브 잠금 해제"]
* link:unlock-drives-using-an-external-security-key.html["외부 키 관리 사용 시 드라이브 잠금 해제"]
