= SANtricity System Manager에서 가져온 인증서 정보를 확인하세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
인증서 페이지에서 스토리지 어레이에 대한 인증서 유형, 발급 기관 및 인증서의 유효 날짜 범위를 확인할 수 있습니다.

.시작하기 전에
보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 인증서 관련 기능이 표시되지 않습니다.

.단계
. 메뉴:설정[인증서]를 선택합니다.
. 인증서에 대한 정보를 보려면 탭 중 하나를 선택하십시오.
+
[cols="25h,~"]
|===
| 탭 | 설명 


 a| 
어레이 관리
 a| 
루트 파일, 중간 파일 및 서버 파일을 포함하여 각 컨트롤러에 대해 가져온 CA 서명 인증서에 대한 정보를 봅니다.



 a| 
신뢰할 수 있습니다
 a| 
컨트롤러에 가져온 다른 모든 유형의 인증서에 대한 정보를 볼 수 있습니다. *다음과 같은 인증서 표시...* 아래의 필터 필드를 사용하여 사용자 설치 인증서 또는 사전 설치된 인증서를 볼 수 있습니다.

** *사용자 설치* -- 사용자가 스토리지 어레이에 업로드한 인증서로, 컨트롤러가 서버 대신 클라이언트 역할을 할 때 사용되는 신뢰할 수 있는 인증서, LDAPS 인증서 및 Identity Federation 인증서가 포함될 수 있습니다.
** *사전 설치됨* -- 스토리지 어레이에 포함된 자체 서명 인증서.




 a| 
키 관리
 a| 
외부 키 관리 서버에 가져온 CA 서명 인증서에 대한 정보를 확인합니다.

|===
