[role="lead"]
SANtricity System Manager를 구성하여 스토리지 배열 알림을 이메일, SNMP 트랩 및 syslog 메시지로 보낼 수 있습니다.



[[what-are-alerts]]
== 알림이란 무엇인가요?

_Alerts_는 스토리지 어레이에서 발생하는 중요한 이벤트에 대해 관리자에게 알립니다. 이벤트에는 배터리 장애, 최적 상태에서 오프라인 상태로 이동하는 구성 요소 또는 컨트롤러의 이중화 오류와 같은 문제가 포함될 수 있습니다. 모든 위험 이벤트는 일부 경고 및 정보 이벤트와 함께 "경고 가능"으로 간주됩니다.

자세한 정보:

* link:how-alerts-work.html["알림 작동 방식"]
* link:alerts-terminology.html["알림 용어"]




[[how-do-i-configure-alerts]]
== 알림은 어떻게 구성하나요?

알림은 하나 이상의 이메일 주소로 메시지 형태로 전송되거나, SNMP 서버로 SNMP 트랩 형태로 전송되거나, syslog 서버로 메시지 형태로 전송되도록 구성할 수 있습니다. 알림 구성은 menu:Settings[Alerts]에서 사용할 수 있습니다.

자세한 정보:

* link:configure-mail-server-and-recipients-for-alerts.html["알림을 위한 메일 서버 및 수신자 구성"]
* link:configure-syslog-server-for-alerts.html["경고에 대한 syslog 서버 구성"]
* link:configure-snmp-alerts.html["SNMP 알림 구성"]
