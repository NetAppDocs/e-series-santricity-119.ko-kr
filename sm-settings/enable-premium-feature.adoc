= SANtricity System Manager에서 프리미엄 기능을 활성화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
프리미엄 기능은 활성화하려면 키가 필요한 추가 옵션입니다.

.시작하기 전에
* 기능 키를 받았습니다. 필요한 경우 기술 지원 부서에 문의하여 키를 받으십시오.
* 관리 클라이언트(System Manager에 액세스하기 위한 브라우저가 있는 시스템)에 키 파일을 로드했습니다.


.이 작업 정보
이 작업에서는 System Manager를 사용하여 프리미엄 기능을 활성화하는 방법을 설명합니다.

[NOTE]
====
프리미엄 기능을 비활성화하려면 명령줄 인터페이스(CLI)에서 Disable Storage Array Feature 명령(`disable storageArray) (featurePack | feature=featureAttributeList`을 사용해야 합니다.

====
.단계
. 메뉴:Settings[System]를 선택합니다.
. *Add-ons*에서 *Enable Premium Feature*를 선택합니다.
+
프리미엄 기능 활성화 대화 상자가 열립니다.

. *Browse*를 클릭한 다음 키 파일을 선택합니다.
+
파일 이름이 대화 상자에 표시됩니다.

. *활성화*를 클릭합니다.
