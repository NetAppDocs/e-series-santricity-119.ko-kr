= SANtricity System Manager에서 SNMPv3 트랩용 사용자를 추가합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SNMPv3 트랩에는 최대 256명의 사용자를 추가할 수 있습니다.

.단계
. 메뉴:Settings[Alerts]를 선택합니다.
. *SNMP* 탭을 선택합니다.
+
트랩 대상과 사용자 이름이 표에 나타납니다.

. *사용자 구성*을 선택합니다.
+
SNMPv3 사용자 구성 대화 상자가 열립니다.

. *추가*를 선택합니다.
. 다음 정보를 입력한 후 *추가*를 클릭합니다.
+
** *사용자 이름* -- 사용자를 식별할 이름을 입력합니다. 최대 31자까지 입력할 수 있습니다.
** *엔진 ID* -- 메시지에 대한 인증 및 암호화 키를 생성하는 데 사용되는 엔진 ID를 선택하십시오. 이 ID는 관리 도메인 내에서 고유해야 합니다. 대부분의 경우 *Local*을 선택해야 합니다. 비표준 구성이 있는 경우 *Custom*을 선택하십시오. 그러면 권한 있는 엔진 ID를 10~32자 사이의 짝수 문자로 구성된 16진수 문자열로 입력해야 하는 다른 필드가 나타납니다.
** *인증 자격 증명* -- 사용자의 신원을 확인하는 인증 프로토콜을 선택하십시오. 다음으로, 인증 프로토콜을 설정하거나 변경할 때 필요한 인증 암호를 입력하십시오. 암호는 8자에서 128자 사이여야 합니다.
** *개인정보 보호 자격 증명* -- 메시지 내용을 암호화하는 데 사용되는 개인정보 보호 프로토콜을 선택합니다. 다음으로 개인정보 보호 프로토콜을 설정하거나 변경할 때 필요한 개인정보 보호 암호를 입력합니다. 암호는 8자에서 128자 사이여야 합니다.
