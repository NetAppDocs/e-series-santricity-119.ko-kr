= SANtricity System Manager에서 스토리지 어레이 구성을 초기화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에서 모든 풀, 볼륨 그룹, 볼륨, 호스트 정의 및 호스트 할당을 삭제하려면 Clear Configuration 작업을 사용하십시오.

.시작하기 전에
스토리지 어레이 구성을 지우기 전에 데이터를 백업하십시오.

.이 작업 정보
스토리지 어레이 구성 지우기 옵션은 두 가지가 있습니다.

* *볼륨* -- 일반적으로 볼륨 옵션은 테스트 스토리지 어레이를 운영 스토리지 어레이로 재구성하는 데 사용할 수 있습니다. 예를 들어, 테스트용으로 스토리지 어레이를 구성한 다음 테스트가 완료되면 테스트 구성을 제거하고 운영 환경용 스토리지 어레이를 설정합니다.
* *스토리지 배열* -- 일반적으로 스토리지 배열 옵션은 스토리지 배열을 다른 부서나 그룹으로 이동할 때 사용합니다. 예를 들어, 엔지니어링 팀에서 스토리지 배열을 사용 중인데 새 스토리지 배열이 추가되는 경우, 기존 스토리지 배열을 관리 팀으로 이동하여 재구성할 수 있습니다.
+
스토리지 어레이 옵션을 선택하면 일부 추가 설정이 삭제됩니다.

[CAUTION]
====
*데이터 손실 위험* -- 이 작업은 스토리지 어레이의 모든 데이터를 삭제합니다. (안전한 삭제 작업이 아닙니다.) 작업이 시작되면 취소할 수 없습니다. 기술 지원 부서에서 지시한 경우에만 이 작업을 수행하십시오.

====
.단계
. 메뉴:Settings[System]를 선택합니다.
. *Clear Storage Array Configuration*을 선택합니다.
. 드롭다운 목록에서 *볼륨* 또는 *스토리지 배열*을 선택합니다.
. *선택 사항:* 구성(데이터가 아님)을 저장하려면 대화 상자의 링크를 사용하십시오.
. 작업을 수행할 것인지 확인합니다.


.결과
* 현재 구성이 삭제되어 스토리지 어레이에 있는 기존 데이터가 모두 삭제됩니다.
* 모든 드라이브가 할당되지 않았습니다.
+

NOTE: 스토리지 어레이가 복구 모드로 시작됩니다. 스토리지 어레이를 사용하기 전에 복구 모드를 해제해야 합니다.  https://docs.netapp.com/us-en/e-series-santricity/sm-support/clear-recovery-mode.html["복구 모드 지우기"^]자세한 내용은 를 참조하십시오.
