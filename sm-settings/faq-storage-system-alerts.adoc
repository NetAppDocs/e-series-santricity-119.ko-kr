= SANtricity System Manager의 스토리지 시스템 알림 FAQ
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 FAQ는 질문에 대한 빠른 답변을 찾고 있을 때 도움이 될 수 있습니다.



== 알림이 비활성화되어 있으면 어떻게 됩니까?

스토리지 어레이에서 발생하는 중요한 이벤트에 대한 알림을 관리자가 받을 수 있도록 하려면 알림 방법을 구성해야 합니다.

SANtricity System Manager로 관리되는 스토리지 어레이의 경우 알림 페이지에서 알림을 구성합니다. 알림 알림은 이메일, SNMP 트랩 또는 syslog 메시지를 통해 전송할 수 있습니다. 또한 초기 설정 마법사에서 이메일 알림을 구성할 수 있습니다.



== SNMP 또는 syslog 알림을 구성하려면 어떻게 해야 합니까?

이메일 알림 외에도 Simple Network Management Protocol(SNMP) 트랩 또는 syslog 메시지를 통해 알림을 보내도록 구성할 수 있습니다.

SNMP 또는 syslog 알림을 구성하려면 menu:Settings[Alerts]로 이동하십시오.



== 어레이와 알림 간에 타임스탬프가 일치하지 않는 이유는 무엇입니까?

스토리지 어레이는 알림을 전송할 때 알림을 수신하는 대상 서버 또는 호스트의 시간대를 고려하지 않습니다. 대신 스토리지 어레이는 현지 시간(GMT)을 사용하여 알림 레코드에 사용되는 타임스탬프를 생성합니다. 따라서 스토리지 어레이의 타임스탬프와 알림을 수신하는 서버 또는 호스트의 타임스탬프 간에 불일치가 발생할 수 있습니다.

스토리지 어레이는 알림 전송 시 시간대를 보정하지 않으므로 알림의 타임스탬프는 GMT 기준이며, 시간대 오프셋은 0입니다. 사용자의 현지 시간대에 맞는 타임스탬프를 계산하려면 GMT와의 시간 차이를 확인한 후 해당 값을 타임스탬프에 더하거나 빼야 합니다.
