= SANtricity System Manager에서 iSCSI 검색 설정을 활성화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
iSCSI 네트워크에서 스토리지 디바이스 검색과 관련된 설정을 활성화할 수 있습니다.

대상 검색 설정을 사용하면 Internet Storage Name Service(iSNS) 프로토콜을 사용하여 스토리지 어레이의 iSCSI 정보를 등록하고 이름 없는 검색 세션을 허용할지 여부를 결정할 수 있습니다.

.시작하기 전에
iSNS 서버가 고정 IP 주소를 사용하는 경우 해당 주소는 iSNS 등록에 사용 가능해야 합니다. IPv4와 IPv6 모두 지원됩니다.

.이 작업 정보
iSCSI 검색과 관련된 다음 설정을 활성화할 수 있습니다.

* *iSNS 서버가 타겟을 등록하도록 설정* -- 활성화하면 스토리지 시스템이 iSNS 서버에 iSCSI Qualified Name(IQN) 및 포트 정보를 등록합니다. 이 설정을 사용하면 iSNS 검색이 가능하므로 이니시에이터가 iSNS 서버에서 IQN 및 포트 정보를 검색할 수 있습니다.
* *이름 없는 검색 세션 활성화* -- 이름 없는 검색 세션을 활성화하면 이니시에이터(iSCSI 호스트)는 검색 유형 연결의 로그인 시퀀스 동안 대상(컨트롤러)의 IQN을 제공할 필요가 없습니다. 비활성화하면 호스트는 컨트롤러에 대한 검색 세션을 설정하기 위해 IQN을 제공해야 합니다. 단, 일반(I/O 기반) 세션에는 대상 IQN이 항상 필요합니다. 이 설정을 비활성화하면 권한이 없는 iSCSI 호스트가 IP 주소만 사용하여 컨트롤러에 연결하는 것을 방지할 수 있습니다.


[NOTE]
====
iSCSI 설정 및 기능은 스토리지 어레이가 iSCSI를 지원하는 경우에만 설정 페이지에 표시됩니다.

====
.단계
. 메뉴:Settings[System]를 선택합니다.
. *iSCSI 설정*에서 *대상 검색 설정 보기/편집*을 클릭합니다.
+
Target Discovery Settings 대화 상자가 나타납니다. *Enable iSNS server* 필드 아래에 컨트롤러가 이미 등록되었는지 여부가 표시됩니다.

. 컨트롤러를 등록하려면 *iSNS 서버를 활성화하여 내 타겟 등록*을 선택한 다음 다음 중 하나를 선택합니다.
+
** *DHCP 서버에서 구성 자동 가져오기* -- DHCP(Dynamic Host Configuration Protocol) 서버를 사용하여 iSNS 서버를 구성하려면 이 옵션을 선택하십시오. 이 옵션을 사용하는 경우 컨트롤러의 모든 iSCSI 포트도 DHCP를 사용하도록 구성해야 합니다. 필요한 경우 컨트롤러 iSCSI 포트 설정을 업데이트하여 이 옵션을 활성화하십시오.
+
[NOTE]
====
DHCP 서버가 iSNS 서버 주소를 제공하려면 DHCP 서버를 옵션 43 -- "`Vendor Specific Information`"를 사용하도록 구성해야 합니다. 이 옵션에는 데이터 바이트 0xa-0xd(10-13)에 iSNS 서버 IPv4 주소가 포함되어야 합니다.

====
** *수동으로 정적 구성 지정* -- iSNS 서버에 대한 정적 IP 주소를 입력하려면 이 옵션을 선택하십시오. (필요한 경우 주소를 복사하여 필드에 붙여넣을 수 있습니다.) 필드에 IPv4 주소 또는 IPv6 주소를 입력하십시오. 둘 다 구성한 경우 IPv4가 기본값입니다. 또한 TCP 수신 포트를 입력하십시오(기본값 3205를 사용하거나 49152에서 65535 사이의 값을 입력하십시오).


. 스토리지 어레이가 이름 없는 검색 세션에 참여할 수 있도록 하려면 *이름 없는 검색 세션 사용*을 선택하십시오.
+
** 이 기능이 활성화되면 iSCSI 이니시에이터는 컨트롤러 정보를 검색하기 위해 타겟 IQN을 지정할 필요가 없습니다.
** 이 기능을 비활성화하면 이니시에이터가 대상 IQN을 제공하지 않는 한 검색 세션이 차단됩니다. 이름 없는 검색 세션을 비활성화하면 보안이 강화됩니다.


. *저장*을 클릭합니다.


.결과
System Manager가 iSNS 서버에 컨트롤러를 등록하는 동안 진행률 표시줄이 나타납니다. 이 프로세스는 최대 5분이 걸릴 수 있습니다.
