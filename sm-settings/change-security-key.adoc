= SANtricity System Manager에서 보안 키 변경
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
언제든지 보안 키를 새 키로 교체할 수 있습니다. 회사에 보안 침해 사고가 발생하여 권한이 없는 사람이 드라이브 데이터에 접근하지 못하도록 하려면 보안 키를 변경해야 할 수 있습니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. * 보안 키 관리 * 에서 * 키 변경 * 을 선택합니다.
+
보안 키 변경 대화 상자가 열립니다.

. 다음 필드에 정보를 입력합니다.
+
** *보안 키 식별자 정의* -- (내부 보안 키에만 해당) 기본값(스토리지 배열 이름 및 타임스탬프, 컨트롤러 펌웨어에서 생성됨)을 사용하거나 고유한 값을 입력하십시오. 공백, 구두점 또는 기호 없이 최대 189자의 영숫자를 입력할 수 있습니다.
+
[NOTE]
====
추가 문자가 자동으로 생성되어 입력한 문자열의 양쪽 끝에 추가됩니다. 생성된 문자는 식별자의 고유성을 보장하는 데 도움이 됩니다.

====
** *Define a pass phrase/Re-enter pass phrase* -- 각 필드에 암호를 입력합니다. 값은 8자에서 32자 사이여야 하며 다음 각 항목을 포함해야 합니다.
+
*** 대문자(하나 이상). 암호는 대소문자를 구분한다는 점에 유의하십시오.
*** 숫자(하나 이상).
*** !, *, @와 같은 영숫자가 아닌 문자(하나 이상).




. 외부 보안 키의 경우 새 보안 키를 생성할 때 이전 보안 키를 삭제하려면 대화 상자 하단의 "현재 보안 키 삭제..." 확인란을 선택하십시오.
+
[CAUTION]
====
*나중에 사용할 수 있도록 항목을 기록해 두십시오* -- 보안 지원 드라이브를 스토리지 어레이에서 이동해야 하는 경우 드라이브 데이터 잠금을 해제하려면 식별자와 암호를 알아야 합니다.

====
. *변경*을 클릭합니다.
+
새 보안 키가 이전 키를 덮어쓰므로 이전 키는 더 이상 유효하지 않습니다.

+
[NOTE]
====
다운로드된 파일의 경로는 브라우저의 기본 다운로드 위치에 따라 달라질 수 있습니다.

====
. 키 식별자, 암호, 다운로드한 키 파일의 위치를 기록해 둔 다음 *닫기*를 클릭하십시오.


.완료한 후
키 파일이 손상되지 않았는지 확인하려면 보안 키를 검증해야 합니다.
