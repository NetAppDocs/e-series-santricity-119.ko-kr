= SANtricity System Manager에서 iSCSI 세션을 확인하세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에 대한 iSCSI 연결에 대한 자세한 정보를 볼 수 있습니다. iSCSI 세션은 비동기식 미러 관계에서 호스트 또는 원격 스토리지 어레이와 함께 발생할 수 있습니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. *View/End iSCSI Sessions*를 선택하십시오.
+
현재 iSCSI 세션 목록이 표시됩니다.

. *선택 사항:* 특정 iSCSI 세션에 대한 추가 정보를 보려면 세션을 선택한 다음 *View Details*를 클릭하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 항목 | 설명 


 a| 
Session ID(SSID)
 a| 
iSCSI 이니시에이터와 iSCSI 타겟 간의 세션을 식별하는 16진수 문자열입니다. SSID는 ISID와 TPGT로 구성됩니다.



 a| 
이니시에이터 Session ID(ISID)
 a| 
세션 식별자의 이니시에이터 부분입니다. 이니시에이터는 로그인 중에 ISID를 지정합니다.



 a| 
타겟 포털 그룹
 a| 
iSCSI 타겟.



 a| 
타겟 포털 그룹 태그(TPGT)
 a| 
세션 식별자의 타겟 부분입니다. iSCSI 타겟 포털 그룹에 대한 16비트 숫자 식별자입니다.



 a| 
이니시에이터 iSCSI 이름
 a| 
이니시에이터의 전 세계적으로 고유한 이름입니다.



 a| 
iSCSI 이니시에이터 레이블
 a| 
System Manager에 설정된 사용자 레이블입니다.



 a| 
이니시에이터 iSCSI 별칭
 a| 
iSCSI 노드와 연결할 수 있는 이름이기도 합니다. 이 별칭을 사용하면 조직에서 iSCSI 이름과 사용자 친화적인 문자열을 연결할 수 있습니다. 그러나 별칭은 iSCSI 이름을 대체하는 것이 아닙니다. 이니시에이터 iSCSI 별칭은 호스트에서만 설정할 수 있으며 System Manager에서는 설정할 수 없습니다



 a| 
호스트
 a| 
스토리지 어레이로 입력과 출력을 보내는 서버입니다.



 a| 
Connection ID(CID)
 a| 
이니시에이터와 타겟 간의 세션 내 연결에 부여되는 고유 이름입니다. 이니시에이터는 이 ID를 생성하여 로그인 요청 시 타겟에게 제공합니다. 연결 ID는 연결을 종료하는 로그아웃 시에도 제공됩니다.



 a| 
포트 식별자
 a| 
연결과 연결된 컨트롤러 포트입니다.



 a| 
이니시에이터 IP 주소
 a| 
이니시에이터의 IP 주소입니다.



 a| 
협상된 로그인 매개 변수
 a| 
iSCSI 세션 로그인 중에 처리되는 매개 변수입니다.



 a| 
인증 방법
 a| 
iSCSI 네트워크에 액세스하려는 사용자를 인증하는 기술입니다. 유효한 값은 *CHAP* 및 *None*입니다.



 a| 
헤더 다이제스트 방법
 a| 
iSCSI 세션의 가능한 헤더 값을 보여주는 기법입니다. HeaderDigest와 DataDigest는 *None* 또는 *CRC32C*일 수 있습니다. 두 값 모두 기본값은 *None*입니다.



 a| 
데이터 다이제스트 방법
 a| 
iSCSI 세션에 대한 가능한 데이터 값을 표시하는 기법입니다. HeaderDigest와 DataDigest는 *None* 또는 *CRC32C*일 수 있습니다. 두 값 모두 기본값은 *None*입니다.



 a| 
최대 연결 수
 a| 
iSCSI 세션에 허용되는 최대 연결 수입니다. 최대 연결 수는 1에서 4까지 가능합니다. 기본값은 *1*입니다.



 a| 
타겟 별칭
 a| 
타겟과 연결된 레이블입니다.



 a| 
이니시에이터 별칭
 a| 
이니시에이터와 관련된 레이블입니다.



 a| 
타겟 IP 주소
 a| 
iSCSI 세션의 타겟 IP 주소입니다. DNS 이름은 지원되지 않습니다.



 a| 
초기 R2T
 a| 
초기 전송 준비 상태입니다. 상태는 *Yes* 또는 *No*일 수 있습니다.



 a| 
최대 버스트 길이
 a| 
이 iSCSI 세션에 대한 최대 SCSI 페이로드(바이트)입니다. 최대 버스트 길이는 512에서 262,144(256 KB)까지 가능합니다. 기본값은 *262,144 (256 KB)*입니다.



 a| 
첫 번째 버스트 길이
 a| 
이 iSCSI 세션에 대한 비요청 데이터의 SCSI 페이로드(바이트)입니다. 첫 번째 버스트 길이는 512에서 131,072(128 KB) 사이일 수 있습니다. 기본값은 *65,536(64 KB)*입니다.



 a| 
기본 대기 시간
 a| 
연결이 종료되거나 연결이 재설정된 후 연결을 시도하기 전에 대기하는 최소 시간(초)입니다. 기본 대기 시간 값은 0에서 3600 사이입니다. 기본값은 *2*입니다.



 a| 
기본 보존 기간
 a| 
연결이 종료되거나 재설정된 후에도 연결이 가능한 최대 시간(초)입니다. 기본 유지 시간은 0에서 3600 사이입니다. 기본값은 *20*입니다.



 a| 
최대 미해결 R2T
 a| 
이 iSCSI 세션에 대해 대기 중인 "전송 준비" 항목의 최대 개수입니다. 대기 중인 전송 준비 최대값은 1에서 16까지입니다. 기본값은 *1*입니다.



 a| 
오류 복구 수준
 a| 
이 iSCSI 세션의 오류 복구 수준입니다. 오류 복구 수준 값은 항상 *0*으로 설정됩니다.



 a| 
최대 수신 데이터 세그먼트 길이
 a| 
iSCSI 페이로드 데이터 단위(PDU)에서 이니시에이터 또는 타겟이 수신할 수 있는 최대 데이터 양입니다.



 a| 
타겟 이름
 a| 
타겟의 공식 명칭(별칭 아님). _iqn_ 형식의 타겟 이름입니다.



 a| 
이니시에이터 이름
 a| 
이니시에이터의 공식 이름(별칭이 아님). _iqn_ 또는 _eui_ 형식을 사용하는 이니시에이터 이름입니다.

|===
====
. *선택 사항:* 보고서를 파일에 저장하려면 *저장*을 클릭합니다.
+
파일은 브라우저의 다운로드 폴더에 파일 이름 `iscsi-session-connections.txt`으로 저장됩니다.
