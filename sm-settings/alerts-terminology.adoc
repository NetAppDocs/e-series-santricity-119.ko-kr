= SANtricity 소프트웨어의 알림 용어에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
알림 용어가 스토리지 어레이에 어떻게 적용되는지 알아보십시오.

[cols="25h,~"]
|===
| 구성 요소 | 설명 


 a| 
이벤트 모니터
 a| 
이벤트 모니터는 스토리지 어레이에 상주하며 백그라운드 작업으로 실행됩니다. 이벤트 모니터는 스토리지 어레이에서 이상 징후를 감지하면 해당 문제에 대한 정보를 이벤트 로그에 기록합니다. 문제에는 배터리 오류, 구성 요소가 최적 상태에서 오프라인 상태로 전환되는 경우, 컨트롤러의 이중화 오류 등의 이벤트가 포함될 수 있습니다. 이벤트 모니터는 해당 이벤트가 "경고 대상"이라고 판단되면 구성된 경고 방식(이메일, SNMP 및/또는 syslog)을 사용하여 알림을 전송합니다. 모든 중요 이벤트는 물론 일부 경고 및 정보 이벤트도 "경고 대상"으로 간주됩니다.



 a| 
메일 서버
 a| 
메일 서버는 이메일 알림을 보내고 받는 데 사용됩니다. 이 서버는 Simple Mail Transfer Protocol(SMTP)를 사용합니다.



 a| 
SNMP
 a| 
SNMP(Simple Network Management Protocol)는 IP 네트워크의 디바이스 간에 정보를 관리하고 공유하는 데 사용되는 인터넷 표준 프로토콜입니다.



 a| 
SNMP 트랩
 a| 
SNMP 트랩은 SNMP 서버로 전송되는 알림입니다. 이 트랩에는 스토리지 어레이의 중요한 문제에 대한 정보가 포함되어 있습니다.



 a| 
SNMP 트랩 대상
 a| 
SNMP 트랩 대상은 SNMP 서비스를 실행하는 서버의 IPv4 또는 IPv6 주소입니다.



 a| 
커뮤니티 이름
 a| 
커뮤니티 이름은 SNMP 환경에서 네트워크 서버에 대한 암호처럼 작동하는 문자열입니다.



 a| 
MIB 파일
 a| 
MIB(관리 정보 베이스) 파일은 스토리지 어레이에서 모니터링 및 관리되는 데이터를 정의합니다. 이 파일은 SNMP 서비스 애플리케이션이 설치된 서버에 복사하여 컴파일해야 합니다. 이 MIB 파일은 지원 사이트의 System Manager 소프트웨어와 함께 사용할 수 있습니다.



 a| 
MIB 변수
 a| 
관리 정보 베이스(MIB) 변수는 SNMP GetRequests에 대한 응답으로 스토리지 배열 이름, 배열 위치 및 담당자와 같은 값을 반환할 수 있습니다.



 a| 
Syslog
 a| 
Syslog는 네트워크 장치가 이벤트 메시지를 로깅 서버로 전송하는 데 사용하는 프로토콜입니다.



 a| 
UDP
 a| 
User Datagram Protocol(UDP)은 패킷 헤더에 소스 및 대상 포트 번호를 지정하는 전송 계층 프로토콜입니다.

|===
