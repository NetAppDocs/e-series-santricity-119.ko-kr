= SANtricity System Manager에서 새 볼륨 그룹 또는 풀에 대한 리소스 프로비저닝을 활성화 또는 비활성화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이전에 리소스 프로비저닝에 대한 기본 기능을 비활성화한 경우, 새로 생성하는 모든 SSD 볼륨 그룹 또는 풀에 대해 해당 기능을 다시 활성화할 수 있습니다. 또한 설정을 다시 비활성화할 수도 있습니다.

리소스 프로비저닝은 EF300 및 EF600 스토리지 어레이에서 사용할 수 있는 기능으로, 백그라운드 초기화 프로세스 없이 볼륨을 즉시 사용할 수 있도록 합니다. 볼륨에 할당된 모든 드라이브 블록은 할당 해제(매핑 해제)되므로 SSD 수명을 연장하고 최대 쓰기 성능을 향상시킬 수 있습니다.


NOTE: 기본적으로 리소스 프로비저닝은 드라이브가 DULBE를 지원하는 시스템에서 활성화됩니다.

.시작하기 전에
* EF300 또는 EF600 스토리지 시스템이 있어야 합니다.
* 모든 드라이브가 NVMe Deallocated 또는 Unwritten Logical Block Error Enable(DULBE) 오류 복구 기능을 지원하는 SSD 볼륨 그룹 또는 풀이 있어야 합니다.
+

NOTE: 현재 EF300C 또는 EF600C 스토리지 어레이에서는 DULBE가 지원되지 않습니다.



.이 작업 정보
새 볼륨 그룹 또는 풀에 대해 리소스 프로비저닝을 다시 활성화하면 새로 생성된 볼륨 그룹 및 풀에만 적용됩니다. 리소스 프로비저닝이 활성화된 기존 볼륨 그룹 및 풀은 변경되지 않습니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. 아래로 스크롤하여 *Additional Settings*를 찾은 다음 *Enable/Disable Resource-Provisioned Volumes*를 클릭합니다.
+
설정 설명에는 리소스 프로비저닝이 현재 활성화되어 있는지 비활성화되어 있는지 여부가 표시됩니다.

. 대화 상자에서 작업을 확인합니다.


.결과
리소스 프로비저닝을 활성화 또는 비활성화하면 새로 생성하는 SSD 풀 또는 볼륨 그룹에만 영향을 줍니다. 기존 풀 또는 볼륨 그룹은 변경되지 않습니다.
