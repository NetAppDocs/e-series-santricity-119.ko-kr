= SANtricity System Manager에서 감사 로그 레코드에 대한 syslog 서버 설정을 편집합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
감사 로그 보관에 사용되는 syslog 서버의 설정을 변경하고 서버에 사용할 새 CA(인증 기관) 인증서를 업로드할 수 있습니다.

.시작하기 전에
* 보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 액세스 관리 기능이 표시되지 않습니다.
* syslog 서버 주소, 프로토콜 및 포트 번호를 사용할 수 있어야 합니다. 서버 주소는 정규화된 도메인 이름, IPv4 주소 또는 IPv6 주소일 수 있습니다.
* 새 CA 인증서를 업로드하는 경우 해당 인증서가 로컬 시스템에 있어야 합니다.


.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. 감사 로그 탭에서 * Syslog 서버 구성 * 을 선택합니다.
+
구성된 syslog 서버가 페이지에 표시됩니다.

. 서버 정보를 편집하려면 서버 이름 오른쪽에 있는 *편집*(연필) 아이콘을 선택한 다음 다음 필드에서 원하는 내용을 변경하십시오.
+
** *서버 주소* -- 정규화된 도메인 이름, IPv4 주소 또는 IPv6 주소를 입력합니다.
** *프로토콜* -- 드롭다운 목록에서 프로토콜을 선택합니다(예: TLS, UDP 또는 TCP).
** *포트* -- syslog 수신기에 사용할 포트 번호를 입력하십시오.


. 프로토콜을 UDP 또는 TCP에서 보안 TLS 프로토콜로 변경한 경우 *신뢰할 수 있는 인증서 가져오기*를 클릭하여 CA 인증서를 업로드합니다.
. 스토리지 어레이와의 새 연결을 테스트하려면 *Test All*을 선택하십시오.


.결과
구성 후 모든 새 감사 로그는 syslog 서버로 전송됩니다. 이전 로그는 전송되지 않습니다.
