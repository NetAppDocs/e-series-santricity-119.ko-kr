= SANtricity System Manager에서 기능 팩을 활성화합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기능 팩은 스토리지 어레이 속성을 변경하는 번들입니다(예: 프로토콜을 Fibre Channel에서 iSCSI로 변경). 기능 팩을 활성화하려면 특수 키가 필요합니다.

.시작하기 전에
* 새로운 스토리지 어레이 속성에 대한 변환 및 준비를 설명하는 적절한 지침을 따랐습니다. 호스트 프로토콜 변환 지침은 컨트롤러 모델의 하드웨어 유지 관리 가이드를 참조하십시오.
* 스토리지 어레이가 오프라인 상태이므로 호스트나 애플리케이션이 해당 어레이에 액세스하지 않습니다.
* 모든 데이터가 백업됩니다.
* 기능 팩 파일을 얻었습니다.
+
기능 팩 파일은 관리 클라이언트(System Manager에 액세스하기 위한 브라우저가 있는 시스템)에 로드됩니다.



[NOTE]
====
다운타임 유지보수 윈도우를 예약하고 호스트와 컨트롤러 간의 모든 I/O 작업을 중지해야 합니다. 또한 변환이 성공적으로 완료될 때까지 스토리지 어레이의 데이터에 액세스할 수 없다는 점에 유의하십시오.

====
.이 작업 정보
이 작업에서는 System Manager를 사용하여 기능 팩을 활성화하는 방법을 설명합니다. 작업이 완료되면 스토리지 어레이를 다시 시작해야 합니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. *Add-ons*에서 *Change Feature Pack*을 선택합니다.
. *Browse*를 클릭한 다음 키 파일을 선택합니다.
+
파일 이름이 대화 상자에 표시됩니다.

. 필드에  `change`을(를) 입력합니다.
. *변경*을 클릭합니다.
+
기능 팩 마이그레이션이 시작되고 컨트롤러가 재부팅됩니다. 기록되지 않은 캐시 데이터가 삭제되어 I/O 활동이 발생하지 않습니다. 새 기능 팩이 적용되도록 두 컨트롤러 모두 자동으로 재부팅됩니다. 재부팅이 완료되면 스토리지 어레이가 정상 응답 상태로 돌아갑니다.
