= SANtricity System Manager에서 보안 키를 검증합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보안 키가 손상되지 않았는지 확인하고 올바른 암호를 가지고 있는지 검증하기 위해 보안 키를 검증할 수 있습니다.

.이 작업 정보
이 작업에서는 이전에 생성한 보안 키를 검증하는 방법을 설명합니다. 이 단계는 키 파일이 손상되지 않았는지, 암호가 올바른지 확인하는 데 중요합니다. 이를 통해 보안이 활성화된 드라이브를 한 스토리지 어레이에서 다른 스토리지 어레이로 이동할 경우에도 드라이브 데이터에 액세스할 수 있습니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. *보안 키 관리*에서 *키 유효성 검사*를 선택하십시오.
+
보안 키 유효성 검사 대화 상자가 열립니다.

. * 찾아보기 * 를 클릭한 다음 키 파일(예: `drivesecurity.slk`)을 선택합니다.
. 선택한 키와 연결된 암호를 입력하십시오.
+
유효한 키 파일과 암호를 선택하면 *유효성 검사* 버튼을 사용할 수 있습니다.

. *검증*을 클릭합니다.
+
유효성 검사 결과는 대화 상자에 표시됩니다.

. 결과에 "보안 키가 성공적으로 유효성 검사를 통과했습니다"라는 메시지가 표시되면 *닫기*를 클릭하십시오. 오류 메시지가 나타나면 대화 상자에 표시된 지침을 따르십시오.
