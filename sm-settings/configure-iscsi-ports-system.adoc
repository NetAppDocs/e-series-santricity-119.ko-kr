= SANtricity System Manager에서 iSCSI 포트를 구성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
컨트롤러에 iSCSI 호스트 연결이 포함된 경우 시스템 페이지에서 iSCSI 포트 설정을 구성할 수 있습니다.

.시작하기 전에
* 컨트롤러에 iSCSI 포트가 있어야 합니다. 그렇지 않으면 iSCSI 설정을 사용할 수 없습니다.
* 네트워크 속도(포트와 호스트 간의 데이터 전송 속도)를 알아야 합니다.


[NOTE]
====
iSCSI 설정 및 기능은 스토리지 어레이가 iSCSI를 지원하는 경우에만 나타납니다.

====
.단계
. 메뉴:Settings[System]를 선택합니다.
. *iSCSI 설정*에서 *iSCSI 포트 구성*을 선택하십시오.
+
[NOTE]
====
Configure iSCSI Ports 옵션은 System Manager가 컨트롤러에서 iSCSI 포트를 감지한 경우에만 나타납니다.

====
. 구성하려는 iSCSI 포트가 있는 컨트롤러를 선택하십시오.
. 드롭다운 목록에서 구성할 포트를 선택한 다음 * Next * 를 클릭합니다.
. 구성 포트 설정을 선택한 다음 *다음*을 클릭합니다.
+
모든 포트 설정을 보려면 대화 상자 오른쪽에 있는 *더 많은 포트 설정 표시* 링크를 클릭하십시오.

+
.필드 세부 정보
[%collapsible]
====
[cols="1a,1a"]
|===
| 포트 설정 | 설명 


 a| 
구성된 이더넷 포트 속도(특정 유형의 호스트 인터페이스 카드에만 표시됨)
 a| 
포트의 SFP 속도 기능과 일치하는 속도를 선택합니다.



 a| 
순방향 오류 수정(FEC) 모드(특정 유형의 호스트 인터페이스 카드에만 표시됨)
 a| 
원하는 경우 지정된 호스트 포트에 대해 FEC 모드 중 하나를 선택하십시오.


NOTE: Reed Solomon 모드는 25Gbps 포트 속도를 지원하지 않습니다.



 a| 
IPv4 활성화 / IPv6 활성화
 a| 
IPv4 및 IPv6 네트워크에 대한 지원을 활성화하려면 하나 또는 두 옵션을 모두 선택합니다.


NOTE: 포트 액세스를 비활성화하려면 두 확인란의 선택을 모두 해제하십시오.



 a| 
TCP 수신 포트(*더 많은 포트 설정 표시*를 클릭하면 사용 가능)
 a| 
필요한 경우 새 포트 번호를 입력합니다.

수신 포트는 컨트롤러가 호스트 iSCSI 이니시에이터의 iSCSI 로그인 요청을 수신 대기하는 데 사용하는 TCP 포트 번호입니다. 기본 수신 포트는 3260입니다. 3260 또는 49152에서 65535 사이의 값을 입력해야 합니다.



 a| 
MTU 크기(*더 많은 포트 설정 보기*를 클릭하면 확인할 수 있습니다.)
 a| 
필요한 경우 Maximum Transmission Unit(MTU)의 새 크기를 바이트 단위로 입력하십시오.

기본 최대 전송 단위(MTU) 크기는 프레임당 1500바이트입니다. 1500에서 9000 사이의 값을 입력해야 합니다.



 a| 
ICMP PING 응답 활성화
 a| 
이 옵션을 선택하면 인터넷 제어 메시지 프로토콜(ICMP)이 활성화됩니다. 네트워크로 연결된 컴퓨터의 운영 체제는 이 프로토콜을 사용하여 메시지를 전송합니다. 이러한 ICMP 메시지를 통해 호스트에 연결할 수 있는지 여부와 해당 호스트로 패킷을 주고받는 데 걸리는 시간을 확인할 수 있습니다.

|===
====
+
*Enable IPv4*를 선택한 경우 *Next*를 클릭하면 IPv4 설정을 선택하는 대화 상자가 열립니다. *Enable IPv6*을 선택한 경우 *Next*를 클릭하면 IPv6 설정을 선택하는 대화 상자가 열립니다. 두 옵션을 모두 선택한 경우 IPv4 설정 대화 상자가 먼저 열리고 *Next*를 클릭하면 IPv6 설정 대화 상자가 열립니다.

. IPv4 및/또는 IPv6 설정을 자동으로 또는 수동으로 구성하십시오. 모든 포트 설정을 보려면 대화 상자 오른쪽의 *추가 설정 표시* 링크를 클릭하십시오.
+
.필드 세부 정보
[%collapsible]
====
[cols="1a,1a"]
|===
| 포트 설정 | 설명 


 a| 
자동으로 구성 가져오기
 a| 
구성을 자동으로 가져오려면 이 옵션을 선택하십시오.



 a| 
정적 구성을 수동으로 지정합니다
 a| 
이 옵션을 선택한 다음 필드에 고정 주소를 입력하십시오. (원하는 경우 주소를 복사하여 필드에 붙여넣을 수 있습니다.) IPv4의 경우 네트워크 서브넷 마스크와 게이트웨이를 포함합니다. IPv6의 경우 라우팅 가능한 IP 주소와 라우터 IP 주소를 포함합니다.



 a| 
VLAN 지원 활성화(*더 많은 설정 표시*를 클릭하면 사용 가능)
 a| 
VLAN을 활성화하려면 이 옵션을 선택하고 VLAN ID를 입력하십시오. VLAN은 동일한 스위치, 라우터 또는 둘 다에서 지원하는 다른 물리적 및 가상 근거리 통신망(LAN)과 물리적으로 분리된 것처럼 동작하는 논리적 네트워크입니다.



 a| 
이더넷 우선 순위를 활성화합니다(*추가 설정 표시*를 클릭하면 사용 가능).
 a| 
이 옵션을 선택하면 네트워크 액세스 우선 순위를 결정하는 매개 변수가 활성화됩니다. 슬라이더를 사용하여 1(최저)에서 7(최고) 사이의 우선 순위를 선택합니다.

이더넷과 같은 공유 근거리 통신망(LAN) 환경에서는 여러 스테이션이 네트워크 액세스를 위해 경쟁할 수 있습니다. 액세스는 선착순으로 이루어집니다. 두 스테이션이 동시에 네트워크에 액세스하려고 하면 두 스테이션 모두 백오프하고 다시 시도하기 전에 대기합니다. 이 프로세스는 스위치드 이더넷에서 최소화되며, 여기서는 하나의 스테이션만 스위치 포트에 연결됩니다.

|===
====
. *완료*를 클릭합니다.
