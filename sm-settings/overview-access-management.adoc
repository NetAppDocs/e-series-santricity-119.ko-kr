= SANtricity System Manager의 액세스 관리에 대해 알아보세요
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Access Management는 SANtricity System Manager에서 사용자 인증을 설정하는 방법입니다.



== 사용 가능한 인증 방법에는 어떤 것들이 있습니까?

인증 방법에는 RBAC(역할 기반 액세스 제어), Directory Services 및 SAML(Security Assertion Markup Language)이 포함됩니다.

* *RBAC/로컬 사용자 역할* -- 인증은 스토리지 어레이에 적용된 RBAC 기능을 통해 관리됩니다. 로컬 사용자 역할에는 특정 액세스 권한이 있는 사전 정의된 사용자 프로필 및 역할이 포함됩니다.
* *디렉터리 서비스* -- 인증은 LDAP(Lightweight Directory Access Protocol) 서버와 Microsoft의 Active Directory와 같은 디렉터리 서비스를 통해 관리됩니다.
* *SAML* -- 인증은 SAML 2.0을 사용하는 ID 공급자(IdP)를 통해 관리됩니다.

== 인증은 어떻게 구성하나요?

스토리지 어레이는 RBAC 기능의 구현인 로컬 사용자 역할을 사용하도록 사전 구성되어 있습니다. 다른 방법을 구성하려면 메뉴:설정[액세스 관리]로 이동하십시오.
