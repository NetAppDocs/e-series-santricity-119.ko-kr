= SANtricity System Manager에서 알림에 대한 이메일 주소를 편집합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이메일 알림을 받는 수신자의 이메일 주소를 변경할 수 있습니다.

.시작하기 전에
편집하려는 이메일 주소는 알림 페이지의 이메일 탭에 정의되어 있어야 합니다.

.단계
. 메뉴:Settings[Alerts]를 선택합니다.
. *Email* 탭을 선택합니다.
. *이메일 주소* 표에서 변경하려는 주소를 선택한 다음 맨 오른쪽에 있는 *편집*(연필) 아이콘을 클릭합니다.
+
해당 행은 편집 가능한 필드가 됩니다.

. 새 주소를 입력한 다음 *저장*(확인 표시) 아이콘을 클릭합니다.
+
[NOTE]
====
변경 사항을 취소하려면 *취소*(X) 아이콘을 선택합니다.

====


.결과
알림 페이지의 이메일 탭에는 업데이트된 이메일 주소가 표시됩니다.
