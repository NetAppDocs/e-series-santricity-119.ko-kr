= SANtricity System Manager에서 디렉터리 서버 설정 및 역할 매핑을 편집합니다.
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Access Management에서 디렉터리 서버를 이전에 구성한 경우 언제든지 설정을 변경할 수 있습니다. 설정에는 서버 연결 정보와 그룹-역할 매핑이 포함됩니다.

.시작하기 전에
* 보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 액세스 관리 기능이 표시되지 않습니다.
* 디렉터리 서버를 정의해야 합니다.


.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. *디렉터리 서비스* 탭을 선택합니다.
. 서버가 두 개 이상 정의된 경우 표에서 편집할 서버를 선택하십시오.
. *View/Edit Settings*를 선택합니다.
+
디렉터리 서버 설정 대화 상자가 열립니다.

. 서버 설정 탭에서 원하는 설정을 변경합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
*구성 설정*



 a| 
도메인
 a| 
LDAP 서버의 도메인 이름입니다. 도메인이 여러 개인 경우 쉼표로 구분된 목록으로 도메인을 입력하십시오. 도메인 이름은 로그인(_username_@_domain_)에서 인증할 디렉터리 서버를 지정하는 데 사용됩니다.



 a| 
서버 URL
 a| 
LDAP 서버에 액세스하기 위한 URL은 다음과 같은 형식입니다 `ldap[s]://host:port`.



 a| 
계정 바인딩(선택 사항)
 a| 
LDAP 서버에 대한 검색 쿼리 및 그룹 내 검색을 위한 읽기 전용 사용자 계정입니다.



 a| 
바인드 암호(선택 사항)
 a| 
바인드 계정의 암호입니다. (이 필드는 바인드 계정을 입력할 때 나타납니다.)



 a| 
저장하기 전에 서버 연결 테스트
 a| 
스토리지 어레이가 LDAP 서버 구성과 통신할 수 있는지 확인합니다. 이 테스트는 대화 상자 하단의 *저장*을 클릭한 후에 실행됩니다. 이 확인란을 선택한 상태에서 테스트에 실패하면 구성이 변경되지 않습니다. 오류를 해결하거나 이 확인란을 선택 해제하여 테스트를 건너뛰고 구성을 다시 편집해야 합니다.



 a| 
*권한 설정*



 a| 
검색 기본 DN
 a| 
사용자를 검색하기 위한 LDAP 컨텍스트는 일반적으로  `CN=Users, DC=cpoc, DC=local` 형식입니다.



 a| 
사용자 이름 속성
 a| 
인증을 위해 사용자 ID에 연결된 속성입니다. 예를 들면 다음과 같습니다. `sAMAccountName`.



 a| 
그룹 속성
 a| 
사용자의 그룹 속성 목록으로, 그룹과 역할 간의 매핑에 사용됩니다. 예를 들면 다음과 같습니다. `memberOf, managedObjects`.

|===
====
. 역할 매핑 탭에서 원하는 매핑을 변경합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
*매핑*



 a| 
그룹 DN
 a| 
매핑할 LDAP 사용자 그룹의 도메인 이름입니다. 정규 표현식이 지원됩니다. 다음 특수 정규 표현식 문자는 정규 표현식 패턴의 일부가 아닌 경우 백슬래시(`\`로 이스케이프해야 합니다: \.[{}()<>*+-=!?^$|



 a| 
역할
 a| 
그룹 DN에 매핑할 스토리지 어레이의 역할입니다. 이 그룹에 포함할 각 역할을 개별적으로 선택해야 합니다. SANtricity System Manager에 로그인하려면 Monitor 역할이 다른 역할과 함께 필요합니다. 스토리지 어레이의 역할은 다음과 같습니다.

** *Storage admin* -- 스토리지 객체(예: 볼륨 및 디스크 풀)에 대한 전체 읽기/쓰기 액세스 권한이 있지만 보안 구성에 대한 액세스 권한은 없습니다.
** *보안 관리자* -- Access Management의 보안 구성, 인증서 관리, 감사 로그 관리 및 레거시 관리 인터페이스(SYMbol)를 켜거나 끌 수 있는 기능에 대한 액세스 권한.
** *지원 관리자* -- 스토리지 어레이의 모든 하드웨어 리소스, 장애 데이터, MEL 이벤트 및 컨트롤러 펌웨어 업그레이드에 액세스할 수 있습니다. 스토리지 객체 또는 보안 구성에 대한 액세스 권한이 없습니다.
** *모니터* -- 모든 스토리지 객체에 대한 읽기 전용 액세스 권한이 있지만 보안 구성에 대한 액세스 권한은 없습니다.


|===
====
+
[NOTE]
====
관리자를 포함한 모든 사용자에게 Monitor 역할이 필요합니다. Monitor 역할이 없으면 System Manager가 어떤 사용자에 대해서도 올바르게 작동하지 않습니다.

====
. 원하는 경우 *Add another mapping*을 클릭하여 그룹-역할 매핑을 더 입력할 수 있습니다.
. *저장*을 클릭합니다.


.결과
이 작업을 완료하면 활성 사용자 세션이 모두 종료됩니다. 현재 사용자 세션만 유지됩니다.
