= SANtricity System Manager에 LDAP 디렉터리 서버를 추가합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
액세스 관리용 인증을 구성하려면 스토리지 어레이와 LDAP 서버 간의 통신을 설정한 다음 LDAP 사용자 그룹을 어레이의 사전 정의된 역할에 매핑하면 됩니다.

.시작하기 전에
* 보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 액세스 관리 기능이 표시되지 않습니다.
* 사용자 그룹은 디렉터리 서비스에 정의되어 있어야 합니다.
* 도메인 이름, 서버 URL, 그리고 선택적으로 바인드 계정 사용자 이름과 암호를 포함한 LDAP 서버 자격 증명을 사용할 수 있어야 합니다.
* 보안 프로토콜을 사용하는 LDAPS 서버의 경우, LDAP 서버의 인증서 체인이 로컬 컴퓨터에 설치되어 있어야 합니다.


.이 작업 정보
디렉터리 서버를 추가하는 과정은 두 단계로 이루어집니다. 먼저 도메인 이름과 URL을 입력합니다. 서버에서 보안 프로토콜을 사용하는 경우, 표준 서명 기관이 아닌 곳에서 서명한 CA 인증서를 업로드하여 인증해야 합니다. 바인드 계정에 대한 자격 증명이 있는 경우 사용자 계정 이름과 암호를 입력할 수도 있습니다. 다음으로 LDAP 서버의 사용자 그룹을 스토리지 어레이의 사전 정의된 역할에 매핑합니다.

[NOTE]
====
LDAP 서버를 추가하는 절차 중에 기존 관리 인터페이스가 비활성화됩니다. 기존 관리 인터페이스(SYMbol)는 스토리지 어레이와 관리 클라이언트 간의 통신 방식입니다. 이 인터페이스가 비활성화되면 스토리지 어레이와 관리 클라이언트는 더욱 안전한 통신 방식(https를 통한 REST API)을 사용합니다.

====
.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. 디렉터리 서비스 탭에서 *디렉터리 서버 추가*를 선택합니다.
+
디렉터리 서버 추가 대화 상자가 열립니다.

. 서버 설정 탭에서 LDAP 서버에 대한 자격 증명을 입력합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
*구성 설정*



 a| 
도메인
 a| 
LDAP 서버의 도메인 이름을 입력합니다. 도메인이 여러 개인 경우 쉼표로 구분된 목록으로 도메인을 입력합니다. 도메인 이름은 로그인(_username_@_domain_)에서 인증할 디렉터리 서버를 지정하는 데 사용됩니다.



 a| 
서버 URL
 a| 
LDAP 서버에 액세스하기 위한 URL을  `ldap[s]://*host*:*port*` 형식으로 입력합니다.



 a| 
인증서 업로드(선택 사항)
 a| 

NOTE: 이 필드는 위의 서버 URL 필드에 LDAPS 프로토콜이 지정된 경우에만 나타납니다.

*찾아보기*를 클릭하고 업로드할 CA 인증서를 선택합니다. LDAP 서버 인증에 사용되는 신뢰할 수 있는 인증서 또는 인증서 체인입니다.



 a| 
계정 바인딩(선택 사항)
 a| 
LDAP 서버에 대한 검색 쿼리 및 그룹 내 검색을 위한 읽기 전용 사용자 계정을 입력합니다. LDAP 유형 형식으로 계정 이름을 입력합니다. 예를 들어, 바인드 사용자가 "bindacct"인 경우 "CN=bindacct,CN=Users,DC=cpoc,DC=local"과 같은 값을 입력할 수 있습니다.



 a| 
바인드 암호(선택 사항)
 a| 

NOTE: 이 필드는 위에 바인드 계정을 입력할 때 나타납니다.

바인드 계정의 암호를 입력합니다.



 a| 
추가하기 전에 서버 연결을 테스트합니다
 a| 
입력한 LDAP 서버 구성과 스토리지 어레이가 통신할 수 있는지 확인하려면 이 확인란을 선택하십시오. 테스트는 대화 상자 하단의 *추가*를 클릭한 후에 실행됩니다. 이 확인란을 선택한 상태에서 테스트에 실패하면 구성이 추가되지 않습니다. 오류를 해결하거나 확인란을 선택 해제하여 테스트를 건너뛰고 구성을 추가해야 합니다.



 a| 
**권한 설정**



 a| 
검색 기본 DN
 a| 
사용자를 검색할 LDAP 컨텍스트를 입력합니다. 일반적으로 `CN=Users, DC=cpoc, DC=local` 형식입니다.



 a| 
사용자 이름 속성
 a| 
인증을 위해 사용자 ID에 연결된 속성을 입력하십시오. 예: `sAMAccountName`.



 a| 
그룹 속성\(s\)
 a| 
그룹-역할 매핑에 사용되는 사용자 그룹 속성 목록을 입력하십시오. 예: `memberOf, managedObjects`.

|===
====
. **역할 매핑** 탭을 클릭합니다.
. LDAP 그룹을 미리 정의된 역할에 할당합니다. 하나의 그룹에는 여러 개의 역할을 할당할 수 있습니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
*매핑*



 a| 
그룹 DN
 a| 
매핑할 LDAP 사용자 그룹의 그룹 고유 이름(DN)을 지정합니다. 정규 표현식이 지원됩니다. 다음 특수 정규 표현식 문자는 정규 표현식 패턴의 일부가 아닌 경우 백슬래시(`\`로 이스케이프해야 합니다: \.[]{}()<>*+-=!?^$|



 a| 
역할
 a| 
해당 필드를 클릭하고 그룹 DN에 매핑할 스토리지 어레이의 역할 중 하나를 선택하십시오. 이 그룹에 포함할 각 역할은 개별적으로 선택해야 합니다. SANtricity System Manager에 로그인하려면 모니터 역할이 다른 역할과 함께 필요합니다. 매핑된 역할에는 다음과 같은 권한이 포함됩니다.

** *Storage admin* -- 스토리지 객체(예: 볼륨 및 디스크 풀)에 대한 전체 읽기/쓰기 액세스 권한이 있지만 보안 구성에 대한 액세스 권한은 없습니다.
** *보안 관리자* -- Access Management의 보안 구성, 인증서 관리, 감사 로그 관리 및 레거시 관리 인터페이스(SYMbol)를 켜거나 끌 수 있는 기능에 대한 액세스 권한.
** *지원 관리자* -- 스토리지 어레이의 모든 하드웨어 리소스, 장애 데이터, MEL 이벤트 및 컨트롤러 펌웨어 업그레이드에 액세스할 수 있습니다. 스토리지 객체 또는 보안 구성에 대한 액세스 권한이 없습니다.
** *모니터* -- 모든 스토리지 객체에 대한 읽기 전용 액세스 권한이 있지만 보안 구성에 대한 액세스 권한은 없습니다.


|===
====
+
[NOTE]
====
관리자를 포함한 모든 사용자에게 Monitor 역할이 필요합니다. Monitor 역할이 없으면 System Manager가 어떤 사용자에 대해서도 올바르게 작동하지 않습니다.

====
. 원하는 경우 *Add another mapping*을 클릭하여 그룹-역할 매핑을 더 입력할 수 있습니다.
. 매핑을 완료했으면 * 추가 * 를 클릭합니다.
+
시스템은 스토리지 어레이와 LDAP 서버 간의 통신이 가능한지 확인하는 유효성 검사를 수행합니다. 오류 메시지가 나타나면 대화 상자에 입력한 자격 증명을 확인하고 필요한 경우 다시 입력하십시오.
