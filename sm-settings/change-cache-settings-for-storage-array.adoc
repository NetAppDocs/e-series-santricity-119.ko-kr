= SANtricity System Manager에서 스토리지 어레이 캐시 설정을 변경합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이의 모든 볼륨에 대해 플러싱 및 블록 크기에 대한 캐시 메모리 설정을 조정할 수 있습니다.

.이 작업 정보
캐시 메모리는 컨트롤러에 있는 임시 휘발성 저장 영역으로, 드라이브 미디어보다 액세스 시간이 빠릅니다. 캐시 성능을 최적화하려면 다음 설정을 조정할 수 있습니다.

[cols="25h,~"]
|===
| 캐시 설정 | 설명 


 a| 
요청 시 캐시 플러싱 시작
 a| 
수요 캐시 플러싱 시작은 캐시 플러시(디스크에 쓰기)를 트리거하는 캐시의 기록되지 않은 데이터 비율을 지정합니다. 기본적으로 캐시 플러싱은 기록되지 않은 데이터가 80% 용량에 도달하면 시작됩니다. 높은 비율은 주로 쓰기 작업이 수행되는 환경에 적합한 선택입니다. 이렇게 하면 디스크로 이동하지 않고도 캐시에서 새 쓰기 요청을 처리할 수 있습니다. 낮은 설정은 I/O가 불규칙한(데이터 버스트 포함) 환경에 더 적합합니다. 이렇게 하면 시스템이 데이터 버스트 사이에 캐시를 자주 플러시할 수 있습니다. 그러나 80%보다 낮은 시작 비율은 성능 저하를 초래할 수 있습니다.



 a| 
캐시 블록 크기
 a| 
캐시 블록 크기는 캐시 관리의 구성 단위인 각 캐시 블록의 최대 크기를 결정합니다. 기본적으로 블록 크기는 32KiB입니다. 시스템에서는 캐시 블록 크기를 4, 8, 16 또는 32KiBs로 설정할 수 있습니다. 애플리케이션마다 사용하는 블록 크기가 다르며, 이는 스토리지 성능에 영향을 미칩니다. 작은 크기는 파일 시스템이나 데이터베이스 애플리케이션에 적합합니다. 큰 크기는 멀티미디어와 같이 순차적인 I/O를 생성하는 애플리케이션에 이상적입니다.

|===
.단계
. 메뉴:Settings[System]를 선택합니다.
. *추가 설정*으로 스크롤한 다음 *캐시 설정 변경*을 클릭합니다.
+
캐시 설정 변경 대화 상자가 열립니다.

. 다음 값을 조정합니다.
+
** *요청 캐시 플러싱 시작* -- 사용 환경에서 사용되는 I/O에 적합한 비율을 선택하십시오. 80% 미만의 값을 선택하면 성능 저하가 발생할 수 있습니다.
** **캐시 블록 크기 -- **애플리케이션에 적합한 크기를 선택하십시오.


. *저장*을 클릭합니다.
