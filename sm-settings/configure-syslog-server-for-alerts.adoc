= SANtricity System Manager에서 알림을 위한 syslog 서버를 구성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
syslog 알림을 구성하려면 syslog 서버 주소와 UDP 포트를 입력해야 합니다. 최대 5개의 syslog 서버를 사용할 수 있습니다.

.시작하기 전에
* syslog 서버 주소를 사용할 수 있어야 합니다. 이 주소는 정규화된 도메인 이름, IPv4 주소 또는 IPv6 주소일 수 있습니다.
* syslog 서버의 UDP 포트 번호를 사용할 수 있어야 합니다. 이 포트는 일반적으로 514입니다.


.이 작업 정보
이 작업에서는 syslog 서버의 주소와 포트를 입력한 다음 입력한 주소를 테스트하는 방법을 설명합니다.

.단계
. 메뉴:Settings[Alerts]를 선택합니다.
. *Syslog* 탭을 선택합니다.
+
syslog 서버가 아직 정의되지 않은 경우 알림 페이지에 "Add Syslog Servers"가 표시됩니다.

. * Syslog 서버 추가 * 를 클릭합니다.
+
Syslog 서버 추가 대화 상자가 열립니다.

. 하나 이상의 syslog 서버(최대 5개)에 대한 정보를 입력한 다음 *추가*를 클릭합니다.
+
** *서버 주소* -- 정규화된 도메인 이름, IPv4 주소 또는 IPv6 주소를 입력합니다.
** *UDP 포트* -- 일반적으로 syslog의 UDP 포트는 514입니다. 이 표에는 구성된 syslog 서버가 표시됩니다.


. 서버 주소로 테스트 알림을 보내려면 *Test All Syslog Servers*를 선택하십시오.


.결과
이벤트 모니터는 경고 대상 이벤트가 발생할 때마다 syslog 서버로 경고를 보냅니다. 감사 로그에 대한 syslog 설정을 추가로 구성하려면 다음을 참조하십시오 https://docs.netapp.com/us-en/e-series-santricity/sm-settings/configure-syslog-server-for-audit-logs.html["감사 로그에 대한 syslog 서버 구성"].


NOTE: 여러 개의 syslog 서버가 구성된 경우, 구성된 모든 syslog 서버는 감사 로그를 수신합니다.
