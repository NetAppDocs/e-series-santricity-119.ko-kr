= SANtricity System Manager에서 보안 키를 백업하십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보안 키를 생성하거나 변경한 후에는 원본 파일이 손상될 경우를 대비하여 키 파일의 백업 복사본을 만들 수 있습니다.

.이 작업 정보
이 작업에서는 이전에 생성한 보안 키를 백업하는 방법을 설명합니다. 이 절차를 진행하면서 백업에 사용할 새 암호를 생성합니다. 이 암호는 원래 키를 생성하거나 마지막으로 변경했을 때 사용한 암호와 일치할 필요가 없습니다. 새 암호는 생성하는 백업에만 적용됩니다.

.단계
. 메뉴:Settings[System]를 선택합니다.
. *Security key management*에서 *Back Up Key*를 선택하십시오.
+
백업 보안 키 대화 상자가 열립니다.

. *암호 정의/암호 재입력* 필드에 이 백업 복사본에 사용할 암호를 입력하고 확인하십시오.
+
값은 8자에서 32자 사이여야 하며 다음 각 항목을 포함해야 합니다.

+
** 대문자(하나 이상)
** 숫자(하나 이상)
** !, *, @와 같은 영숫자가 아닌 문자(하나 이상)


+
[CAUTION]
====
*나중에 사용할 수 있도록 항목을 기록해 두십시오*. 이 보안 키의 백업에 액세스하려면 암호가 필요합니다.

====
. *Back Up*을 클릭합니다.
+
보안 키 백업 파일이 로컬 호스트로 다운로드된 후 *보안 키 백업 확인/기록* 대화 상자가 열립니다.

+
[NOTE]
====
다운로드한 보안 키 파일의 경로는 브라우저의 기본 다운로드 위치에 따라 달라질 수 있습니다.

====
. 암호를 안전한 곳에 기록해 두신 다음 * 닫기 * 를 클릭하십시오.


.완료한 후
백업 보안 키를 검증해야 합니다.
