= SANtricity System Manager의 감사 로그에서 이벤트를 삭제합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
감사 로그에서 오래된 이벤트를 삭제하면 이벤트 검색이 더욱 편리해집니다. 삭제 시 오래된 이벤트를 CSV(쉼표로 구분된 값) 파일로 저장하는 옵션도 제공됩니다.

.시작하기 전에
보안 관리자 권한이 포함된 사용자 프로필로 로그인해야 합니다. 그렇지 않으면 액세스 관리 기능이 표시되지 않습니다.

.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. *감사 로그* 탭을 선택합니다.
. *삭제*를 선택합니다.
+
감사 로그 삭제 대화 상자가 열립니다.

. 삭제할 가장 오래된 이벤트 수를 선택하거나 입력합니다.
. 삭제된 이벤트를 CSV 파일로 내보내려면(권장) 확인란을 선택한 상태로 유지하세요. 다음 단계에서 *삭제*를 클릭하면 파일 이름과 위치를 입력하라는 메시지가 표시됩니다. 그렇지 않고 CSV 파일에 이벤트를 저장하지 않으려면 확인란을 클릭하여 선택을 해제하세요.
. *삭제*를 클릭합니다.
+
확인 대화 상자가 열립니다.

. 필드에  `delete`를 입력한 다음 *삭제*를 클릭합니다.
+
감사 로그 페이지에서 가장 오래된 이벤트가 제거됩니다.
