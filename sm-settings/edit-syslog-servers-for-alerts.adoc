= SANtricity System Manager에서 알림에 대한 syslog 서버 편집
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
syslog 알림을 수신하는 데 사용되는 서버 주소를 편집할 수 있습니다.

.단계
. 메뉴:Settings[Alerts]를 선택합니다.
. *Syslog* 탭을 선택합니다.
. 표에서 syslog 서버 주소를 선택한 다음 맨 오른쪽에 있는 *편집* (연필) 아이콘을 클릭합니다.
+
해당 행은 편집 가능한 필드가 됩니다.

. 서버 주소와 UDP 포트 번호를 편집한 다음 *저장*(확인 표시) 아이콘을 클릭합니다.


.결과
업데이트된 서버 주소가 표에 표시됩니다.
