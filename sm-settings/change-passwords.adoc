= SANtricity System Manager에서 비밀번호 변경
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Access Management에서 각 사용자 프로필의 사용자 암호를 변경할 수 있습니다.

.시작하기 전에
* Root 관리자 권한을 포함한 로컬 관리자로 로그인해야 합니다.
* 로컬 관리자 암호를 알고 있어야 합니다.


.이 작업 정보
비밀번호를 선택할 때 다음 지침을 염두에 두십시오.

* 새로운 로컬 사용자 암호는 최소 암호에 대한 현재 설정(View/Edit Settings)을 충족하거나 초과해야 합니다.
* 비밀번호는 대소문자를 구분합니다.
* 비밀번호를 설정할 때 끝에 있는 공백은 제거되지 않습니다. 비밀번호에 공백이 포함된 경우 공백을 포함하도록 주의하십시오.
* 보안 강화를 위해 최소 15자의 영숫자를 사용하고 비밀번호를 자주 변경하십시오.


[NOTE]
====
System Manager에서 암호를 변경하면 명령줄 인터페이스(CLI)에서도 암호가 변경됩니다. 또한 암호를 변경하면 사용자의 활성 세션이 종료됩니다.

====
.단계
. 메뉴:설정[액세스 관리]를 선택합니다.
. *로컬 사용자 역할* 탭을 선택합니다.
. 표에서 사용자를 선택합니다.
+
비밀번호 변경 버튼이 활성화됩니다.

. *Change Password*를 선택합니다.
+
암호 변경 대화 상자가 열립니다.

. 로컬 사용자 암호에 최소 암호 길이가 설정되어 있지 않은 경우 확인란을 선택하여 선택한 사용자가 스토리지 어레이에 액세스하기 위해 암호를 입력하도록 요구한 다음 선택한 사용자의 새 암호를 입력할 수 있습니다.
. 로컬 관리자 암호를 입력한 다음 *변경*을 클릭합니다.


.결과
사용자가 현재 로그인 중인 경우, 비밀번호를 변경하면 사용자의 활성 세션이 종료됩니다.
