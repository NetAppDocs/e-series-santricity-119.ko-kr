= SANtricity System Manager의 드라이브 상태에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager는 드라이브의 다양한 상태를 보고합니다.



== 접근성 상태

[cols="25h,~"]
|===
| 상태 | 정의 


 a| 
우회됨
 a| 
드라이브는 물리적으로 존재하지만 컨트롤러가 두 포트 모두에서 드라이브와 통신할 수 없습니다.



 a| 
호환되지 않음
 a| 
다음 조건 중 하나가 존재합니다.

* 해당 드라이브는 스토리지 어레이에서 사용하도록 인증되지 않았습니다.
* 드라이브의 섹터 크기가 다릅니다.
* 드라이브에 이전 또는 최신 펌웨어 버전의 사용할 수 없는 구성 데이터가 있습니다.




 a| 
제거됨
 a| 
드라이브가 스토리지 어레이에서 부적절하게 제거되었습니다.



 a| 
현재
 a| 
컨트롤러는 두 포트 모두에서 드라이브와 통신할 수 있습니다.



 a| 
응답 없음
 a| 
드라이브가 명령에 응답하지 않습니다.

|===


== 역할 상태

[cols="25h,~"]
|===
| 상태 | 정의 


 a| 
할당됨
 a| 
드라이브가 풀 또는 볼륨 그룹의 구성원입니다.



 a| 
사용 중인 핫 스페어
 a| 
해당 드라이브는 현재 고장난 드라이브를 대체하기 위해 사용되고 있습니다. 핫 스페어는 볼륨 그룹에서만 사용되며 풀에서는 사용되지 않습니다.



 a| 
대기 핫 스페어
 a| 
해당 드라이브는 고장난 드라이브를 대체하여 바로 사용할 수 있도록 준비되었습니다. 핫 스페어는 풀이 아닌 볼륨 그룹에서만 사용됩니다.



 a| 
미지정
 a| 
해당 드라이브는 풀 또는 볼륨 그룹의 구성원이 아닙니다.

|===


== 가용성 상태

[cols="25h,~"]
|===
| 상태 | 정의 


 a| 
실패
 a| 
드라이브가 작동하지 않습니다. 드라이브의 데이터를 사용할 수 없습니다.



 a| 
임박한 장애
 a| 
해당 드라이브가 곧 고장날 수 있다는 것이 감지되었습니다. 드라이브에 저장된 데이터는 여전히 사용 가능합니다.



 a| 
오프라인
 a| 
일반적으로 드라이브가 내보내지는 볼륨 그룹의 일부이거나 펌웨어 업그레이드가 진행 중이기 때문에 데이터 저장에 사용할 수 없습니다.



 a| 
최적
 a| 
드라이브가 정상적으로 작동하고 있습니다.

|===
