= SANtricity System Manager에서 드라이브 상태 및 설정을 확인하세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
미디어 유형, 인터페이스 유형 및 용량과 같은 드라이브의 상태 및 설정을 볼 수 있습니다.

.단계
. * Hardware * 를 선택합니다.
. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 상태 및 설정을 보려는 드라이브를 선택하십시오.
+
드라이브의 컨텍스트 메뉴가 열립니다.

. *View settings*를 선택합니다.
+
드라이브 설정 대화 상자가 열립니다.

. 모든 설정을 보려면 대화 상자의 오른쪽 상단에 있는 *Show more settings*를 클릭합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
상태
 a| 
최적, 오프라인, 비중요 오류 및 실패 상태를 표시합니다. 최적 상태는 바람직한 작동 조건을 나타냅니다.



 a| 
모드
 a| 
할당됨, 할당되지 않음, 핫 스페어 대기 또는 사용 중인 핫 스페어를 표시합니다.



 a| 
위치
 a| 
드라이브가 있는 쉘프 및 베이 번호를 표시합니다.



 a| 
할당 대상/보호 가능 대상/보호 중
 a| 
드라이브가 풀, 볼륨 그룹 또는 SSD 캐시에 할당된 경우 이 필드에는 "할당 대상"이 표시됩니다. 값은 풀 이름, 볼륨 그룹 이름 또는 SSD 캐시 이름일 수 있습니다. 드라이브가 핫 스페어에 할당되고 모드가 대기인 경우 이 필드에는 "보호 가능"이 표시됩니다. 핫 스페어가 하나 이상의 볼륨 그룹을 보호할 수 있는 경우 볼륨 그룹 이름이 표시됩니다. 볼륨 그룹을 보호할 수 없는 경우 0개의 볼륨 그룹이 표시됩니다.

드라이브가 핫 스페어에 할당되고 해당 모드가 사용 중인 경우 이 필드에는 "보호 중"이 표시됩니다. 값은 영향을 받는 볼륨 그룹의 이름입니다.

드라이브가 할당되지 않은 경우 이 필드가 표시되지 않습니다.



 a| 
미디어 유형
 a| 
드라이브에서 사용하는 기록 매체의 유형을 표시합니다. 하드 디스크 드라이브(HDD) 또는 SSD(Solid State Disk)일 수 있습니다.



 a| 
사용된 내구성 백분율(SSD 드라이브가 있는 경우에만 표시됨)
 a| 
현재까지 드라이브에 기록된 데이터 양을 총 이론적 쓰기 제한으로 나눈 값입니다.



 a| 
인터페이스 유형
 a| 
드라이브가 사용하는 인터페이스 유형(예: SAS)을 표시합니다.



 a| 
드라이브 경로 이중화
 a| 
드라이브와 컨트롤러 간의 연결이 이중화되어 있는지(예) 아니면 이중화되어 있지 않은지(아니요)를 표시합니다.



 a| 
용량(GiB)
 a| 
드라이브의 사용 가능한 용량(총 구성 용량)을 표시합니다.



 a| 
속도(RPM)
 a| 
RPM 속도를 표시합니다(SSD의 경우 표시되지 않음).



 a| 
현재 데이터 전송 속도
 a| 
드라이브와 스토리지 어레이 간의 데이터 전송 속도를 보여줍니다.



 a| 
논리적 섹터 크기(바이트)
 a| 
드라이브가 사용하는 논리 섹터 크기를 표시합니다.



 a| 
물리적 섹터 크기(바이트)
 a| 
드라이브가 사용하는 물리적 섹터 크기를 보여줍니다. 일반적으로 하드 디스크의 물리적 섹터 크기는 4096바이트입니다.



 a| 
드라이브 펌웨어 버전
 a| 
드라이브 펌웨어의 수정 레벨을 표시합니다.



 a| 
전세계 식별자
 a| 
드라이브의 고유한 16진수 식별자를 표시합니다.



 a| 
제품 ID
 a| 
제조업체가 부여한 제품 식별자를 표시합니다.



 a| 
일련번호
 a| 
드라이브의 일련 번호를 표시합니다.



 a| 
제조업체
 a| 
드라이브 공급업체를 표시합니다.



 a| 
제조 날짜
 a| 
드라이브가 제작된 날짜를 보여줍니다.


NOTE: NVMe 드라이브에서는 사용할 수 없습니다.



 a| 
보안 가능
 a| 
드라이브가 보안 기능을 지원하는지 여부를 표시합니다(예 또는 아니요). 보안 기능을 지원하는 드라이브는 FDE(Full Disk Encryption) 드라이브 또는 FIPS(Federal Information Processing Standard) 드라이브(레벨 140-2 또는 140-3)일 수 있으며, 쓰기 중에 데이터를 암호화하고 읽기 중에 데이터를 복호화합니다. 이러한 드라이브는 Drive Security 기능을 사용하여 추가 보안에 사용할 수 있으므로 보안_기능_을 지원하는 것으로 간주됩니다. 이러한 드라이브와 함께 사용되는 볼륨 그룹 및 풀에 대해 Drive Security 기능이 활성화되면 드라이브가 보안_활성화_됩니다.



 a| 
보안 활성화됨
 a| 
드라이브가 보안 기능을 지원하는지(예) 또는 지원하지 않는지(아니요)를 표시합니다. 보안 기능이 활성화된 드라이브는 드라이브 보안 기능과 함께 사용됩니다. 드라이브 보안 기능을 활성화한 다음 보안 기능을 지원하는 드라이브의 풀 또는 볼륨 그룹에 드라이브 보안을 적용하면 드라이브가 보안 기능이 활성화됩니다. 읽기 및 쓰기 액세스는 올바른 보안 키로 구성된 컨트롤러를 통해서만 가능합니다. 이러한 추가 보안 기능은 스토리지 어레이에서 물리적으로 분리된 드라이브의 데이터에 대한 무단 액세스를 방지합니다.



 a| 
읽기/쓰기 액세스 가능
 a| 
드라이브에 읽기/쓰기 액세스가 가능한지(예) 또는 불가능한지(아니요)를 표시합니다.



 a| 
드라이브 보안 키 식별자
 a| 
보안 기능이 활성화된 드라이브의 보안 키를 표시합니다. Drive Security는 스토리지 어레이 기능으로, 전체 디스크 암호화(FDE) 드라이브 또는 연방 정보 처리 표준(FIPS) 드라이브에 추가적인 보안 계층을 제공합니다. 이러한 드라이브를 Drive Security 기능과 함께 사용할 경우 데이터에 액세스하려면 보안 키가 필요합니다. 드라이브가 어레이에서 물리적으로 제거되면 다른 어레이에 설치될 때까지 작동할 수 없으며, 설치된 후에는 올바른 보안 키가 제공될 때까지 Security Locked 상태가 됩니다.



 a| 
Data Assurance(DA) 지원
 a| 
Data Assurance(DA) 기능이 활성화되었는지(예) 또는 비활성화되었는지(아니요)를 표시합니다. Data Assurance(DA)은 데이터가 컨트롤러를 거쳐 드라이브로 전송되는 동안 발생할 수 있는 오류를 검사하고 수정하는 기능입니다. Data Assurance는 풀 또는 볼륨 그룹 수준에서 활성화할 수 있으며, 호스트는 Fibre Channel과 같은 DA 지원 I/O 인터페이스를 사용해야 합니다.



 a| 
DULBE 지원
 a| 
할당 해제 또는 미기록 논리 블록 오류(DULBE) 옵션이 활성화(예)되었는지 또는 비활성화(아니요)되었는지를 나타냅니다. DULBE는 NVMe 드라이브의 옵션으로, EF300 또는 EF600 스토리지 어레이에서 리소스 프로비저닝 볼륨을 지원할 수 있도록 합니다.

|===
