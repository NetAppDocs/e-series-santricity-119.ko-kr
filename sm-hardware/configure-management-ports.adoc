= SANtricity System Manager에서 관리 포트를 구성합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
컨트롤러에는 시스템 관리에 사용되는 Ethernet 포트가 포함되어 있습니다. 필요한 경우 전송 매개변수와 IP 주소를 변경할 수 있습니다.

.이 작업 정보
이 절차에서 포트 1을 선택한 다음 속도와 포트 주소 지정 방식을 결정합니다. 포트 1은 관리 클라이언트가 컨트롤러 및 System Manager에 액세스할 수 있는 네트워크에 연결됩니다.

[NOTE]
====
두 컨트롤러 모두에서 2번 포트를 사용하지 마십시오. 2번 포트는 기술 지원용으로 예약되어 있습니다.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 드라이브가 표시되면 *Controllers & Components* 탭을 클릭하십시오.
+
그래픽이 드라이브 대신 컨트롤러를 표시하도록 변경됩니다.

. 구성하려는 관리 포트가 있는 컨트롤러를 클릭합니다.
+
컨트롤러의 컨텍스트 메뉴가 나타납니다.

. *관리 포트 구성*을 선택합니다.
+
관리 포트 구성 대화 상자가 열립니다.

. 포트 1이 표시되는지 확인한 후 *Next*를 클릭하십시오.
. 구성 포트 설정을 선택한 다음 *다음*을 클릭합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 필드 | 설명 


 a| 
속도 및 이중 모드
 a| 
스토리지 어레이와 네트워크 간의 전송 매개변수를 System Manager가 결정하도록 하려면 Auto-negotiate 설정을 유지하십시오. 네트워크 속도와 모드를 알고 있는 경우 드롭다운 목록에서 매개변수를 선택하십시오. 목록에는 유효한 속도 및 이중 모드 조합만 표시됩니다.



 a| 
IPv4 활성화 / IPv6 활성화
 a| 
IPv4 및 IPv6 네트워크에 대한 지원을 활성화하려면 하나 또는 두 옵션을 모두 선택합니다.

|===
====
+
*IPv4 사용*을 선택하면 *다음*을 클릭한 후 IPv4 설정을 선택하는 대화 상자가 열립니다. *IPv6 사용*을 선택하면 *다음*을 클릭한 후 IPv6 설정을 선택하는 대화 상자가 열립니다. 두 옵션을 모두 선택하면 IPv4 설정 대화 상자가 먼저 열리고 *다음*을 클릭한 후 IPv6 설정 대화 상자가 열립니다.

. IPv4 및/또는 IPv6 설정을 자동 또는 수동으로 구성합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 필드 | 설명 


 a| 
DHCP 서버에서 구성을 자동으로 가져옵니다
 a| 
구성을 자동으로 가져오려면 이 옵션을 선택하십시오.



 a| 
정적 구성을 수동으로 지정합니다
 a| 
이 옵션을 선택한 다음 컨트롤러의 IP 주소를 입력합니다. (필요한 경우 주소를 복사하여 필드에 붙여넣을 수 있습니다.) IPv4의 경우 네트워크 서브넷 마스크와 게이트웨이를 포함합니다. IPv6의 경우 라우팅 가능한 IP 주소와 라우터 IP 주소를 포함합니다.


NOTE: IP 주소 구성을 변경하면 스토리지 어레이에 대한 관리 경로가 손실됩니다. SANtricity Unified Manager를 사용하여 네트워크의 어레이를 전역적으로 관리하는 경우 사용자 인터페이스를 열고 메뉴:관리[검색]으로 이동하십시오. SANtricity Storage Manager를 사용하는 경우 Enterprise Management Window(EMW)에서 장치를 제거한 다음 메뉴:편집[스토리지 어레이 추가]를 선택하여 EMW에 다시 추가하고 새 IP 주소를 입력해야 합니다.

|===
====
. *완료*를 클릭합니다.


.결과
관리 포트 구성이 컨트롤러 설정의 관리 포트 탭에 표시됩니다.
