= SANtricity System Manager의 핫 스페어 드라이브에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
핫 스페어는 SANtricity System Manager의 RAID 1, RAID 5 또는 RAID 6 볼륨 그룹에서 대기 드라이브 역할을 합니다.

이 드라이브들은 데이터가 전혀 없는 완전한 기능을 갖춘 드라이브입니다. 볼륨 그룹에서 드라이브 하나가 고장 나면 컨트롤러는 고장 난 드라이브의 데이터를 핫 스페어로 지정된 드라이브로 자동으로 재구성합니다.

핫 스페어는 특정 볼륨 그룹에 전용으로 사용되지 않습니다. 핫 스페어와 드라이브가 다음 속성을 공유하는 한 스토리지 어레이에서 장애가 발생한 모든 드라이브에 사용할 수 있습니다.

* 동일 용량(또는 핫 스페어의 경우 더 큰 용량)
* 동일한 미디어 유형(예: HDD 또는 SSD)
* 동일한 인터페이스 유형(예: SAS)




== 핫 스페어를 식별하는 방법

초기 설정 마법사 또는 하드웨어 페이지에서 핫 스페어를 지정할 수 있습니다. 핫 스페어가 지정되었는지 확인하려면 하드웨어 페이지로 이동하여 분홍색으로 표시된 드라이브 베이를 찾으십시오.



== 핫 스페어 적용 범위 작동 방식

핫 스페어 커버리지는 다음과 같이 작동합니다:

* RAID 1, RAID 5 또는 RAID 6 볼륨 그룹의 핫 스페어로 할당되지 않은 드라이브를 예약합니다.
+
[NOTE]
====
핫 스페어는 풀에 사용할 수 없으며, 풀에는 다른 데이터 보호 방법이 있습니다. 추가 드라이브를 예약하는 대신 풀은 풀의 각 드라이브 내에 스페어 용량(_보존 용량_)을 예약합니다. 풀의 드라이브에 장애가 발생하면 컨트롤러가 해당 스페어 용량에서 데이터를 재구성합니다.

====
* RAID 1, RAID 5 또는 RAID 6 볼륨 그룹 내의 드라이브에 오류가 발생하면 컨트롤러는 자동으로 이중화 데이터를 사용하여 오류가 발생한 드라이브의 데이터를 복구합니다. 핫 스페어는 물리적인 교체 없이 오류가 발생한 드라이브를 자동으로 대체합니다.
* 고장난 드라이브를 물리적으로 교체한 경우, 핫 스페어 드라이브에서 교체된 드라이브로 데이터 복사 작업이 수행됩니다. 핫 스페어 드라이브를 볼륨 그룹의 영구 멤버로 지정한 경우에는 데이터 복사 작업이 필요하지 않습니다.
* 볼륨 그룹의 트레이 손실 방지 및 드로어 손실 방지 기능 사용 가능 여부는 해당 볼륨 그룹을 구성하는 드라이브의 위치에 따라 달라집니다. 드라이브 고장 및 핫 스페어 드라이브의 위치에 따라 트레이 손실 방지 및 드로어 손실 방지 기능이 손실될 수 있습니다. 트레이 손실 방지 및 드로어 손실 방지 기능에 영향을 미치지 않도록 하려면 고장난 드라이브를 교체하여 재복사 프로세스를 시작해야 합니다.
* 고장난 드라이브를 교체하는 동안에도 스토리지 어레이 볼륨은 온라인 상태를 유지하고 액세스할 수 있습니다. 핫 스페어 드라이브가 고장난 드라이브를 자동으로 대체하기 때문입니다.




== 핫 스페어 드라이브 용량에 대한 고려 사항

보호하려는 드라이브의 총 용량과 같거나 그 이상의 용량을 가진 드라이브를 선택하십시오. 예를 들어, 구성 용량이 8GiB인 18GiB 드라이브가 있는 경우 9GiB 이상의 드라이브를 핫 스페어로 사용할 수 있습니다. 일반적으로 스토리지 어레이에서 가장 큰 드라이브의 용량과 같거나 그 이상의 용량을 가진 드라이브가 아니면 핫 스페어로 지정하지 마십시오.

[NOTE]
====
물리적 용량이 동일한 핫 스페어를 사용할 수 없는 경우 드라이브의 "사용 용량"이 핫 스페어 드라이브의 용량과 같거나 작으면 용량이 더 낮은 드라이브를 핫 스페어로 사용할 수 있습니다.

====


== 미디어 및 인터페이스 유형에 대한 고려 사항

핫 스페어로 사용되는 드라이브는 보호할 드라이브와 동일한 미디어 유형 및 인터페이스 유형을 가져야 합니다. 예를 들어, HDD 드라이브는 SSD 드라이브의 핫 스페어로 사용할 수 없습니다.



== 보안 기능 드라이브에 대한 고려 사항

FDE 또는 FIPS와 같은 보안 기능을 갖춘 드라이브는 보안 기능이 있거나 없는 드라이브의 핫 스페어로 사용할 수 있습니다. 그러나 보안 기능을 지원하지 않는 드라이브는 보안 기능이 있는 드라이브의 핫 스페어로 사용할 수 없습니다.

보안 기능이 활성화된 드라이브를 핫 스페어로 사용하도록 선택하면 System Manager에서 진행하기 전에 보안 삭제를 수행하라는 메시지가 표시됩니다. 보안 삭제를 수행하면 드라이브의 보안 속성이 보안 가능 상태로 재설정되지만 보안 기능이 활성화된 상태로는 재설정되지 않습니다.

[NOTE]
====
드라이브 보안 기능을 활성화한 다음 보안 기능을 지원하는 드라이브로 풀 또는 볼륨 그룹을 생성하면 해당 드라이브는 _보안 활성화_ 상태가 됩니다. 읽기 및 쓰기 액세스는 올바른 보안 키로 구성된 컨트롤러를 통해서만 가능합니다. 이러한 추가 보안 기능은 스토리지 어레이에서 물리적으로 분리된 드라이브의 데이터에 대한 무단 액세스를 방지합니다.

====


== 권장 핫 스페어 드라이브 개수

초기 설정 마법사를 사용하여 핫 스페어를 자동으로 생성한 경우 System Manager는 특정 미디어 유형 및 인터페이스 유형의 드라이브 30개당 하나의 핫 스페어를 생성합니다. 그렇지 않은 경우 스토리지 어레이의 볼륨 그룹 중에서 핫 스페어 드라이브를 수동으로 생성할 수 있습니다.
