= SANtricity System Manager에서 드라이브 보기를 필터링합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에 물리적 및 논리적 속성이 서로 다른 드라이브가 포함된 경우 하드웨어 페이지에서 드라이브 보기를 제한하고 특정 드라이브를 찾을 수 있도록 필터 필드를 제공합니다.

.이 작업 정보
드라이브 필터를 사용하면 특정 유형의 물리적 드라이브(예: 모든 SAS), 특정 보안 속성(예: 보안 기능), 특정 논리적 위치(예: 볼륨 그룹 1)만 표시하도록 보기를 제한할 수 있습니다. 이러한 필터는 함께 또는 개별적으로 사용할 수 있습니다.

[NOTE]
====
모든 드라이브의 물리적 속성이 동일한 경우 *다음과 같은 드라이브 표시...* 필터 필드가 나타나지 않습니다. 모든 드라이브의 논리적 속성이 동일한 경우 *스토리지 어레이 내 모든 위치* 필터 필드가 나타나지 않습니다.

====
.단계
. * Hardware * 를 선택합니다.
. 첫 번째 필터 필드(*다음과 같은 드라이브 표시...* 아래)에서 드롭다운 화살표를 클릭하여 사용 가능한 드라이브 유형 및 보안 속성을 표시합니다.
+
드라이브 유형에는 다음이 포함될 수 있습니다.

+
** 드라이브 미디어 유형(SSD, HDD)
** 드라이브 인터페이스 유형
** 드라이브 용량(최대에서 최소)
** 드라이브 속도(가장 빠른 속도에서 가장 낮은 속도 순) 보안 기능에는 다음이 포함될 수 있습니다.
** 보안 가능
** 보안 활성화됨
** DA(Data Assurance) 가능
** FIPS 준수
** FIPS 규정 준수(FIPS 140-2)
** FIPS 규정 준수(FIPS 140-3)
+
이러한 속성 중 하나라도 모든 드라이브에서 동일한 경우 드롭다운 목록에 표시되지 않습니다. 예를 들어 스토리지 어레이에 SAS 인터페이스와 15000RPM 속도의 SSD 드라이브만 포함되어 있지만 일부 SSD의 용량이 다른 경우 드롭다운 목록에는 용량만 필터링 옵션으로 표시됩니다.

+
필드에서 옵션을 선택하면 필터 기준과 일치하지 않는 드라이브는 그래픽 보기에서 회색으로 표시됩니다.



. 두 번째 필터 상자에서 드롭다운 화살표를 클릭하여 드라이브에 사용 가능한 논리적 위치를 표시합니다.
+
[NOTE]
====
필터 조건을 지워야 하는 경우 필터 상자 맨 오른쪽에 있는 *Clear*를 선택합니다.

====
+
논리적 위치는 다음과 같습니다.

+
** 풀
** 볼륨 그룹
** 핫 스페어
** SSD 캐시
** 미지정
+
필드에서 옵션을 선택하면 필터 기준과 일치하지 않는 드라이브는 그래픽 보기에서 회색으로 표시됩니다.



. 선택적으로 필터 필드의 맨 오른쪽에 있는 *위치 표시등 켜기*를 선택하여 표시된 드라이브의 위치 표시등을 켤 수 있습니다.
+
이 작업을 통해 스토리지 어레이에서 드라이브의 물리적 위치를 확인할 수 있습니다.
