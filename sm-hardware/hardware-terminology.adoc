= SANtricity 소프트웨어에서 사용되는 하드웨어 용어에 대해 알아보십시오

[role="lead"]
다음 하드웨어 용어는 스토리지 어레이에 적용됩니다.

.일반 하드웨어 용어:
[%collapsible]
====
[cols="25h,~"]
|===
| 구성 요소 | 설명 


 a| 
베이
 a| 
베이는 드라이브나 기타 구성 요소가 설치되는 쉘프의 슬롯입니다.



 a| 
컨트롤러
 a| 
컨트롤러는 보드, 펌웨어 및 소프트웨어로 구성됩니다. 드라이브를 제어하고 System Manager 기능을 구현합니다.



 a| 
컨트롤러 쉘프
 a| 
컨트롤러 셸프에는 드라이브 세트와 하나 이상의 컨트롤러 캐니스터가 포함됩니다. 컨트롤러 캐니스터에는 컨트롤러, 호스트 인터페이스 카드(HIC) 및 배터리가 들어 있습니다.



 a| 
드라이브
 a| 
드라이브는 데이터의 물리적 저장 매체를 제공하는 전자기 기계 장치 또는 솔리드 스테이트 메모리 장치입니다.



 a| 
드라이브 셸프
 a| 
드라이브 쉘프(확장 쉘프)는 드라이브 세트와 두 개의 입출력 모듈(IOM)로 구성됩니다. IOM에는 드라이브 쉘프를 컨트롤러 쉘프 또는 다른 드라이브 쉘프에 연결하는 SAS 포트가 있습니다.



 a| 
IOM(ESM)
 a| 
IOM은 드라이브 쉘프를 컨트롤러 쉘프에 연결하기 위한 SAS 포트가 포함된 입출력 모듈입니다. 이전 컨트롤러 모델에서는 IOM을 ESM(Environmental Service Module)이라고 했습니다.



 a| 
전원/팬 캐니스터
 a| 
전원/팬 캐니스터는 쉘프에 끼워 넣는 형태의 조립체입니다. 전원 공급 장치와 통합 팬이 포함되어 있습니다.



 a| 
SFP
 a| 
SFP는 Small Form-factor Pluggable(SFP) 트랜시버입니다.



 a| 
쉘프
 a| 
쉘프는 캐비닛이나 랙에 설치되는 엔클로저입니다. 스토리지 어레이에 필요한 하드웨어 구성 요소를 담고 있습니다. 쉘프에는 컨트롤러 쉘프와 드라이브 쉘프의 두 가지 유형이 있습니다. 컨트롤러 쉘프에는 컨트롤러와 드라이브가 포함됩니다. 드라이브 쉘프에는 입출력 모듈(IOM)과 드라이브가 포함됩니다.



 a| 
스토리지 어레이
 a| 
스토리지 어레이에는 쉘프, 컨트롤러, 드라이브, 소프트웨어 및 펌웨어가 포함됩니다.

.컨트롤러 용어:
[%collapsible]
====
[cols="25h,~"]
|===
| 구성 요소 | 설명 


 a| 
컨트롤러
 a| 
컨트롤러는 보드, 펌웨어 및 소프트웨어로 구성됩니다. 드라이브를 제어하고 System Manager 기능을 구현합니다.



 a| 
컨트롤러 쉘프
 a| 
컨트롤러 셸프에는 드라이브 세트와 하나 이상의 컨트롤러 캐니스터가 포함됩니다. 컨트롤러 캐니스터에는 컨트롤러, 호스트 인터페이스 카드(HIC) 및 배터리가 들어 있습니다.



 a| 
DHCP
 a| 
DHCP(Dynamic Host Configuration Protocol)는 IP 주소와 같은 네트워크 구성 매개 변수를 동적으로 배포하기 위해 Internet Protocol(IP) 네트워크에서 사용되는 프로토콜입니다.



 a| 
DNS
 a| 
도메인 이름 시스템(DNS)은 인터넷이나 사설 네트워크에 연결된 장치를 명명하는 시스템입니다. DNS 서버는 도메인 이름 디렉토리를 유지하고 이를 인터넷 프로토콜(IP) 주소로 변환합니다.



 a| 
듀플렉스 구성
 a| 
듀플렉스는 스토리지 어레이 내에서 두 개의 컨트롤러 모듈로 구성된 방식입니다. 듀플렉스 시스템은 컨트롤러, 논리 볼륨 경로 및 디스크 경로 측면에서 완벽한 이중화를 제공합니다. 하나의 컨트롤러에 장애가 발생하면 다른 컨트롤러가 해당 I/O를 인계받아 가용성을 유지합니다. 또한 듀플렉스 시스템은 팬과 전원 공급 장치에도 이중화 기능을 갖추고 있습니다.



 a| 
전이중/반이중 연결
 a| 
Full-duplex와 half-duplex는 연결 모드를 나타냅니다. Full-duplex 모드에서는 두 장치가 양방향으로 동시에 통신할 수 있습니다. Half-duplex 모드에서는 장치가 한 번에 한 방향으로만 통신할 수 있습니다(한 장치가 메시지를 보내면 다른 장치가 수신합니다).



 a| 
HIC
 a| 
컨트롤러 캐니스터 내에 호스트 인터페이스 카드(HIC)를 선택적으로 설치할 수 있습니다. 컨트롤러에 내장된 호스트 포트를 베이스보드 호스트 포트라고 합니다. HIC에 내장된 호스트 포트를 HIC 포트라고 합니다.



 a| 
ICMP PING 응답
 a| 
Internet Control Message Protocol(ICMP)은 네트워크로 연결된 컴퓨터의 운영 체제가 메시지를 전송하는 데 사용하는 프로토콜입니다. ICMP 메시지는 호스트에 연결할 수 있는지 여부와 해당 호스트로 패킷을 보내고 받는 데 걸리는 시간을 확인합니다.



 a| 
MAC 주소
 a| 
미디어 액세스 제어 식별자(MAC 주소)는 이더넷에서 동일한 물리적 전송 네트워크 인터페이스의 두 포트를 연결하는 별도의 논리적 채널을 구별하는 데 사용됩니다.



 a| 
관리 클라이언트
 a| 
관리 클라이언트는 System Manager에 액세스하기 위한 브라우저가 설치된 컴퓨터입니다.



 a| 
MTU
 a| 
MTU(Maximum Transmission Unit)는 네트워크에서 전송할 수 있는 가장 큰 크기의 패킷 또는 프레임입니다.



 a| 
NTP
 a| 
네트워크 시간 프로토콜(NTP)은 데이터 네트워크에서 컴퓨터 시스템 간의 클록 동기화를 위한 네트워킹 프로토콜입니다.



 a| 
심플렉스 구성
 a| 
심플렉스는 스토리지 어레이 내에서 단일 컨트롤러 모듈 구성입니다. 심플렉스 시스템은 컨트롤러 또는 디스크 경로 이중화를 제공하지 않지만 팬과 전원 공급 장치는 이중화되어 있습니다.



 a| 
VLAN
 a| 
가상 근거리 통신망(VLAN)은 동일한 장치(스위치, 라우터 등)에서 지원하는 다른 네트워크와 물리적으로 분리된 것처럼 동작하는 논리적 네트워크입니다.

====
.드라이브 용어:
[%collapsible]
====
[cols="25h,~"]
|===
| 구성 요소 | 설명 


 a| 
DA
 a| 
DA(Data Assurance)는 데이터가 컨트롤러를 거쳐 드라이브로 전송되는 동안 발생할 수 있는 오류를 검사하고 수정하는 기능입니다. Data Assurance는 Fibre Channel과 같은 DA 지원 I/O 인터페이스를 사용하는 호스트에서 풀 또는 볼륨 그룹 수준에서 활성화할 수 있습니다.



 a| 
드라이브 보안 기능
 a| 
Drive Security는 FDE(Full Disk Encryption) 드라이브 또는 FIPS(Federal Information Processing Standard) 드라이브를 통해 추가 보안 계층을 제공하는 스토리지 어레이 기능입니다. 이러한 드라이브를 Drive Security 기능과 함께 사용하는 경우 데이터에 액세스하려면 보안 키가 필요합니다. 드라이브가 어레이에서 물리적으로 제거되면 다른 어레이에 설치될 때까지 작동할 수 없으며, 설치 후에는 올바른 보안 키가 제공될 때까지 Security Locked 상태가 됩니다.



 a| 
드라이브 셸프
 a| 
드라이브 쉘프(확장 쉘프)는 드라이브 세트와 두 개의 입출력 모듈(IOM)로 구성됩니다. IOM에는 드라이브 쉘프를 컨트롤러 쉘프 또는 다른 드라이브 쉘프에 연결하는 SAS 포트가 있습니다.



 a| 
DULBE
 a| 
DULBE(Deallocated or Unwritten Logical Block Error)는 NVMe 드라이브의 옵션으로, EF300 또는 EF600 스토리지 어레이가 리소스 프로비저닝된 볼륨을 지원할 수 있도록 합니다.



 a| 
FDE 드라이브
 a| 
FDE(Full Disk Encryption) 드라이브는 하드웨어 수준에서 디스크 드라이브 암호화를 수행합니다. 하드 드라이브에는 쓰기 작업 중에 데이터를 암호화하고 읽기 작업 중에 데이터를 복호화하는 ASIC 칩이 포함되어 있습니다.



 a| 
FIPS 드라이브
 a| 
FIPS 드라이브는 연방 정보 처리 표준(FIPS) 140-2 레벨 2를 사용합니다. 이는 기본적으로 강력한 암호화 알고리즘과 방법을 보장하기 위한 미국 정부 표준을 준수하는 FDE 드라이브입니다. FIPS 드라이브는 FDE 드라이브보다 더 높은 보안 표준을 제공합니다.



 a| 
HDD
 a| 
하드 디스크 드라이브(HDD)는 자기 코팅이 된 회전하는 금속 플래터를 사용하는 데이터 스토리지 장치입니다.



 a| 
핫 스페어 드라이브
 a| 
핫 스페어는 RAID 1, RAID 5 또는 RAID 6 볼륨 그룹에서 대기 드라이브 역할을 합니다. 데이터는 저장되어 있지 않지만 기능은 완벽하게 작동하는 드라이브입니다. 볼륨 그룹의 드라이브에 오류가 발생하면 컨트롤러는 오류가 발생한 드라이브의 데이터를 핫 스페어로 자동으로 재구성합니다.



 a| 
NVMe
 a| 
NVMe(Non-Volatile Memory Express)는 SSD 드라이브와 같은 플래시 기반 스토리지 장치를 위해 설계된 인터페이스입니다. NVMe는 이전의 논리 장치 인터페이스에 비해 I/O 오버헤드를 줄이고 성능을 향상시킵니다.



 a| 
SAS
 a| 
SAS(Serial Attached SCSI)는 컨트롤러를 디스크 드라이브에 직접 연결하는 포인트 투 포인트 직렬 프로토콜입니다.



 a| 
보안 기능이 있는 드라이브
 a| 
보안 기능을 갖춘 드라이브는 쓰기 시 데이터를 암호화하고 읽기 시 데이터를 복호화하는 전체 디스크 암호화(FDE) 드라이브 또는 연방 정보 처리 표준(FIPS) 드라이브일 수 있습니다. 이러한 드라이브는 Drive Security 기능을 사용하여 추가 보안을 적용할 수 있으므로 보안_가능_ 드라이브로 간주됩니다. 이러한 드라이브와 함께 사용되는 볼륨 그룹 및 풀에 Drive Security 기능이 활성화되면 드라이브는 보안_활성화_ 상태가 됩니다.



 a| 
보안 기능이 활성화된 드라이브
 a| 
보안 지원 드라이브는 드라이브 보안 기능과 함께 사용됩니다. 드라이브 보안 기능을 활성화한 다음 보안 가능 드라이브의 풀 또는 볼륨 그룹에 드라이브 보안을 적용하면 드라이브가 보안 지원 드라이브가 됩니다. 읽기 및 쓰기 액세스 제어는 올바른 보안 키로 구성된 컨트롤러를 통해서만 사용할 수 있습니다. 이 추가 보안 기능은 스토리지 어레이에서 물리적으로 제거된 드라이브의 데이터에 대한 무단 액세스 제어를 방지합니다.



 a| 
SSD
 a| 
솔리드 스테이트 디스크(SSD)는 솔리드 스테이트 메모리(플래시)를 사용하여 데이터를 영구적으로 저장하는 데이터 저장 장치입니다. SSD는 기존 하드 드라이브를 에뮬레이트하며, 하드 드라이브에서 사용하는 것과 동일한 인터페이스로 제공됩니다.

.iSCSI 용어:
[%collapsible]
====
[cols="25h,~"]
|===
| 용어 | 설명 


 a| 
CHAP
 a| 
CHAP(Challenge Handshake Authentication Protocol) 방식은 초기 링크 중에 타겟과 이니시에이터의 ID를 검증합니다. 인증은 CHAP __secret__이라는 공유 보안 키를 기반으로 합니다.



 a| 
컨트롤러
 a| 
컨트롤러는 보드, 펌웨어 및 소프트웨어로 구성됩니다. 드라이브를 제어하고 System Manager 기능을 구현합니다.



 a| 
DHCP
 a| 
DHCP(Dynamic Host Configuration Protocol)는 IP 주소와 같은 네트워크 구성 매개 변수를 동적으로 배포하기 위해 Internet Protocol(IP) 네트워크에서 사용되는 프로토콜입니다.



 a| 
IB
 a| 
InfiniBand(IB)는 고성능 서버와 스토리지 시스템 간의 데이터 전송을 위한 통신 표준입니다.



 a| 
ICMP PING 응답
 a| 
Internet Control Message Protocol(ICMP)은 네트워크로 연결된 컴퓨터의 운영 체제가 메시지를 전송하는 데 사용하는 프로토콜입니다. ICMP 메시지는 호스트에 연결할 수 있는지 여부와 해당 호스트로 패킷을 보내고 받는 데 걸리는 시간을 확인합니다.



 a| 
IQN
 a| 
iSCSI 적격 이름(IQN) 식별자는 iSCSI 이니시에이터 또는 iSCSI 타겟의 고유한 이름입니다.



 a| 
iSER
 a| 
iSCSI Extensions for RDMA(iSER)는 InfiniBand 또는 Ethernet과 같은 RDMA 전송을 통해 작동하도록 iSCSI 프로토콜을 확장하는 프로토콜입니다.



 a| 
iSNS
 a| 
Internet Storage Name Service(iSNS)는 TCP/IP 네트워크에서 iSCSI 및 Fibre Channel 장치를 자동으로 검색, 관리 및 구성할 수 있도록 하는 프로토콜입니다.



 a| 
MAC 주소
 a| 
미디어 액세스 제어 식별자(MAC 주소)는 이더넷에서 동일한 물리적 전송 네트워크 인터페이스의 두 포트를 연결하는 별도의 논리적 채널을 구별하는 데 사용됩니다.



 a| 
관리 클라이언트
 a| 
관리 클라이언트는 System Manager에 액세스하기 위한 브라우저가 설치된 컴퓨터입니다.



 a| 
MTU
 a| 
MTU(Maximum Transmission Unit)는 네트워크에서 전송할 수 있는 가장 큰 크기의 패킷 또는 프레임입니다.



 a| 
RDMA
 a| 
RDMA(Remote Direct Memory Access)는 네트워크 컴퓨터가 두 컴퓨터의 운영 체제를 거치지 않고 주 메모리에서 데이터를 교환할 수 있도록 하는 기술입니다.



 a| 
이름 없는 검색 세션
 a| 
이름 없는 검색 세션 옵션이 활성화된 경우 iSCSI 이니시에이터는 컨트롤러 정보를 검색하기 위해 타겟 IQN을 지정할 필요가 없습니다.

.NVMe 용어:
[%collapsible]
====
[cols="25h,~"]
|===
| 용어 | 설명 


 a| 
InfiniBand
 a| 
InfiniBand(IB)는 고성능 서버와 스토리지 시스템 간의 데이터 전송을 위한 통신 표준입니다.



 a| 
네임스페이스
 a| 
네임스페이스는 블록 액세스용으로 포맷된 NVM 스토리지입니다. 이는 SCSI의 논리 유닛과 유사하며, 스토리지 어레이의 볼륨에 해당합니다.



 a| 
네임스페이스 ID
 a| 
네임스페이스 ID는 네임스페이스에 대한 NVMe 컨트롤러의 고유 식별자이며 1에서 255 사이의 값으로 설정할 수 있습니다. SCSI의 LUN(논리 유닛 번호)과 유사합니다.



 a| 
NQN
 a| 
NVMe Qualified Name(NQN)은 원격 스토리지 타겟(스토리지 어레이)을 식별하는 데 사용됩니다.



 a| 
NVM
 a| 
비휘발성 메모리(NVM)는 다양한 유형의 스토리지 디바이스에 사용되는 영구 메모리입니다.



 a| 
NVMe
 a| 
NVMe(Non-Volatile Memory Express)는 SSD 드라이브와 같은 플래시 기반 스토리지 장치를 위해 설계된 인터페이스입니다. NVMe는 이전의 논리 장치 인터페이스에 비해 I/O 오버헤드를 줄이고 성능을 향상시킵니다.



 a| 
NVMe-oF
 a| 
NVMe-oF(Non-Volatile Memory Express over Fabrics)는 호스트와 스토리지 간의 네트워크를 통해 NVMe 명령 및 데이터를 전송할 수 있도록 하는 사양입니다.



 a| 
NVMe 컨트롤러
 a| 
NVMe 컨트롤러는 호스트 연결 과정 중에 생성됩니다. 이 컨트롤러는 호스트와 스토리지 어레이의 네임스페이스 간의 액세스 경로를 제공합니다.



 a| 
NVMe 대기열
 a| 
큐는 NVMe 인터페이스를 통해 명령과 메시지를 전달하는 데 사용됩니다.



 a| 
NVMe 하위 시스템
 a| 
NVMe 호스트 연결이 있는 스토리지 어레이입니다.



 a| 
RDMA
 a| 
RDMA(Remote Direct Memory Access)는 네트워크 인터페이스 카드(NIC) 하드웨어에서 전송 프로토콜을 구현하여 서버 내외부로 보다 직접적인 데이터 이동을 가능하게 합니다.



 a| 
RoCE
 a| 
RoCE(RDMA over Converged Ethernet)는 이더넷 네트워크를 통해 원격 직접 메모리 액세스(RDMA)를 허용하는 네트워크 프로토콜입니다.



 a| 
SSD
 a| 
솔리드 스테이트 디스크(SSD)는 솔리드 스테이트 메모리(플래시)를 사용하여 데이터를 영구적으로 저장하는 데이터 저장 장치입니다. SSD는 기존 하드 드라이브를 에뮬레이트하며, 하드 드라이브에서 사용하는 것과 동일한 인터페이스로 제공됩니다.
