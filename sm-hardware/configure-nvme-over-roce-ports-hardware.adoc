= SANtricity System Manager에서 NVMe over RoCE 포트 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
컨트롤러에 RoCE(RDMA over Converged Ethernet)를 통한 NVMe 연결이 포함되어 있는 경우 하드웨어 페이지에서 NVMe 포트 설정을 구성할 수 있습니다.

.시작하기 전에
* 컨트롤러에 NVMe over RoCE 호스트 포트가 포함되어 있어야 합니다. 그렇지 않으면 System Manager에서 NVMe over RoCE 설정을 사용할 수 없습니다.
* 호스트 연결의 IP 주소를 알아야 합니다.


.단계
. * Hardware * 를 선택합니다.
. 그래픽에 드라이브가 표시되면 *Controllers & Components* 탭을 클릭하십시오.
+
그래픽이 드라이브 대신 컨트롤러를 표시하도록 변경됩니다.

. 구성하려는 NVMe over RoCE 포트가 있는 컨트롤러를 클릭합니다.
+
컨트롤러의 컨텍스트 메뉴가 나타납니다.

. *RoCE 포트를 통한 NVMe 구성*을 선택합니다.
+
RoCE 포트를 통한 NVMe 구성 대화 상자가 열립니다.

. 드롭다운 목록에서 구성할 HIC 포트를 선택하십시오.
. * 다음 * 을 클릭합니다.
+
모든 포트 설정을 보려면 대화 상자 오른쪽에 있는 *더 많은 포트 설정 표시* 링크를 클릭하십시오.

+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 포트 설정 | 설명 


 a| 
구성된 이더넷 포트 속도
 a| 
포트의 SFP 속도 기능과 일치하는 속도를 선택합니다.



 a| 
IPv4 활성화 / IPv6 활성화
 a| 
IPv4 및 IPv6 네트워크에 대한 지원을 활성화하려면 하나 또는 두 옵션을 모두 선택합니다.


NOTE: 포트 액세스를 비활성화하려면 두 확인란의 선택을 모두 해제하십시오.



 a| 
MTU 크기(*더 많은 포트 설정 보기*를 클릭하면 확인할 수 있습니다.)
 a| 
필요한 경우 Maximum Transmission Unit(MTU)의 새 크기를 바이트 단위로 입력하십시오.

기본 최대 전송 단위(MTU) 크기는 프레임당 1500바이트입니다. 1500에서 9000 사이의 값을 입력해야 합니다.

|===
====
+
*Enable IPv4*를 선택한 경우 *Next*를 클릭하면 IPv4 설정을 선택하는 대화 상자가 열립니다. *Enable IPv6*을 선택한 경우 *Next*를 클릭하면 IPv6 설정을 선택하는 대화 상자가 열립니다. 두 옵션을 모두 선택한 경우 IPv4 설정 대화 상자가 먼저 열리고 *Next*를 클릭하면 IPv6 설정 대화 상자가 열립니다.

. IPv4 및/또는 IPv6 설정을 자동 또는 수동으로 구성합니다.
+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 포트 설정 | 설명 


 a| 
자동으로 구성 가져오기
 a| 
구성을 자동으로 가져오려면 이 옵션을 선택하십시오.



 a| 
정적 구성을 수동으로 지정합니다
 a| 
이 옵션을 선택한 다음 필드에 고정 주소를 입력합니다. (필요한 경우 주소를 복사하여 필드에 붙여넣을 수 있습니다.) IPv4의 경우 네트워크 서브넷 마스크와 게이트웨이를 포함합니다. IPv6의 경우 라우팅 가능한 IP 주소와 라우터 IP 주소를 포함합니다. 200Gb 지원 HIC가 있는 EF600 스토리지 어레이를 구성하는 경우 이 대화 상자에는 물리적 포트(외부)용과 가상 포트(내부)용의 두 세트의 네트워크 매개변수 필드가 표시됩니다. 두 포트 모두에 고유한 매개변수를 할당해야 합니다. 이러한 설정을 통해 호스트는 각 포트 간의 경로를 설정할 수 있으며 HIC는 최대 성능을 발휘할 수 있습니다. 가상 포트에 IP 주소를 할당하지 않으면 HIC는 최대 속도의 약 절반으로 작동합니다.

|===
====
. *완료*를 클릭합니다.
