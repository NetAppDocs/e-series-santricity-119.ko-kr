= SANtricity System Manager에서 컨트롤러를 재설정(재부팅)합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일부 문제는 컨트롤러 재설정(재부팅)이 필요합니다. 컨트롤러를 직접 조작할 수 없는 경우에도 재설정할 수 있습니다.

.시작하기 전에
* 스토리지 어레이에는 두 개의 컨트롤러가 있어야 합니다. 재설정하지 않을 컨트롤러는 온라인 상태(최적의 상태)여야 합니다.
* 볼륨이 사용 중이지 않은지, 또는 해당 볼륨을 사용하는 모든 호스트에 다중 경로 드라이버가 설치되어 있는지 확인하십시오.


.단계
. * Hardware * 를 선택합니다.
. 그래픽에 드라이브가 표시되면 *Controllers & Components* 탭을 클릭하십시오.
+
그래픽이 드라이브 대신 컨트롤러를 표시하도록 변경됩니다.

. 재설정하려는 컨트롤러를 클릭합니다.
+
컨트롤러의 컨텍스트 메뉴가 나타납니다.

. *재설정*을 선택하고 작업을 수행할 것인지 확인합니다.
