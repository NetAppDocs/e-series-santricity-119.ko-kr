= SANtricity System Manager에서 드라이브를 수동으로 재구성합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일반적으로 드라이브를 교체하면 드라이브 재구성이 자동으로 시작됩니다. 드라이브 재구성이 자동으로 시작되지 않으면 수동으로 재구성을 시작할 수 있습니다.

[NOTE]
====
이 작업은 기술 지원 또는 Recovery Guru의 지시를 받은 경우에만 수행하십시오.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 수동으로 재구성하려는 드라이브를 클릭합니다.
+
드라이브의 컨텍스트 메뉴가 나타납니다.

. *Reconstruct*를 선택하고 작업을 수행할 것인지 확인하십시오.
