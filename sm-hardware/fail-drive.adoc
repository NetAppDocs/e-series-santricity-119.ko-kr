= SANtricity System Manager에서 수동으로 드라이브 오류를 발생시키세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
지시를 받은 경우 수동으로 드라이브에 오류를 발생시킬 수 있습니다.

.이 작업 정보
System Manager는 스토리지 시스템의 드라이브를 모니터링합니다. 드라이브에서 오류가 많이 발생하는 것이 감지되면 Recovery Guru가 드라이브 고장이 임박했음을 알려줍니다. 이 경우 교체용 드라이브가 있다면 예방 조치로 해당 드라이브를 장애 상태로 설정하는 것이 좋습니다. 교체용 드라이브가 없다면 드라이브가 자연적으로 고장 날 때까지 기다릴 수 있습니다.

[CAUTION]
====
*데이터 액세스 손실 가능* -- 이 작업은 데이터 손실 또는 데이터 이중화 손실을 초래할 수 있습니다. 기술 지원 또는 Recovery Guru의 지시가 있을 경우에만 이 작업을 수행하십시오.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 오류를 발생시키려는 드라이브를 클릭합니다.
+
드라이브의 컨텍스트 메뉴가 나타납니다.

. *Fail*을 선택하세요.
. *실패하기 전에 드라이브 내용 복사* 확인란을 선택한 상태로 유지하십시오.
+
복사 옵션은 할당된 드라이브와 비 RAID 0 볼륨 그룹에만 나타납니다.

+
드라이브에 장애가 발생하기 전에 드라이브 내용을 복사해 두십시오. 구성에 따라 드라이브 내용을 먼저 복사하지 않으면 관련 풀 또는 볼륨 그룹의 모든 데이터 또는 데이터 이중화가 손실될 수 있습니다.

+
복사 옵션을 사용하면 재구성보다 드라이브 복구 속도가 빠르며 복사 작업 중에 다른 드라이브에 장애가 발생할 경우 볼륨 장애 가능성을 줄일 수 있습니다.

. 드라이브를 장애 처리하시겠습니까?
+
드라이브에 장애가 발생한 후 최소 60초 이상 기다린 후 제거하십시오.
