= E-Series 컨트롤러의 IP 주소 할당에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기본적으로 컨트롤러는 두 네트워크 포트 모두에 DHCP가 활성화된 상태로 출고됩니다. 고정 IP 주소를 할당하거나, 기본 고정 IP 주소를 사용하거나, DHCP에서 할당한 IP 주소를 사용할 수 있습니다. 또한 IPv6 상태 비저장 자동 구성을 사용할 수도 있습니다.

[NOTE]
====
새 컨트롤러에서는 IPv6가 기본적으로 비활성화되어 있지만, 다른 방법을 사용하여 관리 포트 IP 주소를 구성한 다음 System Manager를 사용하여 관리 포트에서 IPv6를 활성화할 수 있습니다.

====
네트워크 포트가 "링크 다운" 상태, 즉 LAN에서 연결이 끊어진 경우 시스템은 구성을 정적으로 보고하여 0.0.0.0의 IP 주소를 표시하거나(이전 릴리스) DHCP가 활성화되어 IP 주소가 보고되지 않습니다(이후 릴리스). 네트워크 포트가 "링크 업" 상태(즉, LAN에 연결됨)가 되면 DHCP를 통해 IP 주소를 할당받으려고 시도합니다.

컨트롤러가 특정 네트워크 포트에서 DHCP 주소를 할당받지 못하면 기본 IP 주소로 되돌아가며, 이 과정은 최대 3분까지 소요될 수 있습니다. 기본 IP 주소는 다음과 같습니다.

[listing]
----
Controller 1 (port 1): IP Address: 192.168.128.101
----
[listing]
----
Controller 1 (port 2): IP Address: 192.168.129.101
----
[listing]
----
Controller 2 (port 1): IP Address: 192.168.128.102
----
[listing]
----
Controller 2 (port 2): IP Address: 192.168.129.102
----
IP 주소를 할당할 때:

* 컨트롤러의 포트 2를 고객 지원 용도로 예약하십시오. 기본 네트워크 설정(DHCP 활성화)을 변경하지 마십시오.
* E4000, E2800 및 E5700 컨트롤러에 고정 IP 주소를 설정하려면 SANtricity System Manager를 사용하십시오. E2700 및 E5600 컨트롤러에 고정 IP 주소를 설정하려면 SANtricity Storage Manager를 사용하십시오. 고정 IP 주소가 구성되면 모든 링크 다운/업 이벤트를 통해 설정된 상태가 유지됩니다.
* DHCP를 사용하여 컨트롤러의 IP 주소를 할당하려면 DHCP 요청을 처리할 수 있는 네트워크에 컨트롤러를 연결하십시오. 영구 DHCP 임대를 사용하십시오.
+
[NOTE]
====
기본 주소는 링크 다운 이벤트에서 유지되지 않습니다. 컨트롤러의 네트워크 포트가 DHCP를 사용하도록 설정된 경우 컨트롤러는 케이블 삽입, 재부팅 및 전원 사이클을 포함한 모든 링크 업 이벤트에서 DHCP 주소를 얻으려고 시도합니다. DHCP 시도가 실패할 때마다 해당 포트의 기본 정적 IP 주소가 사용됩니다.

====
