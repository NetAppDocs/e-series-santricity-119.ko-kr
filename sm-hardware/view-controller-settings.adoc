= SANtricity System Manager에서 컨트롤러 설정을 확인하십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트 인터페이스, 드라이브 인터페이스 및 관리 포트의 상태와 같은 컨트롤러에 대한 정보를 볼 수 있습니다.

.단계
. * Hardware * 를 선택합니다.
. 그래픽에 드라이브가 표시되면 *Controllers & Components* 탭을 클릭하십시오.
+
그래픽이 드라이브 대신 컨트롤러를 표시하도록 변경됩니다.

. 컨트롤러 설정을 표시하려면 다음 작업 중 하나를 수행하십시오.
+
** 컨트롤러를 클릭하여 상황별 메뉴를 표시한 다음 *View settings*를 선택합니다.
** *Shelf* 드롭다운 목록 옆에 있는 컨트롤러 아이콘을 선택합니다. 이중 구성의 경우 대화 상자에서 *Controller A* 또는 *Controller B*를 선택한 다음 *Next*를 클릭합니다.
+
Controller Settings 대화 상자가 열립니다.



. 탭을 선택하여 속성 설정 간에 이동합니다.
+
일부 탭의 오른쪽 상단에는 *Show more settings* 링크가 있습니다.

+
.필드 세부 정보
[%collapsible]
====
[cols="25h,~"]
|===
| 탭 | 설명 


 a| 
베이스
 a| 
컨트롤러 상태, 모델 이름, 교체 부품 번호, 현재 펌웨어 버전 및 비휘발성 정적 랜덤 액세스 메모리(NVSRAM) 버전을 표시합니다.



 a| 
캐시
 a| 
데이터 캐시, 프로세서 캐시 및 캐시 백업 장치를 포함하는 컨트롤러의 캐시 설정을 표시합니다. 캐시 백업 장치는 컨트롤러의 전원이 손실될 경우 캐시의 데이터를 백업하는 데 사용됩니다. 상태는 Optimal, Failed, Removed, Unknown, Write Protected 또는 Incompatible일 수 있습니다.



 a| 
호스트 인터페이스
 a| 
호스트 인터페이스 정보와 각 포트의 링크 상태를 표시합니다. 호스트 인터페이스는 컨트롤러와 호스트 간의 연결이며, Fibre Channel 또는 iSCSI 등이 있습니다.


NOTE: 호스트 인터페이스 카드(HIC) 위치는 베이스보드 또는 슬롯(베이)입니다. "베이스보드"는 HIC 포트가 컨트롤러에 내장되어 있음을 나타냅니다. "슬롯" 포트는 옵션 HIC에 있습니다.



 a| 
드라이브 인터페이스
 a| 
드라이브 인터페이스 정보와 각 포트의 링크 상태를 표시합니다. 드라이브 인터페이스는 컨트롤러와 드라이브 간의 연결이며, SAS 등이 있습니다.



 a| 
관리 포트
 a| 
컨트롤러에 액세스하는 데 사용되는 호스트 이름 및 원격 로그인 활성화 여부와 같은 관리 포트 세부 정보를 표시합니다. 관리 포트는 컨트롤러와 관리 클라이언트를 연결하며, 관리 클라이언트에는 System Manager에 액세스하기 위한 브라우저가 설치되어 있습니다.



 a| 
DNS 서버/NTP 서버
 a| 
DNS 서버 및 NTP 서버가 System Manager에 구성된 경우 해당 서버의 주소 지정 방법과 IP 주소를 표시합니다.

도메인 이름 시스템(DNS)은 인터넷이나 사설 네트워크에 연결된 장치를 명명하는 시스템입니다. DNS 서버는 도메인 이름 디렉토리를 유지하고 이를 인터넷 프로토콜(IP) 주소로 변환합니다.

네트워크 시간 프로토콜(NTP)은 데이터 네트워크에서 컴퓨터 시스템 간의 클록 동기화를 위한 네트워킹 프로토콜입니다.
