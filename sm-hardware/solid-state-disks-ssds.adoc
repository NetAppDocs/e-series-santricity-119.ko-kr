= SANtricity System Manager에서 SSD(Solid State Disk)에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
솔리드 스테이트 디스크(SSD)는 솔리드 스테이트 메모리(플래시)를 사용하여 데이터를 영구적으로 저장하는 데이터 저장 장치입니다. SSD는 기존 하드 드라이브를 에뮬레이트하며, 하드 드라이브에서 사용하는 것과 동일한 인터페이스로 제공됩니다.



== SSD의 장점

SSD가 하드 드라이브에 비해 가지는 장점은 다음과 같습니다.

* 더 빠른 시작(스핀업 없음)
* 지연 시간 단축
* 초당 입출력 작업 수(IOPS) 향상
* 움직이는 부품이 적어 안정성이 향상됩니다
* 전력 사용량 감소
* 열 발생량이 적고 냉각 필요량이 줄어듭니다




== SSD 식별

하드웨어 페이지에서 전면 선반 보기로 SSD를 찾을 수 있습니다. 번개 모양 아이콘이 표시된 드라이브 베이를 찾으세요. 이 아이콘은 SSD가 설치되어 있음을 나타냅니다.



== 볼륨 그룹

볼륨 그룹의 모든 드라이브는 동일한 미디어 유형이어야 합니다(모두 SSD이거나 모두 하드 드라이브). 볼륨 그룹에는 미디어 유형이나 인터페이스 유형이 혼합되어 있을 수 없습니다.



== 캐싱

컨트롤러의 쓰기 캐싱 기능은 SSD에서 항상 활성화됩니다. 쓰기 캐싱은 성능을 향상시키고 SSD의 수명을 연장합니다.

컨트롤러 캐시 외에도 SSD 캐시 기능을 구현하여 전체 시스템 성능을 향상시킬 수 있습니다. SSD 캐시에서는 데이터가 볼륨에서 복사되어 두 개의 내부 RAID 볼륨(컨트롤러당 하나씩)에 저장됩니다.
