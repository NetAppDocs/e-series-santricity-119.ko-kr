= SANtricity System Manager에서 드라이브를 지웁니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
시스템에서 제거를 위해 할당되지 않은 드라이브를 준비하려면 삭제 옵션을 사용할 수 있습니다. 이 절차를 통해 데이터가 영구적으로 삭제되어 다시 읽을 수 없게 됩니다.

.시작하기 전에
드라이브는 할당되지 않은 상태여야 합니다.

.이 작업 정보
드라이브의 모든 데이터를 영구적으로 제거하려는 경우에만 지우기 옵션을 사용하십시오. 드라이브가 보안 설정된 경우 지우기 옵션은 암호화 지우기를 수행하고 드라이브의 보안 특성을 보안 가능으로 재설정합니다.

[NOTE]
====
삭제 기능은 일부 구형 드라이브 모델을 지원하지 않습니다. 이러한 구형 모델을 삭제하려고 하면 오류 메시지가 나타납니다.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 선택적으로 필터 필드를 사용하여 셸프에 있는 할당되지 않은 모든 드라이브를 볼 수 있습니다. *다음과 같은 드라이브 표시...* 드롭다운 목록에서 *할당되지 않음*을 선택합니다.
+
쉘프 뷰에는 할당되지 않은 드라이브만 표시되고 나머지는 모두 회색으로 표시됩니다.

. 드라이브의 상황별 메뉴를 열려면 지우려는 드라이브를 클릭하십시오. (여러 드라이브를 선택하려면 드라이브 지우기 대화 상자에서 선택할 수 있습니다.)
+
[CAUTION]
====
*데이터 손실 가능성 있음* -- Erase 작업은 되돌릴 수 없습니다. 절차를 진행하는 동안 올바른 드라이브를 선택했는지 확인하십시오.

====
. 컨텍스트 메뉴에서 *지우기*를 선택합니다.
+
드라이브 지우기 대화 상자가 열리고 지우기 작업에 사용할 수 있는 모든 드라이브가 표시됩니다.

. 필요한 경우 표에서 추가 드라이브를 선택하십시오. _모든_ 드라이브를 선택할 수는 없으며, 드라이브 하나는 선택 해제된 상태로 유지해야 합니다.
.  `erase`를 입력하여 작업을 확인한 다음 *지우기*를 클릭하십시오.
+
[CAUTION]
====
이 작업을 계속 진행할지 확인하십시오. 다음 대화 상자에서 예를 클릭하면 작업을 중단할 수 없습니다.

====
. 예상 완료 시간 대화 상자에서 *예*를 클릭하여 지우기 작업을 계속하십시오.


.결과
삭제 작업은 몇 분에서 몇 시간까지 소요될 수 있습니다. menu:Home[View Operations in Progress]에서 상태를 확인할 수 있습니다. 삭제 작업이 완료되면 해당 드라이브는 다른 볼륨 그룹이나 디스크 풀 또는 다른 스토리지 시스템에서 사용할 수 있습니다.

.완료한 후
드라이브를 다시 사용하려면 먼저 초기화해야 합니다. 초기화하려면 드라이브의 컨텍스트 메뉴에서 *Initialize*를 선택하십시오.
