= SANtricity System Manager에서 컨트롤러를 오프라인 상태로 설정하세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
지시를 받으면 컨트롤러를 오프라인 상태로 전환할 수 있습니다.

.시작하기 전에
* 스토리지 어레이에는 두 개의 컨트롤러가 있어야 합니다. 오프라인으로 전환하지 않는 컨트롤러는 온라인 상태(최적 상태)여야 합니다.
* 볼륨이 사용 중이지 않은지, 또는 해당 볼륨을 사용하는 모든 호스트에 다중 경로 드라이버가 설치되어 있는지 확인하십시오.


.이 작업 정보
++ ++

[CAUTION]
====
복구 전문가 또는 기술 지원 부서에서 지시하지 않는 한 컨트롤러를 오프라인으로 전환하지 마십시오.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 드라이브가 표시되면 *Controllers & Components* 탭을 클릭하십시오.
+
그래픽이 드라이브 대신 컨트롤러를 표시하도록 변경됩니다.

. 오프라인으로 전환하려는 컨트롤러를 클릭합니다.
+
컨트롤러의 컨텍스트 메뉴가 나타납니다.

. * 오프라인으로 전환 * 을 선택하고 작업을 수행할 것인지 확인하십시오.


.결과
System Manager가 컨트롤러의 상태를 오프라인으로 업데이트하는 데 몇 분 정도 걸릴 수 있습니다. 상태가 업데이트된 후까지 다른 작업을 시작하지 마십시오.
