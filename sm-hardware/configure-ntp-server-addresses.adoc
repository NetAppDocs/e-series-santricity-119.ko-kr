= SANtricity System Manager에서 NTP 서버 주소를 구성합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
컨트롤러가 주기적으로 NTP 서버에 쿼리하여 내부 시간 시계를 업데이트하도록 네트워크 시간 프로토콜(NTP) 서버에 대한 연결을 구성할 수 있습니다.

.시작하기 전에
* 네트워크에 NTP 서버를 설치하고 구성해야 합니다.
* 기본 NTP 서버와 선택적 백업 NTP 서버의 주소를 알아야 합니다. 이러한 주소는 정규화된 도메인 이름, IPv4 주소 또는 IPv6 주소일 수 있습니다.


[NOTE]
====
NTP 서버에 하나 이상의 도메인 이름을 입력하는 경우 NTP 서버 주소를 확인하기 위한 DNS 서버도 구성해야 합니다. NTP를 구성하고 도메인 이름을 제공한 컨트롤러에서만 DNS 서버를 구성하면 됩니다.

====
.이 작업 정보
NTP를 사용하면 스토리지 어레이가 SNTP(Simple Network Time Protocol)를 사용하여 외부 호스트와 컨트롤러의 시계를 자동으로 동기화할 수 있습니다. 컨트롤러는 구성된 NTP 서버를 주기적으로 쿼리한 다음 그 결과를 사용하여 내부 시간 시계를 업데이트합니다. 하나의 컨트롤러만 NTP를 활성화한 경우 대체 컨트롤러는 NTP가 활성화된 컨트롤러와 주기적으로 시계를 동기화합니다. 두 컨트롤러 모두 NTP를 활성화하지 않은 경우 컨트롤러는 서로 주기적으로 시계를 동기화합니다.

[NOTE]
====
두 컨트롤러 모두에 NTP를 구성할 필요는 없지만, 구성하면 하드웨어 또는 통신 장애 발생 시 스토리지 어레이의 동기화 상태가 유지되는 능력이 향상됩니다.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 드라이브가 표시되면 *Controllers & Components* 탭을 클릭하십시오.
+
그래픽이 드라이브 대신 컨트롤러를 표시하도록 변경됩니다.

. 구성하려는 컨트롤러를 클릭합니다.
+
컨트롤러의 컨텍스트 메뉴가 나타납니다.

. *NTP 서버 구성*을 선택합니다.
+
NTP(Network Time Protocol) 서버 구성 대화 상자가 열립니다.

. *컨트롤러에서 NTP를 활성화하려면* (*A* 또는 *B*)을 선택하십시오.
+
대화 상자에 추가 선택 항목이 나타납니다.

. 다음 옵션 중 하나를 선택하십시오.
+
** * DHCP 서버에서 NTP 서버 주소를 자동으로 가져옵니다* -- 감지된 NTP 서버 주소가 표시됩니다.
+
[NOTE]
====
스토리지 어레이가 고정 NTP 주소를 사용하도록 설정된 경우 NTP 서버가 표시되지 않습니다.

====
** *NTP 서버 주소를 수동으로 지정* -- 기본 NTP 서버 주소와 백업 NTP 서버 주소를 입력하십시오. 백업 서버는 선택 사항입니다. (이 주소 입력란은 라디오 버튼을 선택한 후에 나타납니다.) 서버 주소는 정규화된 도메인 이름, IPv4 주소 또는 IPv6 주소일 수 있습니다.


. *선택 사항:* 백업 NTP 서버에 대한 서버 정보 및 인증 자격 증명을 입력합니다.
. *저장*을 클릭합니다.


.결과
NTP 서버 구성이 컨트롤러 설정의 *DNS/NTP* 탭에 표시됩니다.
