= SANtricity System Manager에서 배터리 학습 주기를 업데이트하세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
학습 주기란 스마트 배터리 게이지를 보정하기 위한 자동 주기입니다. 이 주기는 컨트롤러당 8주 간격으로 같은 요일과 시간에 자동으로 시작되도록 예약되어 있습니다. 다른 일정을 설정하려면 학습 주기를 조정할 수 있습니다.

.이 작업 정보
학습 주기를 업데이트하면 두 컨트롤러 배터리 모두에 영향을 미칩니다.

.단계
. * Hardware * 를 선택합니다.
. Controller Shelf의 드롭다운 목록을 선택한 다음 *설정 보기*를 선택합니다.
. *배터리* 탭을 선택합니다.
. *Update battery learn cycles*를 선택합니다.
+
배터리 학습 주기 업데이트 대화 상자가 열립니다.

. 드롭다운 목록에서 새 날짜와 시간을 선택합니다.
. *저장*을 클릭합니다.
