= SANtricity System Manager에서 쉘프의 보기 순서 변경
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
하드웨어 페이지에 표시되는 쉘프 순서를 캐비닛의 쉘프 물리적 순서와 일치하도록 변경할 수 있습니다.

.단계
. * Hardware * 를 선택합니다.
. 선반 보기의 오른쪽 상단에서 위쪽 또는 아래쪽 화살표를 선택하여 Hardware 페이지에 표시되는 선반 순서를 재배열할 수 있습니다.
