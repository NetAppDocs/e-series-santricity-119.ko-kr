= SANtricity System Manager에서 하드웨어 구성 요소 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
하드웨어 페이지는 구성 요소를 더 쉽게 찾을 수 있도록 정렬 및 필터링 기능을 제공합니다.

.단계
. * Hardware * 를 선택합니다.
. 다음 표에 설명된 기능을 사용하여 하드웨어 구성 요소를 확인합니다.


[cols="25h,~"]
|===
| 기능 | 설명 


 a| 
드라이브, 컨트롤러 및 구성요소 보기
 a| 
전면 및 후면 선반 보기 간에 전환하려면 오른쪽 끝에서 *Drives* 또는 *Controllers & Components*를 선택하십시오(표시되는 링크는 현재 보기에 따라 다릅니다). *Drives* 보기에는 드라이브와 빈 드라이브 베이가 표시됩니다. *Controllers & Components* 보기에는 컨트롤러, IOM(ESM) 모듈, 전원/팬 캐니스터 또는 빈 컨트롤러 베이가 표시됩니다. 페이지 하단에서 *Show all drives*를 선택할 수도 있습니다.



 a| 
드라이브 보기 필터
 a| 
스토리지 어레이에 물리적 및 논리적 속성이 서로 다른 드라이브가 포함된 경우 *Hardware* 페이지에 드라이브 보기 필터가 있습니다. 이러한 필터 필드를 사용하면 페이지에 표시되는 드라이브 유형을 제한하여 특정 드라이브를 빠르게 찾을 수 있습니다. *Show drives that are...*에서 왼쪽 필터 필드(기본값: *Any drive type*)를 클릭하면 물리적 속성(예: 용량 및 속도) 드롭다운 목록이 표시됩니다. 오른쪽 필터 필드(기본값: *Anywhere in the storage array*)를 클릭하면 논리적 속성(예: 볼륨 그룹 할당) 드롭다운 목록이 표시됩니다. 이러한 필터는 함께 또는 개별적으로 사용할 수 있습니다.

[NOTE]
====
스토리지 어레이에 포함된 드라이브의 물리적 속성이 모두 동일한 경우 왼쪽의 *Any drive type* 필드가 표시되지 않습니다. 드라이브가 모두 동일한 논리적 위치에 있는 경우 오른쪽의 *Anywhere in the storage array* 필드가 표시되지 않습니다.

====


 a| 
범례
 a| 
구성 요소는 역할 상태를 나타내기 위해 특정 색상으로 표시됩니다. 이러한 상태에 대한 설명을 펼치거나 접으려면 *Legend*를 클릭하십시오.



 a| 
상태 아이콘 세부 정보 표시
 a| 
상태 표시기에는 사용 가능 상태에 대한 텍스트 설명이 포함될 수 있습니다. *상태 아이콘 세부 정보 표시*를 클릭하여 이 상태 텍스트를 표시하거나 숨깁니다.



 a| 
Shelf/Shelf 아이콘
 a| 
각 셸프 뷰는 관련 명령 목록과 속성 및 상태를 제공합니다. *Shelf*를 클릭하면 명령 드롭다운 목록이 나타납니다. 또한 상단의 아이콘 중 하나를 선택하여 컨트롤러, IOM(ESM), 전원 공급 장치, 팬, 온도, 배터리 및 SFP와 같은 개별 구성 요소의 상태와 속성을 볼 수 있습니다.



 a| 
쉘프 순서
 a| 
선반은 하드웨어 페이지에서 재배열할 수 있습니다. 각 선반 보기의 오른쪽 상단에 있는 위아래 화살표를 사용하여 선반의 위/아래 순서를 변경하세요.

|===
