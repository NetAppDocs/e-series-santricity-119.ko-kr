= SANtricity System Manager에서 앞면과 뒷면 보기를 표시합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Hardware 페이지에는 쉘프의 전면 또는 후면이 표시될 수 있습니다.

.이 작업 정보
뒷면에는 컨트롤러/IOM과 전원 팬 캐니스터가 표시됩니다. 앞면에는 드라이브가 표시됩니다.

.단계
. * Hardware * 를 선택합니다.
. 그래픽에 드라이브가 표시되면 *Controllers & Components* 탭을 클릭하십시오.
+
그래픽이 드라이브 대신 컨트롤러를 표시하도록 변경됩니다.

. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 필요에 따라 페이지 하단에 있는 *Show all front* 또는 *Show all back*을 선택할 수 있습니다.
