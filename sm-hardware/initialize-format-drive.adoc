= SANtricity System Manager에서 드라이브를 초기화(포맷)합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
할당된 드라이브를 한 스토리지 어레이에서 다른 스토리지 어레이로 이동하는 경우 새 스토리지 어레이에서 사용하기 전에 드라이브를 초기화(포맷)해야 합니다.

.이 작업 정보
초기화를 수행하면 드라이브에서 이전 구성 정보가 제거되고 드라이브는 할당되지 않은 상태로 돌아갑니다. 그러면 해당 드라이브는 새 스토리지 어레이의 새 풀 또는 볼륨 그룹에 추가할 수 있게 됩니다.

단일 드라이브를 이동할 때 드라이브 초기화 작업을 사용합니다. 전체 볼륨 그룹을 한 스토리지 어레이에서 다른 스토리지 어레이로 이동하는 경우에는 드라이브를 초기화할 필요가 없습니다.

[CAUTION]
====
*데이터 손실 가능성 있음* -- 드라이브를 초기화하면 드라이브의 모든 데이터가 손실됩니다. 기술 지원 부서에서 지시한 경우에만 이 작업을 수행하십시오.

====
.단계
. * Hardware * 를 선택합니다.
. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 초기화할 드라이브를 클릭합니다.
+
드라이브의 컨텍스트 메뉴가 나타납니다.

. *초기화*를 선택하고 작업을 수행할 것인지 확인합니다.
