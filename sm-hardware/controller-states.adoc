= SANtricity System Manager의 컨트롤러 상태에 대해 알아보십시오

[role="lead"]
컨트롤러를 온라인, 오프라인 및 서비스 모드의 세 가지 상태로 전환할 수 있습니다.



[[online-state]]
== 온라인 상태

온라인 상태는 컨트롤러의 정상 작동 상태입니다. 컨트롤러가 정상적으로 작동하고 있으며 I/O 작업에 사용할 수 있음을 의미합니다.

컨트롤러를 온라인 상태로 전환하면 해당 컨트롤러의 상태가 최적 상태로 설정됩니다.



[[offline-state]]
== 오프라인 상태

오프라인 상태는 일반적으로 스토리지 어레이에 컨트롤러가 두 개 있을 때 컨트롤러 교체를 준비하는 데 사용됩니다. 컨트롤러는 명시적인 명령을 실행하거나 컨트롤러에 오류가 발생하는 두 가지 방식으로 오프라인 상태로 전환될 수 있습니다. 컨트롤러는 명시적인 명령을 다시 실행하거나 오류가 발생한 컨트롤러를 교체해야만 오프라인 상태에서 벗어날 수 있습니다. 스토리지 어레이에 컨트롤러가 두 개 있는 경우에만 컨트롤러를 오프라인 상태로 전환할 수 있습니다.

컨트롤러가 오프라인 상태일 때 다음 조건이 참입니다.

* 컨트롤러를 I/O에 사용할 수 없습니다.
* 해당 컨트롤러를 통해서는 스토리지 어레이를 관리할 수 없습니다.
* 해당 컨트롤러가 현재 소유하고 있는 모든 볼륨은 다른 컨트롤러로 이동됩니다.
* 캐시 미러링이 비활성화되고 모든 볼륨이 쓰기 스루 캐시 모드로 변경됩니다.




[[service-mode]]
== 서비스 모드

서비스 모드는 일반적으로 기술 지원에서 모든 스토리지 어레이 볼륨을 하나의 컨트롤러로 이동하여 다른 컨트롤러를 진단할 수 있도록 할 때만 사용됩니다. 컨트롤러는 수동으로 서비스 모드로 전환해야 하며, 서비스 작업이 완료된 후 수동으로 다시 온라인 상태로 전환해야 합니다.

컨트롤러가 서비스 모드일 때 다음 조건이 참입니다.

* 컨트롤러를 I/O에 사용할 수 없습니다.
* 기술 지원 부서에서는 직렬 포트 또는 네트워크 연결을 통해 컨트롤러에 액세스하여 잠재적인 문제를 분석할 수 있습니다.
* 해당 컨트롤러가 현재 소유하고 있는 모든 볼륨은 다른 컨트롤러로 이동됩니다.
* 캐시 미러링이 비활성화되고 모든 볼륨이 쓰기 스루 캐시 모드로 변경됩니다.
