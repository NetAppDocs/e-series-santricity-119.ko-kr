== 쉘프 손실 방지 및 드로어 손실 방지란 무엇입니까?

쉘프 손실 방지 및 드로어 손실 방지는 단일 쉘프 또는 드로어에 장애가 발생하더라도 데이터 액세스를 유지할 수 있도록 하는 풀 및 볼륨 그룹의 속성입니다.



[[shelf-loss-protection]]
=== 쉘프 손실 방지

쉘프는 드라이브 또는 드라이브와 컨트롤러를 포함하는 엔클로저입니다. 쉘프 손실 보호는 단일 드라이브 쉘프와의 통신이 완전히 두절될 경우 풀 또는 볼륨 그룹의 볼륨에 있는 데이터에 대한 액세스를 보장합니다. 통신 완전 두절의 예로는 드라이브 쉘프에 전원이 공급되지 않거나 두 I/O 모듈(IOM) 모두에 장애가 발생하는 경우를 들 수 있습니다.

[NOTE]
====
풀 또는 볼륨 그룹에서 드라이브에 이미 장애가 발생한 경우 쉘프 손실 보호가 보장되지 않습니다. 이 경우 드라이브 쉘프에 대한 액세스가 손실되고 결과적으로 풀 또는 볼륨 그룹의 다른 드라이브에 액세스할 수 없게 되어 데이터가 손실됩니다.

====
쉘프 손실 방지 기준은 다음 표에 설명된 바와 같이 보호 방법에 따라 다릅니다.

[cols="1a,1a,1a"]
|===
| 수준 | 쉘프 손실 보호 기준 | 필요한 최소 쉘프 수 


 a| 
풀
 a| 
풀에는 최소 5개의 쉘프에서 가져온 드라이브가 포함되어야 하며, 각 쉘프에는 동일한 수의 드라이브가 있어야 합니다. 쉘프 손실 보호는 고용량 쉘프에는 적용되지 않습니다. 시스템에 고용량 쉘프가 있는 경우 드로어 손실 보호를 참조하십시오.
 a| 
5



 a| 
RAID 6
 a| 
볼륨 그룹의 단일 쉘프에는 2개 이하의 드라이브가 포함됩니다.
 a| 
3



 a| 
RAID 3 또는 RAID 5
 a| 
볼륨 그룹의 각 드라이브는 별도의 쉘프에 위치합니다.
 a| 
3



 a| 
RAID 1
 a| 
RAID 1 쌍의 각 드라이브는 별도의 쉘프에 위치해야 합니다.
 a| 
2



 a| 
RAID 0
 a| 
쉘프 손실 방지를 달성할 수 없습니다.
 a| 
해당 사항 없음

|===


[[drawer-loss-protection]]
=== 드로어 손실 방지

드로어는 드라이브에 액세스하기 위해 당겨서 빼내는 쉘프의 구획 중 하나입니다. 고용량 쉘프에만 드로어가 있습니다. 드로어 손실 방지는 단일 드로어와의 통신이 완전히 손실되는 경우에도 풀 또는 볼륨 그룹의 볼륨에 있는 데이터에 대한 액세스 가능성을 보장합니다. 통신 완전 손실의 예로는 드로어에 대한 전원 손실 또는 드로어 내부 구성 요소의 장애가 있습니다.

[NOTE]
====
풀 또는 볼륨 그룹에서 드라이브에 이미 장애가 발생한 경우 드로어 손실 방지가 보장되지 않습니다. 이 경우 드로어(및 결과적으로 풀 또는 볼륨 그룹의 다른 드라이브)에 대한 액세스 권한을 잃으면 데이터가 손실됩니다.

====
드로어 손실 방지 기준은 다음 표에 설명된 대로 보호 방법에 따라 다릅니다.

[cols="1a,1a,1a"]
|===
| 수준 | 드로어 손실 방지 기준 | 필요한 최소 드로어 수 


 a| 
풀
 a| 
풀 후보에는 모든 드라이브의 드라이브가 포함되어야 하며, 각 드라이브에는 동일한 수의 드라이브가 있어야 합니다.

풀에는 최소 5개의 드로어에서 나온 드라이브가 포함되어야 하며, 각 드로어에는 동일한 수의 드라이브가 있어야 합니다.

60개 드라이브 셸프는 풀에 15개, 20개, 25개, 30개, 35개, 40개, 45개, 50개, 55개 또는 60개의 드라이브가 포함될 경우 드로어 손실 방지 기능을 구현할 수 있습니다. 초기 생성 후 5의 배수 단위로 풀에 추가할 수 있습니다.
 a| 
5



 a| 
RAID 6
 a| 
볼륨 그룹에는 단일 드로어에 최대 두 개의 드라이브만 포함될 수 있습니다.
 a| 
3



 a| 
RAID 3 또는 RAID 5
 a| 
볼륨 그룹의 각 드라이브는 별도의 드로어에 있습니다.
 a| 
3



 a| 
RAID 1
 a| 
미러링된 쌍의 각 드라이브는 별도의 서랍에 있어야 합니다.
 a| 
2



 a| 
RAID 0
 a| 
서랍 손실 방지를 달성할 수 없습니다.
 a| 
해당 사항 없음

|===

== 배터리 학습 사이클이란 무엇입니까?

학습 주기란 스마트 배터리 게이지를 보정하기 위한 자동 주기입니다.

학습 주기는 다음 단계로 구성됩니다:

* 제어된 배터리 방전
* 휴식 기간
* 충전


배터리는 미리 정해진 임계값까지 방전됩니다. 이 단계에서 배터리 게이지가 보정됩니다.

학습 주기에는 다음과 같은 매개변수가 필요합니다.

* 완전히 충전된 배터리
* 배터리 과열 없음


듀플렉스 컨트롤러 시스템의 학습 사이클은 동시에 진행됩니다. 두 개 이상의 배터리 또는 배터리 셀 세트에서 백업 전원을 공급받는 컨트롤러의 경우, 학습 사이클은 순차적으로 진행됩니다.

학습 주기는 정기적으로, 같은 요일과 같은 시간에 자동으로 시작되도록 예약됩니다. 주기 간격은 주 단위로 표시됩니다.

[NOTE]
====
학습 주기를 완료하는 데 몇 시간이 걸릴 수 있습니다.

====
