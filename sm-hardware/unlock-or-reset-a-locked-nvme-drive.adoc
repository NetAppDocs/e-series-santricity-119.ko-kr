= SANtricity System Manager에서 잠긴 NVMe 또는 FIPS 드라이브의 잠금을 해제하거나 재설정합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에 하나 이상의 잠긴 NVMe 또는 FIPS 드라이브를 장착한 경우, 해당 드라이브와 연결된 보안 키 파일을 추가하여 드라이브 데이터의 잠금을 해제할 수 있습니다. 보안 키가 없는 경우, 각 잠긴 드라이브의 Physical Security ID(PSID)를 입력하여 보안 속성을 재설정하고 드라이브 데이터를 삭제할 수 있습니다.

.시작하기 전에
* 잠금 해제 옵션을 사용하려면 보안 키 파일(확장자가 `.slk`인 파일)이 관리 클라이언트(System Manager에 액세스하는 데 사용되는 브라우저가 있는 시스템)에 있는지 확인하십시오. 또한 키와 연결된 암호를 알고 있어야 합니다.
* 초기화 옵션을 사용하려면 초기화할 각 드라이브의 PSID를 찾아야 합니다. PSID를 찾으려면 드라이브를 물리적으로 분리한 후 드라이브 레이블에 표시된 PSID 문자열(최대 32자)을 확인하고 드라이브를 다시 설치하십시오.


.이 작업 정보
이 작업에서는 보안 키 파일을 스토리지 어레이로 가져와 NVMe 또는 FIPS 드라이브의 데이터 잠금을 해제하는 방법을 설명합니다. 보안 키를 사용할 수 없는 경우, 잠긴 드라이브를 재설정하는 방법도 설명합니다.

[NOTE]
====
외부 키 관리 서버를 사용하여 드라이브가 잠겨 있는 경우 System Manager에서 menu:Settings[System > Security key management]를 선택하여 외부 키 관리를 구성하고 드라이브 잠금을 해제하십시오.

====
하드웨어 페이지 또는 menu:Settings[System > Security key management]에서 잠금 해제 기능에 액세스할 수 있습니다. 아래 작업은 하드웨어 페이지의 지침을 제공합니다.

.단계
. * Hardware * 를 선택합니다.
. 그래픽에 컨트롤러가 표시되면 *드라이브* 탭을 클릭합니다.
+
그래픽이 컨트롤러 대신 드라이브를 표시하도록 변경됩니다.

. 잠금 해제 또는 재설정할 NVMe 또는 FIPS 드라이브를 선택하십시오.
+
드라이브의 컨텍스트 메뉴가 열립니다.

. 보안 키 파일을 적용하려면 *잠금 해제*를 선택하고, 보안 키 파일이 없는 경우 *재설정*을 선택하십시오.
+
이러한 옵션은 잠금된 NVMe 또는 FIPS 드라이브를 선택한 경우에만 나타납니다.

+
[CAUTION]
====
재설정 작업을 수행하는 동안 모든 데이터가 삭제됩니다. 보안 키가 없는 경우에만 재설정을 수행하십시오. 잠긴 드라이브를 재설정하면 드라이브의 모든 데이터가 영구적으로 삭제되고 보안 속성이 "보안 가능" 상태로 재설정되지만 활성화되지는 않습니다. *이 작업은 되돌릴 수 없습니다.*

====
. 다음 중 하나를 수행합니다.
+
.. *잠금 해제*: *보안 드라이브 잠금 해제* 대화 상자에서 *찾아보기*를 클릭한 다음 잠금 해제할 드라이브에 해당하는 보안 키 파일을 선택합니다. 그런 다음 암호를 입력하고 *잠금 해제*를 클릭합니다.
.. *재설정*: *잠긴 드라이브 재설정* 대화 상자에서 PSID 문자열을 필드에 입력한 다음 `RESET`을 입력하여 확인합니다. *재설정*을 클릭합니다.
+
잠금 해제 작업의 경우, 모든 NVMe 또는 FIPS 드라이브의 잠금을 해제하려면 이 작업을 한 번만 수행하면 됩니다. 초기화 작업의 경우, 초기화할 각 드라이브를 개별적으로 선택해야 합니다.





.결과
이제 해당 드라이브를 다른 볼륨 그룹이나 디스크 풀 또는 다른 스토리지 어레이에서 사용할 수 있습니다.
