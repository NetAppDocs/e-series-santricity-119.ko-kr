= SANtricity System Manager에서 암호 보호를 관리하세요
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
무단 액세스로부터 보호하려면 스토리지 어레이에 암호를 구성해야 합니다.



== 비밀번호 설정 및 변경

System Manager를 처음 시작할 때 관리자 암호를 설정하라는 메시지가 표시됩니다. 관리자 암호를 가진 사용자는 스토리지 어레이에 대한 구성 변경(예: 객체 또는 설정 추가, 변경 또는 제거)을 수행할 수 있습니다. 초기 시작 시 관리자 암호를 설정하려면 link:../san-getstarted/access-sam.html["System Manager 액세스"]을 참조하십시오.

보안상의 이유로 스토리지 어레이가 "잠금" 상태로 전환되기 전에 암호를 5번만 입력할 수 있습니다. 이 상태에서는 스토리지 어레이가 이후의 암호 입력 시도를 거부합니다. 암호를 다시 입력하기 전에 스토리지 어레이가 "정상" 상태로 재설정될 때까지 10분을 기다려야 합니다.

관리자 암호 외에도 스토리지 어레이에는 하나 이상의 역할이 매핑된 사전 정의된 사용자 프로필이 포함되어 있습니다. 자세한 내용은 link:../sm-settings/permissions-for-mapped-roles.html["매핑된 역할에 대한 권한"]를 참조하십시오. 사용자 프로필 및 매핑은 변경할 수 없습니다. 암호만 수정할 수 있습니다. 관리자 암호 또는 다른 사용자 암호를 변경하려면 link:../sm-settings/change-passwords.html["암호 변경"]를 참조하십시오.



== 세션 시간 초과 후 암호를 다시 입력합니다

시스템은 단일 관리 세션 동안 한 번만 암호를 입력하라는 메시지를 표시합니다. 그러나 30분 동안 활동이 없으면 세션 시간이 초과되어 암호를 다시 입력해야 합니다. 다른 관리 클라이언트를 사용하여 동일한 스토리지 어레이를 관리하는 다른 사용자가 세션 진행 중에 암호를 변경하면 다음에 구성 작업이나 보기 작업을 시도할 때 암호를 입력하라는 메시지가 표시됩니다.

세션 시간 제한을 조정하거나 세션 시간 제한 기능을 완전히 비활성화할 수 있습니다. link:../sm-settings/manage-session-timeouts-sam.html["세션 시간 초과 관리"]을 참조하십시오.



== 드라이브 또는 암호 보호를 제거합니다

암호로 보호된 드라이브를 제거하거나 암호 보호를 해제하려는 경우 다음 사항에 유의하십시오.

* *암호로 보호된 드라이브를 제거하는 경우* -- 암호는 스토리지 어레이의 각 드라이브에 있는 예약된 영역에 저장됩니다. 스토리지 어레이에서 모든 드라이브를 제거하면 암호가 더 이상 작동하지 않습니다. 이 문제를 해결하려면 원래 드라이브 중 하나를 스토리지 어레이에 다시 설치하십시오.
* *암호 보호를 해제하려면* -- 더 이상 명령에 암호 보호를 적용하지 않으려면 현재 관리자 암호를 입력하고 새 암호 텍스트 상자는 비워 두십시오.


[CAUTION]
====
스토리지 어레이에서 구성 명령을 실행하면 데이터 손실을 포함한 심각한 손상이 발생할 수 있습니다. 따라서 스토리지 어레이에는 항상 관리자 암호를 설정해야 합니다. 보안 강화를 위해 최소 15자 이상의 영숫자로 구성된 긴 관리자 암호를 사용하십시오.
