= SANtricity System Manager 설정 마법사에 대해 알아보십시오
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
설정 마법사를 사용하여 하드웨어, 호스트, 애플리케이션, 워크로드, 풀, 경고 및 AutoSupport를 포함한 스토리지 시스템을 구성합니다.



== 최초 설정

System Manager를 처음 열면 설정 마법사가 시작됩니다. 설정 마법사는 스토리지 어레이 이름 지정, 호스트 구성, 애플리케이션 선택, 스토리지 풀 생성과 같은 기본 구성 작업을 수행하도록 안내합니다.


NOTE: 초기 설정을 계속하기 전에 업그레이드 센터(메뉴: 지원[업그레이드 센터])로 이동하여 SANtricity OS 소프트웨어가 최신 버전인지 확인하십시오. 필요한 경우 최신 버전으로 업그레이드하고 브라우저를 새로 고침하여 설정을 계속하십시오. 자세한 내용은 link:../sm-support/overview-upgrade-center.html["Upgrade Center 개요"]를 참조하십시오.

마법사를 취소하면 수동으로 다시 실행할 수 없습니다. System Manager를 열거나 브라우저를 새로 고칠 때 다음 조건 중 _하나 이상_이 충족되면 마법사가 자동으로 다시 실행됩니다.

* 풀 및 볼륨 그룹이 감지되지 않았습니다.
* 워크로드가 감지되지 않았습니다.
* 설정된 알림이 없습니다.




== 용어

설치 마법사는 다음 용어를 사용합니다.

[cols="25h,~"]
|===
| 용어 | 설명 


 a| 
애플리케이션
 a| 
애플리케이션은 Microsoft SQL Server 또는 Microsoft Exchange와 같은 소프트웨어 프로그램입니다.



 a| 
경고
 a| 
경고는 스토리지 어레이에서 발생하는 중요한 이벤트에 대해 관리자에게 알려줍니다. 경고는 이메일, SNMP 트랩 또는 syslog를 통해 전송될 수 있습니다.



 a| 
AutoSupport
 a| 
AutoSupport 기능은 스토리지 어레이의 상태를 모니터링하고 기술 지원 부서에 자동 발송을 전송합니다.



 a| 
하드웨어
 a| 
스토리지 시스템 하드웨어에는 스토리지 어레이, 컨트롤러 및 드라이브가 포함됩니다.



 a| 
호스트
 a| 
호스트는 스토리지 어레이의 볼륨으로 I/O를 전송하는 서버입니다.



 a| 
객체
 a| 
객체는 모든 논리적 또는 물리적 스토리지 구성 요소를 의미합니다. 논리적 객체에는 볼륨 그룹, 풀 및 볼륨이 포함됩니다. 물리적 객체에는 스토리지 어레이, 어레이 컨트롤러, 호스트 및 드라이브가 포함됩니다.



 a| 
풀
 a| 
풀은 논리적으로 그룹화된 드라이브 집합입니다. 풀을 사용하여 호스트에서 액세스할 수 있는 하나 이상의 볼륨을 생성할 수 있습니다. (볼륨은 풀 또는 볼륨 그룹에서 생성합니다.)



 a| 
볼륨
 a| 
볼륨은 애플리케이션, 데이터베이스 및 파일 시스템이 데이터를 저장하는 컨테이너입니다. 이는 호스트가 스토리지 어레이의 스토리지에 액세스하기 위해 생성되는 논리적 구성 요소입니다.

볼륨은 풀 또는 볼륨 그룹에서 사용 가능한 용량으로 생성됩니다. 볼륨에는 정의된 용량이 있습니다. 볼륨은 둘 이상의 드라이브로 구성될 수 있지만 호스트에는 하나의 논리적 구성 요소로 표시됩니다.



 a| 
볼륨 그룹
 a| 
볼륨 그룹은 공통된 특성을 가진 볼륨들을 담는 컨테이너입니다. 볼륨 그룹은 용량과 RAID 레벨이 정의되어 있습니다. 볼륨 그룹을 사용하여 호스트에서 접근 가능한 하나 이상의 볼륨을 생성할 수 있습니다. (볼륨은 볼륨 그룹 또는 풀에서 생성합니다.)



 a| 
워크로드
 a| 
워크로드는 애플리케이션을 지원하는 스토리지 개체입니다. 애플리케이션당 하나 이상의 워크로드 또는 인스턴스를 정의할 수 있습니다. 일부 애플리케이션의 경우 시스템은 유사한 기본 볼륨 특성을 가진 볼륨을 포함하도록 워크로드를 구성합니다. 이러한 볼륨 특성은 워크로드가 지원하는 애플리케이션 유형을 기반으로 최적화됩니다. 예를 들어, Microsoft SQL Server 애플리케이션을 지원하는 워크로드를 생성한 다음 해당 워크로드에 대한 볼륨을 생성하면 기본 볼륨 특성이 Microsoft SQL Server를 지원하도록 최적화됩니다.

|===
