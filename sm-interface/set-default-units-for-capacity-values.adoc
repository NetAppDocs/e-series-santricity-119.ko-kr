= SANtricity System Manager에서 용량 값의 기본 단위를 설정합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager는 용량 값을 기비바이트(GiB) 또는 테비바이트(TiB) 단위로 표시할 수 있습니다.

기본 설정은 브라우저의 로컬 스토리지에 저장되므로 모든 사용자가 자신만의 설정을 가질 수 있습니다.

.단계
. menu:Preferences[Set preferences]를 선택합니다.
. *Gibibytes* 또는 *Tebibytes* 중 하나에 해당하는 라디오 버튼을 클릭하고 작업을 수행할 것인지 확인하십시오.
+
약어 및 값은 다음 표를 참조하십시오.

+
[cols="1a,1a"]
|===
| 약어 | 가치 


 a| 
GiB
 a| 
1,024^3^ 바이트



 a| 
TiB
 a| 
1,024^4^ 바이트

|===
