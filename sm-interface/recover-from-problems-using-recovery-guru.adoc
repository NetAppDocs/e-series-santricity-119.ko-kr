= SANtricity System Manager Recovery Guru를 사용하여 문제를 복구하세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Recovery Guru는 SANtricity System Manager의 구성 요소로, 스토리지 어레이 문제를 진단하고 문제를 해결하기 위한 복구 절차를 권장합니다.

.단계
. * Home * 을 선택합니다.
. 창 중앙 상단에 있는 *_n_가지 문제에서 복구* 링크를 클릭합니다.
+
Recovery Guru 대화 상자가 나타납니다.

. 요약 목록에 표시된 첫 번째 문제를 선택한 다음 복구 절차의 지침에 따라 문제를 해결하십시오. 필요한 경우 교체 지침을 사용하여 고장난 부품을 교체하십시오. 목록에 있는 각 문제에 대해 이 단계를 반복하십시오.
+
스토리지 어레이 내의 여러 문제는 서로 연관되어 있을 수 있습니다. 이 경우 문제를 해결하는 순서가 결과에 영향을 미칠 수 있습니다. 요약 목록에 나열된 순서대로 문제를 선택하고 해결하십시오.

+
전원 공급 장치 캐니스터의 여러 장애는 요약 목록에서 하나의 문제로 그룹화되어 나열됩니다. 팬 캐니스터의 여러 장애도 하나의 문제로 나열됩니다.

. 복구 절차가 성공했는지 확인하려면 *Recheck*을 클릭합니다.
+
비동기 미러 그룹 또는 비동기 미러 그룹 구성원에 대한 문제를 선택한 경우 먼저 *Clear*를 클릭하여 컨트롤러에서 오류를 지운 다음 *Recheck*을 클릭하여 Recovery Guru에서 이벤트를 제거하십시오.

+
모든 문제가 해결되면 스토리지 어레이 아이콘이 주의 필요에서 최적으로 바뀝니다. 일부 문제의 경우, 재구성 등의 작업이 진행되는 동안 수정 중 아이콘이 나타납니다.

. *선택 사항:* Recovery Guru 정보를 파일에 저장하려면 *저장* 아이콘을 클릭합니다.
+
해당 파일은 브라우저의 다운로드 폴더에 `recovery-guru-failure-yyyy-mm-dd-hh-mm-ss-mmm.html`이라는 이름으로 저장됩니다.

. Recovery Guru 정보를 인쇄하려면 *Print* 아이콘을 클릭하십시오.
