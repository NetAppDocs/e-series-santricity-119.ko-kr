== 개별 볼륨에 대한 성능 통계는 전체와 어떤 관계가 있습니까?

풀 및 볼륨 그룹에 대한 통계는 예약된 용량 볼륨을 포함한 모든 볼륨을 집계하여 계산됩니다.

예약된 용량은 씬 볼륨, 스냅샷 및 비동기 미러링을 지원하기 위해 스토리지 시스템에서 내부적으로 사용되며 I/O 호스트에는 표시되지 않습니다. 따라서 풀, 컨트롤러 및 스토리지 어레이 통계가 표시되는 볼륨의 합계와 일치하지 않을 수 있습니다.

하지만 애플리케이션 및 워크로드 통계의 경우 표시되는 볼륨만 집계됩니다.



== 그래프와 표에서 데이터가 0으로 표시되는 이유는 무엇입니까?

그래프와 표에서 데이터 포인트 값이 0으로 표시되는 경우, 해당 시점에 해당 객체에 대한 I/O 활동이 없음을 의미합니다. 이러한 상황은 호스트가 해당 객체에 대한 I/O를 시작하지 않거나 객체 자체에 문제가 있는 경우에 발생할 수 있습니다.

해당 객체의 기간별 데이터는 계속해서 확인할 수 있습니다. 객체에 대한 입출력 활동이 시작되면 그래프와 표에 0이 아닌 데이터가 표시됩니다.

다음 표에는 특정 객체의 데이터 포인트 값이 0이 될 수 있는 가장 일반적인 이유가 나와 있습니다.

[cols="25h,~"]
|===
| 어레이 수준 객체 유형 | 데이터가 0으로 표시되는 이유 


 a| 
볼륨
 a| 
* 볼륨에 호스트가 할당되지 않았습니다.




 a| 
볼륨 그룹
 a| 
* 볼륨 그룹을 가져오는 중입니다.
* 볼륨 그룹에는 호스트에 할당된 볼륨이 포함되어 있지 않으며, *_또한_* 볼륨 그룹에는 예약된 용량도 포함되어 있지 않습니다.




 a| 
드라이브
 a| 
* 드라이브에 장애가 발생했습니다.
* 드라이브가 제거되었습니다.
* 드라이브 상태를 알 수 없습니다.




 a| 
컨트롤러
 a| 
* 컨트롤러가 오프라인 상태입니다.
* 컨트롤러에 장애가 발생했습니다.
* 컨트롤러가 제거되었습니다.
* 컨트롤러의 상태를 알 수 없습니다.




 a| 
스토리지 어레이
 a| 
* 스토리지 어레이에 볼륨이 없습니다.


|===


== 지연 시간 그래프에는 무엇이 표시됩니까?

지연 시간 그래프는 볼륨, 볼륨 그룹, 풀, 애플리케이션 및 워크로드에 대한 지연 시간 통계를 밀리초(ms) 단위로 제공합니다. 이 그래프는 논리적 보기, 물리적 보기 및 애플리케이션 및 워크로드 보기 탭에 표시됩니다.

지연 시간은 데이터를 읽거나 쓸 때 발생하는 모든 지연을 의미합니다. 그래프의 한 지점 위에 커서를 올려 놓으면 해당 시점에 대한 다음 값(밀리초(ms))이 표시됩니다.

* 읽기 시간.
* 쓰기 시간.
* 평균 I/O 크기




== IOPS 그래프에는 무엇이 표시됩니까?

IOPS 그래프는 초당 입출력 작업 통계를 표시합니다. 홈 페이지에서는 스토리지 어레이에 대한 통계가 표시됩니다. 성능 타일의 논리적 보기, 물리적 보기, 애플리케이션 및 워크로드 보기 탭에서는 스토리지 어레이, 볼륨, 볼륨 그룹, 풀, 애플리케이션 및 워크로드에 대한 통계가 표시됩니다.

IOPS는 _초당 입출력(I/O) 작업_의 약자입니다. 그래프의 특정 지점에 마우스 커서를 올리면 해당 시점의 다음 값을 볼 수 있습니다.

* 읽기 작업 수입니다.
* 쓰기 작업 수입니다.
* 총 읽기 및 쓰기 작업을 합산한 값입니다.




== MiB/s 그래프는 무엇을 보여줍니까?

MiB/s 그래프는 초당 메비바이트 단위로 전송 속도 통계를 표시합니다. 홈 페이지에서 이 그래프는 스토리지 어레이에 대한 통계를 표시합니다. Performance 타일의 Logical View, Physical View 및 Applications & Workloads View 탭에서 이 그래프는 스토리지 어레이, 볼륨, 볼륨 그룹, 풀, 애플리케이션 및 워크로드에 대한 통계를 표시합니다.

MiB/s는 _mebibytes per second_의 약자로, 초당 1,048,576바이트를 의미합니다. 그래프의 특정 지점에 마우스 커서를 올리면 해당 시점의 다음 값을 볼 수 있습니다.

* 읽은 데이터의 양입니다.
* 기록된 데이터의 양입니다.
* 읽고 쓴 데이터의 총량입니다.




== CPU 그래프에는 무엇이 표시됩니까?

CPU 그래프는 각 컨트롤러(컨트롤러 A와 컨트롤러 B)의 처리 용량 통계를 표시합니다. CPU는 _central processing unit_의 약자입니다. 홈 페이지에서는 이 그래프에 스토리지 어레이에 대한 통계가 표시됩니다. 성능 타일의 물리적 보기 탭에서는 이 그래프에 스토리지 어레이와 드라이브에 대한 통계가 표시됩니다.

CPU 그래프는 어레이에서 수행되는 작업에 대한 CPU 처리 용량 사용률을 백분율로 보여줍니다. 외부 I/O 작업이 발생하지 않더라도 스토리지 운영 체제가 백그라운드 작업 및 모니터링을 수행할 수 있으므로 CPU 사용률이 0%가 아닐 수 있습니다. 그래프의 특정 지점에 마우스 커서를 올리면 해당 시점의 처리 용량 사용률을 백분율로 확인할 수 있습니다.



== Headroom 그래프는 무엇을 보여줍니까?

헤드룸 그래프는 스토리지 어레이 컨트롤러의 잔여 성능 용량과 관련이 있습니다. 이 그래프는 홈 페이지와 성능 타일의 물리적 보기 탭에서 확인할 수 있습니다.

헤드룸 그래프는 스토리지 시스템의 물리적 객체에 남아 있는 성능 용량을 보여줍니다. 그래프의 특정 지점에 마우스 커서를 올리면 컨트롤러 A와 컨트롤러 B에 대해 남은 IOPS 및 MiB/s 용량의 백분율을 확인할 수 있습니다.

사용 가능한 디스플레이 옵션에 대한 정보를 찾으려면:

* 용량 값을 표시하는 기본 단위에 대한 자세한 내용은 link:set-default-units-for-capacity-values.html["용량 값에 대한 기본 단위를 설정합니다"]을(를) 참조하십시오.
* 성능 그래프 표시의 기본 시간 범위에 대한 자세한 내용은 link:set-default-time-frame-for-performance-graphs.html["성능 그래프의 기본 시간 범위를 설정합니다"]을(를) 참조하십시오.
