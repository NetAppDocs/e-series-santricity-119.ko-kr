= SANtricity 시스템 관리자 인터페이스에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager는 단일 화면에서 스토리지 어레이를 관리할 수 있는 웹 기반 인터페이스입니다.



== 홈 페이지

홈 페이지는 스토리지 어레이의 일일 관리를 위한 대시보드 보기를 제공합니다. System Manager에 로그인하면 홈 페이지가 가장 먼저 표시되는 화면입니다.

대시보드 보기에는 스토리지 어레이의 상태 및 건전성에 대한 주요 정보를 포함하는 네 개의 요약 영역이 있습니다. 요약 영역에서 더 자세한 정보를 확인할 수 있습니다.

[cols="25h,~"]
|===
| 영역 | 설명 


 a| 
알림
 a| 
알림 영역에는 스토리지 어레이 및 구성 요소의 상태를 나타내는 문제 알림이 표시됩니다. 또한 이 포틀릿은 스토리지 환경의 다른 영역에 영향을 미치기 전에 문제를 해결하는 데 도움이 되는 자동화된 알림을 표시합니다.



 a| 
성능
 a| 
Performance 영역에서는 시간 경과에 따른 리소스 사용량을 비교하고 대조할 수 있습니다. 스토리지 어레이의 응답 시간(IOPS), 전송 속도(MiB/s) 및 사용 중인 처리 용량(CPU)에 대한 성능 메트릭을 볼 수 있습니다.



 a| 
용량
 a| 
용량 영역에는 스토리지 어레이에 할당된 용량, 사용 가능한 스토리지 용량 및 할당되지 않은 스토리지 용량이 차트 보기로 표시됩니다.



 a| 
스토리지 계층 구조
 a| 
스토리지 계층 구조 영역은 스토리지 어레이에서 관리하는 다양한 하드웨어 구성 요소 및 스토리지 객체를 체계적으로 보여줍니다. 드롭다운 화살표를 클릭하여 해당 하드웨어 구성 요소 또는 스토리지 객체에 대해 특정 작업을 수행할 수 있습니다.

|===


== 인터페이스 설정

메인 인터페이스에서 디스플레이 기본 설정 및 기타 설정을 변경할 수 있습니다.

[cols="25h,~"]
|===
| 설정 | 설명 


 a| 
디스플레이 기본 설정
 a| 
인터페이스 오른쪽 상단의 기본 설정 드롭다운에서 용량 값과 기간을 변경합니다.



 a| 
세션 시간 초과
 a| 
지정된 시간 후 비활성 사용자 세션 연결이 끊어지도록 시간 제한을 구성하십시오.



 a| 
도움말
 a| 
인터페이스 오른쪽 상단의 드롭다운에서 도움말 문서 및 기타 리소스에 액세스할 수 있습니다.

|===
