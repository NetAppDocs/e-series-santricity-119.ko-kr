= SANtricity System Manager에 액세스합니다
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager 사용자 인터페이스에 액세스하려면 브라우저에서 컨트롤러의 IP 주소를 지정합니다. 설정 마법사를 통해 시스템 구성을 시작할 수 있습니다.

.시작하기 전에
* 빠른 구성 가이드 중 하나에 설명된 대로 하드웨어를 설치하고 구성하십시오.
+
** https://docs.netapp.com/us-en/e-series/config-linux/index.html["Linux 빠른 구성"^]
** https://docs.netapp.com/us-en/e-series/config-vmware/index.html["VMware 빠른 구성"^]
** https://docs.netapp.com/us-en/e-series/config-windows/index.html["Windows 빠른 구성"^]


* 다음 요구 사항을 충족하는 관리 스테이션을 구성하십시오.
+
** 1Gbps 이상의 네트워크에 연결되어 있습니다.
** 스토리지 관리 포트와 동일한 서브넷에 연결되어 있습니다.
** 데이터 관리에 사용되는 호스트(I/O 연결)가 아닌 별도의 스테이션으로 사용됩니다.
** 아웃오브밴드(out-of-band) 관리를 설정합니다. 이 방식에서는 스토리지 관리 스테이션이 컨트롤러에 대한 이더넷 연결을 통해 스토리지 시스템에 명령을 보냅니다.
** 지원되는 브라우저로 설정하세요. link:supported-browsers-os.html["지원되는 브라우저 및 운영 체제"]을 참조하십시오.




.단계
. 브라우저에서 다음 URL을 입력합니다. `+https://<IPAddress>+`
+
`IPAddress`는 스토리지 어레이 컨트롤러 중 하나의 주소입니다.

+
구성되지 않은 어레이에서 System Manager를 처음 열면 Set Administrator Password 프롬프트가 나타납니다.

. Set Administrator Password 및 Confirm Password 필드에 admin 역할에 대한 System Manager 암호를 입력한 다음 *Set Password*를 클릭합니다.
+
처음 로그인할 때 설정 마법사가 실행됩니다.

. 설정 마법사를 사용하여 다음 작업을 수행하십시오.
+
** *하드웨어(컨트롤러 및 드라이브) 확인* -- 스토리지 어레이에 있는 컨트롤러 및 드라이브의 개수를 확인합니다. 어레이에 이름을 지정합니다.
** *호스트 및 운영 체제 확인* -- 스토리지 시스템이 액세스할 수 있는 호스트 및 운영 체제 유형을 확인합니다.
** *풀 수락* -- 빠른 설치 방법에 권장되는 풀 구성을 수락합니다. 풀은 드라이브의 논리적 그룹입니다.
** *알림 구성* -- 스토리지 어레이에 문제가 발생할 경우 System Manager가 자동 알림을 받을 수 있도록 합니다.
** *AutoSupport 활성화* -- 스토리지 어레이의 상태를 자동으로 모니터링하고 기술 지원 부서에 디스패치를 전송합니다.




설정 마법사에 대한 자세한 내용은 link:../sm-interface/setup-wizard-overview.html["설정 마법사 개요"]을 참조하십시오.
