= SANtricity 소프트웨어에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
E-Series 시스템에는 스토리지 프로비저닝 및 기타 작업을 위한 SANtricity 소프트웨어가 포함되어 있습니다.

이 사이트는 다음 SANtricity 관리 인터페이스 사용 방법을 설명합니다.

* System Manager -- 네트워크에서 개별 스토리지 어레이를 관리하는 데 사용되는 웹 기반 인터페이스입니다.
* Unified Manager -- 네트워크의 모든 스토리지 어레이를 보고 관리하는 데 사용되는 웹 기반 인터페이스입니다.



NOTE: EF600/EF600C 및 EF300/EF300C 스토리지 어레이는 동기식 미러링 또는 씬 볼륨을 지원하지 않습니다.



[[santricity-system-manager]]
== SANtricity System Manager

System Manager는 각 컨트롤러에 내장된 웹 기반 관리 소프트웨어입니다. 사용자 인터페이스에 액세스하려면 브라우저에서 컨트롤러의 IP 주소를 가리킵니다. 설정 마법사를 통해 시스템 구성을 시작할 수 있습니다.

System Manager는 다음과 같은 다양한 관리 기능을 제공합니다.

|===


 a| 
image:../media/sam1130_icon_performance.gif["성능"] *성능*
 a| 
I/O 지연 시간, IOPS, CPU 사용률 및 처리량을 포함하여 최대 30일간의 성능 데이터를 확인할 수 있습니다.



 a| 
image:../media/sam1130_icon_volumes.gif["스토리지"] *스토리지*
 a| 
풀 또는 볼륨 그룹을 사용하여 스토리지를 프로비저닝하고 애플리케이션 워크로드를 생성합니다.



 a| 
image:../media/sam1130_icon_async_mirroring.gif["데이터 보호"] *데이터 보호*
 a| 
스냅샷, 볼륨 복사본 및 원격 미러링을 사용하여 백업 및 재해 복구를 수행합니다.



 a| 
image:../media/sam1130_icon_controllers.gif["하드웨어"] *하드웨어*
 a| 
구성 요소 상태를 확인하고 핫 스페어 드라이브 할당과 같은 해당 구성 요소와 관련된 일부 기능을 수행합니다.



 a| 
image:../media/sam1130_icon_alerts.gif["알림"] *알림*
 a| 
스토리지 어레이에서 발생하는 중요 이벤트에 대해 관리자에게 알립니다. 알림은 이메일, SNMP 트랩 및 syslog를 통해 전송할 수 있습니다.



 a| 
image:../media/sam1140_icon_active_directory.gif["액세스 관리"] *액세스 관리*
 a| 
사용자가 지정된 자격 증명으로 시스템에 로그인해야 하는 사용자 인증을 구성하십시오.



 a| 
image:../media/sam1130_icon_settings.gif["시스템 설정"] *시스템 설정*
 a| 
SSD 캐시 및 자동 로드 밸런싱과 같은 다른 시스템 성능 기능을 구성하십시오.



 a| 
image:../media/sam1130_icon_support.gif["지원"] *지원*
 a| 
진단 데이터를 확인하고, 업그레이드를 관리하고, 스토리지 어레이의 상태를 모니터링하고 기술 지원 부서에 자동 발송을 전송하는 AutoSupport를 구성합니다.

|===


[[santricity-unified-manager]]
== SANtricity Unified Manager

Unified Manager는 전체 도메인을 관리하는 데 사용되는 웹 기반 소프트웨어입니다. 중앙 집중식 보기에서 E4000, E2800, EF280, EF300, E5700, EF570, EF600, EF300C 및 EF600C와 같은 모든 최신 E-Series 및 EF-Series 어레이의 상태를 확인할 수 있습니다. 또한 선택한 스토리지 어레이에 대해 일괄 작업을 수행할 수 있습니다.

Unified Manager는 Web Services Proxy와 함께 관리 서버에 설치됩니다. Unified Manager에 액세스하려면 브라우저를 열고 Web Services Proxy가 설치된 서버를 가리키는 URL을 입력합니다.

Unified Manager는 다음과 같은 다양한 관리 기능을 제공합니다.

|===


 a| 
image:../media/artboard_9.png["스토리지 어레이 검색"] *스토리지 어레이 검색*
 a| 
조직 네트워크에서 관리하려는 스토리지 어레이를 찾아 추가하세요. 그러면 모든 스토리지 어레이의 상태를 한 페이지에서 확인할 수 있습니다.



 a| 
image:../media/artboard_11.png["시작"] *시작*
 a| 
특정 스토리지 어레이에 대한 개별 관리 작업을 수행하려면 System Manager 인스턴스를 엽니다.



 a| 
image:../media/sam1130_icon_system.gif["설정 가져오기"] *가져오기 설정*
 a| 
하나의 스토리지 어레이에서 여러 어레이로 일괄 가져오기를 수행하며, 알림, AutoSupport 및 디렉터리 서비스 설정도 포함합니다.



 a| 
image:../media/sam1130_icon_async_mirroring.gif["미러링"] *미러링*
 a| 
두 스토리지 어레이 간에 비동기 또는 동기 미러링된 쌍을 구성합니다.



 a| 
image:../media/artboard_10.png["그룹 관리"] *그룹 관리*
 a| 
스토리지 어레이를 그룹으로 구성하여 관리를 용이하게 합니다.



 a| 
image:../media/sam1130_icon_upgrade_center.gif["업그레이드 센터"] *업그레이드 센터*
 a| 
여러 스토리지 어레이에서 SANtricity OS 소프트웨어를 업그레이드하십시오.



 a| 
image:../media/sam1140_icon_certs.gif["인증서"] *인증서*
 a| 
여러 스토리지 어레이에 대한 인증서 서명 요청(CSR)을 생성하고, 인증서를 가져오고, 기존 인증서를 관리합니다.



 a| 
image:../media/sam1140_icon_active_directory.gif["액세스 관리"] *액세스 관리*
 a| 
사용자가 할당된 자격 증명으로 Unified Manager에 로그인해야 하는 사용자 인증을 구성합니다.

|===
