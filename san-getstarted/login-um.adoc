= SANtricity Unified Manager에 액세스합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Web Services Proxy를 설치한 후 SANtricity Unified Manager에 액세스하여 웹 기반 인터페이스에서 여러 스토리지 시스템을 관리할 수 있습니다.


NOTE: 지원되는 브라우저는 link:supported-browsers-os.html["지원되는 브라우저 및 운영 체제"]를 참조하십시오.

.단계
. 브라우저를 열고 다음 URL을 입력합니다.
+
`+http[s]://<server>:<port>/um+`

+
이 URL에서 `<server>`는 Web Services Proxy가 설치된 서버의 IP 주소 또는 FQDN을 나타내고, `<port>`는 수신 포트 번호를 나타냅니다(HTTP의 경우 기본값은 8080이고 HTTPS의 경우 기본값은 8443입니다).

+
Unified Manager 로그인 페이지가 열립니다.

. 처음 로그인할 때는 사용자 이름에  `admin`을(를) 입력한 다음 관리자 사용자의 암호를 설정하고 확인하십시오.
+
암호는 최대 30자까지 포함할 수 있습니다.



사용자 및 비밀번호에 대한 자세한 내용은 link:../um-certificates/how-access-management-works-unified.html["Access Management 작동 방식"]을 참조하십시오.
